# Spirebound · 0.17.0-prebeta

모바일 웹 액션 로그라이크의 **6층 왕복 시험판**. 2층 파수꾼, 4층 프리즘 수호자, 6층 분열 슬라임을 처치한 뒤 열쇠를 가지고 1층으로 탈출합니다.

## 0.17 화염·유도 밸런스와 탐험 보상

- 화염 성장폭 감소, 화상 3중첩 적을 화염으로 처치해야 장판 생성.
- 유도는 공격 주기당 기술 레벨 수만 적용. 현재 중앙 1발.
- 첫 전투 추격자 4마리·정확히 첫 레벨업. 새 제단은 3·5층.
- 상자 무작위 즉시 지급, 시련 강화 및 무작위 긍정 보상 3택.
- 자동 검사 145개. [수치·확률·저장 호환과 검증](docs/feedback-17.md).

아래는 이전 버전의 변경 이력이며, 같은 항목은 최신 버전 규칙을 적용합니다.

## 0.16 전투 역할과 빈틈

- 근접 전열/사격 후열과 수호 편성, 공격 예고 분산.
- 돌진 충돌, 포화 정예 사격 후, 보스 특정 패턴 후 빈틈.
- 기술 후보 새로고침 도전당 1회, 후보와 횟수 저장.
- 자동 검사 132개. [상세 변경과 검증](docs/tactical-combat-16.md).

## 0.15 최근 플레이 후기 반영

- 시련 돌진과 공격 주기 강화, 오라 범위/피해 성장, 빙결 처치 6방향 서리 파편 연쇄.
- 메인 금색 / 레어 파란색 / 유니크 보라색 반투명 카드와 등급 표시.
- 자동 검사 124개 통과. [상세 변경과 검증](docs/recent-feedback-15.md).

## 0.14 메인 / 보조 트리

- 첫 기술에서 화염·서리·독·번개 중 메인 하나 선택. 이후 메인 강화와 보조만 제시.
- 보조: 갈래(희귀), 관통, 공속, 공격력, 연속탄(희귀), 근접 오라, 유도(전설). 갈래·연속탄에도 감쇠된 주력 속성 발동.
- 화염 폭발/장판 반경 절반, 화염 피해 15% 감소. 서리 3중첩 빙결과 해빙 후 면역.
- 기존 여러 속성 빌드는 유지할 메인을 직접 선택하고 나머지 투자분 환급.
- 자동 검사 116개 통과, 네 메인 각각 60초 CPU/저장 재개 검사 및 브라우저 UI 확인.
- [상세 기획과 수치](docs/main-support-trees.md).

## 0.13 전투 개편

- 갈래 화살 짝수 발수에서도 중앙 기본탄 보장, 짝 없는 추가탄은 좌우 교대.
- 화염 화살: 폭발 → 2레벨 중첩 화상 → 3레벨 짧은 원형 화염 장판.
- 독 화살 추가: 중첩 독, 2중첩 독가스, 3레벨 독 처치 시체 폭발. 녹색 탄환/가스 표시.
- 3층부터 정예 등장 증가. 시련은 보라색 용사 3마리, 체력 2.8배와 공격 강화.
- 기존 불씨 화살 투자와 분기는 독 화살로 자동 이전. 신규 정예 분포는 새 도전부터 적용.
- 자동 검사 102개 통과. [상세 수치와 저장 호환](docs/elemental-rework.md).

## 0.12 추가 시스템

- 2·4층 보스 유물함: 유물 5종 중 현재 빌드에 맞는 최대 3개를 제시하며 장착은 1개. 이점과 대가를 함께 적용.
- 가방/일시정지/종료 화면에 원정 기록: 목격한 적 12종의 도감, 정예 특성, 최근 피격 10건, 층별 시간/피해.
- 마지막 피격 원인과 장착 유물을 결과/개인 이력에 표시. 이번 버전 새 도전은 같은 지도 재도전 지원.
- 기동 사냥의 세로축 속도 누락, 중복 시작, 폴백 저장 잠금 확인, 화상·궁극기 피해 집계를 보완.
- 자동 검사 91개 통과. [상세 기획과 검증](docs/relic-expedition.md).

기존 저장은 유지됩니다. 유물함은 업데이트 후 격파하는 중간 보스부터, 도감과 피격은 업데이트 후 관찰한 내용부터 기록합니다.

## 0.11 추가 시스템

- 보물 무기·생존·기술 1택. 기본 기술 6종은 3레벨에서 각 2가지 분기, 화살비도 즉시형·영역형 선택.
- 폭발·수호·포화 정예와 확정 물약 보상. 층별 선택형 이벤트(체력 계약 / 인장 거래 / 시련).
- 새 지도에 귀환 우회로를 구성하고, 열쇠 획득 후 최단·위험 회피 경로 비교와 미니맵 표시.
- 세로 화면 선택창 확대, 분기 기록 저장, 신규 상태 검증. 자동 검사 80개 통과.
- 전체 기획과 수치: [선택 시스템 기획서](docs/choice-systems.md).

기존 지도를 유지하는 이어하기에서도 미수령 보물과 조건을 달성한 기술의 분기 선택을 사용할 수 있습니다. 새 이벤트 방·정예 편성·고리형 우회로는 **새 도전**에서 적용됩니다. 이미 열쇠를 획득한 저장은 이전 귀환 편성을 보존합니다.

## 실행

Node.js 22 이상에서 npm start → http://localhost:5173 . 별도 패키지 설치가 없습니다. npm test로 자동 검사를 실행합니다.

기존 2·4층 저장은 층 구조와 진행 상황을 보존합니다. **6층 콘텐츠는 새 도전부터 적용**됩니다. 현재 저장을 유지하려면 이어하기를 선택하세요. 저장된 스킬에는 새 피해/공속 공식이 적용되고, 기존 보스는 남은 체력 비율을 유지하여 체력이 한 번만 상향됩니다. 이미 받은 장비 보상은 회수하지 않습니다.

## 조작과 생존

- WASD/방향키 또는 왼쪽 조이스틱 이동. 보이는 가장 가까운 적 자동 공격.
- Q 물약(2하트), Space 회피(20초), F 화살비(스킬 선택 누적 5회 이후, 25초), E 상호작용.
- I 가방, Esc 일시정지. 음식은 적 없는 방에서 사용하고 재개 시 1하트 회복.
- 시작 5하트/물약 1개. 보물로 최대 하트를 10까지 증가. 보호막과 회복 드롭 제한 유지.
- 일반방은 적을 모두 처치하지 않아도 이동 가능. 보스방은 모든 보스 분열체를 처치해야 개방.
- 방문한 방과 문만 미니맵 표시. 장애물은 이동·직선탄·레이저를 막음.
- 2초 자동 저장, 정지·배경 전환 저장, 손상 백업 및 중복 탭 잠금. 도전 종료 시 개인 기록 보관.

## 0.10 전투 조정 (기본 수치, 0.11 분기 효과는 위 기획서 참조)

- 공속 스킬 레벨당 +20% → +10%. 갈래 화살은 기본탄 1발과 45% 피해의 추가탄.
- 연쇄번개 첫 전이는 기본 타격의 30%, 이후 직전 전이의 55%씩 감소. 뇌우는 사거리만 +40.
- 화상 레벨당 초당 5 → 3, 해빙 폭발 60% → 30%/대상별 1.5초, 폭풍 화살 +8 → +3.
- 새 보물 공격력 +6 → +3, 신전 공격력 +12 → +5. 경험치 공식과 궁극기는 유지.
- 일반 궁수 기본 연사 3 → 5발, 산탄 6 → 10발, 반사탄 1 → 2발. 정수 탄 수 때문에 정확히 1.5배가 아닌 약 1.5배 이상의 강화.
- 층이 올라갈수록 탄 수·속도 증가 및 휴식 감소. 돌진 준비 0.5 → 0.32초. 레이저 폭 8 → 30, 방 끝 또는 장애물까지 발사.
- 방마다 역할 조합 무작위 선택. 5·6층은 독 꽃봉우리 등장 보장.
- 파수꾼 체력 550 → 825. 원형 26발, 부채꼴 22발, 회전 탄막 48발, 새 십자포화 60발. 공격 후 휴식 절반, 내려찍기 예고 유지.
- 프리즘 체력 1000 → 1500. 반사탄 18발, 오중 광선, 새 회전 결정 3연사 36발. 휴식 절반.

## 독 꽃봉우리와 분열 슬라임

꽃봉우리는 고정형입니다. 착탄 예고 1초 → 포물선 0.65초 → 장판 2초. 기존 장판이 모두 사라져야 다시 예고합니다. 일반 1개, 광폭 2~3개.

6층 보스는 거대 1 → 중형 2 → 소형 4의 구조입니다. 개체 체력 900 → 450 → 225, 전투 전체 체력 총량 2700. 체력바는 아직 분열하지 않은 후속 체력까지 합산합니다.

원형 독안개는 1.1초 예고 후 3초 지속하며 보스를 따라갑니다. 독 투척은 2~3개, 장판 3.5초 지속. 거대·중형만 미니 슬라임을 소환하고 소형은 소환하지 않습니다. 미니는 소환자 체력의 1/10, 최대 8마리, 추가 분열/소환 및 경험치·회복 보상이 없습니다. 접촉 피해는 하트 체계의 최소 1칸을 사용합니다.

독은 겹친 영역 전체에 대해 1초 간격으로 한 번만 판정합니다. 일반 독 1하트, 보스 독 2하트. 마지막 보스 분열체를 처치하면 소환체·장판·탄환을 정리하고 열쇠를 지급합니다.

## 귀환 광폭화

6층부터 1층까지 광폭 1~6단계. 새 도전의 재생성 적은 방당 8~9 → 13~14마리로 증가합니다. 상층에서 배운 원거리/독 조합도 하층에 나타납니다. 체력은 상층 기준에서 하강 단계별로 증가하고, 탄 속도·탄 수·휴식도 단계별 강화됩니다. 광폭 4단계 이상 일반 직선탄은 2하트 피해입니다. 보스 재생성은 없습니다.

## 검증과 남은 확인

자동 검사 91개: 지도/계단/기존 저장, 스킬 감소율, 탄막 강화, 분열 종료, 소환 보상 제한, 독 중복·지속시간, 독 진행 중 저장 재개 등.

node tools/qa-scenes.mjs: http://localhost:5193/qa 에 별도 저장 공간의 화면 검증 장면 제공. 실제 플레이 주소 5173의 저장은 건드리지 않습니다. 이 테스트 서버는 127.0.0.1 전용이며 기본 게임 서버에서 제공하지 않습니다.

브라우저에서 슬라임/꽃봉우리 표시와 가로 화면 경계, 오류 없는 실행을 확인했습니다. **실제 사람의 6층 왕복 완주, 모바일 기기 성능과 체감 난이도는 다음 플레이테스트가 필요**합니다. 이전 변경 이력은 docs/history-through-0.8.md, 구축일지는 docs/build-journal.md.
