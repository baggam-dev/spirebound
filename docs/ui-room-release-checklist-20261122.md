## 도구만으로 끝나지 않는 항목

- 여러 seed·전체층·세 종류 월드(구원정/새원정·고전/확장)에서 생성/저장 호환, fallback 비율/최대벽수·안전경로·실제 문전실을 검사한다. 현재 도구는 대표 프로필을 선택할 뿐 분포나 모든 접속 형태를 증명하지 않는다.
- 실제 구저장 fixture는 기존 QA와 함께 사용한다. 새 방 metadata를 지운 합성 원정을 ‘실제 구저장 검증’이라고 부르지 않는다.
- 직접 조작으로 벽 근처 이동/회피·발도/넉백·큰 적·귀환 밀집·도약/돌진·낙뢰/범위공격/소환체·XP/정수 획득/문 잠금·재입장, 강제 성장/룰렛 중 빌드 차단을 확인한다. 1.5초 귀환 샘플은 장시간 안정성 검증이 아니다.
- lease 상실/저장 제한/화면 숨김/회전·리사이즈·사망, 키보드 초점 순환/스크롤·최대HP/긴 설명·최대 소지 목록·화면 안전영역을 검사한다. 도구는 저장 실패를 주입하지만 OS별 저장 정책·실제 탭 경합을 모두 재현하지 않는다.
- 지도는 추상 그래프의 상대방 비율이며 실공간 지도/미탐험 공개가 아니다. 미탐험 숨김·위험색/경로·문 마커와 외곽빛/그림자·횃불이 경고를 가리지 않는지 캡처를 직접 본다.
- 버퍼2개·표시 합성/ResizeObserver·BFS생성비용의 모바일 프레임/메모리·cold/warm 로딩을 측정한다. 실제 iPhone·사람 음향 청취·장시간 한 원정의 재미/난이도는 에뮬레이션 통과와 구분한다.
