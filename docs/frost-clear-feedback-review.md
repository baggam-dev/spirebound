# 서리 화살 최종 클리어 후기 검토 (2026-10-07)

사용자의 실제 서리 빌드 최종 클리어 후기 0~8을 현재 코드와 대조했다. 이번 요청은 푸시 후 검토이며 아래 수치는 구현 전 제안이다. 게임 코드는 수정하지 않았다. 저장 보완은 사용자 답변 “잘되는듯”으로 재시도 정상으로 보임을 기록한다. 최초 저장 실패 원인·기기·브라우저는 미확정이다.

## 우선순위와 실행 단위

0(도감 외형) → 1·6(발사체/폭주 외형) → 3(지옥 배경) → 2·4(8/9층 보스) → 5(10층) → 7·8(귀환/탈출) 순서를 권한다. 식별 문제를 먼저 해결해야 다음 난이도 피드백도 정확해진다. 각 단위는 검증과 배포를 따로 완료하고, 난이도 변경은 저장/버전/현재 단일 랭킹 비교 조건까지 함께 검토한다. 과거 시즌 탭을 다시 만드는 것은 사용자의 단일 랭킹 방향과 맞지 않는다. 버전 전환·기존 순위 취급은 구현 시 별도 결정할 사항이다.

### 본체 특수 공격 명세 제안

3초마다 한 위치를 고정하고 “헬 플레임/서브제로 메테오/제우스 · 3…2…1”로 경고한다. 이동하는 표적을 끝까지 추적하지 않는다. 3초 카운트와3초 주기는 매3초 예고 시작→다음 경계에 착탄하는 방식으로 해석한다. 특수 직격은2하트, 원본 raw 피해 단위와 보호막/무적 처리는 기존 피해 체계를 따른다.
