# 모바일 가로 전용·더블탭 확대 억제

2026-10-13 사용자 ‘1,2부터 진행’ 승인. 로컬 구현이며 테스트/브라우저 QA/푸시/배포하지 않았다. 기존 보행 e155065도 누적 미검증 변경이다.

## 구현

- src/ui/mobile-ui.js의 pointer:coarse + orientation:portrait 감지로 세로 플레이 차단 상태를 제공한다. 초기 로드·미디어 조건 변경·resize에 안내 표시/상태 이벤트를 갱신한다.
- game.js는 세로에서 전투 재개를 차단하며 일시정지·기존 저장 경로로 연결한다. 플레이 중 세로 전환은 입력 reset 및 pause, 매 update에도 세로 차단을 확인한다. 가로 복귀는 수동 계속 탐험으로 재개하고 기존 선택/일시정지 상태를 자동 해제하지 않는다.
- styles/mobile.css의 세로용 전투 배치를 제거하고 canvas/HUD/터치/상호작용을 숨긴다. 메뉴/저장 패널은 이용 가능하게 유지한다. ‘가로로 돌려주세요’ 안내를 추가하고 기존 안내 문구도 가로 전용으로 맞췄다.
- 전체화면 버튼은 지원 모바일 환경에서 screen.orientation.lock('landscape')를 시도한다. 실패해도 전체화면 자체는 유지하며 세로 플레이 차단으로 대응한다. 실제 회전 강제는 모든 브라우저에 보장할 수 없다.
- 모바일 body/헤더/일반 버튼/HUD/입력에 touch-action:manipulation을 적용한다. 게임 Canvas/조이스틱/액션의 기존 none 및 유물 목록의 pan-x를 유지한다. OS 확대를 막는 구현이 아니며 viewport 전체 확대금지 메타에 의존하지 않는다.
- 다음 공개 파일 일치 QA에 mobile-ui.js/mobile.css를 추가했다. 실행한 검증은 아니다.

## 배포 지시 때 필요한 검증

1. 모바일 세로 초기 로드에서 새 도전/이어하기/연습 실행 후 전투 시간·HP·위치가 진행되지 않는지 확인.
2. 가로 플레이 중 조이스틱 누른 채 세로 전환 → 입력 해제/시간 정지/저장 유지 → 가로 복귀 후 버튼으로 재개.
3. 수동 일시정지/성장 선택/가방/설정/도감/다른 탭 소유권 상태에서 회전해 기존 상태가 자동 재개/선택 손실되지 않는지 확인.
4. 일반/연습·전체화면 지원/미지원·회전잠금 성공/실패를 구분. 실제 iPhone/Android와 Edge 에뮬레이션 결과를 구분한다.
5. 조작 중 반복 더블탭·두 손가락 조작·HUD 설명 열기·유물 목록 가로 스크롤·패널 세로 스크롤 확인. 브라우저 확대 변화 여부는 실제 기기에서 확인 필요.
6. 기존 QA의 모바일 세로에서도 전투가 진행돼야 한다는 기대는 새 규칙과 다르므로 배포 전 세로 차단 기대값으로 갱신한다. 기존 grunt/brute/warden/full-frame/durability QA 등 세로 플레이 사례 확인 필요.

다른 3~8 항목은 미구현. HUD 시안을 컨펌 받은 뒤 별도 구현한다. 기존 원정/지도/전투 밸런스/저장 버전/랭킹은 변경하지 않는다.
