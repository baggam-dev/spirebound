# 통합 순위 2번: 10층 대악마 전투·발자국 구멍 개선 (2026-09-30)

## 변경 의도와 판정

사용자의 화염 궁수 완주 후기에서 1·2페이즈 이동과 공격 빈도가 낮고 3페이즈 탄환 변화가 적으며 발 착지 구멍이 교체·삭제되는 문제가 나왔다. 부위 체력과 공격 피해 자체는 먼저 올리지 않고, **공격 노출·움직임·회피 공간 변화**를 강화했다. 전투는 여전히 한 번에 큰 주공격 하나를 예고한다.

- 손은 더 빠르게 좁혀오고 발은 접근·측면 이동한다. 2페이즈의 눈은 비행하며 방향을 바꾸고, 코는 더 빨리 길을 가르며, 입은 근접 거리를 좁힌다. 코어는 벽 위 고정 표적을 유지한다.
- 1/2/3페이즈의 기본 공격 대기를 각각 1.35/1.45/1.2초로 줄이고, 일반 공격 후 회복을 0.4초로 줄였다. 손가락 화살 속도는 패턴별 205~320, 눈 탄환은 305로 올렸다. 주요 예고 0.85초, 발 착지/눈 광선 1.1초는 유지해 반응 구간을 보존한다.
- 발 점프 압박 시계는 첫 3.8초, 이후 점프가 나온 뒤 8.2초로 설정했다. 전역 공격 감독이 다른 공격과 직렬 처리하므로 고정된 실제 점프 주기를 보장하는 수치는 아니다. 발 돌진도 선택지에서 유지한다.
- 3페이즈는 기존 부위 잔상 중 눈 탄환을 추가하고, 코어에서 7발 부채 탄막 `coreBurst`를 새로 쏜다. 직전과 같은 패턴은 연속 선택하지 않으며, 준비 표시를 먼저 보여준다.
- 발자국 구멍은 최대 4개다. 새 구멍이 허용되면 오래된 것을 지우지 않으며 2·3페이즈에도 남는다. 상한에 닿으면 추가 생성만 거절한다. 3페이즈의 발 잔상도 구멍을 만들 수 있다. 발바닥·발가락 모양의 어두운 균열로 표시하고 기존 54×54 충돌·탄환 차단 판정을 유지한다. 생성 전 플레이어·출입구·코어 위치·기존 구멍과 거리, 플레이어에서 출구/살아 있는 표적까지의 격자 경로를 확인한다. 새 페이즈의 표적은 남은 구멍을 피해 배치한다.

## 시즌·저장 경계

대악마 난이도 변경은 현재 ASCENT-2 기록과 점수 비교 조건이 달라지므로 신규 10층 도전은 `ASCENT-3/ranking-v4`로 분리한다. `ASCENT-1/ranking-v2`와 `ASCENT-2/ranking-v3`는 종료된 기록으로 조회 가능하고 DB 기록을 삭제·혼합하지 않는다. 이전 시즌의 로컬 저장은 기존 시즌 식별자를 유지한 채 이어갈 수 있지만 종료된 시즌에 새 기록을 등록하지 않는다. 8층 `BETA-1/ranking-v1`은 그대로다. 서버는 종료된 기록 조회와 이미 등록된 기록의 동일 요청 영수증 재시도를 유지한다.
