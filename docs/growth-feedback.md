# 정수 획득·성장 완료 연출

- 정수 획득 성공 시 기존 능력치 안내와 함께, 정수 색상의 픽셀 입자가 획득 위치에서 플레이어로 모인다. 획득 거리와 능력치 적용 시점은 유지한다.
- 레벨업 보상 선택 완료 후 플레이어 양옆의 금빛 입자와 현재 레벨 표시. 연속 선택 시 마지막 성장 표시로 합쳐 중첩을 방지한다. 선택지가 없는 회복 보상에도 적용한다.
- 효과는 0.9초 이내 종료하며 게임 시간 기반으로 일시정지 시 정지한다. 방 이동 시 숨기고 저장에는 포함하지 않는다. 최대 4개 효과 제한 유지.
- 전체 테스트 303개 통과. Edge QA: 정수 5색과 성장 완료의 24개 렌더링 단계, 일시정지 프레임 고정·상태 불변 확인. 4개 PC·모바일 화면 크기에서 게임 실행 오류 없음. 실제 아이폰 검증은 별도.
