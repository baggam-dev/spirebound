# 플레이 피드백 4 — 화살 문지기 이동 사격

- 7층 화살 문지기만 거리 조절·측면 이동을 수행한다. 이동속도 60, 감속 효과 반영. 장애물 경로 탐색과 기존 방 경계 사용.
- 공격 준비 초반에도 이동하며 예고의 원점·조준을 현재 위치에 맞춘다. 마지막 0.3초는 이동과 조준을 고정하여 실제 투사체가 예고선과 일치한다.
- 냉동·공격 빈틈 중 이동하지 않는다. 일반 궁수, 화살 갈래 수, 원형 탄막, 공격 주기·피해 변경 없음.
- 전체 테스트 313개 통과: 준비 중 이동, 발사 전 고정, 실제 발사 원점·각도, 일반 궁수 및 상태 이상 회귀 검사.
