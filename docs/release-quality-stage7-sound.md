# 출시 품질 7번 첫 단위 — 전투 효과음·설정

기존 왕의 강공격 경고음만 있던 상태에서 자동 사격·적 명중·플레이어 피격·보스 전환/마지막 추격·보상에 짧은 Web Audio 합성 효과음을 더한다. 소리 파일 다운로드나 연속 배경 음악은 없다. 자동 사격/명중 소리는 각각 0.17/0.14초 간격 제한으로 탄막 중 중첩을 억제한다. 브라우저 입력 후 오디오를 열며, 지원하지 않거나 차단된 환경에서도 게임 진행은 유지한다.

입구·일시정지·헤더(모바일 메뉴)의 설정에서 효과음 끄기, 음량 0~100%, 장식성 화면 효과 줄이기를 조정한다. 설정은 `spirebound.settings.v1`에 별도로 저장하며 도전 저장·랭킹 규칙에는 포함하지 않는다. 효과 완화는 DOM 장면 애니메이션과 일시적 피격 장식/깜빡임을 줄이되 적 공격 예고의 색·모양과 피해 숫자는 유지한다. 브라우저/기기별 저장이므로 다른 기기에는 적용되지 않는다.

로컬 검증: `node --test` 403개 통과. Edge PC1280×800, 모바일 에뮬레이션844×390·390×844에서 입구 설정·새로고침 유지·플레이 중 설정 진입/일시정지·복귀 후 재개와 페이지 오류0 확인. 실제 기기에서 음색/체감 음량과 장시간 성능은 별도 확인 대상이다.

운영 `release-20261002-040023-d91cc6` 배포 후 서버 Python24개·Nginx·인증서·HTTPS health 통과. 공개 Edge의 동일 3화면 설정/재개와 공개 HTTPS 정적5개·HTTP308·랭킹·Secure/HttpOnly 쿠키·기존 기록 이전 오류0. 운영 도전·점수 제출 없음.
