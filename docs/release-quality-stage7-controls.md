# 출시 품질 7번 둘째 단위 — 입력·모달 포커스

키보드 입력은 버튼·링크·폼에 포커스가 있을 때 해당 컨트롤의 Space/방향키 기본 동작을 우선한다. 게임 캔버스에 포커스가 있을 때만 Space 점멸과 방향키 이동을 처리한다. 플레이로 돌아오면 캔버스에 포커스를 주고, 모달을 열 때는 대화상자에 포커스를 준다. 모달의 Tab/Shift+Tab은 안에서 순환하며 돌아가기 버튼이 있는 메뉴는 Escape로 이전 화면으로 돌아간다. 모바일 메뉴의 열림 상태를 접근성 이름과 `aria-expanded`로 알리고 Escape로 닫을 수 있게 했다.

왕의 강공격 예고는 효과음과 독립적으로 Canvas의 `!! 2♥` 위험 문구·구획 표시를 유지한다. 음소거와 화면 효과 완화 설정도 전투 예고 표시 자체는 숨기지 않는다.
