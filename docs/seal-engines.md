# 봉인 기관 — 5-4

2026-11-21 로컬 구현. 승인된 WORLD 보드 07 SEAL ENGINE의 석재·황동 석궁/봉인핵을 Canvas 코드로 그린다. 새 bitmap 생성이나 imagegen 사용 없음. 외형·장전/발사 반동·휴지·해제 색·분리 사격선/방향 화살표/근접 진행 막대를 함께 연결했다. 런타임/브라우저 검증 전이며 원화와 동등한 미술 완성도를 주장하지 않는다.

## 출현

3~8층 일반 방, 층별 55% 독립 난수 계획/최대1개. 지도·치명타·성장 난수는 소비하지 않는다. 보스/시설/계단/상자/관문/튜토리얼, 현재/방문/배치 완료 방, 유랑정예·추적자·지원 적 조우 제외. 저장 이관 시 이미 방문한 방에 추가하지 않는다. 하강 새 추적자/지원 계획도 기관 방 제외.

왼쪽 x70 또는 오른쪽 x890, y130/410/210/330 후보. 실제 측면 문에서 100px 이상 떨어지고 본체·해제 접근점의 장애물 충돌이 없으며 최소 240px 사격선이 있는 후보만 사용한다. 장애물/문/이동 충돌체를 추가하지 않는다. 적 배치와 적 수, 몬스터 공격 자동 타깃·치유·소환 예산·킬/랭킹과 별도인 `room.sealEngine`이다.

## 사격과 해제

- 최초/재입장 휴지2초+입장 무적 유예 → 주황 고정 사격선1.2초 → 속도330 단발9피해 → 발사 반동0.24초 → 휴지3초. 위치/방향은 플레이어를 추적하지 않는다.
- 사격선은 반경3 장애물 검사로 끝을 잘라 실제 탄환 벽 충돌과 맞춘다. 탄환은 기존 enemy projectile 경로의 구르기·무적·수호·피해 원인 기록을 따른다. 환경 공격에 플레이어 치명타를 적용하지 않는다.
- 핵 42px 이내/벽 없음/이동 입력 없음/구르기·행동 경직 없음 상태1.2초로 자동 해제. 모바일 추가 버튼 없음. 이동·구르기·실제 체력 피해는 진행 초기화. 근접 안내와 진행 막대 표시.
- 해제 시 현재 기관 탄환 제거, 비활성 색/멈춘 기구·해제 문구, 18XP 파편을 정확히1회. 처치·정수·물약 보상 없음. 별도 해제 기능이며 평타 파괴 기능은 이번 범위 아님.
- 적 전멸 시 기관 사격과 남은 탄환 정리. 조우 종료 후 안전하게 해제해 남은 보상을 챙길 수 있다. 재입장 시 경고/진행만 초기화하고 해제·보상 상태는 유지, 하강 재생성에도 유지한다.
- 일반/완화 모두 같은 외곽 경고·범위·타이밍. 완화는 방향 화살표 수만 줄인다.

## 저장·검증 상태

`sealEngineVersion:1`은 계획 완료 표식. 층/방/좌표/방향/단계별 시계 상한/해제 진행/disabled=rewarded/층당1개를 검증한다. old save 필드 없음은 허용하고 migrate에서 안전 계획한다. 별도 런타임 PNG나 manifest 변경 없음.

전용 회귀9개 작성: 계획·난수/제외, 양방향 벽, 경고/단발/휴지, 입장유예/재입장, 해제/XP중복, 행동/벽, 전멸후해제, 하강/저장손상, 렌더불변/완화. **현재 지시의 테스트 보류 규칙에 따라 미실행**. 구문 실행·서버·브라우저 QA·푸시·배포도 하지 않았다. 직전 지원 적853통과는 이번 변경의 검증 근거가 아니다. 최종 일괄 검증에서 신규9개/전체 회귀·실제 배치/문/뷰포트·전멸직후 탄환·해제 중 피격·하강/로드·성장 수지를 확인한다.
