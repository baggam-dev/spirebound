# 후속 전투·캐릭터 개선 검토 (2026-09-29)

사용자 요청은 검토 우선. 아래는 권장안이며 구현·배포하지 않았다. 현재 기준 코드: 0cc9962 및 기존 전투 코드.

## 1. 독립 유도 노멀 화살
- 현재 simulation.fireArrow는 기존 속성탄 중 homing 레벨만큼 유도한다(현재 스킬 최대1). 갈래 추가탄은 이미 elemental:true이며 기본45% 피해다.
- 권장: 기존 탄 유도를 대체해 독립 주기1.5초마다 일반 유도 화살1발 추가. 현재 일반 공격력100% 기준, 장비/공격력 증가 반영, 속성 효과·속성 피해 보너스 없음. 갈래/연속/관통으로 추가 유도탄이 증식하지 않도록 분리. 갈래는 지금처럼 속성탄 추가와45% 계수 유지.
- 독립 주기로 화염 발사속도 감소와 분리. 요정과 같은 방식으로 살아 있고 보이는 적을 타겟으로 하되 벽 통과 금지. 일반 사격과 구분되는 은백색 탄/짧은 꼬리. 별도 동행 요정 개체를 추가할 필요는 없음.
- 1.5초는 제안 수치(기본 공격력17에서 추가 DPS 약11.33, 적중·방어 전). 공격 때마다100% 한 발을 복제하면 무속성 단일탄 빌드 DPS가 사실상2배가 되므로 독립 주기를 우선 추천.
- passivePower는 일반 직격 조건부 배율 전체와 동일하지 않아 그대로100%라고 표기하면 안 됨. 실제 일반화살 피해 규칙에서 속성 부분만 제외하도록 구현/검증 필요. 저장 passive 종류/타이머 허용 목록, 재개 중 기존 유도탄, 스킬 설명/미리보기/유니크 가중치/기존 테스트도 함께 갱신.

## 2. 적 원·예고선
- elites.drawElites의 정예 원, ranged의 본체 원, brute.drawEnemyDetails의 점프/휘두르기 원이 남아 있음. 왕/인력/슬라임 분열 점프 등 일부는 이미 그라데이션이므로 중복 재작업하지 않음.
- 몸 주변 원은 저농도 색 번짐으로 변경. 점프 착지는 실제 피해 반경 안쪽 색 면+중앙 작은 표식, 시간에 따른 밝기 변화로 표현.
- 예고선은 대략1px/불투명도40~55%부터 PC·모바일 비교. 적중 직전은65~75%로 올려 구분. 실제 활성 레이저/공격 폭은 유지하며 예고선만 얇게 한다. 강공격 문구와 탄막 안전 틈은 보존.

## 3. 슬라임 보스 난이도 권장안
- 현재6층 원형 HP1350 → 2체 각675 → 4체 각338로 분열. 모든 단계를 합치면4052 HP, 광역 공격에는 여러 체가 동시에 맞음. 일반탄/독침/독구슬/독장판/작은 슬라임 소환이 이미 있음.
- 우선 체력·피해량 유지. 화살비180→150과 유도 개편을 같이 적용하면 실제 난이도 변화가 커서 HP까지 동시에 올리지 않는 편이 조정하기 쉬움.
- 첫 후보: 패턴 후 대기 약12% 단축(현재 단계별2.21/3.74/4.08초 → 약1.95/3.30/3.60초), 2·4체의 패턴 시작 시차를 주어 공격이 번갈아 이어지게 구성. 모든 분열체가 한꺼번에 바닥을 덮지 않게 위험 장판/동시 공격 상한 마련.
- 피할 수 있는 통로와 기존0.85초 장판 예고/분열 착지 여유 유지. 자동 전투 시간·피격률·동시 장판 수·PC/모바일 회피 가능성을 측정한 뒤 확정. 이는 밸런스 설계안이며 수치 확정/테스트는 아직 아님.

## 4~5. 주인공 디자인·동작
- 현재 pixel-world.js Canvas 픽셀 도형 기반 후드/가죽 궁수. 보행은 sin(distance*.16)의 발 이동±3px와 최대1.5px 수직 들썩임에 크게 의존함.
- 권장 외형: 후드를 벗은 짧은 짙은 머리, 또렷한 눈썹과 좁은 눈매, 정돈된 턱선. 짙은 강철 어깨/흉갑과 가죽 장갑·장화, 짧은 먹청색 망토. 활은 유지하는 기사/용병 궁수. 전장 크기·충돌 반경은 유지.
- 권장 동작: 보폭 빈도와 수직 튀는 폭을 줄이고 전진 기울기/어깨·골반의 반대 회전/팔과 활의 관성/망토 지연을 추가. 착지→체중 이동→밀어내기 구분, 사격 시 상체만 짧게 고정·반동. 대기는 미세한 호흡으로 제한.
- 기존 enemy pose 공통 함수에서 영웅만 분리해 몬스터 움직임을 바꾸지 않음. 게임 시간·이동 거리로 구동하고 일시정지/점멸/저장 복귀에서 잔상/보행 누적 방지. Canvas 도형 작업이므로 이미지 자산 생성은 필수 아님.

## 6. 화살비
- 현재 abilities.js: 60×3회,0/.6/1.2초,반경280. 화면에는24개 장식 화살이 있고 각 화살이 개별 피해를 주는 방식이 아님.
- 권장: 기본 피해50×3회=150(현재180 대비16.7% 감소), 궁극기 피해 유물 배율 유지. 화면의 화살1개마다50 피해로 바꾸는 것은 아님.
- 원 테두리는 앞 작업에서 제거됐지만 drawUltimateGround의 원형 바닥 그라데이션은 남음. 바닥 원 자체를 제거하고 금빛·은빛 낙하 궤적, 3차례 착탄 섬광·짧은 파편으로 화려함 강화. 실제 피해 타이밍과 동기화하고 큰 화면 섬광/파티클 무제한 증가는 피함.
- 저장된 진행 중 화살비 피해값은 보존하고 다음 시전부터50 적용하는 방안 권장. 설명/미리보기/테스트의 피해 수치 일치 필요.

## 7. 석궁 설치·소멸
- 이미0.28초 지지대 펼침과 종료 전1.2초 페이드가 존재함. 현재 종료 시 turret가 즉시 배열에서 제거돼 이후 소멸 연출은 없음.
- 설치: 작은 먼지+금빛 조립 불꽃+지지대 고정 연출 강화. 소멸: 짧은 접힘/빛 파편 잔상0.3~0.4초 추가. 수명 종료와 최대2대 교체 모두 처리.
- 공격 개시/수명19초/주기0.5초/쿨다운20초 유지. 소멸 잔상은 공격하지 않는 한시적 시각 효과로 분리, 개수 제한·방 이동시 제거. 저장 재개 시 설치 연출 재발동하지 않도록 시간 기준 유지.

## 검증 계획
- 유도: 독립1.5초/100%/속성 미발동/갈래 속성 유지/벽/대상 사망/저장 재개.
- 보스: 단계 전환·동시 공격 상한·회피 통로, 시드 고정 비교. 난이도는 화살비 너프 반영 후 평가.
- 시각: 몬스터 경고 식별·주인공8방향 이동/사격·일시정지·궁극기 시작/종료 PC·모바일 캡처와 프레임 비용 확인. 실제 모바일 기기와 에뮬레이션 구분.
- 이번 검토는 코드·기능 문서 정적 확인만 수행. 게임 테스트·배포 반복 없음.
