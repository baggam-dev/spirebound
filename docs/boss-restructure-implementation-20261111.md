- 새 배치: 8층 `demonPending` 잔해, 9층 기존 군단장, 10층 `kingPending` 왕. 기본8층은 잔해 최종 처치로 기존 열쇠/귀환, 확장10층은 8층 계단/10층 열쇠 흐름 유지. 보스 방 접근 시 기존 공통 도전 경로 사용.
- 기존 저장에 marker를 자동 추가하거나 부위를 치환하지 않음. `parseSave`/마이그레이션은 기존 형식의 원정을 계속 유지. 신규 flag와 부위 위치를 저장 검증에 추가. 엔진의 판정/키/귀환/XP 분산 루틴을 재작성하지 않음.

## 3페이즈 등장 순간
- 표시 상태는 WeakMap으로만 보관. simulation 전/후 관찰로 실제 kingStage<3→3과 kingTransition>0을 감지. 실제 로드·도감·연습 시작부터3단계인 개체는 자동 재생하지 않음. 사망 우선, 실제 전환이 끝나면 제거.

- 기존1.4초 전환을 늘리지 않음. 보스 외형은 .55초 전까지 기존 마지막 해골 형태를 보여주고 빛 속에서 전환. 이미지에 오라/후광을 그려 넣지 않고 Canvas 독립 효과.
- 게임 update 시간만 진행, 정지 시 시간 고정. resetTransient/방 전환에서 상태 초기화. 효과 줄이기는 기둥/확대/충격파를 생략하고 낮은 감광/작은 정적 후광 유지. PNG 실패는 기존 몸 fallback.
- `resurrectionRise`, `resurrectionBell` 합성음 추가. 시작 시 기존 combat 음 정리, .55/.85초 alert duck으로 짧게 잦아들게 함. 음소거/volume0/정지/gesture unlock는 기존 sound 정책 사용. BGM 추가 없음. 실제 가청성/클리핑/모바일 재생은 아직 검증하지 않음.
