# 0.28 · 번개 화살과 자동 천둥

- 번개 첫 적중 대상 추가 피해: 공격력의 15/25/35%.
- 전이 첫 피해: 45/55/65%, 이후 직전 피해의 80% 유지. 기본 전이 1/2/3체.
- 집중 방전: 첫 적중 추가 번개 75%, 전이 1체에 120% 피해.
- 번개 그물: 전이 +2, 후속 피해 90% 유지. 최대 레벨에서 첫 전이 65%.
- 번개 스킬 보유 시 3초마다 현재 화면의 적 중 무작위 1/2/3체에 일반 화살 직격 1발분 천둥. 캐릭터 레벨이 아닌 번개 스킬 레벨 기준.
- 동일 발동에서 중복 타격 없음. 단독 보스는 1회, 대상 부족 시 실제 대상 수만 타격. 공중/출현 보호/페이즈 전환 중인 적 제외. 장애물 뒤에도 화면 안의 대상은 타격 가능.
- 천둥은 일반 직격의 공격력, 유물, 직격 분기 및 적 방어 보정 적용. 별도 속성 추가 피해나 연속 화살, 전이 등을 발동하지 않음. 현재 일반 공격에는 별도 치명타 시스템이 없음.
- 천둥 타이머·랜덤 상태 저장, 일시정지 시 정지. 기존 번개 저장에도 적용.
- 하늘색 외곽과 노란 중심의 짧은 낙뢰 효과. 스킬·분기 설명 갱신.

검증: 전체 자동 테스트 250개 통과. 레벨별 피해, 두 분기, 3초 주기, 중복 없는 선택, 보스 단일 타격, 저장 재개, 유물 보정, 과잉 피해 집계 제외 검증. 별도 QA 포트 5199에서 자동 공격을 끈 번개 빌드의 천둥 피해 집계와 게임 실행 확인, 콘솔 오류 없음.
