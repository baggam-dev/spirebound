# 모바일 전투 가독성

- 터치 포인터 환경에서 같은 40px 영역의 같은 속성 타격 및 적 피격 반짝임은 최신 효과를 우선 표시하며 총 16개로 제한한다. 실제 효과 목록과 전투 로직은 수정하지 않는다.
- 적 사망, 번개 공격 표시, 피격 문구·방향, 탄환, 위험 예고는 필터링하지 않는다.
- 정수 획득 문구는 플레이어 아래쪽에 18px 간격으로 배치한다. 화면 가장자리에서 문구가 잘리지 않도록 위치를 보정하며 피격 수치는 더 큰 글씨로 유지한다.
- 전투 문구를 타격 파편 이후에 표시한다. PC는 기존 효과 수와 글자 크기를 유지한다.
- 전체 테스트 305개 통과. 중요 효과 보존·장식 효과 제한·5개 동시 정수 문구의 하단 배치 검증.
- Edge 보스 QA로 PC·모바일 4개 화면 크기를 확인한다. 실제 아이폰 기기에서의 가독성과 성능은 추가 확인 필요.
