# 속성별 명중 효과 (시각 개선 1단계)

- 화염: 짧은 밝은 중심에서 주황 불씨가 퍼지며 위로 사라집니다.
- 서리: 방향이 있는 청백색 얼음 파편이 바깥으로 흩어집니다.
- 독: 녹색 점액 방울이 포물선을 그리며 떨어집니다. 처치 타격에도 표시됩니다.
- 번개: 접촉 지점의 짧은 섬광과 갈라지는 전격, 실제 전이 대상까지 이어지는 굴절된 연결선을 표시합니다.

`element-hit-visuals.js`는 렌더링 전용입니다. `simulation.js`의 실제 투사체 충돌 분기에서만 접촉 효과를 생성합니다. 장애물 뒤의 적, 이미 맞힌 적, 지연 중인 투사체에는 새 효과가 생기지 않습니다. 관통 후에는 기존 속성 적용 규칙을 따르고 서리 사망 파편은 작은 서리 효과만 사용합니다. 번개 연결선은 기존 피해 전이 이벤트에 표시 정보를 추가합니다.

효과는 0.22~0.4초 동안 지속하고 일시정지 때 정지합니다. 동시 명중·전이 효과는 최신 48개로 제한하며 피해 문구와 다른 전투 표시는 보존합니다. 입자는 전장 안으로 잘리고 화면 전체 섬광은 사용하지 않습니다. 피해량, 공격 범위, 발사 속도, 상태 이상, 저장 형식, 난수는 변경하지 않았습니다. 궁극기 연출과 강화 단계별 표현은 이번 단계에 포함하지 않았습니다.

검증: `node --test` 287개 통과. `tools/element-hit-qa.mjs`로 네 속성의 프레임 차이, 정지 프레임 안정성, 소멸, Canvas 상태 복구를 검사했습니다. Edge의 1280×800, 844×390, 390×844에서 속성별 슬라임 보스 전투 총 12회 오류 없이 확인했습니다. 48개 효과 그리기의 데스크톱 중앙값은 약 0.7ms였으며 실제 iPhone 성능 측정치는 아닙니다.
