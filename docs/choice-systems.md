# 0.11 · 선택과 반복 플레이 기획 / 구현 기준

층수는 6층 유지. 그래픽 제작 확대보다 빌드, 위험 감수, 귀환 판단에 집중한다. 아래 다섯 시스템의 첫 구현을 완료했다. 수치는 사람의 장기 플레이 평가에 따라 조정한다.

## 1. 보상 선택

보물방을 비운 뒤 무기(공격력 +3), 생존(최대 하트 +1, 상한 10 / 1하트 회복 / 물약 1개), 기술(기술 선택 1회) 중 하나를 선택한다. 기술 보상은 경험치 레벨을 올리지 않지만 궁극기 해금의 누적 기술 선택 횟수에는 포함된다. 모든 보상을 동시에 얻던 방식은 제거했다. 선택을 미룰 수 있으며 중복 수령은 불가능하다.

## 2. 분기 진화

일반 기술은 3레벨에서 두 분기 중 하나를 고른다. 추가 포인트를 소모하지 않으며 도전 중 변경할 수 없다. 가방과 종료 기록에 선택한 분기를 표시한다. 과거 저장에서 이미 조건을 달성했다면 이어하기 시 선택창을 제시한다.

| 기술 | 분기 A | 분기 B |
|---|---|---|
| 갈래 | 넓은 부채: 넓은 확산, 추가탄 50% | 집중 사격: 좁은 확산, 공격 간격 15% 증가 |
| 관통 | 심층 관통: 관통 +2, 직격 -15% | 충격 화살: 관통 제거, 직격 +25% |
| 공속 | 고속 리듬: 공격 간격 -15%, 직격 -15% | 기동 사냥: 이동속도 +12% |
| 화상 | 긴 불씨: 6초, 초당 피해 -25% | 급속 연소: 1.5초, 초당 피해 +50% |
| 서리 | 깊은 서리: 둔화율 +15%p, 1초 | 잔류 서리: 4초, 둔화율 -10%p |
| 번개 | 집중 방전: 전이 1회, 65% 피해 | 번개 그물: 전이 +2, 20%에서 시작해 45%씩 감쇠 |

화살비는 누적 기술 선택 5회에 해금하며 즉시형(전체 120 피해)과 영역형(현재 위치 반경 145, 5초간 초당 40 피해) 중 선택한다. 재사용 시간은 모두 25초. 영역을 벗어난 적은 피해를 받지 않고 방을 떠나면 영역은 사라진다.

## 3. 정예 몬스터

2층 이상에서는 층당 75% 확률로 일반방 한 곳의 적 1마리를 정예로 만든다. 최대 체력 1.4배, 특성은 하나만 부여한다. 기본 적 공격을 유지한다.

- 폭발: 사망 위치에 1초 예고 후 반경 85 폭발, 2하트. 장애물이 피해를 막는다.
- 수호: 반경 140 이내 다른 적의 피해를 절반으로 감소. 자신을 보호하지 않으며 죽으면 효과가 해제된다.
- 포화: 0.8초 방향 고정 예고 후 추가 3발, 회복 3초.

처치 시 물약 1개를 확정 지급한다. 재접속으로 중복 수령하지 않는다. 금빛 표시와 이름, 보호받는 적 표시 및 폭발/사격 예고를 제공한다.

## 4. 선택형 이벤트

새 지도는 각 층에 제단 이벤트 방(?) 1개를 포함한다. 세 가지 중 하나를 계약하거나 그냥 지나갈 수 있다.

- 현재 체력 2칸을 내고 보호막 장비 +2. 체력 3칸 이상일 때만 가능.
- 물약 1개를 내고 바람의 인장 획득. 이미 인장을 갖고 있다면 불가.
- 체력 1.5배의 일반 적 4마리와 시련. 문은 잠그지 않는다. 완료 후 보물과 같은 보상 1택.

계약 순간 비용을 한 번만 지불한다. 시련을 떠나도 진행과 적 체력은 보존하며, 완료 전 보상 수령은 불가하다. 시련 개시 시 이전 공격을 정리하고 0.6초 진입 시간을 준다.

## 5. 귀환 경로

새 지도에 고리형 우회로를 포함한다. 보스방이나 확장 방이 입구 옆에 생성되어 선택지를 없애지 않도록 연결을 제한한다. 기존 저장의 지도는 재생성하지 않는다.

열쇠를 얻으면 최단 경로의 중간 방을 위험 구역(붉은색)으로 지정하고 포화 정예를 추가한다. 우회 구역은 초록색이며 기본 광폭 적 수의 60%(올림, 최소 4마리)만 남긴다. 샘물은 우회 구역으로 취급한다. 층별 광폭화 강도는 유지한다.

귀환 경로 버튼은 최단/위험 회피 경로, 이동 횟수와 위험 방 수를 비교한다. 선택한 경로는 미니맵에 테두리로 표시하고 이동은 직접 조작한다. 방문한 방만 대상으로 계산하므로 미탐색 방의 구조는 공개하지 않는다. 일부 구간은 두 경로의 길이가 같거나 경로가 일치할 수 있다. 과거 지도는 우회로를 보장하지 않는다.

## 검증과 다음 평가

자동 검사 80개 통과. 새 지도 40개 × 6층에서 위험 방 수가 더 적은 별도 귀환 경로를 확인했다. 보물·계약·정예 보상 중복 방지, 분기 저장, 시련 이탈·복귀, 영역 궁극기 범위와 총 피해, 정예 예고 및 보호 효과도 검사했다.

별도 QA 주소에서 보물→기술 선택, 분기 선택→가방 표시, 귀환 경로 비교, 이벤트 비용 UI를 확인했다. 세로 화면 선택창은 게임 영역을 넘어 화면 높이를 사용하며 스크롤할 수 있다. 보스/광폭 CPU 시뮬레이션도 재실행했다.

남은 평가는 실제 6층 왕복에서 보물 선택 비중, 스킬 분기별 효율, 정예 물약 수급과 이벤트 비용, 귀환 우회로의 활용도다. 자동 검증은 실제 모바일 성능이나 인간의 체감 난이도 평가를 대체하지 않는다.
