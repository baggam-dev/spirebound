# 0.15 · 최근 개선 목록 11~15

## 적용
- 시련 용사 공격 회복 배율 0.8→0.6 (0.14 대비 회복 구간 25% 단축).
- 시련 돌진 기본 속도 235→305, 지속 0.54→0.65초, 예고 0.32→0.28초. 기존 시련 이동 배율도 적용. 반복 돌진은 예고+돌진+최소 0.1초 회복 확보. 일반몹 수치는 유지.
- 근접 오라: 레벨별 반경 70/85/100, 초당 피해 8/16/24. 벽 차단과 공중 적 제외 유지. 시각 범위와 판정에 같은 수치 사용.
- 빙결 상태 처치 시 서리 파편 6방향 발사, 기본 화살 직격의 1/3 피해. 빙결된 적을 파편으로 처치해도 재발사. 각 시체당 한 번, 다음 시뮬레이션 프레임부터 이동.
- 서리 3레벨부터 파편도 서리 중첩 부여. 기존 빙결 면역 유지. 파편에는 갈래/연속탄/유도/관통을 재복제하지 않아 6방향과 피해 비율을 유지.
- 치명타 직후 죽은 적에 새로 빙결을 걸어 파편을 생성하는 문제 방지. 오라·지속 피해에 죽었을 때도 실제 빙결 사망 상태 보존.
- 메인 선택/강화/분기 카드 금색 반투명, 레어 보조 파란색, 유니크 보조 보라색. 일반은 기존 스타일. 등급 문자도 함께 표시.
- 유도 화살을 유니크로 표기. 가중치는 기존 0.04 유지 (레어 0.18, 일반 1). 새로운 유니크 기술은 이번 묶음에 추가하지 않음.

## 호환 및 검증
기존 지도/스킬 투자/시련 진행을 유지한다. 기존 시련 용사도 다음 공격에 새 수치를 적용하며, 이미 장착한 오라/서리는 새 수치를 즉시 사용한다. 파편과 빙결 사망 표지를 저장 검증에 추가했다.

자동 검사 124개 통과. 파편 6방향/중복 방지/연쇄 처치/레벨별 중첩/사망 원인/피해 배율/저장 재개/방 이동 초기화, 오라 성장, 시련 공격 프로필, 기술 등급 매핑 포함. 별도 브라우저에서 메인·레어·유니크 카드 색과 문구 확인. 인간 체감 밸런스는 다음 플레이로 확인한다.

앞선 기획 후보 1~10은 별도 후속 목록으로 남긴다. 이번 완료 범위는 11~15이다.
