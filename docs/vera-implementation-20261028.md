## 연결
- 피드백 렌더의 베라 경로만 새3자세 프레임을 선택한다. 기본/조준(darkAttack 또는 정예예고)/발사(darkFlash 및 정예 포화 직후)를 기존 시계에서 읽는다. 칼드·일반별자리저격수·벨카르는 기존 자산을 유지한다.
- 걷기는 기존 이동량 기반 cutout 체계, 피격/등장 반응은 remaining-boss-presentation, 사망은 remaining-boss-death의 새 베라 정지 스냅샷을 이어 쓴다. 별도 새 걷기/피격/사망 PNG 프레임을 만든 것은 아니다. 좌우/동결/정지 효과는 같은 옵션을 전달한다. 애니메이션을 위해 저장/AI 시간을 추가하지 않는다.
- 7층 기본 계획과 실제 원정 roster에 베라가 포함되면 vera-sprite를 사전 준비한다. 초상은 새PNG만 준비하며 ready 여부가 캐시 키에 들어간다. 첫층 기본 로딩에는 새PNG를 추가하지 않는다. named-brute 기존 시트는 칼드·거인/구자산 보존을 위해 유지하지만 베라 렌더는 그 시트의 옛 금발 인물을 선택하지 않는다.
- 규격불일치/실패면 새 Ready가 false여서 실제 층 준비는 기존 오류/재시도 화면으로 간다. 준비 전 단독 렌더는 false를 반환하여 기존 일반 fallback 경로를 허용한다. 새 PNG 표시 성공을 확인한 것은 아니다.
- server/deploy PNG 허용목록, 공개검증 파일/바이트 목록, 서버 회귀 목록을 준비했다. 아직 실행하지 않았다.

## 별도 효과와 전투 불변 범위
- vera-effects.js의 얇은 분절 마법진은 캐릭터 발밑의 작은 별도 장식이다. 몸 PNG에 합성하지 않는다. 실제 fan/ring 경고가 장식 위에 그려지며 효과 줄이기에서는 장식 시간·입자 움직임을 생략한다. 새 공격 장판/판정이 아니다.
- 기존 적 탄환 중 베라 출처의 탄환만 옅은 보라 화살 중심과 짧은 별빛 잔광으로 그린다. 일반 별자리 저격수는 그대로다. 기존 정예탄에는 이미 베라 이름이 있고, 전용 fan/ring은 피해 출처 문자열만 ‘별의 눈, 베라 별빛 화살’로 구분한다. 저장된 구 탄환의 출처는 소급 변경하지 않는다.
- 5발 fan/19발 ring·탄속·사거리·생명/위치·경고시간·피해·체력·충돌·보상·대사·랭킹/버전은 바꾸지 않았다. 발사 출처 문자열은 이후 피격 기록의 명칭에도 반영된다.
