# 플레이 피드백 11~13 — 하강 봉쇄

- 모르도 처치로 하강이 시작될 때 등반 방문 이력을 고정하고 방별 봉쇄 규칙을 한 번 결정한다.
- 우선순위: 내려가는 계단방 → 미방문 방 → 방문 방 30% 열쇠수호자. 방마다 규칙 하나만 적용한다.
- 계단방은 적 전멸 전 하강 계단만 봉인한다. 다른 방으로 이동하는 문은 열려 있다.
- 미방문 방은 모든 적을 처치해야 문이 열린다. 처음 하강 중 방문해 seen이 바뀌어도 봉쇄 규칙은 유지한다.
- 방문 방은 30% 확률로 기존 적 하나가 열쇠수호자 정예가 된다. 열쇠 표식과 이름을 표시하며 해당 적만 처치하면 다른 적이 남아 있어도 문이 열린다.
- 해제 상태를 저장하고 재입장·추가 전투에서 재봉쇄하거나 재추첨하지 않는다. 잠긴 1층 출구는 탈출도 막는다. 적이 없는 방은 바로 해제 상태로 둔다.
- 기존에 이미 하강 중인 저장에는 봉쇄를 소급 적용하지 않는다. 등반 중인 기존 저장은 다음 하강 시작 시 적용한다.
- HUD·계단 표시·도움말·열쇠 획득 안내를 갱신했다. 기존 적 편성·하강 피해량은 유지하며 열쇠수호자 지정 시 기존 정예 강화 규칙을 사용한다.
- 전체 테스트 326개 및 추가 실제 문 이동 테스트 1개 통과(총 327개). 우선순위, 수호자 단독 처치, 30% 분포, 저장 유지, 재봉쇄 방지, 계단 이동과 탈출 차단 검사.
- Edge 1280×800 / 844×390 / 390×844 / 667×375에서 세 종류 봉쇄 안내·표시 총 12개 시나리오 확인, 오류 없음. 실제 아이폰 검증 미실시.
