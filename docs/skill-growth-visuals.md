# 스킬 성장 표현 (시각 개선 3단계)

네 주력 속성의 투사체 잔상과 명중 효과를 레벨·진화별로 구분했습니다. 화염·독·번개는 1~3레벨, 서리는 1~4레벨을 표현하고, 각 속성의 두 진화까지 총 21개 상태를 비교 검증합니다.

- 레벨: 잔상 조각과 명중 파편의 수가 증가합니다. 2레벨부터 중심선이 선명해지고, 3레벨 이상은 보조 잔상이 붙습니다. 서리 4레벨에는 추가 결정 무늬가 생깁니다.
- 화염: 확산 폭발은 갈라지는 불씨, 응축 폭발은 밝게 모인 중심선과 타격 중심으로 구분합니다.
- 서리: 깊은 서리는 각진 결정과 마름모 타격, 잔류 서리는 이어지는 작은 눈꽃으로 구분합니다.
- 독: 잔류 독은 이어지는 방울과 기포, 맹독은 보라색 보조 잔상과 밝은 녹색 중심으로 구분합니다.
- 번개: 집중 방전은 굵은 황백색 전격, 번개 그물은 교차하는 잔상과 실제 전이 경로의 겹선으로 구분합니다. 없는 대상에 가짜 연결선을 만들지 않습니다.

투사체의 명중부 크기·히트박스·공격 범위·피해·속도·상태 이상은 그대로입니다. 범위 표시에는 기존 실제 반경을 사용하고, 성장 장식은 잔상과 짧은 국소 타격 효과에만 적용합니다. 파편은 효과당 최대 12개, 동시 명중 효과 48개 제한을 유지합니다.

`skill-visuals.js`는 현재 플레이어의 스킬과 진화를 읽습니다. 기존 저장의 투사체에 새 필드를 요구하지 않으며, 명중 효과에는 그 순간의 단계만 복사하므로 이후 강화가 이미 발생한 타격 표현을 바꾸지 않습니다. 일시정지 중 프레임은 고정되며 전투 난수를 사용하지 않습니다.

검증: 전체 테스트 293개 통과. `tools/skill-growth-qa.mjs`로 21개 상태가 구분되는지, 일시정지 이미지·Canvas 상태·전투 데이터가 유지되는지 확인했습니다. Edge 1280×800과 844×390에서 8개 진화 각각, 390×844에서 속성별 1개 진화를 실행해 총 20개 전투 조합의 브라우저 오류가 없었습니다. 실제 iPhone Safari 확인은 별도로 필요합니다.
