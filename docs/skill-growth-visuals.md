# 스킬 성장 표현 (시각 개선 3단계)

## 2026-11-22 후속4: 액티브 사용 안내 (로컬 구현/미검증)

기존 HUD/버튼/빌드3탭의 디자인을 유지하며 텍스트와 접근성 설명을 개선했다. `utilityUseState`가 기존 사용 조건의 단일 판정을 반환하고 `canCastUtility`와 UI가 이를 공유한다. 소유·생존/상태·보스 등장·경직·대기 중 시전·재사용·마혈 체력·뇌격 지상/거리/벽 조건은 기존과 같으며 새 제한을 추가하지 않았다.

- PC/모바일 기존 버튼 값에 준비/재사용/대상 없음/체력 부족/발동 대기/경직·등장 중을 표시한다. 모바일 버튼은 계속 disabled로 보호하며 실패 이유를 짧은 값으로도 읽을 수 있다. title/aria-label에는 전체 이유·지속 상태·사용 요령을 넣었다. HUD에서 한 번 계산한 안내를 모바일 갱신에 넘겨 뇌격 대상 검사를 중복하지 않는다.
- 실패한 키보드 시전에는 구체적인 이유를 안내한다. 성공 시 기존 toast에는 해당 버프 지속/시전 대기 상태를 보여준다. 별도 팝업/튜토리얼 잠금·확인 버튼은 추가하지 않는다.
- 빌드 스킬 상세에는6종별 사용 요령·실제 유물 적용 재사용 시간·현재 실패 이유·재개 후 사용 가능 여부를 함께 표시한다. 마혈은1하트 초과 필요, 혈월은 만피에서도 회복 기회 소모, 뇌격은 지정 위치 고정/0.65초, 질풍은 특수탄 제외를 명시한다.
- 혈월은 회복 기회0~2회 사용을, 성역은 방어 잔여를, 질풍은 소거 소진 후에도 남은 이속 지속을 구분한다. 기존 전투 상태 줄에도 혈월 횟수/질풍 이속 유지 문구를 맞췄다. 양수 남은 시간은 올림0.1초 단위로 표시해 준비되기 전0.0초로 보이지 않게 한다. 설명의 유물 쿨타임은 기존 소수 둘째 자리 정확도를 유지한다.

관련6회귀는 작성만 했다(마혈 실패 무소모, 뇌격 대상/공중/거리/벽, 경직·등장·발동 대기/0초 경계, 기회 소진과 지속 구분,6종 빌드·유물/입력 불변, 정지·미소유 안내). 새 테스트/구문/서버/브라우저/푸시·배포는 없다. 다음 배포 때 전체 및 실제PC/모바일 작은 버튼의 짧은 이유·title/aria·빌드 스크롤/모달 복귀·사용 성공실패/냉각 종료·구저장·누적 시전/피격/음향을 함께 검증한다. 모바일 실화면 문구가 잘림 없이 읽히는지는 아직 검증하지 않았다.

## 2026-11-22 후속: 액티브 실제 명중 접점·소리 (로컬 구현/미검증)

기존 승인 색상과 `drawImpactAccent`를 재사용해 서리파동/뇌격인장에 실제 명중 접점을 연결했다. 새 원화·캐릭터/디자인 방향 변경이 아니라 기존 효과의 사건 연결·밀도 조정이다. 평타·발도 접점과 화살비 최종음은 이미 존재하므로 이번 단계에서 다시 구현하지 않았다.

- `utility-impact-feedback.js`: 새 stepRun damageResults의 실제 applied/newHit/damage>0만 읽는다. 서리는 파동 중심→명중 방향의 기존 청백 접점, 뇌격은 기존 세로 백색 접점을0.18초 표시한다. 실제 치명은 기존 치명 접점에 맡겨 중복하지 않는다. lethal도 HP 감소 사건이 있어 표시되지만 빗나감/공중·차단/반복틱/구저장 버프로 재생하지 않는다.
- 겹치는32px 셀당1개·신규 최대4개, 기존 utility 총12개 한도 안에서 기존 시전/착탄·흡수/종료 FX를 먼저 보존한다. 남은 슬롯은 실제 피해가 큰 접점을 우선하고 원래 그리기 순서는 유지한다. 화면 흔들기/히트스톱/새 적 움찔을 추가하지 않아 1초 피격 모션 제한과 별개다.
- `utilityFrostHit`는 실제 서리 명중이 있는 프레임에만 한 번, `utilityGaleBreak`는 실제 질풍 탄 소거가 있는 프레임에만 한 번 재생한다. 빈 서리에는 새 명중음이 없고, 기존 뇌격 착탄음은 적이 피했어도 지면 낙뢰로 유지한다. 기존 질풍 소거 파편에 같은 연녹 접점 도형을 재사용한다. guardian 실제 흡수음과 모든 기존 시전/경고음은 유지한다.
- game.update는 새 명중 결과만 사용하며 방 전환 스텝에는 이전 방 접점/음을 넣지 않는다. combat/tickUtilityCast/consumeGaleProjectile의 피해·범위·0.65초 지연·둔화·소거2회·소모/쿨다운, 저장·랭킹 형식은 변경하지 않았다.

관련6회귀는 작성만 했다(실제 서리 성공/공중 제외·반복 없음, 실패/치명 중복, 4개/셀·입력 불변, 전체 예산/시전 보존, 대표음, Canvas 일반·완화 복원). PCM QA 목록에 신규2큐를 추가해29개 준비했으나 아직 실행하지 않았다. 다음 배포 지시 때 누적 전체·실스킬 성공/실패·다수 적·치명·질풍2소거/특수탄 제외·저장/방전환·경고동시/음소거·모바일/완화/부하를 검증한다. 현재 체감 개선·사람 청취/실기기 검증 완료로 표시하지 않는다.

네 주력 속성의 투사체 잔상과 명중 효과를 레벨·진화별로 구분했습니다. 화염·독·번개는 1~3레벨, 서리는 1~4레벨을 표현하고, 각 속성의 두 진화까지 총 21개 상태를 비교 검증합니다.

- 레벨: 잔상 조각과 명중 파편의 수가 증가합니다. 2레벨부터 중심선이 선명해지고, 3레벨 이상은 보조 잔상이 붙습니다. 서리 4레벨에는 추가 결정 무늬가 생깁니다.
- 화염: 확산 폭발은 갈라지는 불씨, 응축 폭발은 밝게 모인 중심선과 타격 중심으로 구분합니다.
- 서리: 깊은 서리는 각진 결정과 마름모 타격, 잔류 서리는 이어지는 작은 눈꽃으로 구분합니다.
- 독: 잔류 독은 이어지는 방울과 기포, 맹독은 보라색 보조 잔상과 밝은 녹색 중심으로 구분합니다.
- 번개: 집중 방전은 굵은 황백색 전격, 번개 그물은 교차하는 잔상과 실제 전이 경로의 겹선으로 구분합니다. 없는 대상에 가짜 연결선을 만들지 않습니다.

투사체의 명중부 크기·히트박스·공격 범위·피해·속도·상태 이상은 그대로입니다. 범위 표시에는 기존 실제 반경을 사용하고, 성장 장식은 잔상과 짧은 국소 타격 효과에만 적용합니다. 파편은 효과당 최대 12개, 동시 명중 효과 48개 제한을 유지합니다.

`skill-visuals.js`는 현재 플레이어의 스킬과 진화를 읽습니다. 기존 저장의 투사체에 새 필드를 요구하지 않으며, 명중 효과에는 그 순간의 단계만 복사하므로 이후 강화가 이미 발생한 타격 표현을 바꾸지 않습니다. 일시정지 중 프레임은 고정되며 전투 난수를 사용하지 않습니다.

검증: 전체 테스트 293개 통과. `tools/skill-growth-qa.mjs`로 21개 상태가 구분되는지, 일시정지 이미지·Canvas 상태·전투 데이터가 유지되는지 확인했습니다. Edge 1280×800과 844×390에서 8개 진화 각각, 390×844에서 속성별 1개 진화를 실행해 총 20개 전투 조합의 브라우저 오류가 없었습니다. 실제 iPhone Safari 확인은 별도로 필요합니다.
