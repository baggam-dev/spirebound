## 차별이 약한 실제 원인
`upper-floors.js`에서 일반 성운기사/망령근위병은 같은 slash 선택·155px 도달거리·.25초 예고를 공유하며, 균열사냥꾼도 blink 뒤 같은 slash다. 일반 별자리저격수는 fan, 인력술사 하강형/운반체/포탑은 ring을 공유한다. `simulation.js`의 공통 enemy-melee가 악마병사·부대장의 밀착 공격을 먼저 처리해, 병사의 기존 베기나 부대장의 돌진이 가까이서는 일반 근접처럼 보일 수 있다. 성운기사의 전방 피해 감소(.65)는 이미 존재하므로 새 능력인 것처럼 중복 추가하지 않는다.

악마사수·폭렬박쥐·가시핵은 현재 역할을 우선 유지하고 예고/효과를 맞춘다. 이미 다른 저격수와 같은 새2점사격을 모두 복제하지 않는다. 시련/정예/하강도 같은 종류의 행동 정체성을 유지하며, 추가 탄 수/연타 수를 무조건 늘리지 않는다. 칼드·베라·기존 보스는 일반몹 변경이 자동으로 덮어쓰지 않도록 분리한다.

## 통합 가독성·난이도 규칙
- 피해를 주기 전 실제 영역과 일치하는 예고. 도착/연계/두번째 발사도 별도 예고. 이미 조준을 고정한 뒤 플레이어를 다시 따라 휘지 않는다.
- 각 연계의 다음 단계까지 기존 공유 예고 예산에 포함한다. 인력장·찌르기·포탑 축으로 모든 회피 공간이 닫히지 않도록 동시 조합을 확인한다. 보스 예외를 일반몹까지 확대하지 않는다.
- 두 동작을 붙이면 총 주기와 회복도 함께 배분한다. 피해량/체력을 먼저 상향하지 않는다. 짧은 재사용 시간이나 연속 흡입으로 난이도를 올리지 않는다.
- 연계 중 사망/동결/벽 가림/방 이동/저장 재개를 명시적으로 처리한다. 공통근접이 새로운 고유 패턴을 가로채지 않도록 종별 진입점을 분리한다.
- 시각 우선순위는 실제 공격/지면 경계 → 몸체 → 위상 표식 → 소품 → 바닥. 캐릭터와 오라는 분리, 배경 장식은 공격처럼 빛내지 않는다.

# 고층 비주얼 2차 검토 — 2026-10-22

사용자 요청: 군집 AI 후속과 함께 고층 비주얼 2차 개선. 현재 **검토·시안 준비 단계**, 디자인 승인 전 런타임/배포 자산 미수정. 테스트·배포 권한으로 확대하지 않는다. 군집 AI 로컬 커밋3fe6ffa는 미검증·미푸시이며 운영은0.45 그대로다.

## 기존 환경 확인
7·8층은 같은 몰락한 왕국, 9·10층은 같은 마족 점령 영역이다. `upper-hall-art.js`가 두 atlas와 층별 작은 장식을 담당한다. 실제 기존 화면 자료는 `docs/qa-environment-pixel-20261019/public-floors/floor-7-844.png`와 `floor-10-844.png`이며, 10-19 당시 자료로서 현재 새 브라우저 검증이 아니다.

현재 바닥은3개 프레임을144×96 단위로 반복한다. 공통 `environmentMaterial`은 벽/바닥을 같은 승인 reference의 일부로 재질화하고 색·명암을 크게 압축한다. 이는 시인성을 위한 기존 개선이나, 고층 고유 문양과 소재의 차이를 약하게 만들 수 있다. 실제 자료에서도 사각 타일 격자가 먼저 보이고 작은 장식은 잘 구분되지 않는다. 2차에서는 밝기나 도트 크기를 무작정 키우기보다 **재질 안의 낮은 대비 변화와 주변부 실루엣**을 개선하는 편이 적절하다.

## 환경 우선일 경우 제안
- 7·8층: 청회색/보랏빛 석재, 퇴색한 자주색 왕실 천, 탁한 황동. 7층은 부서진 천체 장치/별 부조, 8층은 금이 간 왕관 부조·무너진 기둥과 찢긴 왕실 장식. 같은 건축 양식을 유지한다.
- 9·10층: 잿빛 현무암·그을린 무쇠. 마족 침식은 벽의 틈새와 가장자리 소품에서 표현하고, 바닥 전체를 붉게 빛내지 않는다. 9층은 파손된 군단 장비, 10층은 상단 벽 파열과 가장자리의 침식 흔적. 최종 악마 몸체가 나오는 상단 중앙 여백은 보존한다.
- 불규칙한 판석·칩·모서리 결손을 선명한 작은 픽셀 군집으로 표현하되, 이미 줄였던 과도한 블록 도트와 검은 격자 대비로 돌아가지 않는다. 실제 게임 960×540 및 공통2px 표면 기준으로 구현할 수 있는 밀도로 시안을 제한한다.
- 전투 중심은 비운다. 공격 예고/독장판/광포화와 오인할 빛나는 원·긴 붉은 균열·안개를 바닥에 그리지 않는다. 파티클·천 흔들림·벽 틈의 빛은 별도 레이어로 계획한다.
- 현 방/문의 위치, 기존 랜덤 장애물 충돌과 파손 형상·시설 좌표를 유지한다. 시안의 소품 배치를 그대로 모든 방에 강제하지 않는다.
