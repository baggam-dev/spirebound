# 플레이 피드백 9 — 방 형태 다양화

- 새 도전의 일반 방에 기본형·세로형·가로형·좁은형을 무작위 배정한다. 실내 벽이 실제 이동·탄환·시야 판정에 참여한다.
- 화면 크기와 출입구 위치는 유지하고 방 안쪽 벽으로 전투 공간을 조정한다. 네 방향 연결 통로와 기존 상자·제단·샘물 접근 공간을 보장한다.
- 보스룸·7층 문지기방·튜토리얼 제외. 벽과 겹치거나 너무 붙는 기존 장애물을 제거하고 적 생성 위치를 안전한 위치로 보정한다.
- 방 형태와 벽은 저장되어 하강·재접속 시 동일하다. 기존 저장에는 벽을 추가하지 않는다. 새로운 방 형태는 새 도전부터 적용된다.
- 기존 전체 테스트 317개 및 신규 형태·통로·저장/하강 회귀 검사 2개 통과. 기존 적 배치·출입구별 진형·저장 검증도 통과.
- Edge 4개 형태 갤러리 및 4개 PC·모바일 크기 게임 실행 확인, 오류 없음. 실제 아이폰 검증 미실시.
