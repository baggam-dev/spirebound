# 캐릭터·월드 픽셀 디테일 개선

## 표현 변경

- 주인공: 후드, 목도리, 망토, 화살통, 가죽 벨트, 부츠, 활을 층별로 그립니다. 이동 거리에 따른 발 교차와 망토 흔들림, 대기 호흡, 실제 공격 쿨다운 재설정에 맞춘 활 반동을 추가했습니다. 발사 직후에는 화살의 좌우 방향을 바라봅니다.
- 일반 적: 궁수의 활, 돌진병의 뿔과 도끼, 산탄병의 총구, 추격자의 검, 하강 적의 붉은 장비를 구분했습니다. 거인의 장갑·망치, 레이저·반사병의 금속 패널도 보강했습니다.
- 보스: 수호자의 층진 갑옷과 망치, 프리즘의 결정 면과 공전 파편, 슬라임의 명암·왕관·호흡, 모르도의 왕관·흉갑·흔들리는 망토를 보강했습니다. 상층 기사와 사수·마법사·포탑에도 재질 디테일을 추가했습니다.
- 맵: 바닥 균열과 석재 흔적, 벽 기둥, 움직이는 횃불, 문틀과 봉쇄 장식, 계단 난간을 추가했습니다. 장애물의 외곽과 통행 판정은 기존 값을 사용합니다.
- 오브젝트: 바위의 균열과 이끼, 책등의 금박, 탁자 위 촛불, 상자의 경첩·잠금장치, 신전의 보석, 샘물의 반짝임을 추가했습니다.
- 스킬: 진행 방향으로 회전하는 화살, 화염 꼬리, 서리 결정, 독 방울, 번개 잔상, 타격 파편과 굴절된 연쇄선을 추가했습니다. 화염 장판·빙결·독 상태, 자동 석궁과 요정도 보강했습니다.

## 구조와 호환성

`pixel-world.js`는 Canvas 표현 전용 모듈입니다. 이동/발사 애니메이션 이력은 WeakMap에만 보관하고 게임 상태, 저장 형식, 전투 난수에 기록하지 않습니다. 시간 기반 효과는 도전의 `elapsed`를 사용하므로 일시정지 시 멈춥니다. 공격력·공격 주기·히트박스·공격 예고·보호막·보스 패턴은 변경하지 않았습니다.

기존 런타임 JavaScript 자동 수집 규칙으로 배포 패키지에 포함됩니다. 별도 이미지 다운로드나 외부 라이브러리가 필요하지 않습니다.

## 검증

- `node --test`: 기존 전체 테스트 283개 통과.
- `tools/pixel-world-qa.mjs`: Edge에서 보스 테스트 5종을 실행하고, 1280×800 / 844×390 / 390×844 / 667×375 화면을 확인합니다. 실제 iPhone Safari의 성능과 터치 감각은 실기기 확인이 필요합니다.
- 시각 검사: 캐릭터·보스·속성·오브젝트 갤러리 및 실제 전투 화면을 캡처합니다.
- 렌더러 검사: 동결된 상태를 변경하지 않는지, Canvas 변환을 복구하는지, 걷기·발사 프레임 변화와 일시정지 프레임 고정을 검증합니다.

실행 시 `PLAYWRIGHT_PATH`에 Playwright 패키지 디렉터리, `SPIREBOUND_URL`에 개발 서버 주소를 지정하고 출력 디렉터리를 인자로 전달합니다. QA는 격리된 브라우저 컨텍스트를 사용합니다.
