# 통합 순위 4번: 정밀 사격과 유틸 액티브

2026-09-30 구현. 기존 설계 판단은 [skill-expansion-review.md](skill-expansion-review.md), 전체 순서는 [integrated-improvement-priorities.md](integrated-improvement-priorities.md)를 따른다. 운영 배포·공개 QA 완료 여부와 릴리스 ID는 [WORK_STATUS.md](WORK_STATUS.md)가 기준이다.

## 플레이 규칙

- 메인 `정밀 사격`은 화염·서리·독·번개와 같은 첫 선택 슬롯을 사용한다. 일반 화살의 주탄 직격만 표식을 쌓는다. 같은 적을 4초 안에 세 번 맞히면 세 번째가 강화되며, 적마다 단계가 따로 유지된다. 갈래 부탄·연속탄·유도탄·석궁은 표식을 쌓거나 소모하지 않는다. 일반 방어 수치를 만들거나 프리즘 보호를 우회하지 않는다.
- 메인 2레벨은 직접 피해를 높이고, 3레벨은 `집중 저격`(2회 주기 강화탄) 또는 `결정 사격`(체력 35% 이하 추가 피해)으로 분기한다. 전용 보조 `약점 추적`은 표식 유지 중 직격, `마무리 조준`은 체력 35% 이하 직격을 높인다. 정밀 빌드의 초반 2~3레벨 후보에는 두 보조 중 하나가 없을 때 `약점 추적`을 보장한다. 다른 메인에는 둘 다 나오지 않는다. 기존 궁극기 5·10레벨 보장은 그대로다.
- 4레벨에는 성장 3장과 별도로 유틸 3지선다를 한 번 선택한다. 슬롯은 1개이고 바꿀 수 없다. `전투 집중`: 5초간 플레이어 기본 화살 직격 20%·발사 속도 약 11% 증가, 재사용 25초. 속성 장판·궁극기·석궁·유도탄은 피해 증가 대상이 아니다. `응급 처치`: 적과 140px 이상 떨어져 있을 때 1하트, 층당 1회, 재사용 20초. `수호 환영`: 5초 내 다음 유효 피격 1회 차단, 재사용 25초. 환영은 적·지형에 충돌하지 않고 보스 패턴을 끊지 않는다. PC G/모바일 유틸 버튼으로 사용한다.
- 표식 단계는 적 체력바 위 작은 점, 강화탄은 짧은 타격 문구로 구별한다. 버프/환영은 영웅 주변에 연한 색 차이를 준다. 모바일 액티브는 기존 조작 영역에 배치했다.

## 저장·랭킹

- 유틸 종류·남은 시간·쿨다운·층당 회복 사용, 탄환의 주탄/버프 상태와 적의 표식은 저장/재개된다. 이전 저장의 무기 스냅샷은 새 필드가 없어도 읽힌다. 4레벨 이상 옛 저장에서 유틸을 아직 고르지 않았다면 이어가기 때 별도 선택이 나온다.
- 새 도전은 기본 `BETA-3/ranking-v7`, 확장 `ASCENT-5/ranking-v8`, 게임 버전 `0.32.0-prebeta`. 이전 BETA-1/2·ASCENT-1~4 기록은 조회만 가능하다. 과거 시즌 저장은 이어갈 수 있으나 종료 시즌에 새 점수를 등록하지 않는다. API는 새 `precision` 빌드를 받는다.
