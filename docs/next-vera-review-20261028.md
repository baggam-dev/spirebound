# 다음 개선 점검: 베라의 외형 구분
2026-10-28. 이번 배포 범위는 기존 칼드·베라 외형의 크기 조정과 전투 수치이며, 아래는 후속 디자인 검토만이다. BGM은 보류한다.

- 사용자는 비교 그림의 베라가 주인공처럼 보인다고 지적했다. 실제 코드를 확인한 결과 gateTitle이 있는 astralSniper는 feedback-named-brute-v1.png의 둘째 줄을 사용한다. 이 기존 원화도 금발·보라 스카프·활을 든 주인공과 유사하다. 이전에 ‘시안만 잘못됐으며 실제 베라 원본은 다르다’고 한 답은 확인 없이 단정한 오류였다.
- 다음에는 기존 원화·주인공 및 일반 별자리 저격수·군단장 벨카르를 함께 비교하고, 4~5등신과 현재 활 역할을 유지하면서 실루엣·장비·색감으로 베라를 구분하는 한 캐릭터 시안 패키지를 제안한다. 움직이는 오라는 별도 이펙트로 유지한다.
- 캐릭터 디자인 변경은 시안을 직접 보여주고 승인받은 뒤 반영한다. 실제 런타임 원본·현재 시안·프롬프트는 보존하며, 승인 전 런타임 PNG를 교체하지 않는다. 이전 이름·대사·AI·보상은 새 디자인 확인만으로 변경하지 않는다.
- 그 다음은 플레이 후기에 따른 고층/하강 전투 난이도와 보상 수치 조정이다. 사용자 실기 장기 플레이 자료가 없으므로 0.47의 적정 난이도를 확정하지 않는다.
