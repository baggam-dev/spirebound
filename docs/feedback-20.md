# 0.20 전투·보상방·정수 HUD

## 적용 규칙

- 반사탄 피해: 2하트 → 1하트. 탄속과 반사 횟수 유지.
- 모든 지상 몬스터 접촉: 1하트. 공격 피해와 피격 무적 0.65초 공유. 점멸 무적·공중 몬스터·생성 보호 시간에는 접촉 피해 제외. 돌진과 내려찍기는 기존 공격 피해 유지.
- 등반은 전멸 후 문과 계단 개방. 신전은 주술 선택까지 완료해야 개방. 하강은 생존 몬스터와 관계없이 이동 가능.
- 입장 보호 0.6초와 입구 근처 몬스터 재배치. 잠긴 방에는 남은 적 표시.
- 샘물방의 25%에 상자 추가. 복합방은 일반방 개체 수와 편성을 사용한다.
- 단독 샘물방: 30% 무전투, 70% 1~3마리. 샘물과 상자는 전멸 후 사용하며 각각 사용 상태를 저장한다. 상자 함정이 발생하면 다시 전투한다.
- 독 1레벨 중첩당 기본 초당 피해 4 → 4.8, 3초 총 피해 12 → 14.4. 2·3레벨과 독가스 피해 유지.
- 시련: 3층 3마리, 5층 5마리. 5층 개별 체력 15% 감소. 같은 종류 최대 2마리, 배치 분산과 첫 공격 시차 적용.
- 정수 HUD: 유물 아래 종류별 아이콘·누적 개수·효과 설명. 궁극기 정수 3개는 곱연산 기준 27.1% 감소로 표시한다. 최종 궁극기 재사용 시간에는 기존 최소 시간 제한이 계속 적용된다.
- 앞서 수정한 꽃 장판의 벽·모서리 조준과 몬스터 독의 보라색 효과 유지. 플레이어 독은 초록색이다.

## 저장 호환

기존 지도와 능력치는 유지한다. 새 샘물 구성은 새 도전부터 적용된다. 전투와 출구 규칙은 이어하기에도 적용된다. 과거 저장은 정수 획득 개수를 기록하지 않았으므로 HUD 개수는 이번 버전 이후 획득분부터 집계한다. 능력치에서 개수를 추정하지 않으며, 기존 정수 효과를 재적용하지 않는다. 이미 시작한 시련의 몬스터 수와 체력은 유지된다.

## 검증

- 자동 검사 185개 통과. 모든 적 종류 접촉, 공중 제외·무적, 반사탄, 문·계단 잠금, 방 생성 분포, 복합 보상 개별 저장, 층별 시련 수·중복 제한, 정수 저장·효과 표기 포함.
- 브라우저에서 정수 HUD와 27.1% 설명, 복합방 상자 개봉 후 샘물 유지 확인. 오류 로그 없음.
- 보스 3종 및 하강 각각 120초 시뮬레이션과 저장 재개 검사 통과. 실제 체감 난이도는 플레이로 평가해야 한다.

## 보스·귀환 추가 조정

- 프리즘 첫 수호자 소환 3초, 이후 10초 유지. 살아 있는 소환 수호자가 있으면 본체가 받는 직격·속성·지속·오라·궁극기 피해를 1/3로 제한한다. 여러 수호자가 있어도 중첩되지 않으며 마지막 수호자가 죽으면 즉시 해제한다. 보라 보호막·연결선·피해 안내 표시.
- 큰 슬라임은 첫 공격부터 독장판을 사용하고, 소환 패턴에도 장판을 추가했다. 기본 공격 간격 2.89초 → 2.21초. 작은 슬라임 소환 유지.
- 6층 보스방의 7층 계단은 부서진 도트 그래픽으로 표시한다. 클리어 후 보스 유물함을 따로 표시한다.
- 최종 클리어 시 유물 줄에 탈출 열쇠 표시. 큰 열쇠와 하강 목표 안내 화면에서 전투를 멈추고, 귀환 시작 버튼으로 재개한다. 열쇠는 기존 key 저장 상태를 사용하며 유물 슬롯을 소비하지 않는다.
- 자동 검사 190개 통과. 브라우저에서 실제 최종 클리어 이벤트와 열쇠·귀환 안내를 확인했다. 이미 진행 중인 소환 시계는 저장된 남은 시간을 유지한다.
