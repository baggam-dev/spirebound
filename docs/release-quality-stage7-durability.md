# 7번 셋째 단위 — 저장·재개 내구성

## 변경 범위
- 시작 화면에 자동 공격과 브라우저별 진행 저장을 짧게 알린다. 모바일 가로처럼 높이가 430px 이하인 화면에서는 기존 버튼 공간을 위해 보조 문구를 숨기고, 도움말에서 같은 내용을 볼 수 있게 한다.
- 도움말의 PC/모바일 입력, 이어하기, 약 2초 자동 저장, 일시정지·화면 크기 변경 동작을 현재 코드에 맞춘다. 이전의 개별 경고음 해제 안내는 현재 효과음 설정으로 고친다.

## 자동화 검사
- `PLAYWRIGHT_PATH`를 설정하고 `node tools/qa/durability-qa.mjs`를 실행한다. 기본 지속 시간은 **실제 경과 31분**이다. 짧은 진단용으로만 `SPIREBOUND_DURATION_MS`를 바꿀 수 있다.
- 로컬 Edge 헤드리스 1280×800의 저장된 도전을 이어가고, 비전투 방에서 게임 루프와 약 2초 자동 저장을 유지한다. 수동 일시정지, 다른 탭 전환 처리, 새로고침·이어하기, 가로/세로 뷰포트 변경, 입구 복귀·이어하기를 각 단계에서 검사한다. 같은 도전 ID·저장 시간 증가·일시정지 중 시간 불변·페이지 오류 0을 확인한다.
- 헤드리스 Edge의 다른 탭 전환은 원래 탭에 `blur`를 전달하지 않을 수 있어 자동화가 `blur` 이벤트를 명시 호출한다. 이는 앱의 배경 전환 처리 경로 검증이며, 실제 사용자 기기의 백그라운드/회전·발열·체감 프레임 검증은 아니다. 비전투 방 검사도 장시간 고부하 전투 성능을 대표하지 않는다.

## 결과
- 90초 예비 검사: 전환 5종·저장/재개·페이지 오류 0. 모바일 에뮬레이션 가로→세로→가로 및 새로고침 재개도 오류 0.
- `node --test`: 403개 통과. 시작 화면 신규/저장 PC·모바일 에뮬레이션 10화면 잘림·버튼 가림·페이지 오류 0.
- 실제 경과 31분 검사: 1,860,079ms(31분 0.079초), 게임 진행 1,855.27초(30분 55.27초). 저장 ID 유지·전환 단계 5종·페이지 오류 0, 검사 종료 코드 0. PC 헤드리스 Edge 비전투 방 자동화 결과이며, 별도 90초 검사에서 모바일 에뮬레이션 회전·재개를 확인했다.
