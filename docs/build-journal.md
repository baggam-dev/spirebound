# Spirebound 구축일지 — 베타 준비

## 2026-09-08 · 착수

사용자 요청: 앞으로 약 2시간 직접 확인이 어려우므로 4층을 유지하고, 기존 방향 안에서 베타테스트 직전 품질을 목표로 자율 개선. 디자인 연출보다 시스템 완성도를 우선한다. 구축일지는 Google Drive에도 중간 갱신한다.

현재 기준: 0.8, 4층 왕복, 하트 체력, 성장 지연, 보호막·회복 제한, 일반 적 강화. 기존 자동 검사 42개 통과. 실제 모바일/전체 난이도 플레이 검증은 완료되지 않았다.

이번 점검 우선순위:
1. 저장 검증, 사망 처리, 중복 탭, 상태 보존 및 중단/복귀.
2. 투사체 판정·방 이동·접촉 피해·고정 시간 진행 등 전투 정확성.
3. 모바일 입력/화면, 조작 설명, 개인 기록과 테스트 진단.
4. 재현 가능한 시뮬레이션과 검증 기록. 자동 결과를 사람의 플레이 품질 검증과 구분한다.

아직 위 개선이 완료되었다는 의미는 아니며, 아래에 완료 항목과 근거를 추가한다.

## 중간 기록 1 · 전투와 저장 기반 분리

완료 및 검사:
- simulation.js로 전투 계산을 분리. 직선 투사체의 연속 충돌 검사와 가까운 적 우선 충돌, 엄폐물 앞/뒤 판정, 사망 직후 회복으로 부활하는 순서 문제를 수정.
- 60Hz 고정 시뮬레이션. 큰 화면 응답 지연 시 자동 정지. 방 진입 시 이전 방문의 공격 예고를 정리하고 0.6초 도착 시간을 둠.
- 저장에 현재 방 투사체와 공격 상태 포함. 검증·체크섬·정상 백업·종료 표식 추가. 체크섬은 손상 확인 용도이며 부정행위 방지 기능이 아님.
- 동일 저장을 여러 탭에서 쓰지 않도록 Web Locks와 폴백 실행 잠금 추가.
- 도움말, 최근 개인 이력 조회, 진단 JSON 내보내기, 저장 실패 표시 추가. UI 연결은 완료했으나 모바일 화면 검증은 다음 단계.
- 로컬 서버는 게임 파일만 제공하고 저장소 내부 파일은 제공하지 않도록 제한.
- 자동 검사 54개 통과. 저장 후 동일 전투 진행, 손상 백업 복구, 종료 저장 복구 차단, 전투 판정 포함.

Drive 업로드는 처음에 폴더 공개 범위 미확인으로 자동 검토에서 거부되었으나, 실제 대상이 공유되지 않은 소유자 전용 내 드라이브임을 메타데이터로 확인한 뒤 동일 업로드가 승인되었다.

남은 작업: 입력/모바일 화면 검증, 추가 상태 경계 검사, 재현 가능한 자동 전투 실험, 문서 정리. 사람에 의한 4층 전체 플레이 검증은 아직 미실시.


## 2026-09-09 · 0.10 전투 성장 재조정 및 6층 확장

사용자의 새 플레이 피드백에 따라 기존 4층 유지 제한을 해제하고 6층으로 확장했다. 디자인 고도화는 보류하고 적 식별과 공격 예고에 필요한 최소 그림만 추가했다.

구현 완료:
- 공속 증가율 20%→10%, 추가 화살 피해 45%, 연쇄번개 30%에서 시작해 전이마다 55%씩 감쇠. 화상·폭발·조합 및 새 장비 보상도 축소.
- 일반 탄 수 기본 3→5(궁수), 6→10(산탄), 1→2(반사). 층별 탄 속도·개수·휴식 조정. 돌진 준비 0.32초, 레이저 폭 30.
- 역할 조합 기반의 방 구성과 5~6층 꽃봉우리. 고정 위치, 착탄 예고, 포물선, 2초 장판, 기존 장판 종료 후 재발사. 광폭 2~3개.
- 기존 보스 체력 1.5배, 탄 수 2배 이상 및 휴식 절반. 파수꾼 십자포화와 프리즘 회전 결정 연사 추가.
- 6층 분열 슬라임: 900→450×2→225×4, 독안개/투척 장판/미니 소환. 2단계까지만 소환, 보상 없는 미니 최대 8마리. 모든 분열체 처치 후 잔여 공격 정리 및 열쇠 지급.
- 귀환 광폭 1~6단계. 방당 적 8~9에서 13~14까지, 하강할수록 체력·탄 수·속도 증가와 휴식 감소. 기존 보스 재생성 없음.
- 2·4층 기존 저장의 지도와 진행 유지. 새 도전만 6층. 기존 보스 체력 보정은 비율 유지 및 중복 방지.

검증:
- 자동 검사 67개 통과. 신규 분열/독/전이 감소/층별 공격/귀환/저장 호환 포함.
- 보스 3종과 광폭 장면 각각 120초 CPU 시뮬레이션 및 주기적 저장 재개 완료. 최대 170개 동시 탄환. 렌더링 성능이나 인간 플레이 검증은 아님.
- 별도 QA 주소에서 슬라임과 독 꽃봉우리 화면 실행. 자바스크립트 오류 없음. 화면 검사 중 발견한 5~6층 이름 누락과 이전 버전 표시를 수정.
- 실제 플레이 주소에서 신규 poison.js와 6층 버전 HTML 제공 확인.

남은 확인: 사용자의 6층 왕복 체감 난이도, 후반 스킬 빌드별 격차, 실제 모바일 장치 성능. 수치는 첫 조정안이며 인간 플레이로 검증되었다고 주장하지 않는다.


## 2026-09-09 · 0.11 선택 시스템 첫 구현 완료

사용자가 보물 선택·스킬 분기·정예·이벤트·귀환 경로의 다섯 제안을 모두 승인하여 6층을 유지한 채 구현했다. 상세 기획은 docs/choice-systems.md에 작성했다.

- 보물 3택과 일반 기술 6종의 2분기, 궁극기 즉시형/영역형을 구현. 선택은 저장하고 가방/종료 기록에 표시한다.
- 정예 3특성(지연 폭발, 주변 피해 경감, 추가 사격), 체력 1.4배, 확정 물약 1개. 예고와 보상 중복 방지 포함.
- 이벤트 방: 체력 계약, 인장 거래, 선택형 시련. 비용 부족 시 선택 불가. 시련 이탈/복귀와 보상 대기 상태 보존.
- 신규 지도에 고리형 우회로. 귀환 위험 구역에 정예, 우회 구역은 적 수 60%. 방문한 방만 이용한 최단/위험 회피 경로 비교 및 미니맵 표시.
- 브라우저로 보물→기술 선택, 분기→가방 기록, 귀환 경로 비교, 이벤트 비용 표시 확인. 세로 화면 선택창을 넓혀 세 가지 비용/보상을 한 화면에서 읽도록 수정.
- 자동 검사 80개 통과. 새 지도 40개 × 6층의 별도 위험 회피 경로, 시련 이탈, 중복 보상, 저장 복귀 등 포함.
- 보스 3종 및 광폭 구간 각각 120초 CPU 시뮬레이션 재실행 완료. 인간 플레이·실기기 FPS 검증은 아님.

기존 저장의 지도·진행은 유지. 새 이벤트/편성/우회로는 새 도전에서 확인한다. 다음 실제 플레이에서는 보물 선택 편중, 분기 효율, 정예 물약 수급, 우회로 선택 가치를 평가한다.


## 2026-09-09 · 0.12 유물과 원정 기록

사용자의 다음 버전 자율 기획/구현 요청에 따라 6층과 기존 난이도 방향을 유지하고 보스 보상·전투 이해·재도전을 확장했다.

완료:
- 장착 1개 제한의 유물 5종. 중간 보스 처치 시 빌드 조건에 맞는 최대 3개 선택, 교체 또는 포기. 후보 고정 저장 및 재사용 대기 초기화 방지.
- 원정 도감: 만난 적만 공격 설명 공개, 처치와 정예 특성 기록. 현재 도전의 관찰을 기록하며 과거 내용을 임의 추정하지 않음.
- 최근 피격 10건 및 층별 시간/피해. 무적 중 무시된 공격 제외, 보호막 방어 구분, 마지막 실제 피해 원인을 종료 화면/개인 이력에 표시.
- 0.12 새 도전의 종료 화면에서 같은 지도 재도전. 체력·장비·유물·기술·시간은 초기화.
- 기동 사냥 이동속도 보너스의 세로축 누락 수정. 중복 시작 방지와 저장 직전 폴백 잠금 확인. 화상·궁극기 피해 진단 집계 보완.

검증:
- 자동 검사 91개 통과. 유물 선택/교체/저장, 도감 비공개 범위, 치명타 기록, 최근 이력 상한, 이동 대칭 및 피해 집계 포함.
- 별도 QA 브라우저에서 철의 부적 장착 후 보호막 27초/회피 25초 확인. 사망→원정 기록→결과 복귀→같은 지도 재도전의 정상 연결 확인.
- 보스 3종과 광폭 구간 각각 120초 CPU 시뮬레이션 재실행 및 저장 재개 확인. 최대 170개 탄환. 브라우저 FPS나 인간 플레이 밸런스 검증은 아님.

상세 문서: docs/relic-expedition.md. 다음 실제 플레이에서 유물 선택 편중과 2·4층 이후 난이도, 원정 기록의 설명력을 평가한다.

## 2026-09-09 · 0.13 화염/독 전투 개편

사용자 플레이 후기의 다섯 항목을 반영했다. 6층 구성과 기존 성장 속도를 유지하면서 원소 기술 역할을 분리했다.

완료:
- 3층부터 일반 전투 방의 정예 확률 40/58/76/94%, 5~6층 두 번째 정예 확률 15/35%. 기존 지도는 재추첨하지 않음.
- 시련은 보라색 용사 3마리, 일반 체력 2.8배, 탄속/추가탄/회복 간격 강화. 처치 후 보상 한 번과 이탈 후 체력 보존 유지.
- 갈래 화살은 총 발수를 유지하면서 중앙 기본탄을 항상 발사. 짝 없는 추가탄은 사격마다 좌우 교대.
- 화염 화살: 즉시 폭발, 2레벨 짧은 중첩 화상, 3레벨 짧은 원형 화염 장판. 레벨별 범위·피해 증가 및 2분기 재설계.
- 독 화살 신규: 녹색 탄환과 중첩 표시, 2중첩 이상 독가스, 3레벨 독 처치 시체 폭발. 중첩당 피해·가스 범위 성장, 2분기 제공.
- 원소 효과는 중앙탄 첫 적중에만 발동. 겹치는 가스/장판은 가장 높은 피해 하나만 적용하고 시체 폭발은 각 시체당 한 번. 화상 6/독 8중첩 상한.
- 기존 불씨 화살 레벨·분기·대기 중 후보는 독 화살로 일회 이전. 지도/체력/아이템/기술 투자 총합과 궁극기 조건 보존. 새 효과와 사격 교대 저장 검증 추가.

검증:
- 자동 검사 102개 통과. 원소 레벨/타이머/중첩 상한/가스 범위/직격 사망 제외/시체 연쇄/관통 제한/이전 호환/시련/층별 빈도 포함.
- 별도 QA 브라우저에서 화염 장판, 녹색 독가스, 보라색 시련 용사 3마리 표시 확인. 세 장면 오류 로그 없음. 실제 플레이 저장과 다른 포트 사용.
- 원소 및 화살 기술 만렙·적 32마리로 120초 CPU 시뮬레이션, 저장 재개 6회 통과. 최대 장판 4개/독 7중첩. 인간 밸런스 또는 실기기 FPS 검증은 아님.

상세 수치: docs/elemental-rework.md. 압박 검사: docs/qa-elements.json.
다음 플레이: 화염의 군집 처리 대 독의 장기전 가치, 3층 이후 정예 물약 수급, 소수 시련의 체감 난이도 확인. 서리/연쇄 번개 자체 수치는 이번에 추가 상향하지 않고 화염/독 피드백을 먼저 받는다.

## 2026-09-09 · 0.14 메인/보조 트리와 빙결

플레이 후기의 메인 단일 선택/보조 조합, 화염 하향, 서리 빙결을 구현했다.

- 메인 4종(화염/서리/독/번개): 첫 기술에서 하나를 선택하고 이후 다른 메인 습득 차단. 메인 강화 및 보조 후보만 제시.
- 보조 7종: 갈래/관통/공속/공격력/연속탄/근접 오라/유도. 갈래·연속탄 추첨 가중치 0.18, 유도 0.04, 일반과 메인은 1. 실제 등장률은 남은 후보에 따라 변동.
- 갈래의 추가탄도 45% 피해로 주력 속성 적용. 연속탄은 0.16초 후 같은 방향 한 발, 피해/지속 피해 60%. 유도는 제한된 선회 속도와 벽 차단, 근접 오라는 범위·장애물·공중 여부 검사.
