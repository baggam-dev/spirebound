# 통합 순위 1번: 9층 악마 군단장 개선 (2026-09-30)

## 변경

- 군단장이 플레이어와 190~330px 간격을 맞추며 좌우 측면으로 계속 이동한다. 약 3.5초(2페이즈 2.5초)마다 회전 방향을 바꾸고 벽/장애물 충돌에는 기존 `moveBody`를 사용한다. 기존 정지 위주의 움직임을 줄이되 순간이동 도착 안전 거리와 이동 경계는 유지한다.
- 기존 두/세갈래 빙결 연사, 첫 화살비 9초·이후 20초, 10초 점멸은 유지한다. 여기에 약 5.5초 뒤 첫 고정 조준 저격을 시작하고 0.72초 얇은 예고선 후 빠른 빙결 화살을 한 발 쏜다. 이후 저격 시도 간격은 1페이즈 7.2초/2페이즈 6초다. 다른 동작과 겹치면 직렬 처리하므로 실제 시작 간격은 더 길 수 있다. HP 8500은 우선 유지한다.
- 예고/저격 중 저장과 재개, 기존 ASCENT-1 저장의 새 상태 기본값, 방 재입장 시 예고 초기화, 도감 힌트를 반영했다.

## 고정 조건 전후 비교

`tools/qa/boss-baseline.mjs`의 고정 시드·1/60초·정지/무적/자동사격 **합성 조건**이다. `×2`는 연습 빌드 기본 공격력만 두 배로 한다. 사용자 화염 빌드나 사람이 회피하며 싸운 시간/피격률이 아니다.

| 조건 | 이전 처치 시간 | 현재 처치 시간 | 실제 걷기 거리(점멸 제외) | 현재 공격 시작 수 |
| --- | ---: | ---: | ---: | --- |
| 화염·시드98 | 75.42초 | 88.45초 | 209→2,440px | 갈래35, 저격12, 화살비4, 점멸8 |
| 화염×2·시드98 | 54.80초 | 68.93초 | 139→1,866px | 갈래27, 저격10, 화살비3, 점멸6 |
| 서리·시드98 | 120초 안에 미처치 | 120초 안에 미처치 | 2,355px(현재) | 갈래39, 저격13, 화살비5, 점멸9 |

서로 다른 두 공격이 실제로 시작되며 플레이어가 정지해 있어도 군단장이 방을 횡단한다. 다만 이 도구는 피해량/회피 성공률을 측정하지 못하므로 실제 플레이가 여전히 단조롭거나 피할 수 없이 어렵다면 예고·피격률을 보고 조정한다. 후속 화살비 20초 합의는 유지한다.

## 랭킹·저장 경계

이 변경은 10층 확장 도전의 난이도/점수 비교를 바꾸므로 새 도전은 `ASCENT-2/ranking-v3`으로 분리한다. 8층 `BETA-1/ranking-v1`은 유지한다. 기존 `ASCENT-1/ranking-v2` 기록은 RANK의 종료된 기록 탭에서 읽을 수 있고 서버 DB에서 삭제하지 않는다. 새 시즌 기록과 이전 기록을 혼합하거나 소급 이전하지 않는다.

기존 ASCENT-1 로컬 저장은 식별자를 유지한 채 이어갈 수 있으나 종료된 시즌에 새 기록 제출은 불가하다. 이미 제출된 기록의 응답 유실 재시도는 서버의 기존 영수증 반환 규칙을 유지한다. 새 도전만 새 시즌으로 시작한다. 이행은 서버/클라이언트가 함께 배포돼야 하며 운영 DB에 시험 기록을 등록하지 않는다.
