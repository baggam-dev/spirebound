# 상호작용 연출

- 상자: 성공한 개봉 직후 0.25초 동안 뚜껑이 들리며, 이후 열린 모습 유지. 일반 보상은 금색, 정예·보스 함정은 붉은 파편.
- 샘물: 실제 회복 성공 시 민트색 물방울과 수면 잔상.
- 계단: 이동 성공 후 도착 위치 양옆에 상승·하강 방향 표시. 화면 가림과 입력 대기 없음.
- 파편·방향 표시는 0.9초 이내 종료. `elapsed` 기반으로 일시정지 시 정지하며 WeakMap에 보관하여 저장 데이터에 포함하지 않는다. 현재 방 외 효과는 표시하지 않으며 최대 4개로 제한한다.
- 보상, 회복량, 상호작용 거리, 이동 판정과 저장 로직 유지. 저장에서 복원한 열린 상자는 개봉 효과를 재생하지 않는다.
- 전체 테스트 303개 통과. Edge QA 12개 단계 렌더링의 정지 프레임·상태 불변, 4개 PC/모바일 화면 크기의 실행 확인. 브라우저 오류 없음. 실제 아이폰 검증은 미실시.
