# 0.25 — 편성, 공간, 귀환

## 이번 범위

디테일업 후속 항목 중 방 편성, 7층 관문, 층별 배경, 처치와 탈출 연출을 구현했다. 결과 화면에 기존 빌드·피해 기록과 새 궁극기 피해 기록을 연결했다. 경험치나 스킬 보상의 수치 재조정은 하지 않았다.

## 편성

- 7층: 저격 진형, 인력 사냥, 별의 호위대, 교차 사격, 성운 전열, 별빛 추격대.
- 8층: 위 6종 + 왕실 근위대, 균열 습격대, 마지막 궁정.
- 인력술사/별 운반체는 합쳐 최대 1체. 적 개체수와 기본 층별 체력 공식은 유지.
- 상층 첫 인접 전투방은 일반 적 4체, 2종만 배치해 새 패턴을 소개한다.
- 새 도전에서는 첫 방 입장 시 근접 전열과 원거리 후열을 입구 반대쪽으로 배치한다. 입구 반경 155 확보, 개체 간 최소 48, 장애물과 충돌하지 않는 위치를 선택한다. 재방문 시 위치를 다시 섞지 않는다.
- 하강 시 새 무리만 다시 배치. 1~6층 하강 편성의 30%에 해당 층군의 상층 추격자 1체가 섞인다. 추가 개체 생성은 없다.

## 문지기 관문

- 왕의 방패 칼드 / 별의 눈 베라. 독립 체력바·전용 기둥 배치·봉인 문양.
- 한 체 처치 후 남은 적은 기존 30% 준비 가속과 격노 표시.
- 전멸 후 봉인 해제 문구와 유물함. 기존 보상 1회 및 계단 조건을 유지한다.

## 배경과 연출

- 1~2층 성벽과 병기 문양 / 3~4층 서가와 결정 / 5~6층 식물과 군체 흔적 / 7층 관측 장치와 별자리 / 8층 왕실 깃발·석상·카펫.
- 배경 장식에는 충돌 판정을 추가하지 않으며 전투 전조보다 낮은 대비로 표현한다.
- 왕 처치: 쓰러짐 → 왕관 붕괴 → 도트 열쇠 출현. 시뮬레이션은 정지하며 귀환 버튼은 즉시 사용 가능.
- 열쇠 획득 안내 대기 상태를 저장하므로 이때 새로고침해도 안내를 복원한다. 보상과 광폭화를 중복 실행하지 않는다.
- 1층 탈출 결과에 문이 열리고 캐릭터가 밖으로 나가는 연출. 결과 저장은 즉시 완료하며 연출 종료를 기다릴 필요가 없다.
- 동작 줄이기 OS 설정을 존중한다. 새로운 배경 음악은 포함하지 않는다.

## 결과 기록

최종 기술과 레벨, 최대 피해 층, 궁극기 기록 피해 표시. 궁극기 기록은 이번 버전에서 실제 적용한 화살비·석궁 피해만 누적하며 적 남은 체력을 초과한 피해는 제외한다. 기존 저장의 과거 궁극기 피해는 소급 계산하지 않는다.

## 저장과 검증

새 생성 버전 25. 기존 지도와 편성은 저장된 상태를 유지하며 외형·UI 개선은 즉시 적용된다. 새로운 상층 편성·입문방·관문 배치를 보려면 새 도전이 필요하다.

- 자동 테스트 231개 통과.
- 150개 시드 표본 편성 다양성·지원 개체수 제한.
- 4방향 × 20개 시드 입장 배치: 안전 거리·장애물·겹침·저장 복원.
- 관문 격노·보상 중복 방지, 하강 혼합 편성, 열쇠 안내 저장, 궁극기 실제 피해 집계.
- 독립 QA 브라우저에서 7층 관문, 열쇠 연출, 귀환 재개, 탈출 결과·저장 확인. 콘솔 오류 없음.
