# 0.29 · 문지기 재강화와 하강 피해 통일

- 문지기 체력 기존 배율 1.4 → 3.5 (직전 버전 대비 2.5배). 초기 공격 대기 0.5/0.7초, 패턴 후 대기 0.65초.
- 칼드: 2연속 베기와 돌진 교대. 베라: 5갈래 사격 2회 후 원형 탄막. 생존자 분노 유지.
- 모르도 체력 9000 → 11700 (+30%). 페이즈별 패턴 후 대기 1/0.65/0.45 → 0.7/0.4/0.25초, 일반 빈틈 0.8/0.55 → 0.6/0.4초. 심판 마무리 후 긴 빈틈 유지.
- 별빛 저격수: 3갈래 정조준 사격, 예고 0.6초, 기본 탄속 290 → 330, 패턴 후 대기 1.1초. 예고선도 실제 발사 방향과 동일.
- 7~8층 일반 궁수: 기본 탄속 190 → 230, 연사 간격 0.22 → 0.16초, 회복 대기 기본 2.4 → 1.7초.
- 7~8층 별 기사·왕실 근위병 기본 체력 약 15% 증가. 도입 방에도 적용.
- 하강(key 획득 이후)은 공통 피해 처리에서 모든 양수 피해를 1하트로 처리. 피격 무적과 보호막 우선 처리 유지. 등반 피해 환산 유지.

검증: 자동 테스트 254개 통과. 하강 피해 9/12/18/24/100의 1하트 환산, 실제 강탄 충돌, 문지기 패턴 교대·연속 베기, 왕 체력·회복 간격, 저장 검증 포함.

적 행동과 하강 피해는 새로고침 후 이어하기에도 적용. 이미 생성되어 저장된 적의 체력은 보존. 문지기·기사 체력은 새 도전, 모르도 체력은 새 소환부터 적용.

## 피해 예외 정정
레이저(프리즘 광선 포함)와 도약 거인 점프 착지는 등반·하강·시련 모두 2하트로 유지합니다. 하강의 일반 근접타·탄환 등은 1하트이며 보호막과 무적은 그대로 적용합니다. 전체 테스트 256개 통과.
