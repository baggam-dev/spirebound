# 8층·10층 보스 재구성 계획

2026-11-10 사용자 ‘그렇게 수정 플랜 잡자’. 구조 변경 방향 승인, 이번 작업은 계획 수립만. 기존 ‘10층의 구성/패턴을 그대로 유지’ 방침을 이 계획으로 대체한다. 새 디자인의 최종 승인·구현·테스트·배포 완료를 뜻하지 않는다.

## 목표와 역할
|위치|구성|플레이 경험|
|---|---|---|
|8층|현재 10층 대악마의 손·발 → 얼굴 부위 → 벽 너머 본체를 약화·정돈한 ‘봉인된 잔해’|부위를 공략하는 대형 괴수전|
|9층|현재 군단장 유지|최종전 직전 관문|
|10층|현재 8층 왕의 3페이즈 전투를 기반으로 3페이즈 대악마 각성|왕과의 결투가 마왕과의 결전으로 발전|

왕이 외부의 다른 악마로 교체되는 것보다 동일 인물이 각성하는 흐름을 기본안으로 채택한다. 8층에서는 봉인된 힘의 일부를 쓰러뜨리고, 10층에서는 왕이 그 힘을 받아들이는 연결. 명칭·대사 세부는 디자인 패키지에 포함한다. 8층 승리가 플레이어의 실수처럼 보이지 않도록, 잔해 처치는 정당한 승리이고 왕의 각성은 왕의 선택으로 표현한다.

## 실제 코드 기준과 작업 경계
- `src/combat/demon.js`: expanded/10층 도전 제한, 부위 생성과 3단계 전환·공격·압력 버전이 결합되어 있음. floor 조건만 맞바꾸면 안 됨.
- `src/combat/upper-floors.js`: kingPhase 체력 65%/30% 경계, 전환 1.4초, 소환·3연속 베기·심판 공격이 기존 전투 기반. 각성은 우선 기존 30% 경계에 연결하며 추가 체력바/무료 체력 회복은 기본안에서 제외.
- `src/game/engine.js`: classic 8층/expanded 10층과 진행 제한. `src/game/game.js` 실제 시작 기본값은 expanded. classic 결말을 누락하지 않음.
- 보스 접근/도전, 방 생성, 사망 보상/열쇠/상하행, 연습·도감·표기·사운드, 저장 복구/방 배치 버전, 랭킹 정책까지 연결 지점을 구현 전에 추적한다. 기존 enemy variant ID를 단순 교환하지 않음.

## 1. 통합 디자인 패키지 — 다음 작업
- 8층: 손·발·눈·코·입·본체를 같은 재질/문양으로 묶음. 노출된 장기나 사실적인 절단면 대신 봉인석·갑주·가면 형태로 다듬고, 10층 군주의 실루엣과는 구분.
- 10층: 왕 1/2페이즈부터 왕관·가슴 봉인석·색을 연결. 3페이즈는 은발/왕관형 뿔/검은 갑주/와인색 망토의 군주 시안을 혼합하되, 작은 게임 화면에서 읽히도록 간결한 셀 채색과 데포르메 비율로 재제작.
- 군주 시안 `design-drafts/demon-redesign-20261110/demon-sovereign-v1.png`는 방향 참고용. 벽 위 거대 군주 구도는 새 10층에 그대로 채택하지 않고 이동·결투에 맞춘 체형으로 조정. 8층도 동일 군주의 복제 얼굴로 만들지 않음.
- 두 보스의 기본형/실제 크기 비교/이동/공격 준비·타격·회수/피격/단계 전환/격파, 별도 오라·효과를 한 패키지로 보여주고 한 번에 확인받음. 승인 전 runtime/배포 자산 미반영.

## 2. 8층 전투 조정 — 디자인 확정 후 로컬 구현
- 부위 순서와 대표 패턴 유지. 원래 10층 수치를 그대로 옮기지 않고 8층 도달 성장량을 기준으로 체력·피해·전투 길이 조정.
- 동시 압박과 특수공격/소환/잔류 장판 중첩을 줄이고 공격 간 회복 여유 확보. 예고 시간을 무작정 짧게 줄이지 않으며 이동 가능한 안전 경로 유지.
- 보스 체력 합산·부위 사망/다음 단계·핵 처치 시 보상 1회 지급을 보존. 층별 경험치 보상은 새 보스의 실제 위치 기준으로 매핑.
- 구체적 체력/쿨다운 값은 기존 성장·보스 보정 경로를 확인한 후 기록. 임의로 일괄 n% 하향 확정하지 않음.

## 3. 10층 각성 구현
- 기존 왕 1/2페이즈 패턴을 결투 기반으로 재배치하고 10층 성장량에 맞게 보정. 기존 8층 수치 단순 복사 금지.
- 30% 경계의 3페이즈에서 왕관/봉인석이 열리며 동일 인물이 대악마로 각성. 과한 근육/기괴한 변형 대신 자세·실루엣·광원·음향으로 격상.
- 기존 베기·돌진·심판을 각성 공격으로 다듬되 전조/판정/범위가 일치해야 함. 부위 소환전을 다시 붙이지 않음. 새 패턴 추가는 기존 결투와 구분되는 필요 최소한으로 설계.
- 전환은 실제 게임 상태에서 1회만 발생. 정지/저장 재개/연습/효과 줄이기에서도 일관. 연출을 위해 보상·입력·탈출이 무한 대기하지 않게 함.

## 4. 원정·저장·안내 정합성
- 기본 원정은 8층 잔해 처치로 완결되는 독립 결말, 확장 원정은 같은 승리 뒤 9/10층으로 이어지는 결말을 기본안으로 채택. 현재 각각의 열쇠/탈출/하강/클리어 확정 시점은 코드 확인 후 보존 또는 명시 변경.
- 새 원정부터 새 배치 적용을 기본으로 하고, 기존 진행 원정은 구 보스 구성을 명시적으로 식별해 유지하는 호환 경로 우선. 저장 원본 삭제·계정/랭킹 초기화 없음. 실제 저장 스키마가 유지 방식을 지원하지 않으면 대안을 먼저 문서화하고 사용자 결정 필요 여부 판단.
- 구조 변경은 기록 경쟁 조건에 영향을 줄 수 있으므로 현행 랭킹 버전/시즌 정책을 확인하여 구/신 규칙을 구분하는 방식을 정함. 임의로 기존 점수 삭제 또는 시즌 리셋하지 않음.
- 도감·보스 연습·접근 안내·처치 알림·층별 XP·열쇠/출구·최종 승리·음향의 보스 ID와 층 표기를 함께 갱신.

## 5. 검증·배포 — 새 명시 배포 지시 후 묶음 실행
- 단위/통합: 새 원정/구 저장, 두 캠페인, 도전/부위 단계/왕 각성 경계, 보상 단발·열쇠·하강·클리어, 연습/도감, 랭킹 규칙.
- 브라우저: PC/가로 모바일, 기본/효과 줄이기, 전조와 실제 타격 일치, 정지/저장 재개·로드 시 전환 중복 방지, PNG 실패 fallback, 화면 가림·성능. 실제 기기와 에뮬레이션 구분.
- 사용자 배포 지시 전에는 구현/문서/로컬 커밋까지만. 이후 필요한 검증을 묶어 실행하고 통과 후 푸시·공식 배포·공개 파일/실제 시작/보스 전환/서비스 확인. 런타임 변경 시 릴리스 버전 검토.

## 현재 완료 범위
계획 수립·코드 연결 지점 일부 확인만 완료. 시안 재제작/런타임 구현/테스트/푸시/배포는 미실행. 운영 0.53 유지. 다음은 8층 잔해와 10층 왕→대악마의 통합 디자인 패키지 제작이며, 이번 요청만으로 시안 최종 승인으로 간주하지 않음.

## 2026-11-10 후속 확정 방향 — 해골왕의 부활
사용자는 기존 해골왕 자산 재사용과 3페이즈 육신 복원 형태를 제안하고, ‘신성한 느낌’은 3페이즈 등장 연출을 뜻한다고 정정한 뒤 ‘ㅇㅋ’로 승인했다. 위의 살아 있는 왕 1/2페이즈 설명은 다음으로 대체한다.
- 1/2페이즈는 해골왕 유지. 왕관·망토·갑옷·장병기를 재사용하고, 2페이즈는 뼈 사이 빛과 봉인석 균열을 독립 효과로 추가하는 방향.
- 3페이즈에서만 육신이 복원된 은발 군주가 등장. 왕관/무기/갑옷 정체성 계승, 살점이 자라는 묘사 없이 빛 안에서 외형 전환.
- 신성함은 등장 순간 백금빛 기둥·일시적 후광·정적·낮은 종소리·충격파에 한정. 후광이 걷히면 검은 갑주/와인 망토/보라 봉인석의 악역으로 전투. 영구 후광/천사 날개/신성 캐릭터로 변경하지 않음.
- 상세 연결/재사용/연출 시간 초안은 `design-drafts/demon-redesign-20261110/resurrection-arrival-v3.md`. 기존 보드 v2는 역사적 제안으로 보존하되 10층의 인간형 1/2페이즈는 채택하지 않음. 같은 방향을 재승인받지 않고 합의된 세부는 자율 진행.
