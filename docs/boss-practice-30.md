# 0.30 · 보스 테스트

입구 화면의 보스 테스트에서 2층 수호자, 4층 프리즘, 6층 슬라임, 왕 문지기, 모르도와 메인 속성을 선택합니다.

- LV 10, 메인 기술 3레벨, 보조 기술 랜덤 7포인트. 습득한 분기도 자동 무작위 선택.
- 유물 3~5개(중복 없음), 정수 3~5개(중복 가능), 체력 완충, 물약 3개.
- 생성 결과를 확인하고 시작하거나 다시 뽑기 가능.
- ESC 및 결과 화면에서 같은 빌드로 재도전, 새 빌드 생성, 보스 변경 가능.
- 일반 도전 저장/백업/종료 표시/히스토리에 쓰지 않음. 새로고침 시 테스트는 종료됨.
- 테스트 방 이동 금지, 왕 처치 후 하강 미진입. 슬라임은 마지막 분열체까지 처치해야 성공.

검증: 전체 테스트 260개 통과. 5보스×4메인 조합의 스킬·유물·정수 범위, 분기 배정, 동일 시드 재현, 저장 및 기록 무변경, 슬라임 분열 완료 검증. 별도 브라우저에서 보스 선택·빌드 미리보기·전투 시작·일시정지·동일 빌드 재시작 확인.
