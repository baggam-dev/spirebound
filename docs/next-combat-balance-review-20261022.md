# 다음 개선 검토: 고층·하강의 전투 난이도와 보상
2026-10-22. 검토만 작성했으며 새 기능은 구현하지 않았다. BGM은 보류한다.

이번 배포로 군집 이동과 9종의 역할이 함께 바뀌었으므로, 다음은 새 캐릭터보다 실제 플레이의 피할 공간과 공격 후 빈틈을 맞추는 순서가 좋다.

1. 7~10층과 하강의 조합별 위험도: 인력장·찌르기·포탑이 겹칠 때 탈출로, 근접 포위와 후열 사격의 중첩, 좁은 문턱과 구석을 확인한다. 현재 공유 예고 2개 제한을 기준으로 후기에서 과한 조합만 후딜·시작 간격부터 조정한다.
2. 기존 원정 기록의 층별 피격 원인·회복 소모·전투 시간을 보고 특정 적의 과도한 비중을 확인한다. 아직 사용자 실기 장기 데이터는 확인하지 않았으므로 수치 변경을 확정하지 않는다.
3. 위험에 비해 보상이 빈약한 정예·시련·하강 구간의 경험치와 정수, 성장 속도를 함께 검토한다. 난이도를 낮추기 위해 모든 적의 체력을 일괄 줄이는 방향은 현재 제안하지 않는다.

우선 추천 범위는 1번이다. 모바일 후기에서 어려웠던 층·적 조합을 바탕으로 한 패키지로 조정하고, 변경 후 별도 명시 배포 때 검증한다. 보스 신규 패턴·새 디자인·BGM은 이번 다음 후보에 자동 포함하지 않는다.
