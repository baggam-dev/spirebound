# 몬스터 피격·사망 연출

- 실제 체력 감소를 감지해 짧은 황백색 피격 반짝임을 표시합니다. 화살·원소 피해·지속 피해·궁극기·자동 공격을 포함하며, 즉시 첫 화살비 타격도 별도로 반영합니다. 적을 밀거나 멈추지 않습니다.
- 같은 적의 반응은 0.28초 동안 중복 생성하지 않습니다. 밝은 부분은 그중 약 0.1초만 보이므로 지속 피해가 매 프레임 번쩍이지 않습니다.
- 사망 시 갑옷 조각, 프리즘 결정, 슬라임 점액, 꽃잎, 망령 연기로 구분합니다. 모르도에는 흩어지는 왕관 조각이 포함됩니다. 슬라임의 중간 분열은 좌우로 갈라지는 점액으로 구분합니다.
- 시체는 충돌 판정을 갖지 않습니다. 기존 사망 정리 시점에 적을 즉시 제거하고 보상·분열·문 개방을 처리하며, 남은 시각 효과만 약 0.38~0.55초 동안 소멸합니다.
- 피격 32개·사망 24개로 동시 효과를 제한하고 다른 피해 문구와 스킬 효과를 보존합니다. 사망 시 해당 적의 피격 반짝임을 제거하고, 방 이동 시 이전 방의 잔여 효과를 비웁니다.

`enemy-feedback.js`는 별도의 임시 효과 배열에서 동작합니다. AI·좌표·체력 계산·보상·난수·저장 형식은 변경하지 않습니다. 적 개체를 저장하는 대신 효과 생성 시 위치와 외형 정보만 복사합니다. 보스 처치 정리로 사라진 살아 있는 소환수에는 가짜 사망 효과를 만들지 않습니다. 일시정지 및 선택창에서는 다른 전투 효과와 함께 정지합니다.

검증: `node --test` 298개 통과. 새 검사는 체력 감소 감지, 위치·피격 판정 유지, 한 번만 발생하는 사망 효과와 즉시 보상, 슬라임 분열, 소환수 정리, 중복 억제 및 개수 제한을 확인합니다. `tools/enemy-feedback-qa.mjs`는 7개 표현의 시간별 프레임·소멸·일시정지·Canvas 상태 복구를 확인하고, Edge 1280×800 / 844×390 / 390×844 / 667×375에서 일반 적과 슬라임 처치 총 8개 조합을 검증했습니다. 브라우저 오류가 없었고 임시 효과가 저장 데이터에 들어가지 않았습니다. 실제 iPhone Safari 확인은 별도로 필요합니다.
