# 참고 영상 기반 타격감·원화 연결 — 정적 마감

2026-11-24. 운영은 **0.63.0-prebeta**, 배포 런타임564369d / release-20261123-110150-773b7a 그대로다. 이 문서는 이후 로컬 누적 변경의 정적 검토 및 **향후 명시 배포 지시 때 실행할 계획**이다. 현재 게임 테스트·구문 검사·서버·브라우저 QA·푸시·배포·공개 조회는 수행하지 않았다. 과거985개 통과 결과를 이번 변경의 검증으로 사용하지 않는다.

## 이번 정적 확인

`static-audit.py`는 Python으로 소스 문자열과 이미지/manifest만 읽는다. JavaScript 파서·모듈·게임 코드·테스트를 실행하지 않는다. 기준012f972 대비 변경 런타임24파일, 상대 import247곳에 누락 경로가 없고, 선택적8atlas의 크기/alpha/48색과 제품 manifest SHA8개가 일치했다. `reference-frame-art.js`의 필수`*Ready`export는 없다. 전체 결과는`static-audit.json`이며 해당 작업 트리 시점의 소스 SHA를 담는다. 다른 파일이나 이후 커밋까지 검증했다고 해석하지 않는다. import의 문법·이름 바인딩 검증도 아니다.

추가 테스트 선언은 기준 대비 **49개**다(기존 선언의 기대값 수정 제외). 파일별 숫자는 보고서의`testDeclarationInventory`에 있다. 모두 작성만 했으며 미실행이다.

정적 마감 중 한 가지를 보완했다. 업데이트에서 방별 상태를 초기화하더라도, 층 전환 후 첫 업데이트 이전의 그리기에는 이전 방의 잔상이 남을 여지가 있었다. `combatImpactFilter/Shake/drawCombatImpacts`와`drawRollTrail`에 현재 방을 전달해 그리기에서도 방 일치를 검사한다. 기존 reset/advance 경로는 유지한다. 이 사례 회귀2개도 위49개에 포함되며 미실행이다.

## 명시 배포 지시 후 실행 순서

1. `git status --short`와 최신 기록을 다시 읽어 이후 변경·사용자 후기를 합친다. 버전 표기와 서버 허용 버전은 실제 배포 범위에 맞춰 함께 결정한다. 현재 package.json의 과거 버전만 보고 운영 버전을 추정하지 않는다.
2. 전체 `node --test`를 한 번 묶어 실행하고 로그를 이 폴더에 저장한다. Python API 통합은 프로젝트 기존 러너를 따른다. 실패 시 해당 원인을 고치고 필요한 범위만 재검증한다. 지금은 실행하지 않는다.
3. `node server.js` 출력에서 실제 포트를 확인한 뒤 Edge(channel:msedge)로 아래 흐름을 확인한다. QA 스크립트가 구버전 아틀라스/개수/방 위치만 가정하지 않는지도 먼저 읽는다. 실행 로그·오류·스크린샷·로컬 포트/종료 상태를 기록한다.
4. 통과한 코드와 문서를 로컬 커밋하고 푸시한다. 공식 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\deploy\deploy.ps1`로 배포한다. HTTPS·공개 변경 파일 byte/해시·health/서비스와 공개 PC/모바일 진입을 확인한다. 실제 결과로 운영 릴리스/WORK_STATUS/TODO/WORK_LOG/HANDOFF를 갱신한다.
