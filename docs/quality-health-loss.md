# 초반 적·첫 보스 피격 피드백 — 체력 손실 잔상 (2026-10-06)

일반 적중에는 짧은 빛 표식이 있었지만, 작은 체력 막대에서는 방금 받은 피해 구간이 즉시 구분되지 않았다. 일반 적과 2층 첫 보스의 머리 위 막대에 실제로 감소한 구간을 0.28초 밝은 석색으로 남긴다. 첫 보스의 화면 상단 체력 막대에도 같은 구간을 잠깐 표시한다. 작은 피해는 최소 2~3픽셀로 보여 명중 여부를 읽을 수 있게 한다.

효과는 살아남은 적의 실제 체력 변화에서만 생성하며, 연속 피해는 기존 피격 표식 제한을 따른다. 사망/보상·체력 계산·적 이동·공격·저장·랭킹 시즌은 변경하지 않았다. 여러 부위의 체력을 합산하는 다른 보스의 상단 막대는 개별 피격 비율을 덮어쓰지 않는다.

정지된 효과 비교: [PC](quality-health-loss/health-loss-pc.png)·[모바일 가로](quality-health-loss/health-loss-mobile.png). 단위 테스트는 실제 감소 비율과 첫 보스 상단 표시/다른 보스 제외를, Edge QA는 효과 픽셀·기존 피격 상태 보존·1층/첫 보스 4크기 레이아웃을 확인한다. 실제 사람 플레이와 실기기 가독성 평가는 아직 하지 않았다.
