# 참고 이미지 기준 캐릭터 방향 (2026-10-12)

사용자가 ‘5등신’이라고 표현한 실제 의도는 첨부 직업 스프라이트 이미지의 비율과 톤이다. 이전의 가늘고 각진5등신 코드 도형을 앞으로의 캐릭터 기준으로 사용하지 않는다. 머리가 어느 정도 큰 중간 체형, 둥근 팔다리, 따뜻한 갈색/분홍 피부·저채도 천/가죽/금속, 세밀한 입체 명암·머리카락/옷주름을 기준으로 한다. 등신 숫자보다 참고 이미지의 인상을 우선한다.

## 첫 주인공 적용
imagegen 스킬의 내장 image_gen 도구로 새 원본 궁수4자세 투명 아틀라스를 생성하고 세번째 보행 자세를 수정했다. 기존 등장 캐릭터/의상/픽셀을 복사하지 않고 원작 주인공의 금발·붉은 목천·푸른 회색 망토·활/화살통을 참고 톤으로 다시 디자인한다. 최종 assets/images/hero-reference-atlas.png는2079×756 RGBA/1,257,878bytes, 알파0~255를 확인했고 원 PNG를 그대로 프로젝트에 복사했다. 생성 원본은 generated_images에 보존한다. 실제 프롬프트는 hero-reference-style-prompts.md.

hero-sprite.js는 투명 영역/발 앵커를 고려한4자세를 초기 로딩 시 게임 크기로1회 캐시한다. 정지/두보행/사격과 좌우반전을 지원한다. 초기68px는 실제 화면에서 디테일이 작게 보여80px 기준으로 보완했다. 소스 downsample은 고품질 표시 처리, 게임은 작은캐시4개를 그리므로 매 프레임 대형 원본을 다시 축소하지 않는다. 발 앵커22와 논리적위치/충돌14/이동·발사·피해/저장/RNG/0.38·34·랭킹은 유지한다. 새 머리높이에 맞춰 피격숫자25px 상향 및 경직표시75px 위에 둔다. 사격 이미지는 연출이며 판정/탄환 좌표를 변경하지 않는다.

이미지 로딩/실패 때 이전 코드 렌더러는 임시 fallback으로만 사용한다. 숫자5등신 export는 fallback의 역사적 지표다. 정상 새 디자인 검증은 hero-reference-qa.mjs의 실제아틀라스 로딩/4캐시를 기준으로 한다. 외부 CLI/API키는 사용하지 않았으며 Python/Pillow는 크기/알파/영역을 읽는 검사만 했다. 자산 이미지 편집은 내장 도구를 사용했다.
