# 초반 전투 리듬 — 점멸 잔상 (2026-10-06)

사격은 활 반동·투사체 잔상이 있고, 피격에는 짧은 명중 표식이 있지만, 점멸에는 도착 지점의 흐린 빛만 있었다. 출발점·진행 방향·도착점을 짧게 이어 주면 회피 결과를 한눈에 읽기 쉽다.

점멸 성공 시 실제 이동한 두 좌표 사이에 0.3초 동안 끊어진 두 줄기와 작은 석점 잔상을 남긴다. 넓은 원이나 공격 판정처럼 보이는 외곽선을 그리지 않는다. 벽에 막혀 실패하면 효과를 만들지 않는다. 효과 완화 설정에서는 잔상을 생략한다. 이동 거리, 충돌, 무적 시간, 쿨다운, 저장·랭킹 규칙은 바꾸지 않았다.

동일한 시드419에서 [PC 전](quality-blink/blink-before-pc.png)·[PC 후](quality-blink/blink-after-pc.png), [모바일 가로 전](quality-blink/blink-before-mobile.png)·[모바일 가로 후](quality-blink/blink-after-mobile.png)를 캡처했다. 브라우저 자동화는 PC·모바일 가로의 입력 성공, 경로 내부 픽셀과 영역 밖 미표시, 페이지 오류를 검사한다. 실제 사람의 체감과 iPhone/Android 실기기 평가는 아직 하지 않았다.
