# 0.50.0-prebeta — 이펙트 전반 마감

## 반영 범위
사용자 ‘끝까지 다 하고 배포도해’ 승인에 따라 1단계 통합시안·2단계 c8f7334에 이어 3/4단계 렌더를 마감하고 5단계 검증·배포한다. 새 캐릭터/형태/폰트/이미지 생성 없이 승인된 픽셀/분리효과 방향과 기존 디자인 안에서 정리했다. 기존 등장/전용보스사망 연출은 이미 구현되어 있어 교체하지 않고 일반사망 감쇠만 개선했다.

- 명중: 방향성 파편·원소별 실루엣·기존 정밀 약점! 순간 .2초 강조. 회피/망령검은 진행률 공유 taper 베기. 실제 무작위치명타 시스템 추가 없음.
- 원소비행: 기존 레벨/진화별 모양 유지, 꼬리마다 밝기 감소. reduced는 작은 원소색 흔적1개와 기존 화살 핵 유지. incoming alpha 보존.
- 폭발/장판: 아군 화염폭발은 빈 중심에서 바깥 파편으로 감쇠·실반경 clip, 장판은 중심장식을 비우고 가장자리 작은 불꽃/독연무·마지막 .35초 소멸. 구르기 지뢰 등 아군 burst는 실제 duration 사용/중심광구 제거·파편4/10개. 적 warning/판정 도형과 최상단 경계 유지.
- 착지: 기존 피해/착지관찰시점 유지, 낮은 바닥조각 그림자와 뜨는 파편 분리, 부드러운 감쇠. reduced 최소표시 유지.
- 보조: 기존 보호막 내부농도 완화+실제 charge 수 점표식(최대3), 분리냉기입자 끝부분 수축/감쇠, 상자 방출 ease-out·상자/회복/제단 등 기존 성공효과 부모opacity 보존, 경험치획득 작은수축, 일반사망몸감쇠/입자 부모opacity 보존. 새로운 부활/등장 이벤트 없음.
- reduced 전체skip에서 기존범위효과 playerBlast/groundBurst만 추가예외·전용축약표시. 원소/일반피격·slash 예외는2단계와동일. 적탄/적경계/보스경계 순서 유지.

## 유지한 것
전투 피해/시간/범위/발사수·판정·AI/RNG, 캐릭터와 전용보스 PNG, 원정/지도·DB원본·시즌SPIREBOUND·점수식을 유지한다. 외부 pixelfx 코드를 복사하거나 244개 엔진을 설치하지 않았다. procedural 효과의 시간/형태를 참고한 독자 Canvas 구현이라 새 외부라이선스/생산자산/서버공개목록 불필요. 실제 코드 차용 시 MIT/NOTICE 보존 원칙은 유지한다.
client/API/헤더는 기존 배포정책을 따라0.50 동기화한다. 저장 마이그레이션은 추가하지 않았으며 기존 원정/과거랭킹 원본을 지우지 않는다. 온라인 제출/최신표는 기존 최신버전정책을 따른다.
