# 궁극기 연출 개선 (시각 개선 2단계)

- 화살비: 실제 범위의 얇은 경계와 옅은 바닥 색, 방향이 있는 화살 낙하 궤적, 착탄 섬광과 파편을 추가했습니다. 기존 즉시 첫 타격과 0.6초·1.2초 후속 타격에 착탄 연출을 맞춥니다. 첫 피해를 연출 때문에 지연하지 않으며, 세 번째 타격 뒤에는 더 이상 화살이 떨어지지 않습니다.
- 자동 석궁: 설치 시 바깥으로 펼쳐지는 지지대와 내려앉는 본체, 실제 발사 직후의 활시위·본체 반동과 작은 발사 섬광을 추가했습니다. 남은 수명을 작은 막대로 표시하고 종료 직전에 부드럽게 사라집니다. 설치 애니메이션 중에도 기존 규칙대로 즉시 공격할 수 있습니다.
- 화살비 바닥 표시는 적의 위험 예고와 캐릭터보다 아래에 그립니다. 화살·석궁은 전장 경계 밖으로 잘라 HUD 영역 침범을 줄입니다.

`ultimate-visuals.js`는 기존 `arrowRain.elapsed/pulses`, `turret.time/clock/aim`만 읽습니다. 벽시계·렌더링 이력·난수를 사용하지 않으므로 일시정지 때 멈추고 저장을 재개하면 해당 시점의 연출로 이어집니다. 궁극기의 피해량·범위·쿨다운·수명·발사 주기·저장 형식은 변경하지 않았습니다.

검증: 전체 `node --test` 290개 통과. 새 검사는 실제 화살비 피해 3회와 착탄의 동기화, 표적이 있을 때만 생기는 석궁 반동, 읽기 전용 표현과 저장 상태 복원을 확인합니다. `tools/ultimate-qa.mjs`는 Edge 1280×800 / 844×390 / 390×844 / 667×375에서 두 궁극기를 키보드와 모바일 버튼으로 발동하고 저장 상태를 확인합니다. 총 8개 조합에서 브라우저 오류가 없었습니다. 실제 iPhone Safari의 성능·터치 감각은 별도 확인이 필요합니다.
