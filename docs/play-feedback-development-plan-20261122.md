# 플레이 피드백 개발 계획

작성: 2026-11-22. 상태: 단계1 A패키지 승인·로컬 구현 완료(미검증·미배포). 2~6단계 미착수.

원본 요구는 [피드백 1~15](play-feedback-20261122.md), 코드 근거와 연결 수정은 [파생 검토](play-feedback-derived-review-20261122.md)를 따른다. 이번 요청은 개발 계획 작성이며 구현·디자인 승인·테스트·푸시·배포 지시로 확대하지 않는다. 계획의 초기 제안은 사용자 확정 수치와 구분한다.

## 확정 방향과 계획 전제

- 수도사: 회복 횟수 제한과 고정량 상한 제거. **대상 최대 체력의 20%를 1회 회복**하는 초기 기준으로 확정한다. 실제 회복량은 잃은 체력까지만이며 최대 체력을 넘지 않는다. 이는 20% 증폭이나 지속 초당20%가 아니다. 기존 자기 자신/보스/수문장 등 회복 대상 제외와 시전 중단 가능 규칙은 유지하는 계획이다.
- 구르기 지뢰: 설치 후1초 폭발. 기존 피해·반경·설치 개수 유지.
- 요정: 등장 빈도만 아주 조금 감소. 초기 제안은 요정3종 각각 가중치 .35→.32, 요정왕 완성 보장은 유지. 이는 등장 확률3%p 감소를 의미하지 않으며 확정 수치는 아니다.
- 디자인은 시안 승인 후 반영한다. 캐릭터는 외형·공격 동작·별도 효과를 패키지로 제시한다. 봉인의 잔해는 현재 디자인 사용 방향을 유지하며 다리 표현에 필요한 최소 보완만 확인한다.
- 기본/확장 캠페인과 레거시 원정의 적용 범위를 작업별로 명시한다. 특히 새 보스·탈출 구조는 저장 버전으로 구분하며 기존 진행을 임의 삭제하지 않는다.

## 단계별 작업

| 순서 | 범위 / 피드백 | 개발 내용 | 완료 판단 기준(아직 미검증) |
|---|---|---|---|
| 1 | 화면·문 시인성 / 1~4 | 룰렛 크기·여백, 토스트 중앙 위·시간 체력바 위, 긴 설명 카드 내부 스크롤, 문/횃불 배치·여러 통로 스타일 시안 | 작은 가로 화면에서도 문/전투 예고가 읽힘. 카드 스크롤이 선택으로 처리되지 않음. 룰렛 연출이 당첨 결과를 가리지 않음 |
| 2 | 작은 수치·지원 적 / 5·12·13 | 수도사 무제한20% 회복·생존력/힐속도/이속, 지뢰1초·설명/점멸, 요정 가중치 소폭 감소 | 수도사가 살아 있으면 회복 압박을 주지만 차단/처치 가능. 지뢰 실제 폭발·문구 일치. 요정왕 조건 보존 |
| 3 | 일반 적·수문장 / 6~8·10 | 봉인 추적자 강화, 박쥐 소형 고속 타깃→직선돌진→자폭, 도약 거인 리디자인, 칼드·베라 고유패턴·공속/이속·보스급XP/클리어 연출 | 적마다 대처법이 다름. 박쥐 예고/폭발을 읽고 회피 가능. 수문장 보상 중복 없음·후반 예상 레벨 기록 |
| 4 | 모르도 / 9·14 | 체력/이속/공속·새 패턴, 보스 FX/컷씬, 격파 후 지진·유언·파편, 귀환 환경 균열/불꽃 | 같은 성장 조건에서 군단장보다 최종 보스다운 난도. 예고와 공격 후 빈틈 유지. 컷씬 중 전투/시간 정지·재접속 중복 재생 없음 |
| 5 | 봉인의 잔해 / 11 | 층내5부위 랜덤분산·조각/문, 다리 있는 완전체 새패턴1페이즈→분리5체 동시2페이즈 | 조각 없이 모든 부위 접근 가능. 저장 후 진행 유지. 부위 격파가 보스 완료/보상을 오발동하지 않음 |
| 6 | 최종 탈출 / 8·15 | 검은 육망성·5턴 그림자보스+일반적2체, 체력70%·분열/페이즈 제한, 잔존 적 상태에서 개문/탈출 | 전멸 강요 없이 시간 생존으로 출구 사용 가능. 보스 누적에도 회피 통로 확보. 그림자 처치로 원본 보상/계단/유언 미발동 |

단계1~3에서 후반 성장 기준을 정한 뒤 단계4~6을 맞춘다. 단계5 상세 설계는 병행 준비할 수 있지만 최종 탈출의 그림자 보스 목록은 원본 전투 사양을 정한 후 고정한다. 각 단계는 관련 코드·설명·저장·문서를 함께 로컬 커밋한다.

## 세부 구현 지점과 초기안

### 수도사·보상·일반 적

- support-profile/support-casters/support-save: totalHeals 판정 제거와 healRate=.20·고정 healCap 제거. 이전 supportHeals 값은 새 규칙에서 횟수 제한으로 쓰지 않도록 이관한다. 도감의 '최대3회' 문구도 변경한다.
- 초기 제안: 수도사 힐 재사용5.5→4초, 시전.95→.8초, 이동35→50, 체력 기존 대비+40%. 미확정 튜닝 초안이며 실제 후반 적 체력/처치 시간에 맞춰 조정할 대상이다. 다른 지원술사까지 공유 상수로 함께 상향하지 않는다.
- 추적자·수문장·모르도는 먼저 실제 생성 체력/이속/주기와 층별 성장표를 정리한다. 사용자 비지정 수치를 임의로 확정하지 않고 변경 전/초기안/조정 근거를 기존 상세 문서에 기록한다.
- 칼드 초기 패턴 방향: 방패 돌진 후 방향 전환 베기. 베라: 이동 사격 후 좁혀오는 고리/저격 조합. 패턴 구성은 초기 제안이며 반응 가능한 예고와 빈틈을 포함해 상세화한다.
- enemy-rewards/simulation: 수문장 XP를 해당 시점 보스 보상 기준으로 맞추는 안부터 검토하되 지급 사건은1회로 보장한다. 보상 후 레벨업을 포함해 후반 튜닝한다.
- roll/evolutions/skill-overhaul-effects: 지뢰 시간·설명·폭발 직전 표시에 동일 기준 적용. progression의 요정 추첨과 주력/요정왕 보장 규칙은 분리한다.

### 보스·층·최종 탈출

- 모르도 패턴 초기 방향: 접근을 강요하는 지면 균열, 방향 고정 돌진/베기, 페이즈별 연속 공격. 수를 늘리기보다 이동·자리 선택·공격 기회를 구별한다. 개별 FX는 시안 승인 후 연결한다.
- 잔해 층: 5개 부위 식별자·처치 상태·조각 수·봉인문 상태를 한 진행 데이터로 저장한다. 보스 문에1/5~5/5, 미니맵에 발견한 부위 위치를 표시하는 안을 제안한다. 문 안1페이즈와2페이즈 완료를 분리한다.
- 최종 탈출 초기 시간표 제안: 첫 소환은 시작2초 후, 이후10초 간격(2/12/22/32/42초), 개문은52초. **시간표는 미확정 제안**이며 5턴 출격과 마지막 턴 생존 시간을 보장하려는 기준이다. 보스 풀/순서/중복 여부는 상세 설계에서 정한다.
- 그림자 HP70%는 원본 보스의 기준 최대 체력에 한 번만 적용하고 재접속 시 중복 감산하지 않는다. 슬라임1회 분열의 자식 재분열 금지, 단장1페이즈 동작 고정, 모르도 최종 페이즈 외형/패턴 고정이 모두 필요하다.
- final-escape/engine/storage: 시간·wave·소환 유형 validator와 상태 버전, canEscape/방잠금, 개문시 적/탄 일괄삭제를 함께 변경한다. 일시정지/레벨업/컷씬 중 시간은 멈추고 저장 재개로 턴을 중복 소환하지 않는다.
- 그림자 전용 설정으로 원본 보스 진행/보상/열쇠/클리어 컷씬을 차단한다. 원본 보스 여러 체가 같은 방에서 독립 동작 가능한지 확인하고, 필요하면 보스별 상태를 분리한다.
- 현재 박쥐 다수 소환은 고정 유형 구성에서 확인됐다. 사용자 원정 버전의 실제 현상은 별도 재현할 과제이며, 새5턴 구성에 기존 박쥐 압박 루프를 동시에 남기지 않는다.

## 디자인 검토 묶음

| 묶음 | 함께 제시할 결과 |
|---|---|
| A. UI·문 | 룰렛 비율/당첨 빛·불꽃, 토스트/시간 위치, 카드 내부 스크롤, 문 상태 구분·통로 스타일3종 초기 비교안 |
| B. 적 | 작은 박쥐 기본/타깃/돌진/폭발, 거인 신체 비율/악당 인상/공격 동작, 칼드·베라 새 패턴 예고와 클리어 효과 |
| C. 보스·귀환 | 모르도 각 패턴·컷씬/격파 유언, 지진/파편·균열/불꽃 환경, 현 디자인 기반 잔해 완전체/분리전·봉인문, 그림자/육망성/개문 |

정지 이미지뿐 아니라 모션 순서·실제 게임 크기·효과 줄이기 상태를 포함한다. 공격 예고/문은 장식보다 앞에서 읽혀야 하며 터치 입력을 막지 않는다. 캐릭터 오라는 PNG에 합치지 않고 별도 효과로 유지한다.

## 검증 계획 — 별도 배포 지시 후 실행

계획 단계에서는 아래를 실행하거나 통과 표시하지 않는다.

- 규칙 검증: 수도사20%/횟수무제한·만피/사망대상/중단/기존대상제외·구저장, 지뢰1초 경계·피해보존, 요정 후보 가중치·요정왕 보장, 보상1회 지급.
- 진행 검증: 여러 seed의5부위 도달·조각 중복 방지·문/2페이즈, 저장·재접속·이전 버전 원정, 기본/확장 캠페인.
- 최종 탈출: 5턴·70% 단회 적용·보스 제한·소환 중복없음·개문 후 잔존 적/탄 상태에서도 탈출, 일시정지/레벨업 타이머, 보스 누적 공격/경로.
- 실화면: PC/모바일 에뮬레이션·작은 가로 화면의 카드/터치/토스트/문, 아트 미로딩 대체 표현, 컷씬 건너뛰기/재개, 효과 줄이기·동시 FX/음향 예산.
- 밸런스: 같은 빌드/레벨/유물로 변경 전후 처치 시간·회피 가능성 비교 후 자연 성장 완주 확인. 실기기 성능/사람 조작 난이도는 자동 QA 결과와 분리한다.
- 배포 요청 시 누적 변경의 적절한 전체/집중 검증을 묶어 실행하고 실패 수정·재검증 후 푸시→공식배포→공개 확인. 현재 운영 기록은 그대로 유지한다.

## 다음 작업과 미정 사항

다음 개발 지시가 오면 단계1의 A패키지 상세 시안 준비부터 시작하는 순서를 권장한다. 시안 대기 중 승인과 무관한 규칙 상세화는 가능하나 이번 계획 요청만으로 구현을 시작하지 않는다.

사용자 즉시 답변이 필요한 차단은 없다. 미정은 최종 탈출 보스 순서/시간표, 잔해 구원정 적용 범위, 수문장·모르도 패턴 세부와 튜닝 수치다. 초안과 변경 근거를 묶어 검토할 수 있게 준비하며 부위/동작마다 승인을 반복 요청하지 않는다.

## 1단계 착수 기록 (2026-11-22)
사용자 첫번째부터 구현/배포최종후 지시. 기존 시안승인 규칙에 따라 [A패키지 시안/사양](design-drafts/ui-doors-stage1-20261122/README.md)과 비교PNG/정확프롬프트를 준비해 제시. 사용자 검토 후 UI·문 런타임 반영 예정. 테스트/푸시/배포 없음.

## 1단계 로컬 구현 완료 (2026-11-22)
사용자 구현진행 승인으로 [A패키지 상세](design-drafts/ui-doors-stage1-20261122/README.md)에 기록한 룰렛·토스트/시간·유물설명스크롤·문/횃불 연결 완료. 기존선택/확률·충돌/지도/저장규칙 유지. 신규3회귀작성만/미실행. 정적 diff검토·로컬커밋, 테스트/구문/서버브라우저/푸시/배포없음. 다음2단계는사용자진행지시후,최종배포시누적검증.
