## 현재 구조

- 레벨업 스킬23종 = 메인5 + 공통보조8 + 메인전용보조10.
- 성장 보상3종(일반 후보 소진 뒤), 분기20종(10계열×2), 별도 유틸3종.
- 아이콘 재제작 범위는 스킬/성장/분기46개, 유틸까지 합치면49개. 조합 보너스3개는 자동 발동으로 별도 선택 스킬이 아닙니다.
- 메인은 무작위3개 중1개를 선택하며 이후 해당 메인과 호환되는 보조를 조합합니다. 베르가스는 여섯 번째 메인이 아니라 유니크 보조입니다.

## 검토할 때 같이 볼 부분

- 정밀 계열: 약점 추적/마무리 조준과 두 분기의 역할이 충분히 구분되는지.

- 유니크 보조: 베르가스/추적 화살/궁극기의 희소성과 존재감이 적절한지.
- 메인별 전용 보조2종이 원하는 조합 성장을 만드는지. 아래 판단은 사용자 검토용이며 변경 확정이 아닙니다.
