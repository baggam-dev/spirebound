## A. 화살비 너프 — 가장 먼저

현재 `src/combat/abilities.js`에서 `basicShotPower * 7 * (1 + ultimateDamage 유물 보정)` 피해를 즉시 1회 포함 총 6회, 0.3초 간격으로 준다. 같은 적이 전부 맞는 조건에서 보정 전 합계는 `basicShotPower * 42`다. 실제 피해는 방어·범위·타깃 생존·빌드의 영향을 받는다.

- 첫 후보: 회당 7배→5배, 6회 유지. 총 계수 42→30으로 약 28.6% 감소.
- 범위·시전 속도·마지막 착탄 연출을 동시에 줄이지 않는다. 우선 피해 계수 한 축만 바꿔 체감 원인을 구분한다.
- 보스 전용 감산을 먼저 넣기보다 공통 계수 조정을 우선한다. 일반 방 처리가 지나치게 약해지면 그때 보스/일반 기여를 나눠 재검토한다.
- 비교 항목: 같은 성장 상태의 화살비/석궁, 보스 체력 감소·궁극기 피해 비중·클리어 시간·일반 방 처리. 극단 세팅만으로 결론 내리지 않는다.
- 치명타 도입 뒤 화살비 기대 피해가 다시 상승하므로 B/C/D 완료 시 재조정한다. 위 5배는 검증 출발점이며 확정 밸런스가 아니다.

## B. 치명타 공통 구조

현재 확률 치명타는 없다. 정밀 사격의 연속 적중 강화탄은 별도 확정 조건이며, `precisionHit` 음향도 여기에 연결된다. 이를 치명타로 이름만 바꾸지 않는다.

### 판정과 적용 범위

- 플레이어 기본 치명타 확률·배율을 공통 전투 스탯으로 추가한다. 출발 후보는 확률 5%, 피해 150%. 최종 상한 후보는 확률 50%, 배율 250%로 두고 빌드 검증 후 확정한다.
- 평타·정밀 직격·발도/근접 기술·직접 속성 피해·궁극기·석궁/요정 등 소환체 피해 모두 적용 경로를 정의한다. 일부 기술만 새 공식을 타는 상태로 출시하지 않는다.
- 직접 피해는 실제 유효 명중 시 공격/대상/피해 묶음당 한 번 판정한다. 빗나감·막힘·무효 타깃에는 판정하지 않는다. 한 명중의 물리·속성 성분에 치명타를 중복 곱하지 않는다.
- 광역·다단 공격은 대상/회차별 판정을 제안한다. 렌더링 프레임이나 화면상의 화살 개수로 판정하지 않는다. 화살비 실제 6회와 장식 화살은 명확히 분리한다.
- 독·연소·장판은 적용/생성 때 판정한 배율을 해당 지속 피해 인스턴스에 보관하는 안을 우선한다. 매 프레임 굴려 확률이나 난수 소비가 달라지는 방식을 피한다. 재적용·스택·소유자가 다른 피해의 병합 정책을 별도로 명시한다.
- 치명타로 생기는 추가타는 원본 치명타 결과를 계승하거나 파생 피해 규칙을 사용한다. 치명타→추가타→치명타 무한 발동은 허용하지 않는다. 효과별 발동 계수/재사용 시간과 피해 배율을 구분한다.
- 소환체는 기존 무기 스냅샷 규칙에 맞춰 치명타 스탯도 보관한다. 소환 시/공격 시 중 어느 시점의 스탯인지 섞지 않는다.

### 기술 기반

1. 피해 경로 목록을 먼저 만든다: 직격, 관통/분열/반복, 속성 직격·전이, 지속 피해, 발도, 화살비, 석궁, 요정/패시브, 유물 반격, 적·환경 피해.
2. 플레이어 피해의 공통 결과에 원인/소유자/실제 피해/치명타 여부/파생 깊이를 담는다. 피해 적용·전투 통계·이펙트·음향이 같은 결과를 읽게 한다. 적 공격/환경 피해는 플레이어 치명타에서 제외한다.
3. 맵·AI·성장 선택 난수와 분리된 전투 치명타 난수 스트림을 사용한다. 상태를 저장해 로드로 재추첨되지 않게 하고, 기존 저장은 기본 스탯/난수 상태로 이관한다.
4. 저장 검증·소환체 스냅샷·진행 중 지속 피해·구형 저장·랭킹 재현/수치 검증 경로를 함께 갱신한다. 미래 계정 초기화를 전제로 하지 않는다.
5. 명중 수, 치명타 수, 피해 원인별 기여를 기록하되 지속 피해 틱 수가 치명타 적용 횟수를 부풀리지 않도록 통계 정의를 나눈다.

일반 피해의 평균 상승은 `1 + 확률 × (배율 - 1)`로 먼저 계산한다. 예를 들어 5%/150%면 평균 약 2.5% 상승이다. 정밀 강화탄·속성·유물의 기존 곱연산과 합쳐 최댓값만 폭증하지 않는지 확인한다.

### 이펙트·음향

- 일반 명중 / 정밀 약점 강화탄 / 확률 치명타 / 약점+치명타 / 궁극기 마무리를 구분한다.
- 치명타는 좁은 접점 대비·방향 파편·짧은 전용 음향 중심. 지속적인 화면 전체 섬광과 적 몸의 반복 움찔거림을 기본 표현으로 쓰지 않는다.
- 약점+치명타는 같은 명중에 완성된 강한 표현 하나를 선택한다. 문구·타격음·핵을 중복 재생하지 않는다.
- 빠른 연타에는 시각/음향 예산을 적용하되 실제 치명타 판정·피해는 생략하지 않는다. 모바일/완화 모드와 일반 모드가 같은 결과를 표현한다.
- 기본 접점·정밀·치명타·복합 명중·궁극기/소환체 적용·완화 버전을 한 시안 패키지로 준비한다. 디자인 승인 후 구현하며 항목마다 확인을 반복하지 않는다.

| 묶음 | 첫 후보/역할 | 전투 규칙과 보상 |

| 랜덤 발생 | 황금 도굴꾼 또는 유랑 정예 | 입장/정해진 이벤트에서 한 번 확정·저장. 전투 중 무예고 등 뒤 출현 금지. 추격/위험을 감수하면 추가 정수·유물 기회 |

- 첫 구현은 랜덤 정예 1종 → 하강 추적자 1종 → 소환/회복 지원형 → 장치 순서로 묶는다.
- 랜덤 조우는 방/층당 상한과 출현 제외 구역을 둔다. 보스 연출·입장·계단·출구에서 기존 필수 전투와 겹치지 않게 한다.
- 하강 중 경험치와 성장 선택이 실제로 발생하는지 다시 확인하고, 강적 보상을 단순 생존 시간벌이로 끝내지 않는다.
- 지원형은 동시 소환·치유 수, 재사용 시간, 시야/벽, 대상 선정, 최대 적 수와 프레임 비용을 함께 제한한다.
- 기존 중첩 위험도·방 구성·층별 몬스터 예산에 역할로 편입한다. 모든 방의 적 수를 일괄 늘리지 않는다.
- 각 캐릭터는 기본형·걷기·시전·공격·사망/해제·별도 효과·모바일 공격 예고까지 한 패키지로 시안을 만든다.

## F. 2차 비주얼 개선

1. 현재 자산/실플레이 장면을 기준표로 정리한다: 유지할 것, 재질/명암만 손볼 것, 실루엣/모션을 다시 잡을 것.
2. 맵은 한 대표 층을 먼저 만든다. 바닥/벽/문/소품의 재질·명도·캐릭터 대비를 통일하고, 공격 예고와 적 탄환이 묻히지 않는지 확인한다. 승인 후 다른 층으로 확장한다.
3. 일부 몬스터는 플레이 중 자주 보이거나 역할 구분이 약한 2~3종을 우선 선정한다. 기존 캐릭터를 전부 재생성하지 않는다.
4. 스킬/소환체는 화살비·석궁·요정/요정왕·발도·속성/치명타의 색과 크기 위계를 정리한다. 캐릭터 PNG에 오라를 굽지 않고 별도 효과로 유지한다.
5. 새 적의 외형과 기존 맵/몬스터의 결을 맞춘다. 기괴함보다 실루엣·자세·재질과 역할 전달을 우선한다.
6. 대표 맵+기존 몬스터 후보+신규 적+치명타/소환체 효과를 비교 가능한 통합 시안으로 검토받고, 승인된 패키지부터 구현한다.
