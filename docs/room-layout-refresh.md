# 계단 방향 분산·진입부 완화

2026-10-13 map-entry-v1 방향 사용자 승인. 사용자는 기존 원정 데이터 삭제/덮어쓰기를 허용하고 구버전 배치 분리를 원하지 않았다. 이번 구현은 원정 전체를 삭제하지 않고 기존 지도도 같은 새 배치 규칙으로 갱신한다. 공개 랭킹/사용자 계정/원정 이력 삭제는 이번 범위가 아니다.

## 로컬 구현

- room-layout.js의 refreshRoomLayout은 시드/층별 독립 난수로 0/90/180/270도 회전·좌우반사를 선택해 방 좌표를 변환한다. 방 인덱스/연결/계단방 역할/동선 길이 유지, 시작점 기준 목표 방향 분산. 원정 전투 RNG 상태는 소비하지 않는다. 모든 방향이 매 판에 반드시 나오는 규칙은 아니다.
- newRun 생성 직후 적용, 기존 parseSave에서도 같은 함수를 적용한다. roomLayoutVersion=1은 중복 회전 방지용이지 구버전 지도 유지 분기가 아니다. 기존 필드 없는 원정은 한 번 갱신하고 다음 저장부터 표식이 유지된다.
- 최종10층은 계단이 없는 2방 악마 전용 구조/저장 검증 좌표라 예외로 유지한다. 일반 상층 이동 계단이 있는 층은 모두 방향 분산 대상이다.
- compact는 네 모서리 대형 벽 대신 상/하 55px 깊이의 짧은 진입부만 배치한다. 상하문 중앙150px 틈, 좌우 진입부와 넓은 중앙 회피 공간 확보. 기존 vertical/horizontal도 협소 진입부가 한 축에만 있어 그대로 유지한다. 내부 cross/staggered/maze의 중앙 장애물은 별도 구조로 유지한다.
- 기존 compact의 옛 wall 장애물을 제거하고 같은 새 compact 규칙으로 다시 적용한다. 현재 플레이어는 기존 recoverPlayerPosition 경로로 겹침 시 재배치한다. 적은 applyRoomShape의 safeSpawn을 사용한다.
- storage는 roomLayoutVersion 표식을 검증한다. generationVersion34/게임0.38/랭킹 정책은 유지하며 구버전 지도 보존용 별도 경계는 만들지 않았다.
