# 플레이 피드백 1 — 장판류 연출

- 화염장판: 옅은 바닥색, 실제 반경 테두리, 내부에서 솟는 픽셀 불꽃. 기존 전경 불꽃 중복 제거.
- 아군 독가스: 녹색의 낮게 흐르는 안개. 적 독장판: 붉은 점선 예고에서 보라색 실선·안개로 전환. 투척 궤적 유지.
- 정예 폭발: 고정 반경 예고, 남은 시간에 따른 테두리 진행 표시, 발동 순간 0.6초 충격파와 파편. 독 시체 폭발도 녹색 충격파로 표현.
- 근접 오라: 범위 테두리와 회전하는 세 개의 짧은 호. 3레벨 보호막 준비 시 청백색 분절 테두리와 상단 표식. 중복 원·캐릭터 외곽선 제거.
- 피해량·반경·발동 시점·재사용 시간 변경 없음. 시간은 게임 경과 시간 또는 기존 효과 수명을 사용하며 렌더링 난수와 저장 상태 변경 없음.
- 기존 전체 테스트 305개 및 신규 범위·폭발 타이밍 테스트 2개 통과. Edge에서 8종 효과 갤러리, PC·모바일 4개 화면 크기 게임 실행 확인, 오류 없음. 실제 아이폰 검증 미실시.
