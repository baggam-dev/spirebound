# 플레이 피드백 1 — 장판류 연출

- 화염장판: 옅은 바닥색, 실제 반경 테두리, 내부에서 솟는 픽셀 불꽃. 기존 전경 불꽃 중복 제거.
- 아군 독가스: 녹색의 낮게 흐르는 안개. 적 독장판: 붉은 점선 예고에서 보라색 실선·안개로 전환. 투척 궤적 유지.
- 정예 폭발: 고정 반경 예고, 남은 시간에 따른 테두리 진행 표시, 발동 순간 0.6초 충격파와 파편. 독 시체 폭발도 녹색 충격파로 표현.
- 근접 오라: 범위 테두리와 회전하는 세 개의 짧은 호. 3레벨 보호막 준비 시 청백색 분절 테두리와 상단 표식. 중복 원·캐릭터 외곽선 제거.
- 피해량·반경·발동 시점·재사용 시간 변경 없음. 시간은 게임 경과 시간 또는 기존 효과 수명을 사용하며 렌더링 난수와 저장 상태 변경 없음.
- 기존 전체 테스트 305개 및 신규 범위·폭발 타이밍 테스트 2개 통과. Edge에서 8종 효과 갤러리, PC·모바일 4개 화면 크기 게임 실행 확인, 오류 없음. 실제 아이폰 검증 미실시.

## 2026-09-29 플레이 후기 검토 (구현 대기)
- 요청 범위: 검토 우선. 런타임 수정·배포 없음.
- 장판/범위: ground-visuals.js의 drawGroundField, drawAuraField, drawBurst에 원 stroke가 남아 있음. upper-visuals.js 인력 등 다른 범위 표시도 함께 점검. 선을 없애고 실제 피해 반경 안에서 부드럽게 사라지는 색 면·픽셀 불꽃/안개로 교체 제안. 적 예고는 색·명멸·중앙 경고로 타이밍 식별 유지.
- 첫 조우: engine.js 튜토리얼 추격자 4마리 HP 54, 기본 직격 17로 현재 4발. HP 51이면 무강화 기준 정확히 3발. 일반 적 전체 HP는 유지 제안.
- 화염 첫 선택: 1층 일반 최저 HP는 ceil(32*1.25)=40. hitEnemy 실제 호출 결과 기본 직격17+폭발22.32=39.32로 HP0.68 잔존 확인. 기본 합산40 이상이 되도록 폭발 소폭 상향 제안(기본 폭발 상수18→19라면 합산40.22). 정확히40을 요구하면 계수 재설계 필요. 유물/정수 등 강화 없는 기준이며 고레벨 폭발 영향도 검증 필요.
- 화염 속도: attackInterval은 .65/.7=0.92857초. 빈도 배율 .70→.67 제안: 0.97015초, 현재 대비 빈도 약4.3% 감소. 표시 설명도 30%→33% 감소로 일치 필요.
- 벽: stone-walls.js 본체 #59645e 및 밝은 상단 #a6ad91. 본체 명도 약8~10%, 상단 강조 약15% 감소부터 화면 비교 제안. 충돌/배치 변경 없음.
- PC 점멸: input.js Space와 touch-actions.js 마우스 click 모두 연결돼 있어 단순 누락은 확인되지 않음. abilities.js는 벽에 막혀도 쿨다운을 소비하며, 일시정지/쿨다운 중 실행 불가. PC HUD가 버튼을 가리는지, 클릭/Space/터치 지원 PC/선택창 복귀/벽 인접 조건을 브라우저에서 분리 재현해야 함. 현재 원인 미확정, 실제 브라우저 재현 미실시.
- 검증: 현재 코드 읽기 및 newRun/hitEnemy/attackInterval 직접 호출로 위 수치 확인. 전체 테스트 반복 없음. 다음은 사용자 구현 지시 후 점멸 재현부터 진행.
