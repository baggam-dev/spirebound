## 배포 전 검증

- 신규7+기존sound4 집중11/전체688 통과.
- native OfflineAudioContext에서12종 PCM 유효/검사한 복합 장면의 full-scale1 대비 최대진폭0.0397166, 경보 시 전투음 RMS비0.2800000, 정지/음소거 후 꼬리 파형0 확인. 실제 AudioParam·oscillator·gain 그래프를 렌더했고, 큐를 사전 예약하는 가상 시계 adapter를 썼다. effects-demo.wav 보존. 이 검사는 주관적 청취/스피커·실기 음질 검증이 아니다.
- 실제 Edge PC1280/가로모바일844에서 사용자 키 제스처 unlock, 실제 일반/약점 접점·화살비 첫착탄+5낙하/4연속착탄/마감·석궁 실발사/장전, 정지 시 현재/예약 전투음 취소, mute/volume0 및0→양수의 신뢰 입력 unlock 통과. 출력 장치는 음소거한 채 그래프/상태를 확인했다. 오류0·순위 제출0.
- 교정된 시각 QA2종 모두 PC/가로모바일×기본/완화4조합 통과. `actualReduced`가 false/true로 실제 설정과 일치함을 assert/결과 기록. 궁극기Canvas80/두궁극기 저장재개·실샷각/fallback, 발도4/보행8·보스180/하강12/최종key360XP·클리어/정지/저장재개/fallback/전역Canvas 통과. 과거 getter 사본 helper로 실제 전환을 보장하지 못했던 한계를 이번 실제 설정 재검증으로 닫았다.
- 초기 소리 QA의 타이틀 설정 선택자를 숨겨진 #settings에서 실제 #titleSettings로 교정했다. 로그/실패PNG·JSON 보존. 실행 환경 세션 변경으로 미완료 시각 QA2종만 서버 재시작 후 실행했으며 완료된 단위/오디오 성공은 반복하지 않았다. 런타임 추가 수정은 없다.
- 증거 docs/qa-sound-20261109/. 실제 iPhone/Safari·기기 청취·백그라운드 장기 복귀/부하 미확인.
