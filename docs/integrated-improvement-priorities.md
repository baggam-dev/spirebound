# 완주 후기 + 스킬/비주얼/출시 품질 통합 우선순위 (2026-09-30)

이 문서는 사용자의 화염 궁수 10층 완주 후기와 이후의 순수 화살·유틸 액티브, 전면 비주얼 개선, 출시 품질 목표를 하나의 **구현 권장 순서**로 묶는다. 세부 규칙은 `full-clear-feedback-review.md`, `skill-expansion-review.md`, `visual-overhaul-review.md`, `release-quality-roadmap.md`를 기준으로 한다. 현재까지는 설계 검토이며 아래 항목을 구현/배포했다고 뜻하지 않는다.

## 순서

| 순위 | 검토 가능한 작업 단위 | 이유와 통과 조건 |
| --- | --- | --- |
| 0 | **짧은 기준선 + 아트 규칙 + 랭킹 경계** | 숨겨진 보스 연습/동일 시드에서 9·10층 교전 시간·패턴 수·피격·귀환 출현표를 기록한다. 동시에 영웅/일반방/9층 지옥방의 2~3개 공통 색·픽셀·광원 시안을 비교해 하나를 고른다. 전투·스킬·출구 변경은 점수 비교에 영향을 주므로 BETA-1/ASCENT-1 기존 기록을 보존할 새 시즌/rulesVersion 경계를 결정한다. 이 단계는 대형 재설계가 아닌 다음 변경의 측정·아트 기준을 만드는 짧은 작업이다. |
| 1 | **9층 군단장 전투** | 실제 후기의 가장 선명한 결함이다. 이동/측면 사격·직선 저격 등 패턴을 늘리고, 빠른 빌드에도 첫 화살비/점멸이 보이는지 확인한다. 사용자가 확인한 후속 화살비 20초 간격은 유지 제안. HP 수치는 패턴과 교전 시간이 보인 뒤 조정한다. PC/모바일에서 모든 공격을 보고 피할 수 있어야 한다. |
| 2 | **10층 대악마 3페이즈 + 발자국 구멍** | 1·2페이즈의 이동·공격 빈도, 3페이즈의 선택/탄환 다양성을 조정한다. 구멍은 전투 중 유지하되 상한·경로 연결성·시각/충돌 일치·저장 재개를 통과해야 한다. 공격을 일괄 가속해 피할 수 없는 장면을 만들지 않는다. |
| 3 | **6~9층 진형과 9층 악마 적 4종** | 6층 군체·7층 천문관·8층 왕실·9층 군단의 대표 출현 비중을 높여 하강/귀환 반복을 줄인다. 박쥐·가시핵·악마 병사·부대장을 9층 일반방에서 역할별로 결합한다. 10층은 기존 샘물방+보스방 2방을 유지한다. 이 단계에서 전투/판정용 임시 아트는 넣되, 최종 에셋은 5단계의 공통 규칙을 따른다. |
| 4 | **정밀 사격 메인 + 유틸 액티브** | 보스/적의 실제 위협이 정해진 뒤 물리 직격 빌드와 버프·회복·소환의 상대 가치를 검증한다. 먼저 정밀 사격+직격 시너지, 다음 액티브 1칸/버프, 이후 회복·수호 환영 순. 레벨업 후보 희석, 자동 조준, 모바일 버튼, 저장/랭킹 등록을 통과해야 한다. 새 빌드 뒤에 **최종 보스 HP/탄속·적 HP를 다시 조정**한다. |
| 5 | **전면 비주얼 세로 조각 → 확장** | 0단계의 방향으로 영웅 얼굴/상체 비율, 기본 적·9층 악마 적, 1층 바닥/벽과 9·10층 지옥 질감, 물리/속성 화살·보스 위험 예고를 한 장면에서 함께 완성한다. 성공 후 모든 층/보스/HUD/결과 화면에 확장한다. 귀환 `brute`의 전신 빨강을 부분 발광으로 교체한다. 작은 모바일 화면의 적/탄환/안전 공간 구분과 전체 프레임 p95/p99를 비교한다. |
| 6 | **1층 탈출구 결말 전투** | 귀환과 빌드 밸런스가 정해진 뒤 30~45초 정도의 봉인 파괴/추격 이벤트로 마무리한다. 긴 추가 보스전으로 만들지 않고 저장·실패·탈출·랭킹 점수 조건을 검증한다. |
| 7 | **출시 품질 패스** | 사운드(공격·피격·보스·보상), 음소거/화면효과 조절, 시작/조작/8·10층 문구, 키보드/터치 접근성, 실제 PC/모바일 기기의 성능·30분 이상 저장 재개, 운영 백업/복원·랭킹·HTTPS를 점검한다. 실기기 검증은 에뮬레이션 결과와 구분한다. 외부 백업/알림처럼 사용자 서비스 정보가 필요한 작업은 해당 정보가 정해졌을 때 연동한다. |
| 8 | **통합 밸런스·새 시즌 릴리스 후보** | 화염/서리/독/번개/정밀 빌드로 일반방·9/10층·귀환·출구의 시간/피격/승률을 비교한다. 기존 BETA-1/ASCENT-1 기록·저장에 영향을 주지 않으면서 신규 시즌 제출/조회, 배포·롤백·복원·공개 QA를 검증한다. 기능 고정 후 제한 공개 피드백을 반영한다. |

## 작업 단위 원칙

- 1~6은 **독립적으로 검증·커밋할 수 있는 단위**다. 작은 단위별 로컬 테스트/화면 QA 뒤 배포와 공개 검증을 진행하되, 시즌 규칙/기존 기록 무결성이 준비되지 않은 변경은 운영 랭킹에 섞지 않는다. 9·10층 전투를 공개 변경하기 전에는 ASCENT-1, 6~8층 공통 출현표를 공개 변경하기 전에는 BETA-1까지 새 규칙/시즌 또는 별도 연습·오프라인 경로를 준비해야 한다. 기존 저장의 이어하기/제출 자격도 분리 검증한다. 문서만 바꾼 이번 단계에는 런타임 배포가 필요 없다.
- 5단계에서 전면 아트를 완성하지만 아트 방향 선택은 0단계에서 먼저 한다. 보스/몬스터의 실루엣과 위험 예고를 확정한 뒤 대량 에셋을 만드는 편이 재작업이 적다. 이전 비주얼 검토의 1층+2층 세로 조각은 9층 지옥방/신규 기술 예시를 함께 보여주는 방향으로 확장 제안한다.
- 4단계 기술 추가 전에 1~3단계의 **패턴과 이동**을 안정화하고, 기술 추가 뒤에 최종 수치를 잡는다. 보스 체력만 먼저 크게 올리면 현재 화염 빌드에서는 길어지고 새 정밀 빌드에서는 다시 쉬워질 수 있다.
- 사용자 원시 플레이 기록은 제공되지 않았다. 0단계 계측은 보스 연습/동일 시드 재현을 이용하며 실플레이 후기의 체감 판단을 우선한다. 9층 군단장 수정이 **첫 기능 구현 작업**이다.

보스전은 공격의 노출·대응·반격 박자가 있어야 한다는 [현업 보스 설계 설명](https://www.gamedeveloper.com/design/boss-battle-design-and-structure), 모바일 게임의 글자·조작 가독성을 강조하는 [Apple 게임 가이드](https://developer.apple.com/design/human-interface-guidelines/designing-for-games)를 참고한다. 이 게임의 실제 PC/모바일 플레이 결과가 최종 수치의 기준이다.
