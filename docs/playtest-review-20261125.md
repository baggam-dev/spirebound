## 1. 입장 전 서사: 넣는 것이 좋다

현재 `src/ui/story-copy.js`의 주인공은 **돌아오지 않은 원정대의 흔적을 쫓는 정찰병**이다. 이 정체성과 목적을 먼저 알려주면 입장·왕의 열쇠·탈출의 연결이 분명해진다. 새 혈통/복수/가족 설정을 추가하지 않고 기존 서사를 확장한다.

추천: **4컷 / 약 24~28초 / 평면 세로 스크롤 텍스트**. 글은 천천히 아래에서 위로 흐르고, 뒤의 그림은 장면당 약 6~7초 머무르며 0.8초 정도로 겹쳐 전환한다. 원근으로 기울인 글보다 모바일 가독성이 좋다. 텍스트는 이미지에 굽지 않고 별도 레이어로 둔다. ‘나레이션’은 우선 글 연출로 해석하며 음성 녹음·TTS는 이번 제안에 포함하지 않는다.

| 컷 | 배경 시안 방향 | 글 초안 |

| 1 | 밤에 잠긴 왕국과 멀리 솟은 탑 | 왕국에는, 밤이 끝나지 않는 탑이 있었다. 문을 지난 이들은 돌아오지 않았다. |

필수 흐름: 처음 새 원정에 기본 재생, 이후 원정은 짧은 입장 또는 ‘서사 다시 보기’ 선택. 항상 건너뛰기·일시정지/빠르게 넘기기를 제공한다. 이어하기·보스 연습에서는 재생하지 않는다. 모션 감소에서는 스크롤 대신 같은 네 장의 고정 문단 전환을 쓴다. 탭 비활성·세로 전환 때 시간/읽기를 멈추고, 자산 실패 시 글/정지 화면 또는 즉시 입장으로 이어간다. 서사·입장 중 전투 시간, 위험 판정, 랭킹 도전 시간이 먼저 흐르지 않도록 현재 시작 경계와 묶어 검토한다. 저장을 지웠다고 서사를 보지 못하는 구조로 만들지 않는다.

## 4. 모르도 소환: 해골 전사·궁수로 교체

현재는 2페이즈부터, 약6초 간격·동시2체 상한으로 `astralSniper` 또는 `pulseTurret`를 HP180으로 소환한다. 1페이즈에는 없다. 단순 교체가 아니라 **전용 역할·AI·그림·생존 수 제한·소환 전조**가 필요하다.

사용자 요구를 그대로 일정표로 삼는다:

| 페이즈 | 주기 | 구성 | 정예 |
|---|---:|---|---|
| 1 | 5초 | 전사 **또는** 궁수1체, 무작위 | 그1체가 정예 |
| 2 | 5초 | 전사1+궁수1 | 2체 중 정확히1체 |
| 3 | 3초 | 전사2+궁수2 | 4체 중 정확히1체 |

3페이즈는 분당80체 추가다. 추천 동시 생존 상한은 **1페이즈4 / 2페이즈6 / 3페이즈12**, 그중 정예는 동시3체까지다. 정예 슬롯이 가득 차면 신규 세트 전체를 대기시키고, 한 틱에 밀린 여러 세트를 몰아서 소환하지 않는다. 생존 수가 내려간 다음 정상 주기에 한 세트만 시도한다. 상한은 사용자 지정이 아닌 초기 추천값이다.

소환 시작은 해당 페이즈 진입 후 지정 주기, 별도 바닥 인장 0.7~0.9초 전조 뒤 등장한다. 플레이어 바로 발밑, 탈출구·벽 속에는 등장하지 않는다. 한 패턴에서 광선·돌진과 궁수 예고가 겹칠 때 최소 회피 통로를 남긴다. 전환 때 이전 소환 타이머를 초기화해 즉시 대량 소환하지 않는다. 본체 사망/퇴장 시 소환체·전용 탄환을 정리한다. 원본 그림자 보스의 소환 금지는 우선 유지한다.

### 해골 전사

- 외형: 탑의 낡은 군복·철편을 걸친 마른 해골, 짧은 검/장검과 칼집. 보라색 몸통 오라를 PNG에 굽지 않고 눈빛·정예 효과는 별도 레이어.
- 움직임: 빠른 접근, 근접 짧은 베기와 거리 조건의 대시 베기. 대시 방향 고정 전조 → 직선 돌입 → 빗나갔을 때 짧은 빈틈. 방향을 끝까지 플레이어에게 꺾는 추적 돌진은 피한다.
- 초기 이속160 전후를 검토하되 실제 적/주인공과 비교 후 조정한다. 일반2~3초, 정예4~6초 정도는 살아 역할을 보여 주는 후반 기준 체감이 목표이며, HP는 대표 후반 빌드 DPS 검증 후 정한다. ‘항상 플레이어 DPS에 맞춰 자동 강화’하는 시스템은 추가하지 않는다.

### 해골 궁수

- 외형: 가벼운 망토·갈비뼈 실루엣·각진 뼈 활로 전사와 구분. 이동 빠름/사격 빠름, 무릎·상체 장전 자세와 발사 반동 필요.
- 매 사격 **부채꼴 / 반사 탄환 / 일자 연사** 중 무작위. 예고 아이콘·활 자세를 달리해 무엇을 쏘는지 구분한다. 같은 패턴3회 연속은 피한다.
- 초기안: 이속170 전후, 발사 사이 약1.2~1.5초, 부채꼴3~5발 / 벽 반사1회 / 일자3연사(0.10~0.14초 간격). 이동 중 즉발하지 않고 0.25~0.4초 조준 정지와 전조를 둔다. 모든 수치는 추천 초깃값이다.
- 반사 탄환은 수명/반사횟수/방 전체 탄 수에 상한을 둔다. 정예 포화가 일자 연사의 모든 발을 무제한 복제하지 않도록 기존 정예 특성과의 중첩을 별도 검토한다.

공통: 소환체는 **성장 보상·처치 물약 없음**, 다만 실제 피해량·전투 기록은 현재 기준에 맞춘다. 본체 HP-15%와 소환압 상승을 한 묶음으로 평가한다. 스프라이트는 기본형·이동·예고/공격·피격/사망·정예 별도 효과를 두 캐릭터 패키지로 먼저 제시한다.

## 5. 베르가스 등장률: 실제로 낮게 설정돼 있다

## 6. 일섬: 짧은 발도 돌진 + 1/2/3회 충전

현재 `roll.js`: 기본 일섬0.28초, 평타300% 경로1회, `rollMastery.max=1`이다. **현재 강화2/3단계가 존재하지 않으므로 실제 업그레이드·선택창·저장 이행이 필요**하다.

추천 해석: 1단계1회 / 2단계2회 / 3단계3회 **충전식 연속 사용**. 매번 버튼을 눌러 방향을 선택하고 다음 베기를 잇는다. 자동3회는 원하지 않는 방향·위험 지점으로 들어갈 수 있다. 누르고 있기 연속 시전은 선택 기능으로 두되 모바일 기본은 빠른 재입력, 약0.15초 입력 버퍼를 권한다.

- 1회 이동 **0.10~0.12초**를 초깃값으로, 지금보다 약57~64% 짧게. 회피 전체를 바꾸지 않고 일섬 분기만 변경한다.
- 큰 동작: 칼집에 손 → 몸을 깊게 앞으로 숙임 → 짧은 초고속 돌입/큰 사선 베기 → 납도. 준비는1~2프레임으로 압축하고, 납도는 이동이 끝난 뒤 시각 후행으로 처리해 입력을 오래 묶지 않는다. 활·검의 실제 손 위치와 장비 연결을 패키지 시안에서 확인한다.
- 연출: 칼끝/경로의 짧은 백금 섬광, 넓은 사선 참격, 두 겹 잔상과 끝 점의 작은 파편. 실제 적중 순간에만 짧은 카메라 충격·타격음·국소 플래시를 묶는다. 연속3회가 전 화면 흰색 점멸3회가 되지 않게 한다. 모션/섬광 감소 옵션 유지.
- 피해는 우선 **각300%**, 3회 동일 대상을 관통하면 최대900%가 의도된 강화다. 같은 적은 한 번의 베기 안에서1회만 맞고, 다음 충전 사용에는 다시 맞을 수 있다. 벽 관통/얇은 벽 뒤 피해는 금지한다.
- 각 돌진의 무적은 실제 이동 구간까지만, 사이에는 추가 무적을 주지 않는다. 마지막 사용 이후 기존 재사용시간에 맞춰 묶음 충전을 회복하는 안을 출발점으로 한다. 세부 재충전/아이콘은 시안에서 명확히 제시한다. 충전3개가 각자 기존 긴 쿨을 더해15초를 기다리는 형태는 피한다.
- 다음 입력까지 조준을 갱신하고, 벽에 막히거나 대상이 죽어도 재입력 전까지 강제 돌진하지 않는다. 일시정지/방 이동/사망에서 미시전 예약 입력은 정리하며 이동이 저장 복구로 재실행되지 않게 한다.
- 기존 회피 진화의 지뢰/질풍은 그대로 두고 일섬 분기에만 추가 강화 후보를 연다. 기존 저장의 일섬은1단계로 유지한다. 전용 칼 실루엣·발도/대베기/납도·타격 효과를 한 번에 검토한다.

## 7. 권장 진행 순서와 검증 경계

1. **작은 수치 묶음:** 안내 패널/자동 시간·정예70%·그림자1/2·베르가스 가중치. 요구 해석을 문서와 설명문에 함께 반영한다.
2. **일섬 패키지:** 주인공 큰 발도 동작·참격 효과·1/2/3회 충전 UI 시안 → 승인 후 실제 입력/이동/피해/저장 연결.
3. **모르도 패키지:** 두 해골의 외형/모션/전조 시안 → 승인 후 전용 AI/정예 조합/소환 상한·정리와 HP-15%를 함께 적용.
4. **서사 패키지:** 위 문구+4컷 시안 → 승인 후 앞서 준비한 야간 입장 컷신과 연결. 본 요청만으로 미승인 인트로 패키지를 승인된 것으로 기록하지 않는다.
5. 새 명시 배포 지시 때 변경 범위의 테스트·브라우저·성능 확인을 묶어서 실행, 통과 후 푸시/배포/공개 확인한다.

배포 전 확인할 핵심: 더 짧아진 대사 가독성·70% 판정1회성, shadow1/2만 HP상승, 왕 HP비율/구원정 이행, 페이즈별 정확한 소환 구성/정예 수/상한과 탄 수, 본체 사망 정리·성장 보상 악용 방지, 3회 일섬의 경로 충돌/중복피해/입력·무적·쿨타임/저장, 오프닝 스킵·재접속·모션감소/로드실패와 전투 시계 경계. 현재 코드 열람 중 도움말의 수도사 ‘3회 제한’ 문구가 실제 무제한 회복 개편과 어긋난 것도 발견했으므로 해당 안내 갱신을 같은 문구 정리 묶음에 포함한다.
