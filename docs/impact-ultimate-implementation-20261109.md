## 타격과 화살비

- `drawImpactAccent`에 일반/강타/궁극기 3단계 접점 크기·파편 수/길이 차이, 첫45ms 국소 암부/밝은 핵을 모았다. 기본 화살/약점·베기 접점/화살비 주력 착탄에 연결했다. 기존 화살/약점/베기 효과 수명과 상한을 재사용한다. 적 전체 몸체·AI 피격/경직·세계시간·카메라를 바꾸지 않았다.
- 화살비는24개 주력/보조 화살, 완화는12개다. 굵은 주력6개의 접점과 작은 보조 착탄·먼지/박힌 화살·후속 낙하를 분리했다. 실제 `pulses`와 `elapsed`로 그리며 첫 즉시 피해 및 .3초 간격6회/반경280/1.8초 종료를 유지한다. 마지막 회차에는 시각 파편만 추가하고 일곱 번째 낙하는 만들지 않는다.
- `passives.js`에서 기본/완화 설정을 궁극기 그리기까지 전달했다. 기존 적 경계·적탄 상단 패스의 순서는 유지했다. 현재 Canvas 불투명도는 상속하여 곱하고 저장/복원한다.

## 석궁

승인 `crossbow-poses-v2.png`를 무변환 생산 사본으로 복사했다(1254²/RGBA/1,017,542bytes, 원본/시안 SHA256 일치). 생성 원본·v1/v2·프롬프트는 docs/design-drafts/impact-ultimate-20261109/에 보존했다. 새 생성이나 오프라인 이미지 변환은 없다.

`crossbow-art.js`는 각627² 셀을 .14배 캐시하고 하부 받침과 상부 기계로 나눈다. 설치/장전/발사반동/접기4자세를 실제 build/recoil/ending에 연결한다. 받침은 회전하지 않고 상부만 실제 `t.aim`을 따른다. 섬광·속성 표시·설치 먼지·회수 파편은 PNG와 별도로 그린다. 남은 수명 표시는 유지한다. 실제14초 수명과 .6초 사격, 표적 선정/탄환·피해·무기 스냅샷/저장 상태는 변경하지 않았다. 시안의2.2초 압축은 실제 게임에 사용하지 않는다.

새 PNG 로딩/크기/크롭 실패는 준비 완료를 막지 않고 기존 도형 석궁으로 대체한다. 대체 석궁도 상속 불투명도와 완화 설정을 따른다. 새 모듈을 공통 자산 팩에 연결하여 구저장/하강/연습에서도 쓸 수 있게 했다. 초기 다운로드는1,017,542bytes 증가한다. 자산 예산 테스트는 원래40MB를 유지하며 승인 발도/석궁 각2MB만 별도 허용(총44MB 미만)하도록 갱신했다. 실제 전송/로딩 지연은 미측정이다.
