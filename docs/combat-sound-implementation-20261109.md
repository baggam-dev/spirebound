# 타격·궁극기 효과음 구현 — 2026-11-09

사용자 `ㄱㄱ`로 일반/약점/강한 베기 및 화살비·석궁 전용 효과음, 중첩 제한·경고음 우선 개선을 승인했다. 기존 WebAudio 합성음을 확장했다. 새 외부 음원·라이브러리·BGM·설정 화면은 추가하지 않았다. 이번은 구현·정적 검토·로컬 커밋이며 테스트/청취·배포 완료가 아니다.

## 소리와 실제 동작 연결

- 일반: 짧은 낮은 접점+작은 고역 클릭. 약점: 더 낮은 핵·선명한 금속성 접점/짧은 여운. 베기: 빠르게 내려가는 마찰음·접점. 합성 파형/주파수 하강·음량/길이를 분리했다. 한 simulation update에서는 약점→베기→일반 순으로 가장 강한 실제 접점 하나를 고른다.
- `precisionBurst`, `slash`, `arrowImpact`, `hitElement`를 사용한다. 지속 피해의 일반 `enemyFeedback`만으로는 소리를 만들지 않는다. 발도는 실제 `roll.hit` 증가를 읽으며 마지막 틱에 roll이 제거되어도 직전 참조로 그 틱의 접점을 읽는다. 적/저장 상태를 추가하거나 피해 판정을 바꾸지 않는다.
- 화살비 발동음은 첫 즉시 착탄을 포함한다. 이후 실제 pulses 증가4회는 연속 착탄,6번째는 마감음이다. 다음 타격 .18초 전의 낙하는5회만 알린다. 시뮬레이션이 여러 회차를 건너뛰면 최신 착탄 하나로 합쳐 재생 밀림을 막는다. 새 타이머나 예약된 미래 피해 소리는 없다.
- 석궁은 설치/발사/재장전/접기로 나뉜다. 발사는 실제 `clock` 증가, 재장전은 다음 발사까지 .18초 경과 경계, 회수는 실제 turret 참조 제거를 관찰한다. 무표적 clock0은 발사음을 만들지 않는다. 최대2대 교체 시 이전 구조물 제거도 한 번만 알린다.
- `combat-audio.js`는 run/room·rain 참조와 pulses·turret clock·roll 접점을 메모리에만 보관한다. 행동/step 전에 현재 상태를 기준점으로 잡고 실제 변화만 읽는다. 불러오기·새 방·새 run에서는 과거 발동/착탄/발사를 재생하지 않는다. 상태는 저장되지 않는다.

## 믹싱과 수명

combat/world/alert3버스와 master 음량을 둔다. 전투 동시 음성은12개, UI/보상은8개, 경고/피격/보스 경보는 별도8개 이하로 제한한다. 큐별·계열별 간격과 보상 계열 기존 .2초 제한을 유지한다. 더 강한 접점은 약한 계열 제한을 넘어올 수 있고, 공간이 부족하면 우선순위가 낮은 전투 음성을 정리한다.

경고·피격·보스 경보는 전투 음량을 .008초에 .28배로 낮추고 마지막 경보 이후 .32초까지 유지한 뒤 .08초에 복원한다. 경고와 UI/보상은 전투 버스와 분리된다. 실제 기기에서의 음색/가청성·왜곡·경고 인지성은 아직 청취하지 않았다.

음소거/볼륨0은 이미 재생/예약한 음성도 정리한다. 일시정지는 전투/경보 음성만 끊고 UI 소리는 유지한다. 타이틀·로드/새 run의 transient reset은 전체 음성과 이전 큐 간격을 정리한다. AudioContext는 기존 사용자 제스처 unlock을 유지한다. 설정에서 음량0→양수로 올리는 사용자 입력에서도 unlock을 시도한다. 설정 키/기존 필드와 기본 음량은 유지한다.

## QA 도구 수정과 확인 한계

음량/설정 연결을 확인하다 기존 두 시각 QA의 `sound.settings.reducedEffects=v`가 getter 사본만 바꾸는 것을 발견했다. 해당 helper를 `sound.update()`로 교정하고 실제 반환 설정을 assert/결과에 넣도록 준비했다. 기존 direct Canvas의 reduced 인자 검사와 달리, 과거 helper만으로 실제 게임 완화 모드 전환을 보장하지 못한다. 다음 배포 검증에서 실제 설정 전환/저장 재개를 다시 확인해야 한다. 이번에 기존 배포를 재검증한 것은 아니다.

신규 `combat-audio.test.js`4건(접점 우선순위/실6회·5낙하·중복/로드·catch-up·방이동/실발사·교체·발도 마지막 틱), `sound-mix.test.js`3건(음색·duck·음소거/음성 상한·경보 여유/정지·예약음 취소)을 작성했다. **미실행**이다. 기존 sound4건과 함께 다음 명시 배포 지시 후 실행한다.

이번 확인은 소스/호출 순서·설정/저장 분리·새 모듈 공개 QA 목록 대조 및 git diff --check뿐이다. 테스트·구문 실행·서버·브라우저 QA·오디오 렌더/청취·푸시/배포/공개 확인은 수행하지 않았다. 실제 iPhone/Safari unlock/중단복귀·AudioContext 실패/음성 정리·중첩 부하/음색은 미검증이다. 새 배포 시 가짜 Audio 계약·실제 OfflineAudioContext 파형/최대 진폭·사용자 제스처/음소거/볼륨/정지·저장/6회 타격/무표적/석궁 교체·경고 겹침·실제 완화 설정을 묶어 검증한다.

게임 피해·AI·시간·사격 주기·RNG·DB/저장 스키마·랭킹/버전은 변경하지 않았다. 운영0.52는 이전 배포 기록이며 이번에 재확인하지 않았다. BGM은 기존 보류다.
