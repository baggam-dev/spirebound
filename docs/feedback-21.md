# 0.21 서리·선택형 궁극기·유니크 유물

## 포션과 시련

- 포션 기본 회복 1하트, 재사용 3초. 은빛 성배 보유 시 2하트. 체력이 가득 차면 사용하지 않는다. 쿨타임은 일시정지 중 멈추며 저장된다.
- 시련 전투에서 받는 접촉·돌진·탄환·독 피해를 1하트로 제한한다. 시련 정예의 사망 폭발도 전투 종료 후까지 1하트로 유지한다.

## 서리 화살

| 레벨 | 빙결까지 적중 | 추가 서리 피해 | 파편 피해 |
| --- | --- | --- | --- |
| 1 | 4회 (3중첩 후 다음 적중) | 공격력 10% | 공격력 35% |
| 2 | 3회 | 15% | 40% |
| 3 | 2회 | 20% | 45% |
| 4 | 2회 | 25% | 50% |

- 9월 17일 밸런스 조정: 서리 본 화살과 추가 속성 피해, 파편 실제 피해에 0.92배 적용(8% 감소). 위 표는 감소 전 계수다.
- 중첩 최대 3, 3초 유지. 1/2/3중첩 이동 둔화 15/25/35%, 공격 둔화 10/20/30%. 보스 둔화는 절반. 공격 둔화는 다음 공격 준비에 적용하며 이미 발사된 탄속은 바꾸지 않는다.
- 빙결은 일반몹 1.2초, 보스 0.45초. 종료 후 2초 재빙결 면역 유지.
- 중첩 또는 빙결 상태에서 죽으면 6갈래 파편. 4레벨에서 빙결 사망하면 12갈래. 적당 한 번만 발생한다.
- 중첩 1/2/3개 파편 크기 0.5/1/1.5배. 빙결은 1.5배. 파편 속도 320 → 480. 파편도 같은 중첩 규칙을 적용한다.
- 원소의 결정은 추가 서리 피해와 파편을 강화한다. 빙결 시간은 강화하지 않는다. 지속 피해 유물은 화상·독을 강화하며 서리와는 별개다.

## 궁극기 습득

자동 해금을 폐지했다. 경험치 레벨업 선택지 세 칸 중 최대 한 칸으로 등장한다.

- 5레벨: 미습득이면 확정.
- 6~9레벨: 미습득이면 매 레벨업 30%.
- 10레벨: 미습득이면 확정 1회.
- 11레벨 이후: 미습득이면 매 레벨업 30%.
- 카드 선택 후 화살비 또는 자동 저격 석궁 중 하나를 고른다. 추가 포인트 소비 없음.
- 확정/무작위 후보와 새로고침 결과를 저장한다. 후보 새로고침은 궁극기 칸의 등장 여부를 유지한다. 여러 레벨을 한 번에 올려도 5·10레벨 기회를 보존한다.
- 상자·신전 등의 추가 기술 보상은 경험치 레벨업이 아니므로 궁극기 등장 추첨을 하지 않는다.

### 화살비

시전 위치에 반경 280 영역을 고정하고, 0/0.6/1.2초에 각각 60 피해를 준다. 매 타격 때 범위 내 대상만 판정한다. 반투명 하늘색 영역과 낙하 화살은 1.8초 유지한다. 기본 재사용 25초.

### 자동 저격 석궁

시전 위치에 19초간 고정 설치. 파괴되지 않으며 사거리 308 안의 가까운, 장애물에 가려지지 않은 적에게 0.5초마다 공격력 200% 일반탄을 발사한다. 궁극기 피해 유물은 적용되며 갈래·연속·주력 속성은 적용하지 않는다. 마지막 3초간 깜박인다. 기본 재사용 20초, 유지시간은 쿨감과 무관하게 19초로 고정한다. 쿨감 유물 하나로 2~3초 동안 최대 2대 공존 가능. 세 번째 설치는 가장 오래된 석궁을 교체한다. 방 이동 시 설치물과 활성 화살비는 종료된다.

## 유니크 유물 6종

일반 유물 25종에 아래 6종을 추가했다. 유니크 개별 추첨 가중치는 일반의 40%로, 모두 미소유일 때 한 번의 추첨에서 유니크가 나올 확률은 약 8.8%다. 보스·시련·신전 유물 추첨에 동일하게 적용한다.

| 유물 | 효과 |
| --- | --- |
| 태양요정 | 1.5초마다 주황 유도탄. 공격력 40% 직격 + 3초간 총 60% 화상. 같은 요정 화상은 갱신하며 중첩하지 않음 |
| 눈꽃요정 | 1.5초마다 하늘 유도탄. 공격력 50% 직격 + 2초 이동 둔화 25% |
| 번개요정 | 1.5초마다 노랑 유도탄. 공격력 80% 직격 + 주변 1마리에 절반 피해 |
| 잔상의 망토 | 점멸 무적시간 +2초, 기본과 합쳐 2.45초 |
| 궤도 칼날 | 반경 65를 도는 칼날 2개. 공격력 50%, 같은 적 피격 간격 0.6초 |
| 공허의 종 | 12초마다 가까운 적 주위 반경 180의 몬스터를 1초간 끌어모음. 보스 제외 |

요정은 독립된 주기로 자기 위치에서 발사하며, 사거리 360 안의 가까운 적을 겨냥한다. 패시브 공격으로 사망한 적은 서리 파편을 연쇄 생성하지 않는다. 유니크 아이콘에는 보라 테두리를 사용한다. 기존 혜성의 꼬리는 점멸 거리 +25% → +50%로 상향했다.

## 기존 저장

지도·유물·스킬을 유지한다. 이미 선택한 화살비는 신규 화살비로, 기존 잔류 화살비는 석궁으로 이전한다. 궁극기를 선택하지 않은 저장은 이후 경험치 레벨업부터 새 습득 규칙을 적용한다. 포션 쿨타임, 궁극기 후보와 습득 상태, 서리 파편, 요정 주기, 석궁 수명, 화살비 타격 진행을 저장한다.

## 9월 17일 추가 밸런스

- 4층 수호자 첫 소환 3 → 2초, 반복 간격 10 → 7초. 보호막 및 생존 3마리 제한 유지.
- 상자 유물 가중치 8/100 추가, 회복 가중치 28 → 20. 사용 불가능한 보상 재추첨에 따라 실제 획득률은 더 높아질 수 있다.
- 시련 유물 가중치 0.5 → 4. 세 선택지는 보상 종류 중복 없이 추첨한다. 보스 확정 보상과 유니크 상대 가중치는 유지.
- 검증: 자동 테스트 207개 통과. 쿨감 유물별 2~3초 석궁 중첩, 설치 위치 기준 사거리 경계, 공격 간격/피해, 상자 확률 구간, 1,000개 시드 시련 중복 방지 및 저장 상태 검증 포함.
