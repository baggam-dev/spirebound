# 0.59 프롤로그·서사·강적 대사 배포

사용자 명시 배포 지시에 따라 0.58 운영 코드 `594f41d` 이후 누적 변경을 검증한다. 클라이언트/API 최신 허용/헤더는 `0.59.0-prebeta`. 시즌·점수식·전투 수치·DB 원본은 유지한다. 아래는 배포 전 증거이며 실제 운영 릴리스는 배포 후 기록한다.

## 포함 변경

- 승인된 ‘왕에게 남은 밤’: 프롤로그 동기, 개정 보스 대사, 층 제목, 열쇠·귀환 안내, 생환 후일담. 고전/확장·구버전 배치 분기.
- 7초 4컷 프롤로그: 접근→장비 정리→문턱 통과→문 닫힘. 새 PNG 4개 약 9.1MB, 기존 보행/문 자산 재사용. 원본·프롬프트는 디자인 제작 문서에 보존.
- 원정 기록에 방문한 층의 흔적 10개/목격한 적 12종 관찰, 보유 유물 10종 이야기. 선택형 펼침, 미방문 선공개 방지.
- 강적 47개 랜덤 한 줄: 정예 특성/시련/고유 강적·보스. 구간별 방당 2회, 기존 보스 대사와 주요 예고 우선. 일시 표현 상태/별도 난수, 전투·세이브 상태 불변.
- 봉인 잔해 도감 부위 표기를 실제 전투 명칭과 통일.

## 검증과 수정

증거: `qa-story-release-20261121/`.

- 최초 전체 870/870, 신규 서사·대사 단위 6/6. 추가 회귀 포함 전체 876/876 (`full-final.log`). 실제 표시 연결 수정 후 전체 결과는 후속 기록한다.
- 실제 Edge 프롤로그 12케이스: PC1280×720/모바일844×390 에뮬레이션, 4컷/자동 종료/스킵/입력 소비/저장 재개/로드실패·타임아웃/회전·blur·저장실패/완화·연습 제외. 페이지 오류·점수 제출 0.
- 귀환·하강 19케이스: 전환·스킵·재개/키 저장실패/로드 실패/일시정지 등 (`journey/result.json`). 생환 17케이스: 완료 기록 1회/스킵·중단·fallback/결과 동작 (`escape-final/result.json`). 페이지 오류·점수 제출 0.
- 선택 기록·유물 펼침/후일담·고전확장 분기/닫힌 문·추적자 말풍선 PC/모바일 Canvas 검사, 렌더 전후 상태 동일. 실제 저장 원정 재개 후 게임 루프의 대사 표시도 두 뷰포트 통과 (`story-integrated-fixed/result.json`).
- 발견·수정: `clearActive`는 ‘클리어 연출 시계를 진행해도 됨’인데 이를 ‘클리어 연출 표시 중’으로 써서 실제 게임의 잡담이 항상 숨겨졌다. `bossClearState(s)?.age < 1.5`로 실제 표시만 억제하도록 고쳤다. 모듈 단독 검사로 발견할 수 없던 통합 연결 오류이며 통합 실패·성공 증거를 모두 보존한다.
- QA 보정: 3초 생환 장면 사이 스크린샷 인코딩 대기 때문에 다음 장면을 놓침→RAF에서 Canvas 프레임을 모아 검증. 추적자 단독 QA의 DeferredImage 자산을 활성화하지 않아 대기→명시 준비 후 검증. 게임 제한시간을 늘려 우회하지 않았다.
- 주요 캡처 직접 검토: 외부 근경/내부 최종 닫힘·모바일 후일담/추적자 말풍선. 실제 게임 캡처는 주요 예고 발생 시 말풍선이 숨겨질 수 있어 최초 표시 Canvas 프레임도 별도 보존한다.

## 남은 실제 평가 범위

물리 iPhone·사람의 소리 청취·장시간 전체 원정과 대사 재미/빈도 체감은 이번 자동 검증으로 확정하지 않는다. 모든 탄막·장판을 피해 말풍선을 배치한다는 보장은 없고 주요 공격/연출을 우선 억제한다. 저장 재개 시 잡담 이력은 초기화하며 새 세이브 필드는 없다. 신규 이미지의 공개 cold/warm 로딩은 배포 후 확인한다. 운영 점수는 제출하지 않는다.
