# 통합 순위 5번 비주얼 개선 — 단계별 적용

2026-10-01. 전체 범위와 아트 원칙은 [visual-overhaul-review.md](visual-overhaul-review.md), 통합 순서는 [integrated-improvement-priorities.md](integrated-improvement-priorities.md)를 따른다. 대표 장면을 한 단위씩 개선한다. 전체 비주얼 개선 완료 여부는 [WORK_STATUS.md](WORK_STATUS.md)를 기준으로 한다.

## 첫 단위: 1·9·10층

- 1층은 기존 재의 성채(A) 팔레트를 유지하면서 영웅의 상체를 4픽셀 줄이고 금발 가르마·눈썹·눈·입을 다시 배치했다. 보행·활쏘기 판정/저장 상태는 그대로다.
- 9층은 적갈색 현무암(B), 10층은 더 어두운 자주색 현무암으로 바닥·외곽/내부 벽·상단 부조·횃불을 구분했다. 고정 위치의 낮은 대비 균열과 벽 면의 균열 광점은 장식이며 위험 예고를 뜻하지 않는다. 기존 48×40 벽 격자와 캐시 4장 상한을 유지하고, 같은 지형이라도 층 테마가 바뀌면 캐시를 갱신한다.
- 9층 폭렬 박쥐의 날개/눈, 가시핵의 밑뿌리/가시, 악마 병사/사수/부대장의 갑옷 판을 분리해 어두운 바닥에서도 실루엣을 구별한다. 귀환 도약 거인은 전신 빨강 덮어쓰기를 없애고 녹색/철색 몸통에 눈·어깨·무기 일부만 붉게 표시한다.
- 전투 충돌·공격 타이밍·위험 예고·랭킹 시즌·저장 형식은 변경하지 않았다. 10층은 원래 샘물방/보스방 구조 그대로다.

실제 로컬 화면: [9층 PC 캡처](visual-stage5-9f.png), [영웅·도약 거인 확대 비교](visual-stage5-actors.png). 두 이미지는 검증용 캡처이며 원화/최종 에셋은 아니다.

## 검증과 남은 범위

- 전체 `node --test` 396개 통과. 벽 재질과 캐시 층 테마 갱신 테스트 포함. 로컬 Edge PC1280×800·모바일 에뮬레이션390×844에서 1·9·10층 6장면과 6~9층 회귀 8장면, pageerror 0.
- 격리된 Canvas 정지 장면 120회 측정: 1/9/10층 p95 0.2~0.3ms, p99 0.3~0.5ms. 전체 게임 프레임·실기기 FPS 또는 변경 전 대비 개선을 뜻하지 않는다.
- 운영 `release-20260930-230723-cd53ab` 배포 후 서버 Python24개·Nginx·인증서·HTTPS health 통과. 공개 Edge PC/모바일 에뮬레이션 1·9·10층 오류0, HTTPS 정적5개 일치·HTTP308·랭킹·Secure/HttpOnly 쿠키·기존 HTTP 저장 이전 정상. 운영 도전/점수 제출 없음.
- 이후 같은 규칙을 2층 첫 보스와 기본 적, 다른 층·보스·물리/속성 화살의 준비/발동/피격, HUD/결과 화면에 확장하고 실제 기기 가독성 및 전체 프레임 p95/p99를 비교한다. 이 문서의 첫 세로 조각만으로 5번 전체를 완료 처리하지 않는다.

## 둘째 단위: 첫 보스·기본 적·화살·PC HUD

- 2층 파수꾼에게 차가운 철 투구·산화된 왼쪽 어깨·따뜻한 오른쪽 견갑을 구분해 넣었다. 기본 적은 사수/측면 이동형, 돌진형, 산탄형, 추격/매복형에 작은 갑옷 표식을 더했다. 실루엣과 공격 예고는 유지한다.
- 무속성 정밀 화살은 금빛 화살촉·좁고 짧은 잔상으로 속성탄의 넓은 발광과 구분한다. 기존 화염·빙결·독·번개 발사체를 유지한다. PC 능력치 글자 뒤에는 오른쪽으로 짙어지는 바탕과 대비선을 둔다. 750px 이하 모바일 HUD 규칙은 바꾸지 않았다.
- 전투 피해·충돌·공격 주기·저장·시즌은 변경하지 않았다. 로컬 전체 `node --test` 396개 통과. Edge PC1280×800 파수꾼과 모바일 에뮬레이션 844×390·390×844·667×375 왕 장면/갤러리에서 pageerror 0, 화면 넘침 없음, 반복 렌더 상태 안정. 스킬 선택 PC/모바일, G/터치 유틸·저장 회귀 QA도 오류0. 발사체 150개 격리 그리기 중앙값 약0.7ms로, 전체 프레임이나 사용자 체감 성능 지표가 아니다.
- 운영 `release-20261001-172601-940a52` 배포 후 서버 Python24개·Nginx·인증서·HTTPS health 통과. 공개 Edge PC1280×800의 파수꾼·프리즘·슬라임·문지기·왕, 모바일 에뮬레이션 844×390·390×844·667×375의 왕과 갤러리 모두 오류0·넘침 없음. 공개 HTTPS 정적5개 일치·HTTP308·랭킹·Secure/HttpOnly 쿠키·기존 HTTP 저장 이전 정상. 운영 점수 제출 없음.
- 이후 남은 층·보스·스킬 준비/발동/피격·결과 화면과 실제 기기/전체 프레임 비교를 계속한다. 둘째 단위만으로 5번 전체를 완료 처리하지 않는다.

## 셋째 단위: 3~8층 석조 재질

- 서고·프리즘·온실·군체·천문관·왕실에 회청색, 자주색, 이끼 녹색, 황토색, 푸른 회색, 붉은 갈색의 낮은 대비 벽 면과 작은 마모 표식을 더했다. 1·2층의 기존 성채 석조와 9·10층 현무암은 유지한다. 6층의 넓은 벽 면은 화면 검토 후 밝기를 한 단계 낮췄다.
- 외곽벽과 내부 벽은 같은 월드 좌표 48×40 격자·층별 팔레트로 그린다. 정적 이미지 캐시 최대4장과 층 전환 시 무효화는 유지한다. 충돌·배치·저장·랭킹 상태는 바꾸지 않았다.
- 로컬 검증: 전체 `node --test` 397개(신규 벽 팔레트1개). Edge PC1280×800·모바일 에뮬레이션390×844에서 1~10층 20장면, 오류0·넘침 없음·색상10종 구분·상태 안정. 격리 Canvas 120회/층 p95 0.2~0.3ms, p99 0.2~0.4ms. 이는 전체 프레임/FPS가 아니다.
- 운영 `release-20261001-175511-d82f08` 배포 후 서버 Python24개·Nginx·인증서·HTTPS health 통과. 공개 Edge PC/모바일 에뮬레이션 1~10층20장면 각각 오류0·넘침 없음, 공개 HTTPS 정적5개 일치·HTTP308·랭킹·Secure/HttpOnly 쿠키·기존 기록 이전 정상. 운영 점수 제출 없음.

## 넷째 단위: 9층 군단장 외형

- 빙결 궁수의 왼쪽 화살통·화살 깃, 흉갑 판금과 견갑을 분리해 활/방어구 실루엣을 읽기 쉽게 했다. 2페이즈에는 찢어진 망토 끝, 갑옷 균열, 어깨 얼음 파편과 활의 얼음 흔적을 더했다. 공격 예고선·실제 공격 반경/주기·적 상태·저장·랭킹은 바꾸지 않았다.
- 로컬 `node --test` 397개 통과. Edge PC1280×800·모바일 에뮬레이션390×844에서 9층 군단장 도전/저장/숨긴 연습 메뉴 오류0, 별도 [1·2페이즈 비교 화면](visual-stage5-commander-phases.png)에서 차이와 실루엣 확인. 최초 QA에서 플레이어를 도전 상호작용 범위 밖으로 옮겨 실패한 뒤 원래 위치를 유지했다. 공개 QA의 빈 비교 캡처를 발견하고 게임 DOM과 분리된 캔버스·실제 캐릭터 픽셀 검사로 보완했다.
- 운영 `release-20261001-180645-af23e1` 배포 후 서버 Python24개·Nginx·인증서·HTTPS health 통과. 공개 Edge PC/모바일 군단장 도전·저장·1/2페이즈 비교 화면 오류0, 공개 HTTPS 정적5개·HTTP308·랭킹·Secure/HttpOnly 쿠키·기존 기록 이전 정상. 운영 점수 제출 없음.
