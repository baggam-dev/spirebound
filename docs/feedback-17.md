# 0.17.0-prebeta · 2026-09-11

## 반영 내용

- 화염 폭발 기본 계수는 10/14/18 → 10/13.2/16.4. 화상 초당 피해는 2레벨 3.4 유지, 3레벨 5.1 → 4.76. 직격 피해와 반경 유지.
- 유도는 공격 한 주기에서 기술 레벨만큼만 적용. 중앙 화살, 갈래 추가탄, 연속탄 순서. 현재 유니크 최대 1레벨이므로 중앙 1발만 유도. 서리 파편 제외.
- 화염 3레벨 장판은 사망 직전 활성 화상 3중첩 이상이며 화염 직격·폭발·화상으로 처치한 경우만 생성. 시체당 한 번. 장판·오라·다른 속성 처치는 발동하지 않는다. 중첩이 만료되는 순간을 나누어 화상 피해를 계산한다.
- 새 도전의 입구는 안전한 방. 첫 전투는 추격자 4마리, 장애물·정예 없음, 총 경험치 41로 정확히 첫 레벨업. 완료 전 우회로 제한, 처치 후 고리 경로 개방. 귀환에서는 일반 광폭 방으로 사용하고 경험치를 재지급하지 않는다.
- 상자는 선택 없이 무작위 결과 하나를 즉시 적용. 방 진입 때 결과를 저장하고 재접속해도 유지한다.
- 새 지도 제단은 3·5층에 각 하나. 시련은 보라색 용사 3마리이며 층별 광폭 공격 프로필 적용. 체력은 해당 층 일반 체력 2.8배와 광폭 체력 중 높은 값에 10% 추가. 열쇠 획득 후 새 시련 금지, 이미 진행 중인 시련은 적과 진행도 보존.
- 시련 완료 시 상자의 긍정 보상에서 중복 없는 세 후보 중 하나를 선택. 후보도 저장되며 다시 뽑히지 않는다.

체력이 가득 찼거나 기술이 최대 레벨이면 가능한 긍정 보상으로 대체한다. 함정 확률은 이 대체로 증가하지 않는다. 일반 보조 보상에는 희귀 보조가 포함되고 유니크는 제외된다. 메인 보상은 현재 선택한 메인만 강화한다.

보스는 파수꾼·프리즘·슬라임 중 무작위. 정규 보스 체력을 출현 층에 비례해 환산한 뒤 50% 적용, 몸체와 피격 반경 70%. 슬라임 분열체에도 유지한다. 정규 보스의 계단·열쇠·유물·경험치는 지급하지 않는다. 함정 발동 시 1.2초 보호 시간을 준다.

## 저장과 검증

기존 지도와 성장 상태를 유지한다. 미수령 상자·시련 보상과 전투 규칙은 이어하기에도 적용. 구버전에서 진행 중이던 화염 장판은 최초 변환 시 제거한다. 첫 전투와 제단 빈도는 새 지도에 적용한다.

자동 검사 145개 통과. 신규 검사: 유도 발수 조합, 화염 처치 원인·중첩 만료·연쇄 방지, 첫 전투 경험치와 우회 제한, 상자 확률/대체/중복 지급, 보너스 저장, 보스 3종 및 분열 후 진행 보상 차단, 시련 후보 저장과 잘못된 저장 거부.

별도 5193 브라우저에서 상자 즉시 지급, 시련 3택·재접속 후보 유지·물약 1회 지급, 작은 프리즘 보스 소환과 저장 표시를 확인했다. 오류 로그 없음. 인간 플레이의 체감 난이도는 다음 플레이에서 평가한다.
