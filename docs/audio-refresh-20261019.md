# 다음 작업: 사운드 개선 순서

2026-10-19 환경v2 배포 중 사용자가 비동기 선택으로 **층별 환경음 → 스킬·타격음 → 보스 전환음**을 선택했다. 다음 작업 순서는 확정했고, 아래 세부 설계/수치는 제안이다. 이 문서는 다음 작업 인계이며 사운드 runtime 구현·음원 제작·검증·배포를 시작한 상태가 아니다. 대사·컷씬은 계속 보류한다.

## 현재 기준
`src/ui/sound.js`의 짧은 WebAudio 합성 cue와 기존 음소거/음량 설정을 사용한다. 자동사격/명중/피격/보스/보상/XP수집/성장/경고의 간격 제한이 있고, 배경 음악 파일은 없다. 과거 설계 `release-quality-stage7-sound.md`, 최신 보상음 구현 문서를 함께 참고한다.

## 1. 배경과 맞는 환경음
새 그림의 2층 묶음5테마를 따른다. 큰 음악을 계속 재생하기보다 낮은 바람/잔향 위에 간헐적인 환경음을 놓아 분위기를 만든다.

| 층 | 제안 음색 |
|---|---|
|1~2 돌의 전당/회랑|차가운 약한 바람·드문 물방울·작은 불 타는 소리|
|3~4 서고/프리즘|빈 공간 잔향·드문 책장 마찰·가벼운 수정 울림|
|5~6 온실/군체|낮은 유기적 숨소리·끈적한 방울/포자 공간감|
|7~8 천문관/왕좌|깊은 홀의 공기·낡은 금속/사슬의 드문 울림|
|9~10 군단장/대악마|낮은 진동·멀리서 끓는 소리·불규칙한 균열음|

전투 위험음과 겹치지 않게 작고 드물게 들리게 한다. 층 이동은 짧게 이어 붙이고 일시정지/메뉴/숨김/종료에서는 멈추며, 재개/새로고침/원정 교체 후 중복 루프를 만들지 않는다. 사용자 첫 입력과 기존 음소거/음량을 존중한다. 모바일 오디오 차단 시 게임은 계속 진행한다. 생성용 무작위는 전투 RNG/저장 원정에서 분리한다.

## 2. 스킬과 타격감 구분
화살 발사·금속/살점 명중을 기본으로 불/얼음/전기/폭발/베르가스의 접촉음을 구분한다. 소리가 크고 긴 것보다 짧은 시작음/단단한 타격/작은 잔향으로 차이를 낸다. 요정·석궁·화살비가 겹쳐도 명중음이 무한 중첩되지 않도록 우선순위·전체 발음 수 상한·반복 제한을 둔다. 위험 경고/피격을 일반 공격·보상·환경보다 우선한다. 기존 보상 분출음·성장음의 역할은 유지한다.

## 3. 보스 전환음
입장/페이즈 변경의 짧은 고유 신호를 만들고, 전투 중 공격 예고음과 혼동되지 않게 한다. 대사·컷씬 제작으로 범위를 넓히지 않는다. 실제 페이즈 이벤트에만1회 재생하고, 로드나 방 왕복으로 반복하지 않게 한다.

## 다음 실행 원칙
새 음색은 비교할 수 있는 짧은 샘플과 게임 연결을 한 단위로 준비하되, 이 문서만으로 이미 제작/청취 확인했다고 하지 않는다. 새 UI 디자인 변경이 필요하면 시안부터 검토한다. 일반 ‘진행’에서는 수정·문서·로컬 커밋까지만. 테스트·브라우저 QA·푸시·배포는 새 명시 배포 지시가 필요하며 현재 환경 배포 승인을 상시 권한으로 확대하지 않는다.
