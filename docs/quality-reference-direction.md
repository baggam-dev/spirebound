# 재미·디자인 레퍼런스 적용 방향 — 2026-10-06

## 통합 아트·게임 방향

**절제된 어두운 성채 도트 기반 + 순간적인 선명한 전투 연출 + 조합으로 달라지는 한 판.** 평소 방은 낮은 채도/적은 효과, 적·탄환·보상은 구분되는 색, 강한 타격은 짧고 강한 피드백으로 계층을 만든다. Hades의 회화풍을 섞어 픽셀 크기가 충돌하는 화면은 만들지 않는다. 새 아트의 기준은 복잡한 질감 자체보다 플레이어/적/위험/안전 공간이 한눈에 읽히는지다.

현재 자료의 근거: `visual-overhaul-review.md`는 공통 팔레트·광원·픽셀 규칙 부족 가능성을 지적하고, `visual-stage5.md`는 영웅·벽·보스·속성 화살 등 이미 구현한 단위를 기록한다. `visual-stage5-frame-qa.md`의 모바일 가로 캡처에서는 HUD/미니맵 글자가 작다. `skill-stage4.md`의 정밀 사격·유틸은 이미 구현됐으므로 새 메인을 또 만드는 것보다 기존 5빌드의 선택 결과가 플레이에서 얼마나 다르게 느껴지는지 먼저 확인한다. 보스 비교 캡처 `visual-stage5-commander-phases.png`는 페이즈 구분이 있으나 실제 작은 게임 화면에서 자세/타격 연출이 충분히 읽히는지 별도 확인이 필요하다.

## 첫 개선 단위 제안

1. **재미: 조합 감사.** 메인 5종 × 초반 보조/유물 선택을 현재 코드와 동일 시드 전투로 표로 만들고, 시각·전투 방식이 달라지는 조합과 숫자만 달라지는 조합을 분리한다. 그중 1~2개만 작은 시너지 시안으로 만든다. 신규 플레이어에게 선택 이유와 다음 판에 시도하고 싶은 조합을 묻는다. 자동 전투 QA 수치만으로 재미를 확정하지 않는다.
2. **디자인: 1층 일반방+첫 보스의 한 화면.** 같은 플레이 상황에서 바닥/벽/문/적/영웅/HUD의 재질·광원·픽셀 크기를 통일하고, 기본 사격·피격·점멸의 짧은 연출 박자를 비교한다. PC와 모바일 가로 화면을 함께 봐서 작은 수치와 예고가 묻히지 않게 한다.
3. **확장 여부 판정.** 위 두 단위가 전투 가독성·재도전 동기 개선을 보여줄 때만 6~9층 반복 구간과 다른 보스/스킬에 퍼뜨린다. 새로운 시즌/랭킹 경계가 필요한 전투 수치 변경은 구현 단계에서 별도 검토한다.

이 문서는 방향 제안이다. 코드 변경, 신규 플레이 테스트, 실기기 검증, 배포는 수행하지 않았다.
