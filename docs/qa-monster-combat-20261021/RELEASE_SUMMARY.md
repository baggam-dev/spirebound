## 변경과 수정
- 이동형 사수의 유효 사선 확보 우회, 고정 조준과 발사 직전 벽 재검사. 고정형/곡사/지면 공격의 역할은 유지.
- 근접형의 짧은 예고·방향 고정·벽/플레이어 원 교차·한 번 타격·후딜과 저장 재개. 거인·돌진병 새 6포즈, 다른 적 기존 모션 재사용. 시련 돌진의 기존 전체 회복 시간 중 새 근접이 시작되는 회귀를 추가 차단.
- 별도 하강 광포화와 정예/시련/수호자/열쇠 표식. 실제 화면 확인 후 연무 윤곽 보완·시련 중복 이름 제거. 캐릭터 PNG에 오라 합성하지 않음.

- 효과 완화 모드 성능: 모든 요소에 걸린 CSS animation-duration을 실제 애니메이션 대상에만 적용. 같은 격리 장면 수정 전 평균85.94ms/p95 205.6ms, CSS class 제거 대조 p95 18.6ms, 수정 후 평균17.52/p95 18.7ms. 최종 재측정 PC17.45/18.3ms, 모바일17.44/18.3ms, 완화17.46/18.2ms(평균/p95, 각60RAF). 실제 기기 성능 보장은 아님.
- client/API/표시 0.45.0-prebeta 동기화. 전투 변경에 따른 기존 최신 버전 랭킹 정책 적용. 기존 DB/원시 기록/저장/시즌/점수식 보존.

## 실패 기록과 범위
초기 local 화면 촬영 지연으로 이미 회복된 상태에 active 공격을 요구한 QA 수정, commander fixture 타이머 허용값 수정. `status-final` 장판 fixture3초가 촬영 중 만료되어 QA fixture만8초로 변경하고 일시정지 화면 관찰 사용. `hud-final.log`는 잘못된 도구 파일명으로 실행 전 MODULE_NOT_FOUND, 정확한 mobile-hud-v2 도구로 재실행. 원본 실패 로그 보존, runtime 장판 시간 변경 없음.

정적 상태 PNG는 실제 게임을 잠시 멈추고 overlay만 가려 관찰한 화면이므로 조작 버튼이 숨겨져 있다. 일반 게임 화면/공개 검증 이미지는 별도 파일이다. 실제 iPhone, 장시간 플레이/기기 음질과 고층 종합 난이도는 검증하지 않았다. 생산 점수는 제출하지 않는다.
