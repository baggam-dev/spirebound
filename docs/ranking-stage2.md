# 랭킹 2단계 — 로컬 집계와 결과 화면

- 새 도전에 ranking-v1, BETA-1, 게임 버전과 고정 전체 방 수를 기록한다. 온라인 자격 발급은 아직 없으며 BETA-1은 로컬 준비용 메타데이터다. 온라인 출시 시 이전 로컬 기록 등록 여부는 서버 자격 정책으로 처리한다.
- 실제 방 진입을 고유 집합으로 저장한다. 지도 공개·재방문으로 방문 수가 증가하지 않는다.
- 적에게 도전 전체에서 유일한 순번을 부여하고 처치한 순번을 저장한다. 기존 방별 ID를 재사용하는 하강 신규 편성도 구분하며, 보존된 적의 순번은 유지된다. 모든 순번과 카운터는 저장 이어하기에서 유지된다.
- 소환몹과 슬라임 분열 자식은 제외하고 분열 전 원본은 1회 인정한다. 기존 kills·경험치·드롭·전투 규칙은 그대로 유지한다.
- 탈출 확정 시 플레이 시간을 밀리초로 반올림하고 점수 스냅샷을 한 번 만든다. 결과 화면은 항목별 점수 및 유효 처치·방문 수를 표시한다. 최근 30회 개인 기록에도 버전과 점수 내역을 남긴다.
- 과거 저장에는 집계를 소급 생성하지 않는다. 보스 테스트·실패·모르도 처치만으로 점수를 만들지 않는다.
- 저장 스키마 검증에 고유 방문/처치 목록, 순번 범위, 총 방 수를 추가했다. 레거시 층수 테스트의 저장 픽스처에는 존재하지 않았던 ranking 필드를 제거했다.
- 전체 Node 테스트 336개 통과. 새 9개 테스트는 공식·상한·시간 경계·실제 사망 처리·분열 제외·재개·하강 편성·레거시·결과 저장·잘못된 데이터를 검증한다.
- Edge 1280×800, 터치 에뮬레이션 844×390 / 390×844에서 실제 탈출 버튼 → 점수 화면 → 개인 기록 흐름을 확인했다. 페이지 오류 없음. 실제 iPhone Safari는 미검증.
- 이름 입력·온라인 등록·RANK 메뉴는 3~4단계 범위다. 화면에 온라인 등록 준비 중임을 명시한다.
