## 전투·저장 규칙

- 균열 표식은 중첩하지 않고 후속 유효 치명 명중으로 2초를 갱신한다. 표식을 만든 공격 ID의 물리/속성 성분에는 그 표식 보너스를 소급 적용하지 않는다. 표식이 활성인 동안 다른 공격과 지속 피해는 보너스를 받는다. 지속 틱·파생 피해는 표식을 새로 만들지 않는다.
- 회피의 집중은 구르기 입력이 실제로 성공한 뒤 켜진다. 막힘/재사용 중/시전 거부 시 활성화하지 않는다. 8초 내부 재사용 중 다른 구르기는 지속 시간을 갱신하지 않는다. 전투 시계로 감소해 일시정지 중에는 멈춘다.
- 왕의 선고는 깊이 0의 새 유효 치명 명중만 센다. 전역 충전 간격은 0.35초이고 최대 8회다. 같은 공격의 속성 성분·지속 틱·파생·이미 강화된 궁극기는 충전하지 않는다. 궁극기 시전 실패 시 충전을 보존한다.
- 충전된 다음 궁극기는 시전 시 8회를 소비한다. 화살비는 전체 6회, 석궁은 해당 설치체의 수명 동안 기본 공격력을 1.25배로 저장한다. 강화 여부도 무기/프로필에 보존하여 강화 석궁 화살·유도탄이 선고를 다시 채우지 않는다. 버프는 시전자 원본 공격력을 바꾸지 않는다.
- 무기/소환체는 설치/발사 시의 **유효** 치명 확률·배율을 보관하고 스킬 레벨은 복사하지 않아 중복 가산을 막는다. 설치 후 성장·회피 집중 만료가 옛 무기에 소급 적용되지 않는다.
- 구버전 저장은 새 스킬 레벨을 0으로 채우고 치명 난수를 재설정하지 않는다. 스킬 최대 레벨, 집중 지속/재사용, 표식 시간·공격 ID, 선고 충전/재사용 시각과 강화 플래그를 검증한다. 강화 석궁만 저장 기본 공격력 상한 12,500을 허용한다(기존 최대 기본 공격력 10,000 × 1.25).
