# 0.24 — 상층 전투 다듬기

## 이번 범위

디테일업 목록의 우선 작업 1~3번: 공격 전조/판정, 타락한 왕 보스전, 신규 몬스터 구분. 방 편성 확대·층별 장식·탈출 연출은 후속 범위다.

## 공격 전조와 판정

- 돌진: 반경 35의 경로 예고와 같은 판정. 준비 후 0.32초 동안 실제 이동하며 지나간 구간만 판정하고 최대 한 번 적중한다. 장애물 앞에서 정지.
- 검기: 실제 발사 방향 모두 표시. 고리 탄막은 예고 때 방향을 고정하고 안전 틈을 초록색으로 표시.
- 인력장: 준비 단계 점선, 활성 단계 실선·회전 입자.
- 공격 섬광은 0.18초 뒤 제거. 빈틈·빙결 중에도 정상 소멸.
- 강공격은 이중 테두리와 `!! 2♥` 표시. 합성 경고음을 추가했으며 상단 버튼으로 끌 수 있다. 소리 없이도 시각 전조로 구분 가능.

## 타락한 왕

- 65%·30% 단계 전환 시 1.4초 연출. 기존 적 탄환·참격 예고를 정리하고 전환 중 접촉 피해와 적 행동을 억제한다. 플레이어 공격은 유지.
- 체력바 단계 경계 표시. 왕관 균열·갑옷 발광·그림자 날개 표현.
- 거리에 따라 패턴 선택. 멀리서는 허공 참격을 선택하지 않으며 동일 패턴 즉시 반복 방지.
- 심판은 세로/가로 배치를 번갈아 사용. 첫 예고 1.1초, 후속 0.65초. 다음 줄을 희미하게 표시하며 같은 직사각형을 피해 판정에도 사용.
- 심판 후 고정 위치 강공격(2하트), 검을 꽂고 무릎을 꿇는 2.2초 빈틈.
- 근위병 소환 타이머는 공격·빈틈·빙결 중에도 진행. 소환 원 1초, 출현 유예 1초, 최대 2체. 단계 전환 중 소환 타이머 정지.
- 새 공격 예고는 보스와 근위병을 포함해 최대 2체로 제한. 이미 시작한 예고는 유지.

## 몬스터

- 저격수: 긴 활 / 인력술사: 부유 몸체·궤도 구체 / 성운 기사: 방패와 검.
- 운반체: 큰 별 구조물·금빛 가속 연결선 / 근위병: 찢어진 반투명 망토.
- 포탑: 고정 결정 받침 / 사냥꾼: 낮은 자세·쌍검·균열 흔적.
- 성운 기사의 35% 피해 감소는 참격 준비 중 전방 직격에만 적용. 일반 화살·서리 직격·전이·석궁·요정·궤도 칼날의 공격 출처를 반영. 장판·지속 피해에는 적용하지 않는다.
- 운반체 가속 효과는 별도 타이머로 처리해 자기 공격 준비 중에도 유지되며 빙결되면 중지.

## 저장과 검증

기존 저장 구조를 유지하면서 새 공격/전환/소환 상태를 검증한다. 구버전 6층 저장을 8층으로 재생성하지 않는다. 기존 8층 도전은 새로고침 후 이어서 변경된 전투를 이용할 수 있다.

- 전체 Node 테스트 224개 통과.
- 추가 회귀 검사 12개: 이동 돌진·피해 폭·장애물·저장 재개, 탄막 틈, 거리별 선택, 양방향 심판, 최종 강공격, 단계 전환 정리, 소환 주기, 섬광 만료, 동시 예고 제한, 전후방 방어, 잘못된 상태 거부.
- 독립 QA 브라우저에서 7종 실루엣, 돌진·참격·탄막 전조, 왕관 전환, 단계 체력바와 정상 자동 저장을 확인. 콘솔 오류 없음.
- 음량의 실제 청감과 빌드별 난이도는 플레이 피드백이 필요하다.
