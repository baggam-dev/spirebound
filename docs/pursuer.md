# 봉인 추적자 — 5-2 (2026-11-21)

하강 전용 정예급 중장병을 전용 외형/모션·출현/전투·보상/저장 패키지로 구현했다. 넓은 어깨와 두꺼운 흉갑·팔, 낮은 중심이 사용자 승인 방향이다. 전용 시트/프롬프트/검토 기록은 `design-drafts/pursuer-20261121/README.md`에 있다.

## 출현

- 하강 2~8층 일반 방에서 층별 55% 확률로 최대 1방을 계획한다. 1층 최종 탈출·9/10층·보스·계단·시설/상자·튜토리얼·관문은 제외한다. 기존 적 한 자리를 바꾸므로 총 적 수/랭킹 처치 수 예산을 늘리지 않는다.
- 열쇠 획득 후 하강 편성/봉인을 준비한 뒤 독립 시드 난수로 계획한다. 지도·성장·치명 난수를 소비하지 않는다. 이미 계획했다면 재추첨하지 않는다. 구저장 하강 이관은 현재 방과 이미 하강 배치가 완료된 방을 제외한다. 연습/구형 배치 버전은 새 계획을 만들지 않는다.
- 최초 하강 입장 때만 활성화한다. 원래 로컬 ID/랭킹 ID를 유지하고 적 유형을 `pursuer`로 바꾼다. 체력은 교체 대상의 2.4배, 최대 2,500이며 이동/공격/보상 상태는 새 유형으로 초기화한다.
- 판정 반경 30px에 맞는 안전 위치를 찾지 못하면 취소한다. 초기 후보는 플레이어 190px 이상, 최종 방 배치는 155px 이상 입장 간격을 유지한다. 배치기의 벽/다른 적 간격도 큰 몸체에 맞춰 확인한다. 소환으로 갑자기 등 뒤에 나타나지 않는다.

## 패턴과 대응

| 단계 | 동작/판정 |
|---|---|
| 추적 | 초당 42px 기본 이동, 장애물 경로/둔화 적용. 몸 접촉만으로 피해를 주지 않음 |
| 돌진 준비 | 0.9초, 방향 고정, 폭 60px의 지면 경계 |
| 돌진 | 0.5초/최대 210px, 이동 구간 충돌 검사·1회 피해. 벽/경계에 막히면 2.1초 회복 |
| 별도 베기 준비 | 도착 후 새 방향을 고정하고 0.6초 부채꼴/`!! 2♥` 예고. 밀착 시 돌진 없이 이 단계부터 |
| 중량 베기 | 반경 90px·반각 1rad, 장애물/방향 확인·공격당 1회. 하강 중에도 2하트 피해 |
| 회복 | 베기 후 1.7초 정지·회복 포즈, 이후 1.1초 재사용 |

돌진과 마무리 사이에 새 예고 시간을 보장한다. 경고는 대상의 움직임을 따라 조준하지 않는다. 표시 경계는 현재 몸 위치와 고정 방향·남은 돌진 시간에서 계산하므로 외부 이동 후에도 이전 좌표에 남지 않는다. 실제 움직임이 둔화로 짧아질 때 경고는 보수적으로 더 넓다. 부채꼴은 플레이어의 몸 반경까지 고려해 교차를 검사한다. 구르기/보호막/피격 무적은 기존 전투 경로를 사용하며 2하트는 `pursuerHeavy` 분류로 명시했다.

새 적도 동시 공격 예고 예산을 따르며, 별도 마무리 예고가 경고 음향을 사용한다. 일반 피격 움찔을 얹지 않아 걷기/중량 준비가 흔들리지 않는다. 재입장 때 이전 방 위치를 노린 공격은 초기화하고 체력/보상/조우 상태는 보존한다. 두 방향 스프라이트와 독립 지면 예고를 함께 사용하며 16방향 캐릭터 회전은 구현하지 않았다.

## 성장 보상과 저장

처치 시 기존 파편 경로로 **90XP·정수 1개**, 특수 조우 보상으로 **물약 1개**를 지급한다. 물약 5개 보유 시 물약 대신 체력 정수를 추가한다. 회복 보상은 방의 일반 물약 보상 슬롯도 사용하여 같은 처치에서 일반 회복을 중복 지급하지 않는다. 이미 받은 보상·처치한 조우는 재입장/저장 재개로 되살리지 않는다. 정예급 대상이므로 사냥꾼의 인장 조건에 포함한다.

상태는 `room.pursuerEncounter`의 planned/active/defeated/cancelled·적 ID·rewarded와 `pursuerVersion`에 저장한다. 수호 정예 조우의 등반 기록과 별개로 유지한다. 저장 검증은 층/방·층당 한도·유형/적 ID 일치·단계별 시간/방향·90XP·보상 플래그를 확인한다. 일반 적의 기존 명시 XP 상한은 유지한다. 진행 중 경고/돌진도 phase/time/aim으로 그대로 저장한다.
