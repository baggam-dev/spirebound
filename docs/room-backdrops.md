- 8개 층의 벽면 부조: 석조·병기·서고·결정·온실·군체·천문·왕실.
- 방 좌표로 고정되는 바닥 석재 흔적, 낮은 대비의 상감 띠와 측면 기둥 받침.
- 보물·샘물·신전·제단에는 기존 오브젝트 아래에 색이 다른 받침 문양을 배치.
- `room-backdrops.js`는 렌더링 전용. 난수, 저장 상태, 이동 판정, 문 위치, 전투 예고를 변경하지 않는다. 기존 배경 위, 전투 요소 아래에 그린다.
- `node --test`: 303개 통과. `tools/room-backdrops-qa.mjs`: 8층 구분, 동일 상태의 동일 픽셀, 상태 불변 및 Canvas 복원 확인. Edge 1280×800 / 844×390 / 390×844 / 667×375 보스전 확인, 브라우저 오류 없음.
