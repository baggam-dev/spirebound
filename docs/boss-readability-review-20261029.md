# 고층 보스 가독성 2차 — 통합 시안 검토

2026-10-29. 사용자 ‘ㄱㄱ’로 제안 검토·시안 준비. 시작 5981fd9/git clean. 현재 운영 0.48.0-prebeta. 이번 단계는 문서·PNG만 준비하며, 디자인 확인 전에는 런타임에 반영하지 않는다. 테스트·개발 서버·브라우저 QA·푸시·배포·공개 검증을 실행하지 않는다.

## 이번 범위

모르도·서리군단장 벨카르·최종 악마의 기존 공격 예고와 활성 경계, 페이즈 변화, 공격 종료 표현을 한 패키지로 다듬는다. 새 공격·HP/피해·속도·탄수·쿨타임·무적/반격 시간 변경은 포함하지 않는다. 기존 몸 PNG도 유지한다. 오라는 별도 효과이며 캐릭터 PNG에 합치지 않는다.

0.48은 일반 장판/고층 몹의 위험 경계와 적탄 순서를 보완했다. 이번에는 같은 원칙을 보스 고유 도형에 적용할 여지가 있는지 확인한다. 이미 구현된 효과를 없다고 가정하거나 새로 중복 구현하지 않는다.

## 표현 규칙

- 위험은 ‘준비 점선 → 활성 실선 → 낮은 종료 흔적’. 장식은 경계보다 어둡게, 중앙은 비운다. 기존 얼음/보라/독/화염 색 계열을 유지한다.
- 경계를 다시 그릴 때 면 채우기·충격 입자·라벨을 중복 실행하지 않는다. 적탄은 기존 0.48 최상단 단일 표시를 유지한다.
- 효과 줄이기에서도 실제 경계/방향/현재·다음 구분을 생략하지 않는다. 흔들림·빠른 점멸/추가 이동 장식만 줄인다.
- 색만으로 구분하지 않으며 점선/실선·형태·현재/다음 대비를 함께 사용한다. 거대한 전체 화면 광원/어두워지는 필터는 추가하지 않는다.
- 회복 표식은 공격이 끝났다는 제한적 정보다. 다른 탄환/지속 장판을 무시한 안전 영역이나 무적 시간으로 해석되게 만들지 않는다.

## PNG 시안과 원본

docs/design-drafts/boss-readability-20261029/boss-readability-v1.png. 3열×2행 통합 제안: 모르도/벨카르/악마, 공격 예고 및 전환·회수 표현. 기존 QA 보스 PNG는 인물·실루엣 참고만, 0.48 모바일 PNG는 어두운 배경/픽셀 밀도 참고다. 과거 QA 배경을 현재 운영 모습으로 제시하지 않는다.

이미지는 컨셉 보드로서 픽셀별 타격 판정이나 실제 현재/변경 후 캡처가 아니다. 시안의 상대 크기·도형은 코드 수치로 교체하며, 보스/배경을 시안으로 재생성해 런타임에 넣지 않는다. 숫자·라벨·구도가 코드와 다르면 위 코드 근거가 우선한다. 정확 프롬프트 prompt-v1.md 및 생성 원본/버전 보존. 내장 imagegen 1회 계획, 불필요한 재생성 없음.
