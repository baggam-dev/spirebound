# 타격감·궁극기 그래픽 후속 검토 — 2026-11-09

사용자 요청: 이펙트 타격감을 더 높이는 방법 및 궁극기 그래픽 개선. 이번은 코드 근거와 제안 정리이며 디자인 승인/구현·테스트·배포 지시가 아니다.

## 현재 확인

- 0.51에서 약점/강한 베기/화염의 국소 핵·굵기·분출을 이미 강화했다. 다음은 이 변경을 반복하기보다 명중 순간의 대비와 효과 간 강약 차이를 다룬다.
- ultimate-visuals.js의 화살비는 유사한 화살36개의 하강/십자형 착탄/파편을 반복한다. 석궁은 작은 사각형/선 조립, 회전/반동/잔여시간 표시로 그린다. 사용 순간의 캐릭터 동작과 궁극기만의 시각적 주제가 약할 가능성이 있다. 이는 소스 기반 판단이며 사용자 체감 비교 검증은 아직 없다.
- abilities.js 실제 화살비는 반경280, 첫 피해 즉시 및 0.3초마다 총6회, 1.8초 종료다. 렌더 주석의 0/.6/1.2초 표기는 실제 코드와 다르므로 후속 수정 시 바로잡는다. 그림을 위해 첫 피해를 늦추거나 마지막 피해를 추가하지 않는다.
- game.js 궁극기 발동음은 공용 boss 큐를 사용한다. 전용 준비/발사/착탄 음색을 맞추면 구분이 쉬워질 후보이나 음량·체감은 별도 비교가 필요하다.

## 권장 개선 묶음

1. **명중 강약 3단계**: 일반은 짧고 선명한 접점, 약점/강한 베기는 40~60ms 핵·진행 방향 파편과 선두 강조, 궁극기는 범위 전체에서 동시 착탄 리듬으로 구분한다. 중첩 시 약한 잔상을 먼저 줄여 강한 접점을 살린다. 첫 보스 보행을 다시 움찔로 덮지 않는다.
2. **발사와 피격의 연결**: 발도 손/칼 진행 방향과 검광 선두를 맞추고, 화살은 접촉 위치·진행 방향에서 파편을 뿌린다. 강타 전용 소리를 화면 접점과 맞춘다. 적의 실제 이동·AI 경직/피해는 건드리지 않는다.
3. **화살비 재설계**: 금빛 왕국 궁수 톤의 큰 주력 화살과 작은 보조 화살을 섞고 대각 하강→짧은 밝은 착탄핵→먼지/박힌 화살 소멸로 깊이를 준다. 실제 6회 피해에 각 착탄을 맞추고 마지막 회차는 시각적으로만 강하게 마감한다. 첫 회차는 이미 즉시 피해이므로 지연 예고 없이 즉시 착탄으로 시작하고 후속 화살에 하강 과정을 붙인다. 새 영구 바닥 원형 표식 대신 짧은 화살 그림자/낙하지점으로 영역을 읽게 한다.
4. **자동 석궁 재설계**: 기존 왕국 재질에 맞춘 독립 픽셀 자산으로 삼각 받침·회전 포대·장전 장치·대형 볼트를 구분한다. 몸체 실루엣부터 개선하고 설치/장전/발사/회수 동작과 별도 섬광·탄피/먼지를 붙인다. 방향/표적 추적·속성 탄 색은 실제 무기 상태를 반영하며 공격 주기/수명/탄수는 유지한다. 새 자산은 승인된 시안 후에만 생산에 반영한다.
5. **절제와 선택권**: 위험 경계·적탄을 가리지 않게 궁극기 본체/아군 효과/위험선 레이어를 점검한다. 완화 모드는 핵심 화살/석궁 동작과 범위를 유지하고 잔상·파편 수만 줄인다. 카메라 흔들림이나 화면 전체 섬광은 기본안에 추가하지 않는다. 25~40ms 시각 정지 후보는 정지 없는 안과 비교 시안에서만 평가하고, 세계 시간·입력·피해를 멈추는 hit-stop으로 확대하지 않는다.

## 진행 순서

다음은 일반/강타/궁극기 강약 비교와 화살비·석궁의 통합 움직임 시안이다. 현재/제안·실속도/느린재생·기본/완화를 한 번에 검토받는다. 특히 궁극기는 정지 이미지 한 장보다 연속 동작을 먼저 비교한다. 사용자 확인 후 승인한 그래픽·별도 효과만 구현/기록/로컬커밋한다. 새 명시 배포 요청 후 관련/전체·실제 PC/가로모바일·6회 피해 동기/벽/반경/저장정지·겹침/성능을 검증해 푸시/배포한다.

이번 런타임·생산 자산 수정/새 이미지 생성·테스트/서버/브라우저 QA/푸시/배포/공개 확인은 없다. 운영0.51은 직전 완료 기록이며 이번에 재확인하지 않았다. BGM은 기존 보류를 유지한다.
