# 0.58 대규모 개선 배포 기록

2026-11-21 사용자 명시 배포 지시에 따라 누적 개선을 한 번에 배포한다. 구현 범위는 [요약보고서](major-upgrade-summary-20261121.md)를 따른다. 클라이언트/API 허용 버전·헤더를0.58.0-prebeta로 맞췄다.

## 배포 전 검증 완료

- 전체 `node --test`: 최종 **867/867** 통과(`qa-major-release-20261121/full-final.log`). JS와 Python SQLite/HTTP API 통합·실제 생성 지도 검증을 포함한다.
- 최초866/867의 실패는 성소 벽 옛 팔레트 기대값. 새 팔레트로 갱신 후 벽/기관 집중14통과 및 전체867 재검증. 최초 로그 보존.
- 실제 Edge 궁극기 QA: PC1280·모바일844×390 에뮬레이션 × 일반/완화, 저장/재개·일시정지·범위·석궁 자산실패 fallback 통과. 페이지 오류/점수 제출0.
- 신규 종합 QA: 두 뷰포트에서 각각17,609개 무늬 계획·6종/중앙회피·복제 결정성/상태 불변, 기관18XP 해제·하강 저장, 궁수 연사/취소·복귀 방향 검사 통과. 일반/완화의 성소·하강·기관·이펙트 및6종 비교 캡처. 요정3종 투사체/피드백·왕 빔도 렌더했다. 주요 캡처 직접 검토.
- 지원 적26포즈·Pursuer12포즈/원본 알파·자산 준비·완화/모바일 뷰포트·렌더 불변 통과.
- 통제 표적 비교12조건(3시드×2궁극기×치명 전후), 궁극기/저장 통과. 비치명 화살비510/석궁408; 50%·250% 치명 세팅은 화살비765~1020/석궁637.5~790.5. 자동 평타를 끈 정지 표적에서 궁극기1회/15초를 비교한 값으로 실전 우열 확정값이 아니다.
- 기본 스탯 자동 이동/전투3시드×30초·주기 저장 통과, 종료 체력4/처치4~6. 정상 원정 전체 클리어나 사람의 난이도 평가는 하지 않았다.

증거는 `qa-major-release-20261121/`에 보존한다. 새 QA의 초기 혈흔 표본 탐색(튜토리얼 층 한정), 통제 표적의 빙결 저장 상한/측정 시작점을 수정했다. 모두 QA fixture 문제였으며 실패 로그도 남겼다.

## 남은 현실적 한계

실제 iPhone 등 물리 기기, 사람의 청취·장시간 전체 원정/희귀 성장 조합·보스 처치 시간/최대 모바일 열화는 미평가다. 에뮬레이션과 통제 비교를 해당 평가로 대체하지 않는다. 이후 플레이 후기를 통해 과밀·난이도·성장 수지를 조정한다.
