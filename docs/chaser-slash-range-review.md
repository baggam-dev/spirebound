# 추적병 베기 범위 재검토 — 2026-10-14

사용자 첨부 참조는 칼 바로 옆 잔상보다 몸 앞쪽을 넓게 쓸어 베는 흰색 초승달 궤적이다. 보이는 폭을 실제 공격 범위로 원한다고 명시했다. 현재 v4의 작은 잔상 해석을 수정한다. 첨부는 확대율·월드 좌표를 알 수 없어 정확한 픽셀 환산 근거로 쓰지 않는다.

현재 `src/combat/chaser.js`는 중심거리 45px 이내 + 벽 차단만 검사한다. 공격 방향을 저장하지만 판정에 사용하지 않으므로 뒤쪽에도 맞을 수 있다. `chaser-slash.js`의 PNG 궤적은 독립 시각 요소라 이 원형 판정과 일치하지 않는다.

## 제안 (아직 수치/시안 미승인)

- 전방 반경 55px, 총 각도 120도 부채꼴. 캐릭터 표시 52px 대비 한 몸 높이 정도의 근접 폭. 첨부와 같은 방향을 목표로 한 제안값이며 실측값은 아니다.
- 준비 0.08초 유지. 준비 시작 때 방향 고정, 타격 직전에 부채꼴과 플레이어 충돌 원의 실제 교차 및 벽 차단 검사. 뒤쪽은 안전하게 구분한다.
- 궤적 외곽과 공격 판정이 같은 반경·각도·원점을 사용한다. 흰색 바깥선 + 옅은 안쪽 면으로 넓은 베기 폭을 짧게 표시한다. 대상 몸의 일부가 범위와 겹치는 것도 반영한다.
- 현재 단일 타격 후 약 0.12초 시각 잔상 유지. 잔상 전체 시간 동안 매 프레임 피해를 주지 않는다. 피해9·이동속도·회복 주기는 우선 유지한다.
- 승인된 캐릭터 원본과 타격 자세는 유지하고 베기 효과를 Canvas로 분리하는 방안. PNG에 포함된 작은 잔상의 중복은 시안 단계에서 함께 해결해야 한다. 새 효과/변경 자산은 시안 컨펌 후 반영한다.

다음: 현재 원형45px vs 전방 부채꼴55px/120도 비교 시안 → 사용자 컨펌 → 공유 범위 정의와 렌더/충돌 연결. 꽃 리뉴얼은 별도 컨펌 대기로 유지한다. 테스트·푸시·배포는 별도 배포 지시 후 수행한다.
