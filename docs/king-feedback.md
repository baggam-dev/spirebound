# 플레이 피드백 6 — 모르도 공격·소환

- 1·2페이즈 공격 후 대기시간 0.7 → 0.63초, 0.4 → 0.36초. 3페이즈 0.25초와 기존 반격 빈틈 유지.
- 1페이즈 부채탄: 기존 3발 한 줄 → 5발씩 두 줄. 두 번째 줄은 0.28초 뒤 +0.14rad 엇갈려 발사한다. 최초 조준 유지, 두 번째 줄의 예고선과 발사 각도 일치.
- 2·3페이즈 탄 수·피해·탄속은 유지.
- 2페이즈 이후 소환은 상층 원거리 astralSniper와 pulseTurret로 제한. 살아 있는 소환몹 최대 2마리, 소환 경고·체력·주기·보상 제외 규칙 유지. 기존에 소환된 개체는 교체하지 않는다.
- 전체 테스트 317개 통과. 2줄 발사 수·간격·각도·중간 상태 복제 후 재개와 소환 종류·상한 회귀 검사. 공통 예고선 인자 변경 후 관련 4개 테스트 재검증.
- Edge 4개 화면 크기 모르도 전투 실행 확인. 실제 아이폰 검증 미실시.
