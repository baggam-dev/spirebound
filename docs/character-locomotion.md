# 캐릭터 이동 모션 연결 현황

## 범위와 완료 기준

2026-10-15 사용자 '시안 됐고 마무리까지 한번에 진행 모든캐릭터 걷기모션'에 따라 사전 시안 없이 기존 승인 외형으로 남은 이동 모션을 일괄 연결했다. 이 문서의 구현 완료는 소스 연결을 뜻하며, 테스트·브라우저 QA·실제 화면 확인 완료가 아니다. 새 명시 배포 지시가 없어 테스트·푸시·배포·공개 확인을 실행하지 않는다.

새 걷기 원화를 생성한 작업이 아니다. 기존 PNG를 렌더링할 때 하체를 분절하여 발을 교대로 움직이고 상체/무기를 안정시킨 컷아웃 리그다. 기존 PNG 파일과 승인 디자인은 수정하지 않았다. 손가락·파지·발 형태 등의 원화 디테일은 이번 범위에 포함하지 않는다.

## 구현과 제약

`src/rendering/locomotion.js`는 WeakMap에 화면 전용 이동 이력만 보관한다. 실제 좌표 이동량으로 걸음 위상을 진행하고, 같은 시간의 중복 draw는 중복 진행하지 않는다. 36px 이상 위치 변화는 점멸/재배치로 취급한다. 정지·동결·효과 줄이기·정지 초상에서는 보행을 적용하지 않는다. actor·RNG·저장 형식·이동 속도·충돌·피해를 바꾸지 않는다.

일반 적/보스의 컷아웃 하체는 최대 수 px 범위로 발 디딤과 상체 높이만 바꾼다. 망토·긴 무기가 하체 영역에 걸친 원화는 함께 조금 변형될 수 있어 실제 화면에서 경계를 확인해야 한다. 이는 별도 다관절 원화 프레임 제작을 완료했다는 뜻이 아니다.

귀환 슬라임의 붉은 표시를 위해 기존 임시 복사 객체를 유지하되, 이동 이력은 옵션으로 전달한 실제 actor를 키로 사용한다. 초상은 별도 staticPose를 전달한다. 기존 ready/fallback 동작을 유지한다. 신규 JS는 서버·배포의 기존 경로 허용 규칙을 사용하며 공개 QA 목록에는 준비만 해두었다.

정지/상하좌우/대각선 보행·동결·저속 이동·공격 중 이동·단계 전환·점멸·효과 줄이기·초상/지연 로딩/fallback·귀환 슬라임의 actor 이력·저장 불변·하체 분절 경계·긴 무기/망토 가림·모바일 가로 성능을 누적 검증한다. 모바일 세로 도감은 사용자가 그대로 두기로 했으므로 변경하지 않았다.
