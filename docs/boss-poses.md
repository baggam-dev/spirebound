# 보스 공격 자세 개선

2026-09-22

- 수호자: 망치 준비 자세, 도약 높이, 착지 후 회복 자세. 체력바가 도약 높이를 따라간다.
- 프리즘: 공격 준비 시 코어 상승과 파편 확산, 발사 시 발광과 파편 집중, 회복 시 하강.
- 슬라임: 발사 준비와 반동, 분열 도약 자세. 자신이 만든 위험 구역만 자세 계산에 사용한다.
- 모르도와 문지기: 검의 준비·휘두르기·회복 자세, 짧은 검 궤적, 방패 들기, 활 당기기와 반동.
- 기존 공격 상태와 타이머만 읽으며 피해량, 공격 주기, 충돌 판정, 바닥 예고 위치를 변경하지 않는다. 일시정지 중 자세도 정지한다.

## 검증

- `node --test`: 303개 통과.
- `tools/boss-poses-qa.mjs`: 18개 자세 구분, 일시정지 시 동일 픽셀, 전투 상태 불변, Canvas 상태 복원 확인.
- Edge에서 1280×800, 844×390, 390×844, 667×375 화면의 실제 보스전 14개 조합 확인. 브라우저 오류 없음.
- 실제 아이폰 기기 검증은 별도 피드백이 필요하다.
