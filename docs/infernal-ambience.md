# 9·10층 지옥 배경 (2026-10-07)

서리 최종 클리어 후기3번 반영. 기존 현무암 벽에 용암빛 균열을 넣고 외곽/내부 벽에서 화염·불티가 움직인다. 9층은 주황 용광로, 10층은 검붉은 심연 색으로 구분한다. 바닥 중앙에는 새 장식이 없으며 모든 신규 애니메이션 픽셀은 벽 영역으로 잘라 공격 예고와 발사체를 가리지 않는다.

정적 균열은 기존 벽 이미지 캐시에서 한 번 그린다. 화염은 최대16곳, 불티는 각2개이며 좌표/시각으로 결정해 전투 RNG·저장·충돌/피해/랭킹에 영향을 주지 않는다. 장식성 화면 효과 줄이기 설정에서는 신규 움직임 전체를 생략하고 정적 균열만 남긴다. 1~8층에는 신규 장식이 없다.
