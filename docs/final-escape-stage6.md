# 통합 순위 6번 — 1층 탈출구 결말 전투

새 도전(generationVersion 28)은 최상층 열쇠를 들고 1층 출구로 돌아온 뒤 마지막 봉인을 깨야 탈출한다. 출구의 남은 적을 처치하고 상호작용하면 36초 추격이 시작된다. 0·12·24초에 악마 박쥐·병사·사수·부대장으로 이루어진 4·5·6마리의 파도가 들어온다. 방과 출구는 이벤트 중 잠기며, 36초를 버티면 적과 발사체를 정리하고 열린 출구에서 다시 상호작용해 완주한다. 사망하면 기존 결과 화면으로 끝난다. 추격 소환 적은 점수의 처치 수에 넣지 않고 생존 시간은 기존 시간 점수에 포함한다.

이벤트 경과 시간·파도 번호·완료 상태를 저장하고 검증한다. 진행 중 저장을 불러와도 다음 파도부터 계속한다. generationVersion 27 이하의 기존 저장은 종전 탈출 규칙을 유지한다. 새 기본 시즌은 BETA-4/ranking-v9, 확장은 ASCENT-6/ranking-v10이며 봉인 완료 없이는 새 시즌 점수를 만들거나 제출할 수 없다. BETA-3/ASCENT-5 이하 기록은 조회 전용으로 보존한다. 운영 시즌 전환은 배포와 공개 확인 후 완료로 기록한다.

로컬 검증: `node --test` 401개 통과. Edge PC 1280×800 기본/확장, 모바일 에뮬레이션 844×390·390×844에서 봉인 시작·저장 재개·완주와 사망 시 무랭킹 결과를 확인했다. 독립 임시 SQLite 온라인 등록·기존 시즌 분리·재시도 QA 및 결과 화면 PC/모바일 12장면 오류 0. 사람 조작 난이도와 실제 iPhone 성능은 미검증이다.
