# 모션·보스 클리어·하강 성장 통합 개선 검토

## 요청과 상태
0.50 플레이 피드백 이후 약점/강한 베기/화염폭발 움직임 비교(3c777b9)를 사용자가 ‘좋아’로 승인했다. 여기에 발도 대시 자세, 첫 보스 보행, 화면 전역 보스 클리어, 보스 경험치 대폭 증가/파편 분출, 하강 경험치를 함께 검토해 달라는 요청이다. 승인된 타격 3종 방향은 유지한다. 이번 산출물은 추가 범위의 검토안이며 런타임/생산자산 수정·테스트/서버/브라우저/푸시/배포/공개접속은 하지 않는다.

## 통합 권장안

### 1. 발도: 몸이 먼저 베도록
- 기존 주인공 얼굴/머리·망토/복장/키를 유지한 전용 패키지: 허리에서 칼을 잡는 준비→전방 저자세 발도→칼을 뻗은 이동→검 회수 4자세. 활은 등/몸 뒤로 보내며 발사 손모양/당긴 시위는 보이지 않게 한다.
- 현재 roll.elapsed/duration을 읽어 준비 약15%/발도 약25%/이동 약40%/회수 약20%에 대응한다. 이 분할은 시각만이며 기존 대시 전구간 피해/이동/무적/벽판정을 늦추지 않는다. 최초 프레임부터 칼날이 읽히게 하고 좌/우·상/하 방향은 기존 조준축에 맞춰 표시한다.
- 승인된 베기 선두강조와 같은 검 끝에 궤적을 붙인다. 기존 주인공 PNG를 잘라 활만 숨기는 방식은 손/실루엣이 깨질 수 있어 새 전용자세 시안을 우선한다. 몸 PNG와 칼빛/잔상은 별도 자산이다. 로딩실패도 활발사 자세로 돌아가지 않게 최소 정지발도/일반이동 fallback을 설계한다.

### 2. 첫 보스: 안정된 상체와 무게 있는 보폭
- 뿔투구/망치·몸크기를 유지하고 발목/골반 기준을 맞춘 걷기 6~8자세를 후보로 한다. 양발 교대·접지→무게이동→밀기→반대접지, 상체 높이변화는 실제 표시 기준 약1px로 제한하고 망치는 손에 고정한다. 전신 좌우비틀기를 보폭 대신 사용하지 않는다.
- 이동거리 기준 위상은 유지해 정지시 발이 헛돌지 않게 한다. 프레임간 발/손/머리앵커를 먼저맞추고, 전신이미지 단순페이드로 겹친 잔상을 만들지 않는다.
- 가벼운/지속피해는 갑옷의 작은 타격광으로 표현하고 걷기를 덮지 않는다. 큰 실제명중만 약.08~.10초 어깨반응, 표시간격은 우선.6초 후보. 현재프레임별 체력감소로 판정하는경로에서 직접타격/DoT를구분할수있는지 구현시확인한다. 임의로 실제피격경직/공격취소·AI속도변경을 추가하지 않는다.
- 현재보행/무피격 이동/연속사격/화상/독을 각각 비교해야 ‘걸음이상’과 ‘실제피격표시’를 구별할 수 있다. 정적원본열람만으로 원인비중은 확정하지 않았다.

### 3. 보스 클리어: 화면 전역의 축하 연출
- 마지막 보스 판정이 끝난 한 순간에만 한 번 발동. 보스 중심의 금백색 파동이 화면 네변까지 퍼지고, 가장자리의 파편/빛기둥과 중앙의 짧은 격파문구가 이어지는 약1.3~1.7초 연출을 제안한다. 화면전체에 도달하되 불투명 흰화면이 덮는 방식은 피하고 캐릭터/계단/HUD·남은위험은 식별되게 한다.
- 보스 쓰러짐→0~.2초 핵/파동→.15~.65초 전역확산·XP폭발→.65~1.5초 정리/흡수로 연결한다. 보스별 원소색은 작은 보조색, 보상색은 금빛/XP색으로 구별한다.
- 전용 화면연출 시계는 보스 클리어 이벤트에서 만들고 렌더호출/방재방문/저장로드에서는 재생하지 않는다. 레벨업/유물/최종하강안내가 게임 update를멈춰도 UI를막지않는잔여연출패스가필요하다. 숨김/실제사용자일시정지·방전환에서는정지/취소한다. 효과 때문에보상확정·계단해제·저장·다음행동을지연하지않는다.
- 분열슬라임 중간체/악마중간부위/소환몹/상자보스에는 전체축하와보스XP를 반복지급하지 않는다. 최종key 전환도공통완료연출을보이되 기존하강안내와두개의전체화면연출이충돌하지않게통합한다. 연습은연출만/실XP저장보상없음.
- 효과줄이기는 짧은 격파문구·낮은농도 가장자리광/넓은파동1회만 남긴다. 화면흔들림/강제정지/빠른반복점멸은 기본추가하지 않는다.

### 4. 보스 경험치: 45 고정에서 4~10배 수준으로
- 1차 권장 고정표: **2층180 / 4층240 / 6층300 / 8층360 / 9층420 / 10층480 XP**. 기존45 대비4~10.67배다. 8층캠페인 최종보스는 해당8층360을적용하고 10층캠페인만9/10층을사용한다.
- 현재레벨에비례해보상을무한히키우는것보다 층별고정표가 비교/저장/설명에명확하다. 목표는 보스전뒤 레벨업/선택이 체감되게 하는것이며 보스직전level/xp에따라실제레벨업횟수는달라진다. ‘항상2레벨’ 등은 보장하지 않는다. 실제플레이레벨분포/상승전체XP와함께검증후표를조정한다.
- 보스방 최종완료 기존한곳에서1회만 지급하고 r.used/분열/최종페이즈 조건을유지한다. 처치애니메이션/축하이펙트에서추가지급하지않는다. 기존지급완료보스에추가XP를소급생성하지않는다.
- 최종보스 보상은 enrage(s) 전에생성되므로 하강차단을풀어도이번보상이두번생기지않게한다. 최종안내가수집/레벨선택을막지않도록게임흐름도함께검토한다.

### 5. 보스 파편: 분출은 크고, 회수는 편하게
- 처치지점에서 전방편향없는360도 분출, 목표반경 약80~170px·실제벽/방경계 안의 안전지점으로 배치한다. 초기.45~.6초는 짧은포물선/착지/한번튐을 보여준다. 기존처럼 .18초에자석이분출을끊지않게 보스파편만별도유예한다.
- 날아가는표시위치와판정/수집위치를같은경로에서구해 attract시q=1 순간이동을없앤다. 기존일반몹 .18초수집규칙은유지한다.
- 분출후 보스파편만 약180~200px 넓은회수반경 후보를적용해보상때문에화면을오래쫓아다니지않게한다. 일반자석범위/유물효능은바꾸지않으며 벽막힘/안전배치·보존은유지한다. 자동전액즉시지급이나벽통과흡입은기본안이아니다.
- 물리파편은약36~60개목표/최대64개 수준으로묶고 남는XP는같은tier값에번들해총액을보존한다. 기존1/3/9구분과방별생성-수집=잔량검사를유지한다. 수백XP라고수백입자를생성하지않는다. reduced는분출수/튐/꼬리감소·동일총액/읽히는짧은분출을남긴다.

### 6. 하강 성장: 정상 몬스터는 확실히 XP 지급
- **하강 일반12 / 정예18 / 시련24 / 네임드36 XP**로 상승의현재기본표와같게 시작하는것을권장한다. 별도반액보다 규칙이일관되고 현재0→실제성장변화가명확하다. authored xpReward는현재규칙대로존중한다.
- simulation 지급의!s.key와dropXp 내부차단을함께수정하고 기존collectXp/레벨선택을재사용한다. 스킬풀소진시 기존성장보상(공격력+2/최대체력+1/공속+3%)이있어하강에서도성장할여지가있다. 별도하강전용성장시스템을새로만들필요없다.
- 소환체/중간분열체/자폭만한몬스터/무한추격몹은지급예외를명시한다. 단, ‘자폭만한몬스터’ 예외는현재지급조건과다를수있으므로 실제처치/자폭구분을확인후정해야하며 임의보상누락을만들지않는다. 최종1층추격웨이브는현재summoned:true라기존예외유지, 하강중각방의유한한일반적/봉인수호자는정상지급한다. 만약마지막추격웨이브에도XP를원하면해당범위는추가조정대상이다.
- 기존에죽은적에게소급XP/방재입장재생성하지않는다. enrage의하강몹재구성은한번만, 처치목록제거/저장로드/봉인몹반복드롭/상승잔여파편과하강신규파편의합계보존을검증한다.

## 구현 묶음과 순서
1. 승인된 타격3효과를 유지하고 **발도4자세+파수꾼보행/피격분리+전역클리어/XP분출**을 한 번에 움직임시안으로 보여준다. 캐릭터부위별로확인을반복하지않는다. 기존PNG/시안원본은보존한다.
2. 방향확인후 모션/이펙트렌더를연결한다. 별도로 보스XP표·하강드롭/수집/저장을구현하고 의미있는단위로기록/로컬커밋한다. XP를시각효과와엮어중복지급하지않는다.
3. 사용자명시배포지시가오면관련/전체·PC가로모바일기본/완화·사망동시피격/최종보스key·보상/레벨모달겹침·저장재개/방왕복/소환예외·전체XP/레벨곡선/파편상한/벽/프레임을묶어검증후배포한다. 이번새요청은검토지시이며이전0.50배포권한은종료됐다.

## 호환성/검증 유의점
보스보상/하강성장은실제난이도조건을바꾸므로배포시새클라이언트/API허용버전·기존랭킹정책을검토해야한다. DB원본/시즌/점수식을임의삭제·변경하지않는다. 새정수/보상정책표시가필요하면검증가능한버전태그로구분하고이미완료된방/구저장에추가보상을소급하지않는다. 새파편유예/위치필드가생기면storage 검증·구저장fallback·원정루프총액을함께수정한다.
현재는코드/기존문서·파수꾼보행원본열람만했다. 실제게임재생/실기/자동테스트/성능·수치균형은미검증이며위XP표/시간/거리/자세수는검토초안이다.
