## 비교 PNG
environment-pixel-tone-v1.png: 왼쪽 CURRENT는 실제 canvas를 참조해 생성한 재구성, 오른쪽 PROPOSED는 같은 방을 기준으로 한 미술 방향 시안. 왼쪽도 실제 screenshot 바이트 그대로가 아니며, 패널 종횡비/세부 좌표/캐릭터 픽셀은 구현 판정 근거가 아니다. 원본 실제 화면은 위 QA hero-1280.png다.
- 바닥·벽·문·횃불 받침을 굵은 픽셀 덩어리로 정리. 파일 해상도 자체보다 게임 내 유효 도트 밀도/제한된 색 단계가 중요하다.
- 바닥 밝기 약20~25% 감소/채도 감소를 시안 목표로 요청했으나 실제 구현 수치 확정은 아니다. 그을린 회색·짙은 회녹색/낮은 하이라이트/깨진 돌 모서리. 암부를 완전 검정으로 뭉개지 않는다.
- 캐릭터·적·탄막·위험 예고·XP/정수·HUD까지 검게 덮지 않는다. 횃불/불티·물 반사는 작은 국소 강조를 유지한다.
- 방 틀/문/장애물 위치·충돌·배치 RNG는 변경하지 않는다. 새 등각 시점/기둥 배치/캐릭터 교체가 아니다.
- 이번1안은 1~2층 방향 검토용. 다른4테마 자산 작업 완료를 뜻하지 않는다. 승인 도트/명암 기준을 추후 각 테마의 색과 소품에 적용한다.
