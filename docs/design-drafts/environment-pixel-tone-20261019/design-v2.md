## 변경

- 균열 텍스처만 덧그리지 않고 외곽 윤곽을 계단형으로 깎아 모서리 돌이 몇 개 탈락한 모습, 어두운 노출 속돌, 가장자리 소량 파편을 표현했다.
- 위는 같은 방의 전체 방향, 아래는 작은 사각 블록/긴 벽/ㄴ자 모서리/무너진 끝 4종 상세 예시. 아래 예시는 기존 방에 새 장애물을 추가한 배치가 아니다.
- 모든 모서리를 똑같이 깨지 않고 멀쩡한 면·작은 이빠짐·큰 파손을 섞는다. 단색 둥근 바위로 대체하지 않는다.
- 캐릭터·횃불 가독성을 유지하며 기존 문/통로가 막히지 않게 한다. 방 종횡비·액터 픽셀·불꽃 세부는 생성 재구성이므로 실제 게임 캡처/동작 증거가 아니다.
