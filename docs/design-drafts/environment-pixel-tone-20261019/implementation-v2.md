## 환경 전용 도트·명암
`src/rendering/environment-material.js`는 기존 Canvas 렌더 캐시를 준비하는 공용 모듈이다. 기존 환경6개 로더(environment/guard/archive/prism/infested/upper)가 crop을 축소할 때 high smoothing 대신 nearest를 사용하고, 재질 최대변44px/소품32px 크기에 맞춘 저해상도 캐시를 만든다. 표본색을 밝기0.78/채도0.65/채널값8 간격으로 정리하고 반투명 그림자는 85단위 알파로 유지한다. ‘8색만 사용’이라는 뜻은 아니다. 원본 이미지 파일 자체를 수정하지 않는다.

10층의 기존 테마별 바닥 캐시와 돌벽 캐시는 마지막에 320×180 표본을 960×540으로 nearest 확대해 공통3px 단위가 되게 한다. 방/테마/원화 버전 캐시 무효화 및 기존 개수 상한을 유지한다. 가구 기본 fallback(바위/책장/책상/뼈)도 별도 WeakMap 소품 캐시로 같은 색/도트를 적용한다. 실제 이음/깨짐/가독성/메모리 체감은 실행 미검증이다.

캐릭터·동료·공격·보상·경고·HUD·미니맵·화면 전체에 필터를 씌우지 않는다. 기존 횃불/불티·물웅덩이·층별 장식 함수도 유지하고, 그들이 사용하는 환경 원화만 공용 재질 처리한다. 별도 불꽃/경고 애니메이션을 삭제하지 않는다. ‘시안과 실제 픽셀이 일치함’을 확인한 단계는 아니다.

## 파손 모서리와 충돌
`src/world/stone-shape.js`가 내부 돌벽의 좌표·크기에서 고정 해시로 비대칭 모서리 결손(3px 계단 단위, 깊이6~9px)을 만든다. 기존 직사각형 저장 데이터를 수정하지 않고 WeakMap에 파생 사각 띠 조각을 보관한다. 외곽 경계벽/작은 연결부/비석재 가구/보스 위험 오브젝트는 기존 모양을 유지한다. 살아 있는 보스 지형을 임의로 재설계하지 않는다.

렌더는 같은 조각들의 합집합으로 clip하고 작은 단면을 덧그린다. 마지막 확대가 틈을 메우지 않도록 최종 출력도 같은 조각으로 clip한다. `blocked`, `segmentBlocked`, 대악마 광선의 직접 ray clip은 모두 같은 조각을 사용한다. 실제 빈 모서리를 보이지 않는 사각 벽으로 막는 불일치를 피하는 목적이다. 통로를 막는 새 블록/방 배치/게임 RNG/저장 필드/적 상태는 추가하지 않는다. 작은 모서리의 화살·몸 판정은 달라지므로 다음 배포 시 전투/버전 계약을 검토한다.

큰 붕괴 구멍이나 새 통과 경로를 추가한 구현은 아니다. 시안 아래4개는 미술 세부 예시이며 모든 방을 해당4개 장애물로 바꾸지 않는다. 다른 테마에서도 기존 원화와 색의 계열을 유지한 공통 도트/작은 파손 기준을 적용한다.
