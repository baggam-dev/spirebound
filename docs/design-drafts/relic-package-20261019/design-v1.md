## 전체 아이콘과 HUD

- `relic-icons-v1.png`: 기존32+새5 전부를 같은 재질/시점/윤곽으로 새로 디자인했다. `icon-manifest-v1.md`가 번호↔ID의 기준이다. 마지막5칸은 빈칸이고 추가 유물이 아니다. 종2종/반지3종/불 계열/요정3종은 색뿐 아니라 실루엣을 구분했다.
- 카드에서는 크게, 좌상단에서는 PC20~24px/가로모바일18~20px 목표의 같은 아이콘을 사용한다. 시안의 픽셀 라벨은 실측 결과가 아니다. 작은 크기에서 선이 뭉치면 큰 아트를 무조건 축소하지 않고 단순화한 소형 파생이 필요할 수 있다. 실제 준비/crop/축소 가독성은 미검증이다.
- 사용자는 슬더스처럼 좌상단 소형 아이콘 표시를 요청했다. 이는 보유 아이콘 가로줄/상세 정보라는 인터페이스 방향으로 해석했으며 타 게임 자산을 복제하거나 가져오지 않았다.
- 새 도트 아이콘을 HUD/선택카드/보유목록/거래/획득알림에서 함께 재사용한다. 요정 동료 본체나 스킬 UI는 이번 아이콘 교체로 바꾸지 않는다. 기존SVG/glyph는 PNG 준비 실패 시 안전한 fallback으로 보존한다.
- 평소 이름을 나열하지 않고 소형 아이콘만 표시. PC hover와 키보드 focus에 이름/등급/정확 효과·소모 상태를 표시. 모바일 탭/접힌수(+N)는 보유 상세를 열고 전투입력을 멈춰 이동/구르기 오작동을 막는 방향. 상세 닫으면 기존 pause/resume 정책 사용. 시안의 +6은 예시이며 실제 미표시 개수를 계산한다.
- 최대2줄·폭 제한, 넘침은 +N으로 상세 접근성을 유지한다. 화면상 안전영역/미니맵/정수줄/기존 HUD를 침범하지 않도록 반응형으로 맞춘다. 실제 모바일 입력 타깃은 그림의20px보다 넓게 잡고 키보드/터치 상세 접근을 보장한다. 수집 아이콘만 작아져 버튼 의미가 사라지지 않게 한다.
- 현재 획득 순서를 유지하고 드물다고 매 프레임 재정렬하지 않는다. 새획득 강조는 짧게, 지속 발광/오라/전투위험 같은 링은 없다. 열쇠 표시는 유물과 구분하고 +N에 숨기지 않는다. 소모된 성유골은 목록에서 사라지지 않으며 회색/소모문구로 구분한다.
