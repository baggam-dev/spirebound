## 비교 기준

현재 측은 0.51 `arrow-impact-visuals.js` 및 `ultimate-visuals.js` 원문에서 import/export만 제거한 함수다. 실제 게임 전투 전체를 캡처한 것은 아니며 배경/표적은 비교용 도식이다. 새 석궁 원본을 제외한 제안 효과는 독립 코드 시안이다. 현재 화살비는 완화 인자를 받지 않는 기존 동작을 그대로 보여준다.

화살비 피해는 즉시 및 .3초 간격6회, 반경280/1.8초 종료를 가정한다. 제안은 주력·보조24개(완화12개)와 원근/국소 착탄/박힌 화살·먼지·마지막 회차 시각 마감이다. 첫 착탄은 지연하지 않고 후속 회차에만 낙하를 붙였다. 시안에는 실제 피해/보상 코드가 없다.

명중은 접점과 공격 방향의 파편 밀도/길이·밝기/짧은 암부 대비를 일반·강타·궁극기로 나눈다. 신규 세계정지·AI 경직·화면전체 섬광/카메라흔들림이 없다. 이번 시안은 무음이다. 전용 타격음은 구현 전 후속 검토 대상으로 남긴다.

석궁은 14초 수명 전체를 기다리지 않도록 설치/초기발사·반복 발사·회수를2.2초 모아보기로 압축했다. 공격 주기/수명을 바꾸자는 제안이 아니다. 고정 오른쪽4자세를 같은 발 기준으로 추정 위치 보정한다. 실제 방향별 조준은 상부/받침 분리·추가 방향 자산 검토가 필요하며 이번 시안에 완성되지 않았다. 기존/제안 몸체 크기 차이는 의도된 실루엣 강화이나 실제 적 가림·게임 배치·작은 크기 가독성은 미확인이다. 프레임별 줄/볼트 길이·기계 일관성 및 발 앵커/루프 자연스러움도 사용자 확인과 후속 검증이 필요하다.
