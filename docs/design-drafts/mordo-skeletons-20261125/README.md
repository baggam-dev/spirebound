# 모르도 소환체: 해골 전사·궁수 패키지

2026-11-25 단계별 작업의3단계 **디자인 검토본**이다. 실제 몬스터/소환 AI·모르도 체력·제품 자산은 아직 변경하지 않았다. 이전 안내/확률·일섬 소스 수정은 그대로 보존했다.

## 시각 방향과 동작

- 공통: 성인 해골 비율·작은 보랏빛 눈·바랜 상아색 뼈·낡은 왕실 철/청동 장비·어두운 청회색/버건디 천. 둥근 머리의 귀여운 몬스터보다 마르고 위협적인 실루엣을 목표로 했다.
- 전사8자세: 대기 / 왼발 / 오른발 / 일반 베기 예고 / 베기 / 낮게 숙이는 대시 예고 / 대시 베기 / 사망. 큰 어깨 갑옷·검·드러난 다리로 궁수와 구분한다.
- 궁수8자세: 대기 / 왼발 / 오른발 / 부채꼴 조준 / 발사 / 반사탄 조준 / 일자 연사 자세 / 사망. 가벼운 망토와 뼈 활, 시선·활의 높이·기울기와 별도 예고선으로 패턴을 구분한다.
- 별도6효과: 소환 예고 / 열리는 인장 / 정예 금빛 바닥 표식 / 정예 주변 작은 금빛 조각 / 전사 참격 / 뼈 화살. 몸 PNG에 정예 오라나 공격 궤적을 굽지 않았다.

`motion-preview.gif`에서 전사의 일반공격/대시와 궁수의 부채꼴/반사탄/3연사, 소환 인장을 시연한다. 예고선과 화살 궤적은 **디자인 확인용으로 미리 짠 합성**이며 실제 무작위 AI·충돌·피해·벽 반사·소환 주기를 검증한 결과가 아니다. 정예 효과는 전사에 분리해 붙였고 같은 효과를 궁수에도 재사용할 수 있다.

`phase-board.png`는 요청한1페이즈5초/1정예,2페이즈5초/전사1궁수1 중정예1,3페이즈3초/전사2궁수2 중정예1을 보여준다. 첫 컷의 전사는 ‘전사 또는 궁수’ 중 한 예시이고, 실제 확률을 전사로 고정하는 뜻이 아니다. 정예의 선택도 시안 예시다. 생존 상한·몬스터 HP·속도/공속의 추천값과 실제 구현 순서는 `docs/playtest-review-20261125.md`에 유지한다.

## 출처와 정적 확인

내장 image_gen5회. 첫 전사 생성·배경 교정2회는 실제 alpha가0이 되지 않는 흰 배경 오류로 실패했다. `warrior-alpha-failed.png`(alpha171~248), `warrior-alpha-retry-failed.png`(183~251)는 진단 원본이며 **최종 합성에 쓰지 않았다**. 실제 alpha0~254인 궁수를 기준으로 전사를 다시 생성했다. 원본5장·전체 프롬프트/참조 역할은 `prompts.md`, 최종3장의 SHA·수동 소스 영역·배율/루트는 `manifest.json`에 있다. CLI/API fallback은 쓰지 않았다.

- 인물16장:144×128, 공통 배율64/290·루트64/112, 공통47색+투명. 기본형 높이 약64 논리 픽셀, 검을 드는 자세는 더 높고 사망은 같은 배율로 낮게 놓인다.

- 효과6장:96×96,31색+투명·4px 여백. alpha220 미만의 흐린 주변광을 정리하고 최근접 축소·공통 팔레트를 적용했다.
- `actor-report.json`/`fx-report.json`:22장의 크기·투명도·색 수 통과. 모든 native 셀 여백 확인, 인물/효과 접촉표와 페이즈보드·합성 접촉표를 직접 검토했다.

## 실제 연결 전 남은 일

빠른 보행은 현재 좌우 디딤2자세와 행동 키포즈의 제안이다. 방향별 가림·피격 전용 자세·관절 접합·실제 게임 크기/몬스터 다수일 때 가독성은 최종 연결에서 확인해야 한다. 사망 후 정예 표시 정리도 실제 런타임과 연결해야 한다. 그림만으로 완성된8프레임 보행·실전 AI가 있다고 표시하지 않는다.

승인 후 두 전용 타입·공격/탄막·정예 조합·동시 생존 수/탄 수 상한·소환 전조/위치 안전·성장 보상 없음·본체 사망 정리와 모르도HP-15%를 함께 구현한다. 기존 그림자 모르도의 소환 금지는 유지하는 계획이다. 게임 구문/단위 테스트·브라우저/실기기·성능·푸시·배포는 새 배포 지시 때 진행한다. 운영0.65는 그대로다.
