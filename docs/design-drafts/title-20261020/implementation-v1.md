# 메인 화면 구현 기록 — 2026-10-20

## 승인과 범위
사용자 ‘가즈아’·‘진행하자~ 톤만 조금 더 다크하게’로 통합안 구현 및 가벼운 다크 톤 보완 승인. 메인 화면만 구현하며 새 배포 지시는 없다.

## 구현
- 승인 시안의 왼쪽 로고/메뉴·오른쪽 탑 구도 유지. 배경 중간톤 약15% 하향을 요청해 새 깨끗한 배경판 생성. 시안과 원본은 보존했다. 메뉴/주인공을 원화에 굽지 않고 별도 레이어로 연결.
- `assets/images/title-background-v1.png`: 어두운 탑/입구/돌길, 텍스트·주인공·횃불 불꽃 없는 깨끗한 배경. 생성 결과에 얇은 정적 안개와 입구의 온광은 남아 있으며 별도 동적 안개/빛을 겹친다.
- `title-logo-v1.png`: 투명 석재 로고. 원본 가장자리 색점은 CSS grayscale로 회백화. 투명 여백은 CSS 뷰포트로 자르며 실제 PNG를 오프라인 편집하지 않음.
- `title-hero-idle-v1.png`: 2172×724, 724×724 셀 3개. 뒤돌아 선 기존 머리/목도리/망토/활 정체성. 0→1→2→1 순서로 미세 호흡·망토 동작. 원화 프레임의 미세한 정렬 오차 가능성은 실제 재생 검증 때 확인. 발도/걷기 또는 게임 내 주인공 크기 변경 없음.
- `title-branch-v1.png`: 투명 가지, 좌/우 각각 줄기쪽 고정 회전 약0.46도 이하·위상차. 기존 배경 나무 전체를 흔들지 않는다.
- `src/ui/title-scene.js`: Canvas 별도 불꽃/불티/빛, 낮게 흐르는 안개, 소량 낙엽, 후면 idle/가지. 게임 기존 RAF에 연결해 별도 루프/타이머/이벤트 리스너를 만들지 않는다. 장면은30fps 상한·1600px 폭/1000px 높이 상한, 숨긴 탭 중단, OS reduce-motion/설정 효과 완화 시 정적 장면. 전투 RNG·저장·오디오 사용 없음, BGM 작업 없음.
- `styles/title-scene.css`: 시안풍 왼쪽 투명 메뉴/고정 로고, 어두운 국소 그라데이션. 가로 모바일44px 이상 터치/작은 폰트·보조메뉴 한 줄, 세로 타이틀은 스크롤 가능(세로 전투 허용 변경 아님). 키보드 focus 표시·기존 모달 포커스 순환/Escape 유지.
- 주메뉴: 저장 있을 때 계속 탐험(실제 층/시간/복구안내), 새로운 원정, 기록실, 설정. 저장 없을 때 새 원정 우선. 기록실은 도전 기록/도감/조작안내/백업·가져오기. 명예의 전당/전투 훈련 바로가기 유지. 기록실 내 도감/기록/도움말 뒤로는 기록실로 복귀. 손상 저장 복구는 타이틀에도 직접 표시.
- 기존 저장이 있을 때 새 원정의 저장 교체 확인 화면 추가. 취소하면 원본 그대로 타이틀 복귀, 확인해도 실제 시작 저장 전까지는 기존 시작 절차에 따름. 기존 랭킹/오프라인 시작/훈련/저장·복구 API는 변경 없음.
- 배포 스크립트의 허용 자산 목록에4PNG 등록만. 패키징/배포 명령 실행 안 함. 버전0.42/서버 설정 변경 없음.
