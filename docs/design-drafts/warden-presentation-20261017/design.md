# 2층 수호자 연출 패키지 v1 — 검토안

2026-10-17 ‘ㄱㄱ’ 후 다음 캐릭터 단위. 벨카르/대악마의 로컬 구현을 보존하고 2층 수호자의 빠진 연출만 준비한다. 기존 걷기·망치 내려찍기·회수 자세 재생성 없음. 이번 PNG는 검토용이며 승인 전 runtime/배포자산에 반영하지 않는다.

## 실제 코드 기준
- character-sizes.js: warden 몸높이84. warden-sprite.js에서 발29를 축으로1.1배 확대하므로 표시몸높이92.4, 발29 유지. 이 최신비율과 덩치 유지.
- warden-sprite.js: type=boss이고 variant없음/warden인 경우. 원본2자세 및 motion4·walk·recover3 아틀라스를 순서에 맞춰 사용한다. 새 연출이 걷기/공격/회수 완성을 반복하지 않는다.
- combat/patterns.js: ring/slam/fan/spiral/cross/pincer 순환. 경고 .65초, slam경고1.1초→도약.5초→recover(1.5x.4=.6초). 도약 착지85px/피해24·벽검사·openGuard1.2 유지. 일반패턴별탄수/간격/후딜 불변.
- 왕/군단장과 다르게 새보스도전 버튼을 만들지 않는다. 실제 최초 전투 진입과 저장 재개의 구분이 필요하다. 구현 때 입장 이벤트를 확인하고 로드/도감/렌더 호출만으로 자동등장을 재생하지 않는다.
- red 인자는 귀환 때의 외곽표시이며 이번 시안에서 새로운 체력 페이즈를 만들어내지 않는다.

## 승인 후 연결 제안
- 첫 전투 입장만 .8초 이내 등장→준비, 게임update시간/WeakMap 상태. 공격이 준비되면 즉시 취소. 적 무적·정지·새시전지연·강제카메라·대사 없음.
- 약/강피격 .10/.16초, 최소간격.24초, 최대체력1.5% 손실부터 강반응 제안. warning/leap/firing/recover·openGuard·동결이 우선. 실제피격경직/시전취소/이동정지 없음.
- 처치 .9~1초 시각스냅샷, 좌표/방향만 복사. 기존 적 제거·보상/계단개방 즉시 유지. 시체충돌/드롭장식 추가 없음.
- 무릎자세는 서있는몸 스케일로축소, 길이/망치끝을 몸높이로 재지 않음. 새PNG실패시 기존몸/일반처치fallback.
- 게임시간·정지/선택창·방/층/로드정리 유지. 도감정적/효과줄이기에서는 흔들림생략. 보상모달뒤에서 처치가 가려질수있으며 보상지연으로 해결하지 않는다.
