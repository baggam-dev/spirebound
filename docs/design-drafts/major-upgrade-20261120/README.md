## 직접 검토 결과와 구현 전 제약

- 두 장의 석재/상아/청회색/금빛 톤, 기존 주인공·요정·석궁 정체성, 신규 적의 기본형·행동/분리 FX, 접점 강도/등급별 아이콘을 직접 확인했다.
- 정적 미술 방향 보드다. 투명한 런타임 개별 자산, 실제 걷기/시전/공격 애니메이션 시트, 타격 판정/치명타 시스템의 구현 결과가 아니다. 주인공 참고를 재해석한 그림이며 기존 픽셀의 완전 동일 보존을 뜻하지 않는다.
- 치명타와 복합 명중의 실제 작은 화면 구분, 신규 로브형 적의 축소 실루엣, 맵의 실제 이동/문 통과 여백, 다수 소환체 가독성은 별도 제작/구현 단계에서 확인해야 한다. 전투 UI를 교체하는 시안은 아니다.
- 승인 후 필요한 모션과 개별 자산을 분리 제작하고 실제 게임 크기에서 검증한다. 오라는 캐릭터 PNG에 굽지 않고 별도 효과로 유지한다.
- 이번에는 이미지/문서만 준비했다. 테스트·서버·브라우저 QA·푸시·배포·공개 서비스 확인을 하지 않았다. A 화살비 너프 로컬 커밋 `d8e84fe`는 보존한다.
- 전체 수정 후 한 번에 배포하라는 사용자 권한은 유지된다. 현재는 시안을 먼저 검토하는 단계이며, 패키지 디자인 승인 후 B~F 구현과 누적 검증/배포를 이어간다.
