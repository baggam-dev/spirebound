## 연출 방향

1. 접근: 열린 입구를 향해 실제 무게를 옮겨 걷는다. 발 디딤·무릎/발목·반대쪽 어깨 움직임과 망토 후행을 분리한다. 인물을 크게 줌하는 것으로 보행을 대체하지 않는다.
2. 결심: 문턱에서 발을 모아 멈추고 입구를 살핀 뒤 장비 끈/활을 정리한다. 이미 열린 문을 지나가는 기존 이야기 흐름을 유지하며 새 문밀기 행동은 이번 보드에 넣지 않았다.
3. 입장: 내부에서 입구 쪽을 보는 컷으로 바꾸고, 주인공이 어둠 속으로 걸어온다. 문이 측면 경첩을 축으로 닫히고 바닥 빛이 줄어드는 연출을 목표로 한다.

하단6포즈는 딛기→통과→반대발 딛기→멈춤→올려다봄→장비/활 정리의 행동 구분용이다. 완성6프레임 보행 루프라는 뜻이 아니다. 보행은 목표6~8프레임, 멈춤/시선·손동작/문통과는 필요한 중간동작과 전용방향을 별도로 제작해야 한다. 캐릭터 기본형·행동·별도효과를 이 통합 패키지로 한 번에 검토한다.

## 직접 검토와 구현 경계

기존 밝은갈색머리/붉은목도리/푸른회색망토/가죽옷·활/화살통과 탑·수호상·주황횃불·보랏빛밤의 결을 확인했다. 아래 키포즈는 발/무릎과 손 위치가 서로 달라 타이틀 idle만 반복한 보드와 구분된다. 다만 눈에 보이는 정적 포즈만으로 발 접지/관절 연결/손·활의 모든 중간프레임 일관성이 검증된 것은 아니다. 시선 상승은 작게 표현돼 정식 프레임에서 더 분명히 할 여지가 있다. 3컷의 문은 닫히는 중간 상태로, 경첩·가림 순서와 최종 닫힘/빛 소거는 실제 동작으로 따로 구현해야 한다.

생성 보드의 원화는 참고 정체성을 재해석한 이미지이며 원본 픽셀을 그대로 합성한 것이 아니다. 테두리·로고·라벨은 검토 보드용이며 새 게임 HUD가 아니다. 캐릭터를 배경에 붙여 둔 큰패널 자체를 통째로 이동/줌하는 방식으로 구현하지 않는다. 배경/인물동작/문잎/빛/그림자/먼지를 분리하고, 기존 스킵/중단·로드실패·효과완화 대응을 유지한다. 5~6초는 제안 길이이고 현재3.6초 코드는 변경하지 않았다. 새 BGM이나 전투·저장·랭킹 변화는 없다.

이번에는 이미지 생성/원본복사·정적 직접검토/문서만 수행했다. 실제 모션 제작·테스트·서버·브라우저QA·푸시·배포는 하지 않았다. 디자인 확인 전에는 런타임에 반영하지 않는다. 승인 후 전용 프레임/분리 레이어와 실제 움직임 구현을 이어가고, 실행 검증·배포는 별도 일괄 지시에 따른다. 상세 검토 계획은 `docs/entrance-quality-plan-20261117.md`를 참고한다.
