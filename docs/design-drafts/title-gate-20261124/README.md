# 메인 화면 — 탑의 문 앞 v1

사용자가 제안1번 ‘탑의 문 앞’을 선택하고 도트 그래픽 품질을 높인 시안을 요청했다. `main-menu-gate-v1.png`는 배경·주인공·메뉴를 한 화면에 묶은 검토용 전체 구성이다. 제품 `src/`·`assets/` 반영은 없다.

## 외형 패키지

- 오른쪽 거대한 봉인문을 가까이 잡고, 겹쳐진 첨두 아치·문양·사슬·후드 석상·풍화된 석재로 탑의 규모와 위협을 강조한다.
- 젖은 계단의 짧은 반사 픽셀, 따뜻한 불과 차가운 안개, 어두운 석재 속 밝은 모서리로 재질과 깊이를 구분한다. 광량을 화면 전체가 아니라 문틈·화로·반사에 집중한다.
- 기존 금발 궁수·붉은 스카프·청회색 망토·화살통·활 정체성을 유지한 뒷모습을 문 앞에 둔다.
- 왼쪽 메뉴는 기존 기능 ‘계속 탐험/새로운 원정/기록실/설정/명예의 전당/전투 훈련’을 유지하는 구상이다. 저장 층수·계정·랭킹 등 사용자 데이터를 만들어 넣지 않았다. 실제 저장이 없을 때 계속 탐험은 기존 규칙대로 숨겨야 한다.

## 모션·진입 제안 (미구현)

1. 대기: 불꽃4~6프레임, 사슬·문은 고정하고 망토/머리카락만 작은 바람, 느린 전경/중경 안개·드문 불씨. 글자와 버튼은 움직이지 않는다.
2. 선택: 금빛 테두리와 작은 다이아 커서의 밝기만 부드럽게 강조한다. 큰 확대·화면 흔들림은 넣지 않는다.
3. **새로운 원정**: 문틈 빛이 차례로 밝아지고 봉인선이 풀린 뒤 양 문짝이 벌어짐→주인공이 계단을 향해 걸음→약한 카메라 전진으로 기존 입장 장면과 연결하는 후보. ‘계속 탐험’은 새 원정 입장 연출을 반복하지 않고 기존 저장으로 돌아가야 한다.
4. 효과 줄이기: 정지 대표 프레임·짧은 페이드로 대체하고 스킵을 제공한다. 실제 원정/저장 생성·로딩·입력 상태는 기존 흐름에 맞춰 별도 검토한다.
