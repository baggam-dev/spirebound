## 추천 구현 방향 — 승인 전 후보

작은 흔적3~6개/방, 큰 문양은 일부 방에만 최대1개. 빈 바닥70% 전후를 남긴다. 얼룩·물은 성소에서, 오래된 갈색 핏자국·닳은 의식문양은 하강/적대 테마에서 비중을 올린다. 매 방에 오망성을 의무 배치하지 않는다. 스크래치/이끼도 섞어 혈흔만 반복되지 않게 한다.

맵/전투 RNG와 별도의 방 시드로 종류·위치·회전·크기·농도를 고정하고 재입장/로드에 재추첨하지 않는다. 문·시설·핵·전투 중앙과 공격 예고를 피한다. 바닥 캐시에 구워 처리하고 물의 하이라이트만 선택적으로 미세하게 움직인다. 완화는 정적. 배경용 문양은 발광/펄스/공격 판정 없이 닳은 선으로 구분한다. 이동감속·피해·충돌 등 새 게임 규칙은 이번 제안에 포함하지 않는다.

시안의 물 테두리와 흰 의식문양은 실제 작은 화면에서 다소 밝을 수 있어 구현 때 낮은 대비부터 시작한다. 오망성 샘플은 손상된 별 문양이라 정확한 도형 인지는 확정하지 않았다. 실제 2px 재질/캐릭터·독·기관 예고/XP 대비는 승인 후 최종 누적 QA에서 확인해야 한다.

현재 시안/문서만. 테스트·구문 실행·서버·푸시·배포 없음. 승인 후6-1 추가 작업으로 기존 sanctum-finish/environment-ambience 캐시와 합쳐 구현하고, 기존 근접병·궁수6-2/스킬·소환체6-3 순서를 이어간다.
