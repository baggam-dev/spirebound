# 일섬 발도·참격·충전 비교 패키지

2026-11-25 ‘다음 진행’에 따라 준비한 **2단계 디자인 검토본**이다. 운영0.65와 실제 스킬은 바꾸지 않았다. 이전 1단계 로컬 수정 a74a48e도 그대로 보존했다.

## 무엇을 검토하는가

- 기존 주인공·활/화살통·갑옷을 유지하고 야간 청회색/붉은 목도리 톤으로 맞췄다. 검·칼집을 사용하는 준비 → 깊게 몸 낮추기 → 발도 돌입 → 큰 베기 → 착지 → 납도의6자세다. 전경/망토 후행을 늘려 몸이 먼저 돌입하는 실루엣을 만들었다.
- 칼빛·직선 속도선·상향 큰 참격·하향 큰 참격·적중 섬광·소멸6효과를 몸과 별도로 준비했다. 이펙트를 캐릭터 PNG에 굽지 않았다.
- `motion-preview.gif`는 1/2/3단계의 충전을 각각1/2/3개로 표시하고 **각 버튼을 연속 재입력한 상황을 미리 짠 시연**이다. 한 번 누르면 자동3회 발동하는 확정 설계가 아니다. 남은 충전은 밝은 마름모로 표시한다.
- 이동0.12초, 시연 재입력 간격0.34초. 준비0.04초와 착지/납도는 별도 시각 단계다. 납도 때문에 실제 입력을0.34초 동안 잠그겠다는 뜻은 아니다. 재충전은 이 시안에 구현하지 않았으며 GIF 반복은 시연 재시작이다.
- 섬광은 국소 효과다. 실제 명중 검출·타격음·히트스톱·카메라 충격은 아직 연결하지 않았다. 이번 GIF는 몸/이펙트/타이밍의 검토 자료이며 실전 타격감 검증 결과가 아니다.

## 자산과 정적 확인

내장 image_gen2회. 전체 프롬프트·참조/원본 경로는 `prompts.md`, SHA·수동 소스 영역·배율·루트는 `manifest.json`, 재현 합성은 `build-preview.py`에 보존했다.

- 주인공6 PNG:144×128, 실제 몸 최대80px, 공통 배율80/434, 루트64/112,47색+투명. 생성된 큰 베기가 셀 경계를 넘어간 부분은 여백의 투명 경계를 확인하고 수동 소스 영역으로 분리했다. 검 끝을 셀 경계에서 잘라 버리지 않았다.
- 별도 효과6 PNG:96×96,23색+투명. 소스 alpha220 미만의 흐린 주변광을 제거하고 정수 픽셀/공통 팔레트로 정리했다. 원본은 보존했다.
- `hero-report.json`/`fx-report.json`:12장의 크기·투명도·팔레트 통과. 별도 셀 경계 검사와 자세·효과 접촉표/합성 접촉표 육안 확인을 했다.
- 640×360/3초,25fps 시간 격자75장 합성. GIF는 같은 프레임을 합쳐26프레임으로 인코딩하고 전체3000ms를 유지한다. 1280×720 정지 이미지와 HTML의2배 확대/정지 전환도 제공한다.

## 실제 연결 시 남은 일

단일 오른쪽 방향 시안이다. 상하/뒤 방향·미러 시 손/칼집/활의 가림·실제 게임 크기는 최종 연결에서 확인해야 한다. UI의 충전 소모 표시는 제안이며 실제 HUD 스킨/쿨타임은 구현 전이다. 몸과 효과는 별도이지만 손/검의 모든 관절과 프레임 접지가 최종 보증된 것은 아니다.

시안 승인 후 일섬 전용 강화2/3단계, 재입력/방향 버퍼·충전/쿨타임·경로 충돌·베기당1회 피해/무적·구저장1단계 이행·모션 감소를 연결한다. 기존 지뢰/질풍 분기는 유지한다. 게임 구문/단위 테스트·브라우저 QA·실기기·푸시·배포는 이번에 하지 않았다. 별도 배포 지시 때 누적 변경과 함께 검증한다.
