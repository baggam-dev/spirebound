# 일섬 강화 시안 v2

사용자 요청인 ‘더 크고 화려한 베기 / 더 빠른 돌진 / 더 오래 남는 잔상’을 기존 방향 안에서 조정했다. 기존 v1·원본·native 자산과 제품 코드는 변경하지 않았다. 새 이미지 생성 없이 승인 방향의 분리 스프라이트를 합성했다.

- 돌진 이동0.12→0.08초. 같은104 논리 픽셀 이동 거리에서 속도1.5배다. 시연 연속 입력 간격은0.34→0.26초로 줄였다. 실제 입력 잠금이나 재충전 확정값은 아니다.
- 주참격96×96→160×136: 폭1.67배/높이1.42배. 뒤에125×106 보조 참격을 지연시켜 겹치고, 길어진 속도선·큰 국소 적중 섬광·흩어지는 파편을 더했다. 전 화면 흰색 점멸은 쓰지 않는다.
- 각 이동 경로에서5개 과거 자세/위치를 표본으로 남긴다. 잔상은 주인공을 따라붙는 복제물이 아니라 **지나간 위치에0.24초간 고정돼 소멸**한다. 초기 alpha0.46에서 점차 사라진다. 실제 스킬에서는 모션/섬광 감소 설정과 연결해야 한다.

`motion-preview.gif`:640×360/3초,50fps 시간격자150장 합성→중복 프레임 합산44프레임/3000ms. `main-still.png`1280×720, `comparison.png`이전/수정 정지 비교, `motion-contact.png`시간대별 접촉표. 파일 구조·전체 지속시간을 정적으로 확인하고 정지·접촉표를 직접 검토했다. 기존 native12장의 SHA는 manifest에 기록했다. 새 스프라이트가 없어 자산 규격 검사는 기존 v1 보고서를 기준으로 한다.

오프라인 검토용 연출이다. 실제 스킬 속도/피해/무적/충전/재입력·충돌·음향·카메라 충격은 아직 연결하지 않았다. 게임 구문/단위 테스트·브라우저 QA·실기기·푸시·배포는 하지 않았다. 운영0.65와 이전1단계 미배포 수정은 그대로다.
