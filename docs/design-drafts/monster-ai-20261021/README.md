- 돌진병 그림 예고캡션이 요청 .2초 대신 .3초로 생성됐다. 실제 제안값은 .2~.25초, 거인은 .3초. 숫자는 디자인승인 뒤 로직에 명시하고 캡션이 실제적용값인것처럼 주장하지 않는다. 범위는 사용자 .1~.3초 안.
