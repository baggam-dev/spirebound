# 해골왕 → 대악마 부활 / 3페이즈 강림 연출 v3

2026-11-10 사용자 ‘지금 보스처럼 해골왕에서 3페이즈때 살아나는 형태’, ‘신성한 느낌… 3페 등장시 연출’, 제안 후 ‘ㅇㅋ’. 이 방향은 승인된 것으로 기록하며 같은 방향 결정을 다시 묻지 않는다. 현재 단계는 시안 갱신/연출 설계로, 런타임 구현 완료와 구분한다.

## 합의된 외형
- 1페이즈: 기존 해골왕. 2페이즈: 해골 상태 유지, 뼈 사이 마력·가슴 문양 균열. 원본 자산 유지.
- 3페이즈: 육신을 되찾은 은발·뿔의 군주. 왕관·갑옷·망토·장병기 형태를 계승. 영구 후광/천사 날개/항상 흰옷인 캐릭터가 아니다.
- 육신 복원은 살점/장기 생성 없이 백금빛 속에서 실루엣 전환. 신성한 강림과 악역의 위압감이 함께 느껴지는 등장 순간.
- 8층 잔해 보드와 부위전/층 재배치 계획은 그대로. 10층 보드v2의 인간형 1/2페이즈는 폐기 방향이며 파일은 보존한다.

## 등장 타임라인 초안
기존 왕 전환 1.4초 안에 표현하는 것을 우선 설계한다. 이 수치는 새 구현/연출 검증 결과가 아니며 전환 시간 추가로 난도를 바꾸지 않는다.

|시간(초)|몸/장면|빛·음향|
|---|---|---|
|0~0.20|해골왕이 무기를 짚고 고개를 듦|주변 부드러운 감광, 전투음 짧게 낮춤|
|0.20~0.55|백금빛 기둥 속 해골 실루엣|캐릭터 주변만 강한 빛, 바닥/플레이어는 읽히게 유지|
|0.55~0.90|같은 위치에 육신 복원, 은발/왕관형 뿔이 드러남|거대한 후광 문양이 등 뒤에 펼쳐짐. 낮은 종소리 1회|
|0.90~1.15|살아난 군주의 자세가 안정됨|낮은 바닥 파동 1회, 순수 연출로 피해 없음|
|1.15~1.40|무기를 잡고 전투 자세 복귀|후광/기둥/감광을 완전히 걷고 보라 봉인석만 남김|

왕관·무기·손 위치를 맞춰 변신 전후 동일 인물로 읽히게 한다. 화면 전체 순백 번쩍임/연속 플래시 금지. 빛과 후광은 캐릭터 PNG에 굽지 않고 Canvas 별도 레이어로 구현할 계획이다. 그림 보드의 장면은 시간/광량/실제 게임 크기를 보증하지 않는다.

## 재사용과 연결 경계
- `mordo-phase1-reference-atlas.png`, `mordo-phase2-reference-atlas.png`와 해당 렌더 경로를 우선 재사용. 2페이즈 실제 원화가 새 부활 서사와 맞는지 production 연결 때 확인하고 과거 3페이즈 해골 자산은 삭제하지 않음.
- 새로운 3페이즈 원화는 기존 장병기 준비/베기/돌진/시전/회수/피격/격파 자세와 앵커가 맞아야 함. 이번 storyboard는 완성 애니메이션 atlas가 아님.
- 현재 `upper-floors.js`는 체력 단계 변화에 kingTransition=1.4를 설정하고 적 탄환 정리. 현재 `mordo-presentation-state.js`는 kingTransition을 피격/도입보다 우선 처리하며 WeakMap에 표시 상태 보관. 새 등장은 실제 3페이즈 진입 이벤트에만 연결해야 함.
- 단순 hp/max로 3페이즈라는 이유만으로 로드/도감/연습에서 강림 연출 자동 재생 금지. 큰 피해로 1→3을 건너뛰는 경우도 실제 3페 진입은 1회, 즉사 시 사망 우선. paused/hidden/방전환/로드 시 정지·정리.
- BGM 제작은 기존 보류 유지. 여기서 정적은 전투음의 일시 duck이며 종소리는 별도 단발 합성음 제안. 현재 경고/음소거/volume0/gesture unlock 정책 유지. 배포 지시 전 소리 검증 실행 안 함.
- 효과 줄이기: 빠른 광량변화/화면 흔들림/후광 확대 생략, 정적인 낮은 밝기 후광→외형 전환으로 정보 유지. 빛/PNG 실패 시 기존 외형/단순 전환 fallback, 전투 진행을 막지 않음.
