# 10층 대악마 재디자인 v1 — 마계 군주
2026-11-10 사용자 요청: 기존 디자인은 올드하고 라그나로크 온라인 기준점에서 벗어남. 기괴함·징그러움 대신 위압적이고 멋진 악역. 사용자 확인은 패키지로 최소화.

## 제안
- 단정한 셀 채색, 명확한 외곽선과 간결한 큰 면, 게임에서 읽히는 데포르메 비율. 기존 복잡한 보라 비늘·노출된 신체·가슴 눈을 제거하는 시안.
- 은발·차가운 얼굴·뒤로 뻗은 왕관형 뿔, 검은 갑옷/상아색 장식/와인색 망토/보랏빛 가슴 봉인석. 무기 없이 손과 마법으로 위압감을 표현.
- 1단계 손·발: 동일 갑옷의 건틀릿/장화, 절단면 대신 마법 봉인 표현.
- 2단계 눈·코·입: 동일 얼굴을 암시하는 가면 파편. 기존 각 부위 패턴은 유지하되 눈 레이저·코 독길·입 흡입/밀침/혀의 시각적 대응은 승인 후 제작 시 따로 정교화. 시안의 가면은 완성 공격 자산이 아님.
- 3단계 본체: 벽 위로 드러나는 거대 군주, 손으로 벽을 붙잡는 무게감. 등장/준비/휘두르기/핵 붕괴를 같은 캐릭터로 연결.
- 오라·먼지·파편·광원은 독립 효과. 실제 공격 예고/판정 가림 방지, 효과 줄이기 대응은 승인 후 구현 단계.
