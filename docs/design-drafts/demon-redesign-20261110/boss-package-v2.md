# 8층 잔해·10층 각성왕 통합 디자인 패키지 v2

2026-11-10 ‘순서대로 진행’의 1단계. 수정 계획은 `../../boss-restructure-plan-20261110.md`. 이 패키지는 디자인 검토용으로 제작하며, 이미지를 런타임에 연결하지 않는다. 제안 명칭은 가칭.

## 두 보스의 차이
|항목|8층 — 봉인의 잔해|10층 — 몰락한 왕 / 각성한 대악마|
|---|---|---|
|역할|과거 봉인된 힘이 남은 거대 석상/빈 갑주|힘을 선택해 각성하는 동일한 왕|
|실루엣|낮고 넓은 사각형·돌손·벽 위 거상|서 있는 왕·긴 장병기·망토, 이동하는 결투 상대|
|재질|청회색 돌·상아색 가면·무딘 청동|검은 갑주·절제된 금/상아 장식·와인색 망토|
|색의 중심|호박색 봉인 문양|보라색 가슴 봉인석|
|얼굴|인간 피부 없는 조립식 가면|동일한 차가운 얼굴이 3단계까지 연결|
|기괴함 제한|절단면·내장·사실적 혀 대신 돌과 마법|해골·과한 근육·육체 변형 대신 왕관/머리/자세 변화|

일러스트를 축소해서 쓰는 방식보다 굵은 외곽선·큰 면의 셀 채색·약 3~3.5등신 게임 비율을 기준으로 제작한다. Ragnarok Online을 기준으로 삼은 판타지 게임 톤을 지향하되 기존 캐릭터를 복제하지 않는다. 8층과 10층에 같은 얼굴을 붙여 반복 보스처럼 만들지 않는다.

## 8층 외형·동작·효과
|단계/행동|캐릭터 동작|별도 효과와 가독성|
|---|---|---|
|손·발 등장|봉인 문양 위 빈 건틀릿과 장화가 움직임|절단면 없이 내부 암부/문양, 착지 그림자|
|손가락 사격|다섯 손가락을 조준 방향으로 펴고 발사 후 닫음|기존 손가락별 탄막 구분, 문양 불빛은 독립 효과|
|발 이동/도약/착지|체중을 옮겨 딛기→들기→내리찍기→안정|땅 예고를 먼저 표시, 먼지로 착지점 가리지 않음|
|눈 가면|상체 없는 눈 가면의 슬릿이 열림|레이저 얇은 예고선→타격, 눈 탄환 별도|
|코 가면|환기구가 열리고 이동 방향으로 기울어짐|기존 독길은 회녹색 기류/분진으로 표현하되 위험 장판 경계 유지|
|입 가면|하부 가면의 입구가 열림|흡입/밀침 흐름 방향 분명히, 혀는 분절된 마력 연결체로 대체|
|부위 격파/전환|문양이 꺼지고 돌조각이 낮게 떨어짐|시체 잔상이 다음 적/예고를 가리지 않음|
|본체 등장|같은 가면의 조립 흔적을 가진 거상이 벽 위로 드러남|큰 그림자와 작은 낙진, 10층 군주 등장 구도와 구별|
|본체 준비/타격/회수|큰 팔의 어깨와 손끝이 함께 움직임|땅 예고와 실제 부채꼴/선 공격 대응|
|피격/격파|약한 반응은 돌가루, 격파 시 봉인석 꺼짐→갑주 붕괴|화면 전체 클리어 효과는 실제 마지막 처치 1회에만 연결|

본체에 기존 눈/입/발 능력·특수공격을 연결할 자리가 필요하다. 보드는 대표 행동의 방향 제시이며 모든 패턴/각도별 sprite를 완성한 것은 아니다. 코 독길과 입 연결체의 시각 교체는 피해·범위·막힘 규칙을 바꾸는 의미가 아님. 실제 8층 난이도 완화 수치/패턴 조합은 다음 구현 단계에서 별도 기록한다.

## 10층 외형·동작·효과
|단계/행동|캐릭터 동작|별도 효과와 가독성|
|---|---|---|
|1페이즈|닫힌 왕관·짧은 은백색 머리·절제된 망토, 장병기를 양손으로 지지|봉인석은 작은 불빛만, 기존 왕의 정체성 유지|
|2페이즈|같은 얼굴, 망토가 열리고 머리/왕관이 느슨해짐|가슴석 균열과 작은 빛, 아직 최종 뿔을 드러내지 않음|
|3페이즈 각성|왕관이 뒤로 뻗은 뿔 형태로 열리고 긴 은발·열린 봉인석|배경 감광→가슴 빛→짧은 파동, 같은 인물임을 보여줌|
|대기/이동|장병기와 어깨 무게를 지지, 명확한 발 교대|피격처럼 앞뒤로 튕기는 보행 금지, 오라는 독립|
|베기|양손 준비→무기 궤적을 따라 타격→끝 자세→회수|공격 arc는 날끝 궤적과 실제 판정을 기준으로 표시|
|돌진/순간이동|몸이 먼저 향하고 무기가 따라감, 도착 후 베기 준비|잔상은 짧게, 도착/타격 예고 구분|
|표식/탄막/심판|무기를 세우거나 바닥에 짚어 시전, 근접 베기와 구분|기존 바닥 줄무늬·표식 안전 구간 우선|
|피격|약한 어깨/고개 반응, 공격 중에는 준비 자세 유지|반복 움찔·무기 휘두르기 오인 방지|
|격파|무기를 짚고 무릎 꿇음→봉인석 빛이 흩어짐|마무리 충격파/빛 파편 별도, 열쇠/보상 타이밍 분리|

장병기는 기존 왕의 알아볼 수 있는 긴 양날 장병기를 계승하는 제안. 각성 후에도 무기와 양손·발을 유지하며 벽 위 거대화/분리 부위는 붙이지 않는다. 기존 65%/30% 체력 단계와 1.4초 전환은 현재 코드 기준일 뿐, 시안 보드가 새 타이밍을 확정하지 않는다.

## 제작·검토 경계
- 내장 image_gen으로 8층·10층 보드 각각 제작. 원본 보존, 프롬프트 두 파일 보존. 레퍼런스는 기존 왕의 왕관/장병기와 이전 군주 시안이며 과거 사실적 질감/신체 공포 표현은 계승하지 않음.
- 두 보드는 정적 디자인/대표 포즈 검토 자료다. 실제 게임 크기 캡처·연속 애니메이션·완성 atlas·충돌 검증·성능 확인이 아님. 상대 크기는 개념적이며 정확한 픽셀 크기는 승인 후 기존 판정/앵커 기준으로 정함.
- 장식 단순화·신체/무기 일관성·프레임 경계는 production sprite 단계에서 재확인. 캐릭터 기본형/부위/동작과 독립 효과를 묶어 한 번만 검토받음.
- 다음: 이 패키지 디자인 확정 후 정식 자산/로컬 구현→8층 완화→10층 각성→원정/구저장/도감/보상/랭킹 정합성. 테스트/푸시/배포는 새 명시 배포 지시 후.

## 생성 결과 직접 확인
8층: floor8-remnant-package-v2.png. 10층: floor10-king-awakening-package-v2.png. 두 보드의 부위/재질·동일왕 전후·대표모션을 확인. 10층 비율은 목표보다 길고 세부 장식이 많아 정식 sprite 제작 시 단순화 필요. 보드의 3.5H 라벨은 정확한 실측을 보증하지 않음. 시안 안 작은 전투장면은 생성된 개념 그림이며 실제 게임 캡처가 아님. 최종 디자인 승인 전 원화/런타임 교체 안 함.
