# 타격 체감 강화 v1 — 움직이는 전후 비교

## 목적과 상태
사용자가 0.50 플레이 후 ‘부드러워졌나 싶지만 크게 체감하지 못한다’고 피드백했다. 전체 입자를 늘리기보다 기존 정밀 약점강화/강한 베기/화염 폭발의 순간 대비를 키우는 후속 방향이다. ㄱㄱ는 앞서 제안한 움직임 비교 시안 진행 승인으로 적용했다. 게임 구현/테스트/푸시/재배포 승인이 아니다.

impact-feel.html은 독립 시안이며 실제게임 캡처/검증결과가 아니다. 좌측은 현재0.50 arrow-impact-visuals.js와skill-burst-art.js 원문에서 export만 제거해 내장한 실제 함수를 호출한다. 우측은 시안전용 함수다. 네트워크/서버/게임저장/실계정/운영접속없음. 캐릭터·배경을 재생성하지 않고 추상타일바닥/범위보조점선만 사용한다. 비교 양쪽의 배경·원점·반경/진행시점은 동일하다. 부모opacity/전체게임경계·적탄·다른효과중첩이 있는 실제장면과는 다르다.

## 비교 조작
재생은반복루프없이한번재생하고정지한다. 실제속도/¼속도·효과줄이기·같은시간스크러브로전후를비교한다. 초기40ms정지/자동재생없음. 타격 후650ms까지보이지만모든효과의실제수명은그대로라후반은빈화면이다. 눈속임을위해한쪽만느리게재생하지않는다. 초반핵은짧으므로실제속도로먼저판단하고느린재생으로형태를확인한다.
