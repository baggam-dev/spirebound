## 검토 결론

1층의 습한 회녹 전당과 다른 청회색 석조/남청 깃발/무쇠 보강을 추천한다. 왼쪽 일반방은 짧은 내벽과 외곽 무기거치대, 오른쪽 파수꾼 보스방은 넓은 연병장과 외곽 방패 문양으로 구분한다. 아래 세 소품은 창 거치대/깨진 방패/찢어진 깃발이다. 깃발·불티 움직임은 승인 후 별도 연출로 연결한다.

보스방의 직선 석재 테두리는 낮은 대비로 적용하며 도약 위험 예고와 중앙 회피 공간을 보존해야 한다. 실제2층은 보스포함6방으로 유지한다. 시안의 문/벽/소품 위치는 확정 충돌 배치가 아니며 현재 저장된 오프셋문·벽영역·시설 좌표를 바꾸지 않는다. 기존 공통 시설을 재사용한다.

다음 승인 후 범위: 2층 배경용 모듈과 소품 3종 → 기존 형태/통로를 보존한 시각 연결 → 문서·로컬커밋. 별도 배포 지시 없이는 테스트/푸시/배포하지 않는다. 3~10층 및 대사컷씬은 후속으로 유지한다.
