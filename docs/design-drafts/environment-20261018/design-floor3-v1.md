# 3층 고대신의 서고 — 검토 시안 v1

상태: 시안 완성·실제 PNG 육안 확인·사용자 검토 대기. 사용자 승인 전 runtime/배포 자산에 반영하지 않는다. 대사·컷씬과 4층 이후는 후속으로 둔다.

## 실제 코드와 범위

- `src/game/engine.js`에서 3층은 floor index2, 7~10방이며 보스가 없다. 일반방·샘물·보물·신전·계약/시련·상승계단이 있다.
- 신전은 기존 정예 수호자와 축복/저주 선택을 유지한다. 계약 제단은 생명 계약·유물 거래·봉인된 시련의 기존 역할을 유지한다. 시안은 새로운 보상/시련 규칙을 뜻하지 않는다.
- 기존 `room-backdrops.js`/`atmosphere.js`의 보랏빛 서고 톤, `terrain.js`의 책장/탁자 장애물과 공통 시설 PNG를 기준으로 한다. 충돌·문 오프셋·방 개수·저장 좌표·전투 RNG를 바꾸지 않는다.

## 제안

1층의 습한 회녹 석조, 2층의 청회색 군사 회랑에서 탁한 보라회색 석재·호두색 목재·낡은 양피지·산화된 황동으로 이동한다. 4층 프리즘의 결정·굴절과 겹치지 않게 책·종이·촛불·작은 독서등을 중심으로 한다.

한 장에 왼쪽 일반 서고방, 가운데 기존 책/결정 신전방, 오른쪽 기존 포도주색 계약/시련 제단방을 배치한다. 아래는 낡은 낮은 서가·두루마리 독서 책상·무너진 책더미 3종이다. 캐릭터나 새 보스를 만들지 않는다.

가운데 전투 공간은 넓고 낮은 대비로 비운다. 원고와 책더미는 가장자리에 모으고 큰 바닥 마법진·호버링 책·짙은 안개는 쓰지 않는다. 향후 촛불/드문 먼지/미세한 종이 움직임은 몸체 PNG와 별도 연출로 연결한다.
