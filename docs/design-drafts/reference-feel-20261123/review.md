## 우리 아트 기준

기존 주인공 정체성과 어두운 성채는 유지한다. 모든 것을 밝고 복잡하게 만들지 않고, **묵직한 실루엣 + 읽히는 도트 덩어리 + 폭발 순간의 고명도**를 기준으로 한다.

1. 캐릭터: 얼굴·손·무기 끝을 큰 명암 덩어리로 분리. 발 고정과 무게 이동을 먼저 맞추고 준비/발사/회수 자세 차이를 키운다. 고해상도 이미지를 작은 크기로 줄이는 것만으로 도트 완성도를 판정하지 않는다.
2. 보스: 잡몹과 다른 덩치·위압적인 자세·발동 직전 형태 변화. 크기는 몸체 표시와 실제 위험 판정을 함께 확인하고 임의로 판정 확대하지 않는다. 모르도 등 기존 보스마다 고유한 균열/붕괴 형태를 둔다.
3. 오브젝트: 벽·바닥은 캐릭터보다 낮은 대비, 문/봉인/보상은 별도 발광·명암. 작은 장식마다 동일한 번쩍임을 넣지 않는다. 등불·기둥은 문과 시야 통로에서 비킨다.
4. 도트 효과: 중심은 밝은 작은 코어, 중간은 속성색, 외곽은 어두운 파편. 매끈한 흐림만 쌓기보다 계단형 궤적/조각/짧은 잔상을 기본으로 한다. 화면 기준 픽셀 규칙과 정수 스케일/nearest를 일관되게 적용한다.
5. 색 역할: 기본 사격은 담금빛/뼈색, 화염은 주황, 서리는 청백, 봉인·타락은 보라. 적 예고는 외곽선/무늬로도 구별한다. 전체 색 범위는 대표 장면 시안에서 확정한다.

|사건|타격 반응|잔향/음향 역할|제약|
|---|---|---|---|

|일반 적 처치|피격 방향으로 분해/무릎 꺾임→작은 조각→빠른 소멸|재질별 짧은 파열|통째 사라짐/흰 플래시 반복보다 형태 변화 우선|

다단히트는 매 탄마다 큰 반응을 재시작하지 않고, 같은 대상/짧은 구간을 합친다. FX 전용 난수와 고정 입자 상한을 사용한다. 실제 플레이 스피드는 스킬 후딜·이동·목표 전환도 좌우하므로 광고를 보고 게임 전체 배속을 올리는 방식으로 결정하지 않는다.

## 검토용 모션 시안과 진행 순서

`motion-draft.html`은 우리 기존 거인/모르도 이미지를 사용한 독립 Canvas 연출 시안이다. 일반 명중·강타·보스 격파의 효과 강도/타이밍을 버튼으로 비교한다. 신규 캐릭터 원화, 실제 전투 구현, 검증 완료 제품이 아니다. 오디오 시안은 포함하지 않는다.

1. **대표 한 장면 패키지**: 기존 주인공+일반 적+모르도+문/기둥/바닥, 준비/발동/피격/사망, 별도 FX, 보스 보상 마무리를 PC·모바일 실제 크기로 제시한다. 캐릭터별 파편 승인을 나눠 받지 않는다.
2. **공통 타격 레이어**: 기존 이벤트 훅·중복 억제·국소 플래시·숫자 합산·재질 음향·월드 전용 흔들림을 적용한다. 체감 속도부터 먼저 개선한다.
3. **보스 처치 파이프라인**: 실제 정산과 연출 분리, 모달/남은 적/페이즈·스킵·불러오기 경계 처리. 모르도1종에서 완성한 뒤 각 보스로 확장한다.
4. **자산 가족 확장**: 통일한 픽셀 크기/광원/명암/프레임 앵커로 나머지 캐릭터·오브젝트·스킬을 묶음 제작한다. 기존 승인 주인공을 임의로 재디자인하지 않는다.
5. **새 명시 배포 시 검증**: 재질/다단히트 합치기/보상1회/모달/일시정지/로드·방 이동/실패 fallback·모바일·성능·효과 줄이기, 필요한 회귀를 묶어 실행한다. 지금은 테스트·푸시·배포하지 않는다.

최초에는 디자인 사전 시안 규칙에 따라 분석·모션 시안만 작성했다. 이후 사용자 `ㄱㄱ`를 제시된 연출 방향의 진행 승인으로 반영하여 기존 외형의 공통 피드백부터 연결했다. 새 원화는 `art-board-v1.png`의 대표 패키지 확인 후 제품용 프레임으로 제작한다. 추가 플레이 후기와 기존 가로 화면 TODO는 유지한다.

## 1차 로컬 구현 및 대표 보드

- `combat-impact.js`: 실제 fresh damage만 받아 대상별 국소 밝기40/60ms, 방향 파편 fallback,16개 상한·치명 우선, 대상별180ms 중복 억제. 기존 화살·속성·액티브·치명 파편과 겹치면 fallback만 생략한다. DoT의 동일 snapshot 재타격은 반응을 다시 시작하지 않는다.
- `room-stage.js`: 전용 월드 offset을 추가해 기존 수호자 등장·모르도 붕괴·치명·보스 마무리 흔들림을 합성한다. HUD/입력/캡처의 논리 좌표는 그대로 두고 최종 월드 변환만 최대8px로 제한한다. 전역 시뮬레이션 hit-stop은 추가하지 않았다.
- `boss-clear.js`:1.8초의 국소 충격/파편/기존 몸체 사망/보상 강조를 연결한다. 새 실제 보스 XP가 남아 있을 때만 빛기둥을 그리며 XP 지급·위치·흡수는 기존 로직을 따른다. 그림자·중간 분열은 축하를 만들지 않으며 적/적탄이 남으면 큰 문구를 숨긴다.
- `art-board-v1.png`: 기존 주인공/모르도 참고로 built-in imagegen1회 생성한6패널 대표 방향 보드. 아트·타격·오브젝트·보스 자세·파열·보상을 함께 본다. 독립 PNG, 제품 아틀라스·프레임·새 전리품 목록이 아니다. 보드의 사선 원근·표시 비율은 실제 탑다운 방/충돌·96px 등 제품 크기에 맞춰 별도 제작해야 한다.
- 정적 검토/diff 확인만 수행했다. 회귀7개는 작성만 했으며 구문 검사·게임 테스트·브라우저/성능/실기기 검증을 실행하지 않았다. 새 명시 배포 때 누적 검증한다.
- 후속 미완료: 즉시 성장/유물 모달이 보스 연출을 덮는 기존 흐름, 숫자 합산·음향·구르기 잔상, 새 캐릭터/오브젝트 자산 가족과 프레임 정규화. 전체 개편 완료가 아니다.

## 마감 기준

- 작은 화면에서 주인공/보스/문·적 위험이 먼저 읽힌다. FX가 켜진 상태에서도 다음 회피 방향을 알 수 있다.
- 일반 명중→치명타→보스 최종 처치의 강도 차이가 분명하다. 다단히트 중에도 화면이 계속 흔들리거나 백색으로 덮이지 않는다.
- 효과 줄이기는 플래시/흔들림을 낮추면서 파편 방향·문구·보상 단계를 남긴다.
- 대표 캐릭터의 포즈·프레임 앵커·원래 표시 크기를 확인한다. 타격 연출 때문에 실제 판정/저장/RNG/랭킹 시간이 달라지지 않는다.
- 참고작에서 추출한 이미지·소리·UI·고유 캐릭터·보스 디자인은 배포 자산으로 사용하지 않는다. 우리 신규 자산은 출처/도구/수정/승인 기록을 남긴다.
