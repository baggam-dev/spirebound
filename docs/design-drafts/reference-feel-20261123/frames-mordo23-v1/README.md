## 실제 우선 표시 경로

`upper-visuals.drawUpper`는 먼저 `drawResurrectedKing`을 시도한다. `resurrectionVersion===1`, HP30% 이하, kingStage3(또는 생략)인 부활왕이 대상이다. 실제 참조는 `assets/images/king-resurrection-poses-v1.png`의 인간 얼굴·장발·뿔/왕관·검정금색 갑옷이다. 옛 `mordo-phase3-reference-atlas.png`의 큰 뿔 해골형을 현행 부활형으로 대체하지 않는다. 구버전/그림자/비부활 분기는 후속 연결에서도 보존해야 한다.

2형은 이후 `drawFeedbackSprite`의 king2가 우선이며 몸체높이92.4/발21이다. 그 아래 `mordo-phase2-sprite.js`의84/발29는 fallback이다. 3형 부활 원화는 bossAtlas가 자세별 최대폭/높이(145×104,145×123,165×106,130×128,145×104,145×104)를 읽고 발29로 그린다. 새 시안은 대기 전체실루엣104px 기준 공통배율이고 기존 모든 자세의 크기와 같다고 주장하지 않는다.

## 후속 연결 조건

기존 3형 부활 경로보다 뒤에 새 그림을 붙이면 실제로 표시되지 않는다. 선택적 아틀라스와 실제 공격 상태 매핑을 해당 우선 경로 안에서 처리하고, 실패 시 기존 원화로 돌아가야 한다. 신규필수Ready·게임판정/예고/AI/피해·공격시간·저장/RNG변경없이실제공격의준비/발사/회복을읽는다. 주문시전은별도자세, 효과줄이기는적은자세/기존FX대체·그림자/구버전은기존분기를보존한다.

현재2~3형피격반응은mordo-presentation-state에서의도적으로활성화하지않고있다. 새피격그림만만들었다고자동으로전형태에피격경직을추가하면안된다. 패배자세는중간페이즈/부활중간을최종처치로오인하지않아야한다. 기존보스처치보상·그림자전투·시체이펙트우선순위를먼저확인한다.
