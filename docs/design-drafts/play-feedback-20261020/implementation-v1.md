2. **파손**: 내부 폭28 포함 최소26px 돌벽에 2px 계단/8~20px 크기별 모서리 결손을 공유한다. 70% 이상 면적/중심 솔리드 유지·외곽/폭20 연결부/가구/보스 위험체 보존. 렌더 clip·몸·segment·대악마 ray가 같은 조각을 쓴다. 결손 바닥 위 작은 장식 파편은 충돌하지 않는다. 픽셀 mask 밖 14px은 이 파편이며 고체 영역 누락은0이다. 저장 배치/방 RNG는 변경하지 않는다.
