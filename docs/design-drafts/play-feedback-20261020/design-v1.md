# 플레이 후기 통합 시안 v1 — 2026-10-20 KST

`environment-mobile-v1.png`는 내장 imagegen으로 기존 승인 환경v2를 참고한 디자인 제안이다. 실제 런타임/실기기 스크린샷이 아니며 아직 구현 승인 전이다. 원본 exec-073d0c1b-5313-434e-afdb-5d0afdf364cb.png를 유지하고 프로젝트에 그대로 복사했다. 정확 프롬프트는 prompt-v1.md.

방향: 더 작은 의도적인 픽셀 클러스터·조용한 저대비 바닥/벽, 눈에 보이는 비대칭 블록 파손·내부 석재·소량 잔해. 모바일 높이 우선/양쪽 검정 레일, 좌측 유물, 우측 아이콘 버튼 아래 미니맵, 작은 능력치·큰 물약 수량. XP 밝은 조각/작은 요정 유영·일섬 발도 돌진·서리 상태 표식을 함께 보여준다.

구현 때 시안에 생성된 캐릭터/몬스터·하트 개수·임의 방 구조를 복사하지 않는다. 기존 주인공/적 외형·층별 색 계열/게임 좌표/저장 데이터 유지. 독 장판은 현 게임의 적 보라/플레이어 초록 의미를 지키고, 둔화 표시는 적에게 적용한다(하단 샘플의 주인공은 표식 위치를 설명한 개념). 액티브 네 개를 유지하고 시안의 두 개만으로 줄이지 않는다. 왼쪽 능력치는 현재 요구대로 오른쪽의 지도 아래 배치하며, 왼쪽은 체력/유물/정수/빌드이다. 배경 대비는 시안의 큰 검은 줄눈을 그대로 증폭하지 않고 실제 정상 배율에서 줄인다.

승인 전 기능 변경만 진행: 서리 계수1/둔화+5%p, XP흡인55+자석70 및 정수30과 안내 분리, 일섬/지뢰/질풍의 기존 승인 아이콘·이름을 PC/터치 버튼에 연결. 새 일섬 모션·둔화 표식·요정/XP 외형·환경/HUD 디자인은 승인 후 구현한다. 배포 자체는 이번 사용자 지시로 승인됨.
