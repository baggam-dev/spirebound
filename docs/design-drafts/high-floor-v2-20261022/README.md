## 구현 시 지킬 차이
1. 이 그림은 소재와 레이어의 방향이지 실제 플레이 캡처나 고정 맵 배치가 아니다. 기존 랜덤 방·문·시설·길막 충돌을 유지한다. 가장자리의 큰 구조물을 전부 실제 바닥에 놓지 않는다.
2. 바닥·벽 베벨이 실제 공격보다 밝아지지 않게 한다. 단순 전체 어둡게 필터 대신 층별 저대비 재질과 읽히는 소품 실루엣을 목표로 한다. 2px 공통 표면/미세 픽셀 군집, 거대한 모자이크 금지.
3. 캐릭터 PNG에 오라를 합치지 않는다. 오른쪽 보라 연무·호박색 표식은 별도 움직이는 레이어로 구현하며 기존 위상 색(정예금색/시련보라/수호청백/열쇠금백)을 유지한다. 혼잡·완화 설정에는 입자/연무를 줄이고 공격 경계를 남긴다.
4. 오른쪽 확대 궤적은 재질 샘플이다. 시안의 길이·회전각을 타격 범위로 복사하지 않는다. 최종 범위는 실제 판정과 일치하도록 각 무기별로 그린다. 특히 근위병 할버드는 아래 메커니즘안의 좁은 찌르기이며, 그림의 다른 캐릭터 참격을 공통 재사용하지 않는다.
5. 아래 큰 보라 바닥장은 기존 지면기술의 경계 표현 샘플이다. 모든 적에게 큰 장판을 추가하거나 기존 중력 범위를 넓히는 안이 아니다. 장식 마법진과 공격 장판의 선/투명도를 구분한다.
