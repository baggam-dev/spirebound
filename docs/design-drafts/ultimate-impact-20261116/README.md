# 궁극기·명중 그래픽 통합 시안 v1

2026-11-16 사용자 ‘배포 하지 않고 다음 수정’으로 그래픽 후속 패키지를 작성했다. 내장 image_gen으로 생성한 **정적 디자인 시안**이며 실제 게임 캡처·런타임 자산·완성 애니메이션이 아니다. 이전 승인 석궁과 타격 언어를 유지하는 강화안으로, 구현 전 한 번에 디자인 확인을 받는다.

- `package-v1.png`: 화살비·자동 석궁·일반/강한/궁극기 명중을 함께 보는 보드. 생성 원본을 변환 없이 복사했다.
- `prompt-v1.txt`: 사용한 전체 프롬프트. 내장 도구 사용, CLI/API fallback 미사용.
- 참고: `docs/qa-sound-20261109/ultimate-final/game-rain-1280-false.png`, 같은 폴더 `game-turret-1280-false.png`, `assets/images/crossbow-poses-v2.png`. 생성 전 모두 직접 확인했다. 앞 두 장은 이전 검증 캡처이며 현재 누적 변경의 검증 증거가 아니다.

## 제안 방향

1. 화살비: 모든 화살을 똑같이 밝히기보다 일부 주력 착탄을 선명하게, 보조 화살은 얇게 표현한다. 접점의 짧은 흰 핵·암부 대비·낮은 먼지와 돌 파편으로 무게를 준다. 바닥 전체 원형 마법진이나 화면 전체 섬광은 넣지 않는다.
2. 석궁: 승인된 목재·황동 기계와 고정 받침을 재사용한다. 발사축에 맞춘 짧은 발사광·줄 반응·상부 반동으로 기계의 타격감을 보강하는 방향이다. 캐릭터/석궁 재디자인이 아니다.
3. 명중: 일반→강타→궁극기를 접점 핵과 방향성 파편의 밀도·크기로 구분한다. 큰 섬광을 오래 남기는 대신 순간 대비를 높인다. 기존 피해 판정과 타격 방향을 따른다.

## 구현 시 반드시 유지할 기준

- 화살비 첫 즉시 피해와0.3초 간격6회/1.8초 종료, 석궁14초 수명/기존 사격 간격, 실제 반복 지연0.16초를 바꾸지 않는다. 시안의 장면 배치는 동시 피해 수나 새 사거리의 제안이 아니다.
- 오라/광원/먼지는 별도 효과이며 캐릭터·석궁 PNG에 굽지 않는다. 기존 승인 석궁4자세 atlas를 우선 재사용한다.
- 명중 방향은 실제 투사체 속도/베기 방향 기준이다. 보드 하단의 아래로 박힌 화살 도식이 모든 일반 공격을 수직 낙하로 바꾸자는 뜻은 아니다.
- 기본/효과완화 두 가지를 함께 준비하고 적 공격 전조·플레이어 몸·생존 동선을 가리지 않는다. 모바일 성능이나 시인성은 구현 후 검증해야 한다.
- 새 전체 화면 흔들림·전투 정지·경직·피해량 증가는 이번 제안에 없다.

## 직접 검토 결과와 한계

생성 보드에서 기존 어두운 돌바닥과 작은 캐릭터의 결, 황동 석궁, 세 단계 접점 대비와 요청한 한글 표제를 확인했다. 다만 오른쪽 작은 설치/발사/회수 스트립은 실제 접기 동작이 충분히 구분되지 않으며 완성 연속 프레임으로 사용할 수 없다. 석궁 실제 크기/대각 조준·받침 앵커는 기존 atlas와 렌더 좌표로 유지해야 한다. 생성 이미지는 주인공 픽셀을 원본과 비트 단위로 보존한 합성이 아니며 장면 일부를 재해석했다. 테두리·배너는 보드 장식이지 게임 HUD 변경안이 아니다.

본 이미지는 제작할 효과의 아트 방향만 확인하는 자료다. 투명 FX atlas/애니메이션/Canvas 구현/실제 타격 시간·모바일/효과완화·성능 확인은 아직 하지 않았다. 테스트·서버·브라우저QA·푸시·배포도 하지 않았다. AGENTS.md의 ‘시안을 먼저 보여주고 사용자 컨펌을 받은 안만 구현’ 규칙에 따라 런타임과 배포 자산은 미수정이다. 승인 후 이 패키지의 효과·모션을 함께 구현하고 로컬 커밋하며, 테스트/배포는 별도 일괄 지시를 따른다.
