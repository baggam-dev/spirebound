# 야간 픽셀 메인 수정 패키지

사용자가 첨부한 청회색 밤의 탑 이미지를 기준으로, 주인공 명암·색감과 분리된 화로·나무·낙엽을 묶은 검토용 시안이다. 작업 중 요청한 **작은 불티**도 포함했다. 게임 `src/`·제품 `assets/`는 변경하지 않았다.

`index.html`에서 움직임/정지를 전환할 수 있다. `motion-preview.gif`는640×360/6초/10fps, `main-menu-still.png`는1280×720정지화면이다. HTML에서는GIF도최근접1280×720로확대한다. 실제게임의저장정보는사용하지않았으며메뉴는배치검토용이다.

## 외형·움직임

- **배경:** 첨부구도·차가운저명도 유지, 나무를분리한새배경판. 논리640×360/96색/최근접축소·2배표시로픽셀덩어리를강조한다. 원본1671×941에서약0.1%이하의비율차를포함한전체프레임축소다.
- **주인공:** 기존금발궁수의정체성/복장·후면자세는유지하면서재색칠. 머리는회갈색/피부와갑옷명암은차가운그림자/망토짙은남색·스카프어두운와인색, 오른쪽활가장자리에만적은따뜻한빛.3자세공통배율88/621·native96×112/발48,104.31색+투명.
- **화로:**4개불꽃자세/native48×48/밑점24,44·15색+투명. 생성된부드러운오라는A>192로분리제거하고작은반사픽셀만별도합성.0.12초프레임제안,전체화면밝기변화없음.
- **불티:**화로마다최대3개의작은점이위로떠오르며사라짐. 주황·금빛1px점,큰백색불꽃/폭발·상시화면입자없음.고정계산식으로합성하며게임RNG사용없음.
- **나무:**2자세/native384×360·23색+투명,공통바닥기준과작은0.22도회전후보기준. 현재시안은나무전체의미세한기울기와두키포즈선택이다. 최종제품에서가지끝부분만분리변형할경로는아직구현하지않았다.
- **낙엽:**6초중처음2.1초에최대3장이지나간뒤정적구간.2~3px의갈색조각으로불티와다른모양/큰횡이동을사용한다. 메뉴텍스트/버튼은고정이다.

## 출처와 정적 확인

builtin imagegen3회. `user-tone-reference.jpg`는사용자첨부원본복사, `background/hero/effects-source.png`는각생성원본이다. 기존`assets/images/title-hero-idle-v1.png`는궁수정체성,사용자배경은색감/픽셀클러스터·구도참조다. 타게임홍보영상의원화/소리사용없음. 전체프롬프트/원본위치·SHA/셀·수동몸기준/공통배율·합성시간은prompts/manifest/build-preview.py에보존한다.

선택궁수/효과원본alpha최소0, A>192핵심픽셀셀경계접촉없음. hero3/fire4/tree2의9개분리PNG는실제투명도/48색상한정적검사통과(sprite-report.json),배경은투명아틀라스검사대상이아니다. 접촉시트와합성정지이미지를육안확인했다. GIF는공통팔레트로만들었고프레임별독립양자화깜빡임을피한다.

## 남은 제약·연결 전 조건

이것은독립디자인합성이며게임테스트가아니다. 실제브라우저미리보기실행/게임구문·단위/실기기·성능/푸시/배포는없다. 현재운영0.64는그대로다. 나무가지분리,2키포즈간체적/루트·낙엽궤적,작은모바일의주인공/문/메뉴명암,반사위치·불티과밀은후속검토대상이다. 96색배경과GIF전체는캐릭터48색조건과다르며달의세부명암등일부미세표현이단순화됐다.

승인후에도실제메뉴HTML/CSS·기존저장/이어하기·새원정입장/스킵·reduced모드는보존하고원화실패fallback/허용목록(server/deploy)을함께확인해야한다. 시안GIF를그대로제품배경으로사용하지않는다. 사용자승인전까지검토자료로만유지한다.
