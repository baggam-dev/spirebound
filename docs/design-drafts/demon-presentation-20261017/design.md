# 벽 너머 대악마 본체 연출 패키지 — 검토안

2026-10-17 사용자 ‘다음 진행’. 모르도/벨카르 다음 캐릭터 단위로 본체의 빠진 연출만 제안한다. 기존 공격 모션 재생성·전투 변경·runtime 반영 없음. 시안 전체를 한 번에 검토한다.

## 실제 구현과 연결 경계
- combat/demon.js: 도전 시작은 손/발의 1단계다. 2단계는 눈/코/입, 이 부위가 모두 처치되면 advanceDemonPhase가 3단계 본체를 생성한다. 본체 등장을 도전 버튼에 바로 연결하면 안 된다.
- 단계전환은 기존 recovery 1.0초·attackClock 1.4초. pressureVersion1은 3단계 specialClock=0이므로 특수공격이 바로 시작될 수 있다. 등장 자세를 위해 이를 지연하거나 공격 예고를 가리지 않는다.
- rendering/demon-core-sprite.js는 body/arm/wall/foot 4아틀라스를 합성한다. 본체는180x180, 벽300x150, 팔어깨anchor는 x±64/y−61. 기존 좌우팔·눈·입·스톰프의 준비/타격/회수와 ground 예고·special 효과를 보존한다.
- combat/demon-core-motion.js의 attack/coreFlash/sweepFlash가 공격 자세의 기준이다. 새 피격/등장보다 우선한다. 방 특수공격도 우선 처리해야 한다.
- 본체 체력8500, 실제판정·피해·AI·부위전환·소환·장판·보상·열쇠/탈출 개방을 바꾸지 않는다.

## 6자세 순서
|순서|자세|목적|
|---|---|---|
|1|등장|고개를 낮추고 벽턱을 붙잡으며 상체가 드러남|
|2|각성|고개를 들고 가슴눈이 열림. 입/눈 공격 준비와 구분|
|3|약한 피격|얼굴/어깨만 짧게 반응, 두 손 지지 유지|
|4|강한 피격|고개와 한쪽 어깨가 더 크게 물러남. 실제 경직 없음|
|5|처치 시작|고개와 팔이 처지고 가슴눈이 닫힘|
|6|안식|고개가 더 낮아지고 얼굴/가슴눈 꺼짐. 소멸 효과는 별도|

정면·약간 내려다보는 시점, 벽 위 상반신만, 작은 콧구멍·보라피부/거친외피·긴팔·각 손5손가락 유지 의도. PNG 육안으로 자세/양손 윤곽 확인. 시안은 셀에 맞춰 손이 앞에 모인 구도이므로 기존 공격 팔 길이/손비율을 교체하는 자료로 쓰지 않는다. 벽과 몸이 같이 있는 현재 PNG는 구성 검토용이며 그대로 runtime 한장으로 덮지 않는다. 승인 후 필요한 몸/팔 파생 자세만 레이어별 원화로 분리 준비하고 기존 벽은 재사용한다. 오라·먼지·파편·소멸은 PNG에 넣지 않는다.

## 연결 제안 (아직 미구현)
- 본체 실제 생성 이벤트에서만 .8초 이내 등장→각성. 게임update시간/WeakMap에만 보관. 새 도전 1단계나 로드 재개/도감에서는 자동 재생 안 함. 공격·특수패턴이 시작되면 즉시중단.
- 약/강 피격 .10/.16초, 최소간격 .24초·최대체력1.5% 강반응 제안. 시각만, 공격시 무시. 실제경직·시전취소·무적·공격후딜 추가 없음.
- 본체 사망 좌표/방향의1초 이하 잔상. 기존 적제거·열쇠·보상·탈출 가능 상태는 즉시 유지. 최종처치와 방전환 흐름은 승인 후 simulation 확인하며 모달뒤가림도 기록.
- 일시정지시 시간고정, 방/층/로드/새원정에서 시각상태정리. 효과줄이기는 몸흔들림/먼지생략, 도감정적/PNG실패 fallback 유지.
- 이번 패키지는 3단계 본체만. 1/2단계의 다섯 부위 처치·전환 전체 패키지나 새 컷씬/대사까지 확대하지 않는다.
