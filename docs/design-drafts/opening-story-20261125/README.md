# 입장 전 오프닝 서사4컷·스크롤 시안

2026-11-25 단계별 작업4단계의 **검토용 패키지**다. 실제 새 원정 흐름·저장/랭킹·입장 컷신은 아직 변경하지 않았다. 이전1~3단계의 미배포 코드도 그대로 보존했다.

## 이야기와 영상 구성

주인공은 기존 `src/ui/story-copy.js`의 **실종 원정대의 흔적을 추적하는 정찰병**이다. 새 가족/혈통/복수 설정을 추가하지 않고, 탑에 들어가는 이유를 먼저 알려준다. 새 문구와 네 장면은 아직 승인 전 제안이다. 최종 왕/봉인 반전은 공개하지 않는다.

1. 밤에 잠긴 왕국: 마을 지붕과 멀리 솟은 탑.
2. 끊긴 원정대의 흔적: 주인이 사라진 야영지·짐·발자국·등불.
3. 정찰병의 임무: 주인공이 지도를 확인한다.
4. 탑 도착: 기존 야간 탑/수호상 앞에 선 주인공.

전체 글은 `narration.txt`, 문단·줄바꿈·타이밍·스크롤 설정은 `story.json`에 있다. 글은 이미지에 굽지 않고 별도 레이어로 연속해서 위로 이동시켰다. 원근 기울임 없이 평면 스크롤을 쓰며, 이미지가 바뀌어도 글이 튀거나 처음부터 재시작하지 않는다. 배경은 문단 중심의 흐름에 맞춰 약0.8초 겹쳐 전환한다.

`motion-preview.gif`는 **서사28초 + 입장 연결 예시2초 =30초**다. 마지막은 앞서 만든 야간 입장 시안의0.2~2.2초 부분과0.7초 겹친다. 실제 입장 전체를 새로 구현한 영상이 아니며, 원래 입장 시안도 그대로 보존했다. ‘나레이션’은 글 연출만 만들었고 음성/TTS·새 음악은 추가하지 않았다.

## 시각·정적 확인

- 메인/입장과 같은 어두운 청회색·국소 호박빛, 큰 픽셀 덩어리. 새 원화1회 내장 image_gen 사용, CLI 미사용.
- `background-source.png` 원본, 전체 프롬프트·참조 역할·원본 경로는 `prompt.md`, SHA/셀 분할은 `manifest.json`에 보존했다.
- native 배경4장:640×360, 공통96색. 원본의2×2 패널을 분리해 최근접 축소했다. 전체 원본은 보존했다.
- 글자14 논리 픽셀·줄간격24, 읽는 영역 위/아래에서만 살짝 사라진다. 글자 대비를 위해 배경을 일부 어둡게 처리했지만 주인공·탑·등불은 보이게 남겼다.
- `background-report.json`의 크기/색 수4장 통과, 원화/전체 문구 보드·시간대별 합성 보드를 직접 확인했다. GIF 구조는640×360/10fps 시간격자300장→중복합산295프레임/30000ms로 정적으로 확인했다. 브라우저를 실행한 검증이 아니다.
- `storyboard.png`:1280×720, 네 그림과 각 문단을 한 번에 읽는 비교판. `main-still.png`:정찰병 소개가 흐르는 한 장면. `motion-contact.png`:실제 연속 스크롤의 시간대별 캡처.

## 실제 연결 시 지킬 경계

시안 승인 후 새 원정 시작→서사→야간 입장→전투로 연결한다. 도중 스킵·전체 글 다시 보기, 모션 감소 시 고정 문단 전환, 탭 비활성/화면 회전 중 읽기 시간 정지, 느린 자산 로딩/실패 시 글만 재생 또는 입장으로 넘기기를 포함한다. 첫 새 원정 기본 재생·이후 다시 보기 선택을 추천하며 이어하기/보스 연습에서 강제 재생하지 않는다. 건너뛰어도 저장/원정 시작·랭킹 등록이 중복되지 않게 하고, 서사·입장 중 전투/기록 시계가 먼저 흐르지 않게 해야 한다.

현재 HTML은 GIF 재생과 전체 문구 정지 보기만 제공하는 검토 페이지다. 실제 게임의 스킵/일시정지/접근성·모바일 버튼을 연결한 것은 아니다. 글의 최종 읽기 속도·실기기 가독성/성능은 미검증이며, 구문/단위 테스트·서버·브라우저 QA·푸시·배포는 하지 않았다. 운영0.65는 그대로다.
