## 구현 시 지킬 점 — 아직 구현 승인 전

- AI가 그린 px 라벨은 정확한 픽셀 측정 결과가 아니다. 실제3/6/10px 기준은 코드/원본 자산에 명시하고 모바일 대비를 확인해야 한다. 확대 견본을 그대로 거대한 드롭으로 쓰지 않는다.
