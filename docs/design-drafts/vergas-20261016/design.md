# 망령검: 베르가스 v1 — 외형·성장 검토 패키지

2026-10-16 최신: 사용자 「아주좋아 진행」으로 v1 외형·성장 승인. 아래 원안과 정확 프롬프트는 보존하고, 승인 범위의 로컬 구현을 연결했다. 실행 검증·배포는 하지 않았다.

## 승인안 로컬 구현 / 미검증

- `src/combat/spectral-blade.js` / `src/rendering/spectral-blade.js`. 저장 스킬 키 `aura`와 기존 레벨은 유지하고 표시명·동작을 교체했다. 기존 원형 지속 피해·원형 오라 렌더 제거.
- 내장 imagegen으로 승인 보드의 검을 수직 단일 투명 PNG로 변환. `vergas-isolated-v1.png` 원본과 정확 프롬프트 보존, 동일 파일을 `assets/images/vergas-blade-v1.png`로 복사. 1024×1536, 알파 배경 표본 0. runtime은 투명 여백만 drawImage crop하고 길이32px로 그린다. 검의 오라·연출을 PNG에 추가하지 않았다.
- 1/2/3레벨 기본 피해34/43/52, 재사용1.70/1.35/1.20초, 중심 기준 사거리96, 준비0.16/0.10/0.10초, 부채꼴 반각0.76. 수치는 첫 구현값이며 실제 밸런스 검증 전이다.
- 3레벨 단죄: 피해×1.65, 재사용×1.25, 사거리116, 반각1.05. 검무: 피해×0.65로2타, 0.18초 간격, 재사용×0.85. 두 번째 타격은 원래 대상 생존·공중 여부·사거리·벽을 재확인하고 방향을 다시 잡는다. 첫 타격은 준비 때 잡은 방향을 유지한다.
- 적이 없으면 발동하지 않는다. 감지/타격 시 벽과 공중 상태를 확인하며 경직 중 출격/진행을 취소한다. 방 이동 시 진행 동작 삭제. WeakMap의 진행 동작은 저장하지 않고 `bladeCooldown`만 저장하여 재개 즉시 중복 발동을 막는다. 일시정지는 simulation이 진행되지 않으므로 동작도 정지하고, 효과 줄이기는 대기 부유/참격 궤적 장식을 생략한다. 이미지 지연/실패 시 간단한 검 fallback.
- 메인 보조: 화염/독은1초·초당4 비중첩 별도 DOT(`bladeDot`), 서리는0.6초 이동 둔화(일반20%/보스6%), 번개는 타격당 최대1대상·거리64·25% 추가 방전, 정밀은 범위 내 기존 표식 대상 우선·표식 대상 피해20% 추가. 별도 DOT는 기존 독가스/처치폭발·화염장판을 만들지 않으며 주탄 표식·빙결 중첩·천둥 카운터를 진행하지 않는다. 기존 속성이 만든 상태·사망 처리는 그대로다.
- 검무의 각 타격은 별도 참격이며 그 각각에서 제한된 속성 효과가 적용될 수 있다. 유물 검무의 반지는 피해30%, 궤도의 팔찌는 사거리20%, 순백의 고리는 재사용15% 단축으로 연결한다. 저장 유물 ID/통계 키는 호환을 위해 유지한다.
- 새 도전에는 오라 자동 방어막을 부여하지 않는다. `spectralBladeVersion` 없는 구저장의 오라3레벨은1회 이관 때 `legacyAuraGuard`를 부여하고 기존 `auraShield` 충전 상태/효과를 계승 수호로 보존한다. 순백의 고리의 기존15초 단축도 해당 구저장에서 유지한다. 수호를 별도 새 스킬로 만드는 작업은 이번 범위에 넣지 않았다.
- 스킬 설명/미리보기/HUD/도움말/유물 설명/분기 선택/저장 검증/배포 파일 허용 목록/공개 파일 QA 목록 갱신. 테스트 코드 신규6개 및 기존 오라 관련 기대값 수정만 했고 **실행하지 않았다**.
- 정적 소스·diff 검토만 완료. 실제 궤적과 부채꼴 가독성, 좌우/상하/벽 근처 crop, 원화 알파 전체·32px 가독성, 2타 도주/사망/저장 재개, 구저장 계승 수호, 속성 연계·보스 보호·성능·모바일 가로는 새 명시 배포 때 검증한다. 운영 release-20261016-201844-2ecc33 유지.
- 다음은 레벨업 UI PNG 시안과 메인별 성장표. UI·다른 메인 개편은 이번 검 외형 승인에 묶어 구현하지 않았다.

## 외형

- `vergas-v1.png`: 내장 imagegen 신규 생성 원본 복사. 정확 프롬프트 `prompt-v1.md`.
- 잿빛 양날검, 검은 중앙 홈, 낡은 청동 가드, 검은 손잡이, 작은 보라색 보석. 날 끝이 조금 넓어지는 실루엣으로 일반 직검과 구분한다.
- 오라·잔상·참격 궤적은 PNG에 넣지 않고 별도 효과로 구현한다. 오른쪽 작은 검은 축소 외형 예시이며 실제 24~32 게임 px 가독성을 검증한 결과가 아니다.
- 이번 출력은 불투명 배경의 검토 보드다. 승인 후 동일 디자인의 투명 단일 검 자산을 준비해야 하며 보드 자체를 runtime에 쓰지 않는다. 실제 축소 시 미세 장식은 단순화가 필요할 수 있다.

## 동작 제안

평소: 플레이어 옆 약간 뒤에서 기울어진 검이 작게 상하 부유한다. 캐릭터/탄환/위험 표시를 가리지 않는 배치로 한다. 준비: 가장 가까운 유효 위협 쪽으로 검 끝을 돌린다. 공격: 짧게 전진하며 전방을 한 차례 베고 복귀한다. 재사용 대기 중에는 곁에 머문다. 이것은 지속 접촉 피해나 상시 회전 공격이 아니다.

위협 감지 거리·검 이동 거리·타격 부채꼴은 별도로 정한다. 벽 너머 적을 감지해 출격하거나 베지 않도록 시작/타격 시 벽을 확인한다. 출격한 검의 그림과 판정 범위가 어긋나지 않게 검 궤적 기준으로 설계하며, 기존 검토문의 몸 중심 부채꼴은 구현 확정 사항이 아니다. 적이 없을 때 낭비 발동하지 않는다. 동결/일시정지/효과 줄이기/저장 재개 정책도 구현 시 명시한다.

## 성장 제안 — 수치는 미정

| 단계 | 행동 변화 |
|---|---|
| 1 소환 | 한 자루 부유, 접근 위협에 자동 단발 참격 후 복귀 |
| 2 검의 의지 | 재사용 대기 감소와 준비 회전 단축으로 대응 공백 축소 |
| 3 해방 | 아래 두 분기 중 하나 선택, 검은 여전히 한 자루 |
| 단죄의 칼날 | 발동은 느리지만 더 강하고 넓은 한 번의 베기. 밀집한 근접 적 처리 |
| 집요한 검무 | 더 가벼운 두 번의 빠른 베기. 두 번째 베기 전 대상 생존·거리·벽 재확인, 추가 타격 계수 별도 |

분기는 적을 계속 경직시키거나 검 수를 늘려 화면을 가리는 방식으로 강화하지 않는다. 기존 오라 3레벨 방어막은 별도 수호 선택으로 분리하는 제안이며 구저장 이관은 미설계다.

정확한 피해/쿨다운/범위/상태 이상 계수는 메인별 성장표와 함께 조정한다. 이 문서는 자동으로 밸런스·외형 승인이 되지 않는다.

## 2026-10-16 유니크 보조 등급 승인 반영
