# 모르도 연출 패키지 v1 — 검토안

2026-10-17. 외형 리뉴얼과 걷기·스킬 개선 이후의 다음 단위. 이번은 등장/전환/처치 연출 시안과 설계까지이며 runtime 미반영. 별도 승인 전 테스트·푸시·배포 없음.

## 실제 코드 기준
- `src/combat/upper-floors.js`: `kingPhase` 체력비 65% 초과 1단계, 30% 초과 2단계, 그 이하 3단계. 경계에 정확히 도달하면 다음 단계.
- `tickUpperState`: 단계 상승 시 `kingTransition=1.4`, 진행 중 공격/섬광/소환문 취소, 적탄 제거, 동결 해제. 전환 타이머 동안 행동 정지. 새 연출을 위해 이 시간을 늘리지 않는다.
- `src/game/simulation.js`: 죽은 적은 같은 틱에 제거되고 `enemyDeathEffect` 생성. 마지막 보스 처치 시 기존 보상/계단/열쇠 이벤트로 이어짐.
- `src/rendering/enemy-feedback.js`: 현재 일반 처치 효과는 0.55초(분열 제외). 모르도는 spectral 분류. 새 긴 처치 연출은 기존 완료 이벤트를 지연시키지 않는 잔상으로 설계.
- 기존 단계별 PNG는 그대로 보존. 시안의 오라는 연출 합성 예시이며 캐릭터 PNG에 굽지 않는다.

## 한 번에 검토할 구성
| 구간 | 연출 제안 | 시간과 제약 |
|---|---|---|
| 등장 | 고개를 숙이고 할버드를 짚은 왕 → 해골 얼굴을 들며 왕관 보석의 짧은 반사 → 이름표 | 0.9초 시각 제안. 새 행동 봉쇄/무적 없음. 공격 시작 시 자세 장식 즉시 종료. 1단계 오라 없음 |
| 1→2 | 흉갑 틈의 보라 빛, 작은 갑옷 파편 3~5개, 등 뒤에서 가느다란 검보라 오라가 위로 흐름 | 기존 1.4초 안: 0~.35 수축, .35~.9 침식 공개, .9~1.4 안정. 실제 2단계 외형은 즉시 반영하며 구 외형으로 덮지 않음 |
| 2→3 | 더 큰 뿔/악마화된 외형 주변에 열린 형태의 오라가 솟고 한 차례 파동으로 가라앉음 | 기존 1.4초 안. 2단계보다 높이 약1.4배, 폭1.25배 제안. 불투명 원판/넓은 바닥 고리 금지 |
| 처치 | 몸의 긴장 풀림·고개 숙임 → 오라가 몸에서 위로 빠져나감 → 왕관/갑옷 잔상이 옅은 재로 사라짐 | 최대1.1초 시각 잔상. 사망 순간 단계를 복사하며 1단계 처치라면 오라 생성 금지. 보상/출구/열쇠 판정은 즉시 기존대로 |

정지 원화를 크게 구부리는 신규 관절 애니메이션은 제안하지 않는다. 기존 자세를 작게 이동/기울이거나 새 자세가 필요할 경우 별도 원화 패키지로 제작. 06 REST는 분위기 예시이며 왕관 영구 오브젝트나 드롭 추가를 뜻하지 않는다.

## 대사 초안 — 미확정
- 등장: “왕의 안식을… 어지럽히지 마라.”
- 2단계: “내 몸에서… 나가라.”
- 3단계: “이 왕좌도, 네 영혼도… 우리의 것이다.”
- 처치: “이제야… 잠들 수 있겠구나.”
음성/모달 컷씬 없이 화면 위 작은 자막으로 제안. 새 대사 설정이 기존 세계관 문서와 맞는지 승인 때 함께 검토. 반복 연습은 이름표만 짧게 표시하는 안.

## 구현 경계
- 시각 모듈이 전투 RNG·AI·좌표·충돌·공격 시간·보상·저장을 수정하지 않음.
- 진행 시간은 게임 시간 기준. 일시정지/메뉴에서 진행하지 않고 그리기만으로 상태 변경 금지.
- 전환 진행값은 기존 타이머로 계산, 재개 시 현재 진행값부터 그리기. 렌더 WeakMap이 초기화돼도 등장/대사를 새로 재생하지 않도록 명시적인 이벤트 경계 설계 필요.
- 신규 등장 감지는 방 진입/도전 시작에서 한 번 기록하는 방법을 먼저 검토. 저장 불변만으로 일회성 재생을 보장할 수 없으므로, 구현 전 기존 관찰/이벤트 상태 재사용 여부 확인. 단순 첫 draw를 시작 이벤트로 쓰지 않음.
- 처치 잔상은 좌표/단계/방 ID/시작 게임 시간만 복사, 살아 있는 actor 참조 보존 금지. 방 이동/결과 모달/시련 종료 시 정리. 기존 죽음 효과와 중복 생성 방지.
- 효과 줄이기: 흔들림/화면 번쩍임 없이 단계 외곽색과 짧은 이름표. 오라는 캐릭터 뒤쪽, 위험 예고와 적탄은 항상 그 위. 플레이어·HUD·모바일 액티브 가독성 유지.
- 모든 색은 무채색 갑옷/죽은 금/버건디 망토 유지. 오라는 2/3단계 전용 별도 Canvas 효과. 현재 시안은 구도 검토 자료로 runtime 픽셀 결과와 동일하지 않음.

## 승인 후 작업 및 향후 배포 검증
한 캐릭터의 등장/전환/처치/자막을 묶어 구현·문서·로컬 커밋. 군단장/대악마로 임의 확장하지 않음.
새 배포 지시가 있을 때만 65%/30% 경계·한 틱 다단계 건너뜀·도트/궁극기 처치·동시 사망·소환체 생존·저장 재개·정지·방 이동·연습 재도전·효과 줄이기·가로 모바일·actor/RNG 불변·보상 단일 발생 확인.
