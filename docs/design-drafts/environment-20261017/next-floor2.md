# 다음 구상 — 2층 파수꾼의 회랑

상태: 구상만 작성. 새 디자인 PNG 검토·사용자 승인 전에는 런타임에 반영하지 않는다. 대사·컷씬은 뒤로 미룬다.

1층이 습하고 방치된 외곽 전당이라면, 2층은 무너져가는 옛 왕국의 마지막 검문소로 잡는다. 회녹색 돌의 재질과 저채도 도트 밀도는 이어가되 규칙적인 장방형 판석, 두꺼운 문 주위 석조, 무쇠 보강과 마모된 군사 문양으로 위계를 만든다.

| 요소 | 1층과 구분할 방향 |
| --- | --- |
| 바닥 | 긴 판석과 군화에 닳은 면, 작게 패인 검흔·석재 파편. 균열은 일부에만. 중앙 전투 면은 낮은 대비 유지 |
| 벽·문 | 건축 부재가 보이는 각진 석조, 철제 문틀과 리벳, 하단 검댕. 기존 문 오프셋·폭과 충돌 배치 유지 |
| 오브젝트 | 외곽 부러진 창대·방패 잔해·무너진 무기 거치대, 퇴색한 왕국 문양. 비충돌 장식은 통로 밖에 배치 |
| 조명·움직임 | 성긴 횃불의 불티, 낮게 흐르는 먼지, 작은 바람에 흔들리는 찢어진 깃발. 전투 경고와 겹치는 광원·화면 전체 안개는 피함 |
| 보스 무대 | 기존 파수꾼 보스 앞의 비워진 연병장 분위기. 벽 가장자리 깨진 방패 문양·철제 장식, 중앙 이동 공간과 도약 경고는 명확하게 |

권장 다음 작업 단위: 실제 2층 일반방 + 파수꾼 보스방 + 군사 잔해 3종을 한 PNG 보드로 검토 → 컨펌 후 모듈 자산과 별도 움직임 제작 → 2층만 연결. 이어서 3층 고대신의 서고, 4층 프리즘의 왕좌 순서로 확장한다. 공통 시설은 이번에 만든 상자·샘물·신전·제단·계단을 재사용하며 시설 기능을 바꾸지 않는다.
