# 기존 메인 5종 시너지 성장 수치안 v1

2026-10-16. **사용자 승인 초기 수치 / 로컬 구현 완료·실행 미검증.** UI는 같은 폴더의 `level-up-ui-v1.png` 재사용. 베르가스 유니크화는 이미90e74c2 로컬 구현이며 이번8종 전용 보조와 구분한다. 최신 행동/수치는 본 문서가 최초 design.md의 포괄적 설명보다 우선한다.

## 핵심 구조

- 메인5종 유지, 베르가스는 유니크 공용 보조. 새로운 메인·궁극기·별도 버튼을 추가하지 않는다.
- 화염/서리/독/번개에 일반 등급 전용 보조2종씩 추가. 정밀은 기존 약점 추적·마무리 조준 유지. 전용 보조는 각3레벨, 해당 메인에서만 등장.
- 선택한 메인 자체가 기존 공격의 중심이며 전용 보조를 안 뽑아도 정상 작동한다. 둘 다 최대까지 배우는 것을 빌드 완성의 필수조건으로 만들지 않는다.
- 메인 최대3(서리4), 기존3레벨 무료 분기와 ID 유지. 분기 효과는 현 코드 그대로 보존하고 이번에 몰래 범위/지속 변경을 덧붙이지 않는다. 기존 design.md의 분기별 전투 설명은 추천 활용이지 추가 수치 변경이 아니다.
- 메인3 + 전용 하나3 + 공용2회 = 8포인트, 레벨업당1포인트 기준 Lv.9의 구성 예시. 메인3 + 전용 둘3씩은9포인트이므로 공용을 포기하는 선택 비용이 있다. XP·층별 경험치·레벨업 횟수 자체는 이번 범위에서 바꾸지 않는다.

### 산식·분기와의 관계

- 화약촉: 기존 화염의 폭발 피해를 구한 뒤 중심에 있는 각 피해자에게만 `기존 폭발 피해 × (1 + 중심 보너스)`를 적용한다. 직격·화상·장판·잔불 추가 피해에는 곱하지 않는다. 확산/응축이 바꾼 실제 폭발 반경에 중심 비율을 적용한다. 중심 바깥은 기존 폭발 피해다.
- 잔불: 해당 화살의 기존 폭발 기준 피해(갈래/연속/석궁의 기존 축소·분기·유물 보정 포함) ×0.20 또는0.35. 화약촉 중심 보너스는 기준에 포함하지 않는다. 추가 타격에 다시 적 방어를 한 번 적용하고, 폭발/화상 중첩/장판 발동을 재호출하지 않는다. 화상3중첩 **유지 중에도 간격 후 다시 발동**하는 것으로 명확히 한다. 면역 공격/공중 대상/벽으로 차단된 공격에서는 발동하지 않는다.
- 서리: 빙결 타수4/3/2/2, 빙결시간 일반1.2초/보스0.45초, 빙결 후 면역2초 및 공격 둔화는 변경하지 않는다. 이동 둔화 합계는 일반60%/보스30% 상한. 잔류 둔화는 빙결이 실제로 양수→0으로 끝날 때1회만 적용하며 새 중첩을 만들지 않는다. 이미 강한 둔화가 있으면 강도는 유지하고 최소1초만 보장한다.
- 빙편: 기존 서리레벨의 파편 피해 계수에1.15/1.20/1.30을 곱한다. Lv.3의1.30은 생성 원본이 완전 빙결로 사망한 경우에만 적용한다. 파편 속도480·개수6/12·충돌/벽/기본 서리 중첩 작동은 그대로. 수명 연장은 곡선 유도나 재발사 추가가 아니다. 파편에 강화계수를 저장하고, 후속 파편 생성 때 이전 파편 보너스를 다시 곱하지 않는다.
- 침투 독: 잔류/맹독 분기로 정해진 독 지속에0.5초를 더한다(기본3→3.5, 잔류4.5→5, 맹독2→2.5). DOT 보너스10%는 기존 유물·분기 보정 뒤1.10배를 한 번 적용. 추가 중첩의 지속·피해는 같은 주탄의 일반 독1중첩과 같고 최대8중첩을 넘으면 가장 오래된 중첩 교체. 발동 전부터 화살 독이 있어야 하며, 한 주탄이 관통한 서로 다른 적에서는 각 대상별 간격으로 판정한다.
- 포자: 원본의 실제 가스 반경과 포자 거리 중 작은 범위 안에서, 벽으로 막히지 않은 미감염 대상을 고른다. 원본의 가장 강한 살아 있는 화살 독1중첩을 스냅샷, 이미 보정된 DPS의50%를 전달한다. 새 독에 침투 독/유물 계수를 다시 곱하지 않는다. 대상별 포자독은1개만 유지하고, 일반 화살 독을 얻으면 포자독을 제거한다. 포자독 자체는 가스/추가 포자/독 처치 폭발/침투 추가중첩의 씨앗이 아니다. 별도 DOT로 저장한다. 포자에 죽은 적은 보통 처치 보상을 받는다.
- 축전: 네 번째(또는 세 번째) 유효 주탄 적중에서 충전 완료, **그 다음** 유효 주탄에 보너스 소비. 충전이 준비되어 있는 동안 추가 적중을 저장하지 않는다. 강화 직격이 전이 위력·천둥 횟수를 곱하지 않는다. 기본직격 번개35%라면 강화 시60%/75%가 되는 가산 방식이며, 집중 방전75%라면100%/115%. 표시 피해 기준은 기존 번개 산식의 방어 적용 전 power. 대상 방어는 최종 타격에1회 적용한다.
- 전도: 기본 `first × decay^i` 산식의 decay만 변경한다. 집중 방전의1체 연결에서는 감쇠 개선이 체감되지 않으므로 그 분기에 한해 전도 Lv.1부터 첫 전이 피해 +6%를 대신 제공한다. Lv.2 연결거리·Lv.3 마지막 적 보너스는 양쪽 분기에 동일 적용. 기존 리듬의140→180 사거리 조합에20을 더한다. 살아 있는 대상 경로를 먼저 고정하고 마지막 대상에만15% 적용해, 그 피해로 죽었다고 뒤에 새 적을 무한 탐색하지 않는다.

## 후보·이관·구현 순서

1. 첫 메인5중3 저장 추첨, 기존 도전당 재추첨1회 공유를 권장한다. 아직 사용자 확정 전이다.
2. 레벨업3후보 중 궁극기 기존 보장 우선, 남은 자리1개에 유효한 메인/해당 전용 보조 보정. 나머지는 기존 가중치. 전용 보조 일반 가중치1, 베르가스 최초0.04/보유강화1 유지. 유효 전용 후보가 없으면 강제로 채우지 않는다.
3. 저장된 후보를 다시 열 때 동일 ID를 복원하고, UI에는 해당 시점의 유효 레벨과 정확한 전후 수치를 보여준다. 미습득 화상/가스 전용 후보는 제안하지 않는다. 이미 최대인 스킬은 제외한다.
4. 신규8레벨 키와 설명·미리보기·아이콘의 기존 속성 아이콘 재사용부터 연결한다. 발동 데이터·저장 검증·쿨다운 상한·초당 처리량 제한·구저장0초기화·후보 보존 이관을 함께 구현한다. 기존 메인/분기는 바꾸거나 환급하지 않는다.
5. 신규 상태(주탄 축전, 대상별 잔불/침투 간격, 포자독/감염원 간격, 잔류 둔화 종료 감지)는 유효 범위와 수명 명시 후 저장한다. 저장 재개/방 이동으로 즉시 추가 발동을 얻지 않게 한다. 석궁 snapshot 허용 키/저장검증도 함께 확장한다.
6. 이번은 수치안·원문서 링크·4기록 로컬 커밋까지만. 승인 후 UI·추첨·보조를 의미 있는 단위로 구현한다. 테스트·푸시·배포·공개 확인은 새 명시 배포 지시 후 누적 수행. 숫자는 계산 제안이지 플레이 밸런스 검증 결과가 아니다.

검토 포인트는 '집중 화염/화상', '서리 제어/파편', '독 누적/전파', '충전 직격/연쇄', '기존 정밀 집중/마무리' 중 원하는 방향을 선택할 수 있는지다. 선택지를 더 늘리기 위한 별도 신규 스킬·상위 메인은 이번 범위에서 제외한다.
