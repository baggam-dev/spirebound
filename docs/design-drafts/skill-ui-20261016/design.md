## UI PNG

`level-up-ui-v1.png`: 내장 imagegen 신규 생성 원본 복사. 정확 프롬프트 `prompt-v1.md`. 실제 게임 캡처·실행 검증 결과가 아니다. 중세 전술서의 어두운 가죽 테두리 + 회베이지 양피지3장, 큰 아이콘/구분/이름/레벨 변화/행동 한 문장/주요 수치/연계 이유 순서다. 이번은 정밀 메인을 이미 고른 뒤의 레벨업 예시다.

최초 메인 선택도 같은3카드 틀을 사용하되 제목은 '주력 사격을 선택하세요', 카드에는 '메인'·핵심 전투 방식·첫 레벨 이득을 보여준다. 아직 없는 현재 메인/약점 태그는 표시하지 않는다. 5종 중3종만 제안하며 베르가스가 이 풀에 들어가지 않는다. 상세에는 그 메인의 전용 보조2종과 분기2종을 미리 보여준다.

이미지의 '연속 사격'은 구성 예시이며 실제 표시명은 기존 **연속 화살**을 유지한다. 베르가스 작은 아이콘도 구성용 그림으로, 실제 구현은 승인된 검 PNG/기존 아이콘을 사용한다. 약점 추적의 10→20%는 기존 비강화 연속 직격의 조건부 보너스이며 모든 공격에 무조건 더해지는 뜻으로 쓰지 않는다. 선택 카드에 짧은 조건을 함께 표기한다.

이미지 전체를 배경으로 붙여 글자까지 굽지 않는다. 승인 후 카드·본문·버튼은 기존 HTML/CSS와 폰트로 구현해 정확한 한국어/터치/키보드/포커스/스크린 크기 대응을 유지한다. 원래 화면의 화면 효과·아이콘을 재사용하며 장식용 자산 추가 필요 시만 생성한다. 런타임 글자에 생성 이미지의 오탈자를 옮기지 않는다.

PC와 모바일 전투 **가로** 공통3열. 좁은 가로 화면에서는 큰 상단 여백·아이콘·장식을 먼저 줄이고 본문 핵심은 유지한다. 보조 설명/전체 성장표는 '상세 성장 보기'에 모은다. hover가 없어도 모든 필수 정보가 보여야 한다. 카드 전체를 선택 영역으로 하며 선택으로 확정, 같은 클릭/탭의 중복 소비 방지. 상세 열기/닫기는 포인트를 소비하지 않는다. 메인 선택·보조 선택은 닫기로 건너뛰지 않으며 게임은 정지한다. PNG의 비율·폰트 크기가 실제844×390 등에서 검증된 것은 아니다.
