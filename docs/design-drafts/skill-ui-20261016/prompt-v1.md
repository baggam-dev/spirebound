# 레벨업 UI v1 정확 프롬프트

내장 imagegen 신규 생성. 외형 검토용 PNG, 실제 동작 화면/브라우저 QA 결과 아님. 가로 전투 전용 유지.

Use case: ui-mockup. Create ONE polished actual raster PNG interface concept for the existing pixel-art dark medieval roguelike Spirebound. This is a LANDSCAPE level-up selection modal, desktop and mobile LANDSCAPE friendly, NOT a portrait phone layout. Wide 16:9 composition. Dim blurred dark stone dungeon behind a dark charcoal and worn burgundy leather tactical book frame, three LARGE equal pale muted gray-beige parchment scroll cards side by side in one row. Short curled scroll edges at top/bottom, restrained tarnished bronze corner ornaments, avoid busy medieval clutter. Pixel-art game UI with crisp deliberate pixel edges, clean legible Korean typography, not smooth fantasy illustration. Main focus is readability, generous body text size, high contrast charcoal text on parchment. Very little yellow, no bright gold. No character artwork, no fake screenshot border or phone. Top small text 'LV 7', large heading '새로운 깨달음', below compact build chip '메인 · 정밀 사격' and two subtle tag chips '집중 공격' and '약점'. Cards must be genuine clickable-looking full card choices with tiny number labels 1 2 3. Card 1 has amber target-arrow pixel icon and text '메인 전용' then bold '약점 추적', 'Lv.1 → Lv.2', body '같은 적을 연속 공격하면 더 강해집니다.', a separate large numeric strip '보너스 10% → 20%', and small muted label '정밀 사격과 연계'. Card 2 has two arrow pixel icon and text '공용 보조', bold '연속 사격', '신규 습득', body '첫 화살 뒤에 한 발을 더 발사합니다.', numeric strip '0.16초 후 · 피해 60%', small muted label '공격 공백 보완'. Card 3 has ONE silver sword pixel icon with aged bronze crossguard and tiny violet gem (no aura), text '공용 보조', bold '망령검: 베르가스', '신규 습득', body '다가오는 적을 베고 곁으로 돌아옵니다.', numeric strip '피해 34 · 재사용 1.70초', muted label '근접 위협 대응'. Middle card may have subtle bronze outline for keyboard focus, not neon glow. Bottom one moderate dark button '후보 새로고침 · 1회', and unobtrusive text '상세 성장 보기'. No extra buttons for closing or continuing without choosing; choosing a card commits the upgrade. Fit all content comfortably within the wide landscape screen; game stays paused behind. No watermarks. Exact Korean labels when possible, avoid extra invented text.
