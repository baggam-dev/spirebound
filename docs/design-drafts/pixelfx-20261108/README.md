# 이펙트 통합 시안 01 — 디자인 확인용

## 범위
단계1 통합 시안. 내장 imagegen으로 만든 컨셉이며 실제 Canvas/pixelfx 프레임 출력·게임 적용 캡처가 아니다. 기존 QA의 어두운 석재 바닥을 시각 참고로만 사용한다. 참조 캡처 상단0.48 표시는 당시 로컬 이력이며 이번 운영버전 확인 근거가 아니다.

보드 왼쪽 STANDARD는 일반 효과, 오른쪽 REDUCED는 효과줄이기 제안이다. 양쪽 모두 개선안이며 현재판/개선판 비교가 아니다. 명중/치명타·4원소·베기/착지·적경계중첩을 묶어 확인한다. 생성된 바닥/도형/문자는 설명용이며 생산 자산으로 추출하지 않는다.

## 적용 기준 초안
|항목|기본|효과 줄이기|구현시 고정 조건|
|---|---|---|---|
|일반/정밀 명중|작은 밝은 핵·방향성 파편|핵+1~3파편|기존 .2초 수명·방향/명중 이벤트 유지|
|치명타|일반보다 선명한 방향 강조|식별되는 짧은 핵/방향 표식|기존 실제치명 이벤트와 연결 확인, 별도 치명판정 추가없음|
|화염/냉기/독/연쇄 명중|불꽃편/결정/방울/각진전기 구분|같은 실루엣 유지·입자감소|현재 .3/.34/.4/.22초 및 기존레벨분기·원소최대48 유지|
|베기|두꺼운 선두/가는꼬리·내측잔상1겹|짧은 칼날형태만|현재 공격방향·진행률·타이밍·판정 유지|
|착지·장판|낮은 먼지/바닥충격·빈중앙|먼지생략·필요한상태/경계 유지|실제범위·벽clip·적경계최상단·적탄1회유지|

밝은 핵은 수명의 초반에 집중하고 잔류는 빠르게 어두워지는 방향. 표의 파편 수는 시안 목표이며 구현 성능 검증 후 확정한다. 원소색은 기존 skill-visuals 팔레트, 몸PNG·오라는 분리 유지. 생성 이미지의 광량·비율은 정량 판정값이 아니다.

## 승인 후 다음 범위
먼저 단계2인 일반/정밀/치명타·4원소 명중과 베기만 실제코드 연결한다. 이번에 보인 착지/장판은 전체 방향 확인용으로 단계3에서 확장한다. 코드 차용 시 MIT/NOTICE 사용분을 함께 보존한다. 전체 pixelfx 설치/더미신체/act hit-stop/화면전체섬광은 포함하지 않는다.

## 검증 상태
시안 이미지 직접 확인 및 정적문서·diff 확인만 수행한다. 테스트/구문실행/개발서버/브라우저QA/원격푸시/배포/공개게임확인은 하지 않는다. 움직임·축소게임크기·효과중첩·실휴대폰가독성/성능은 미검증이다. 디자인 확인 후 구현·기록·로컬커밋, 새 명시배포 지시 후 누적검증한다.
## v1 생성 결과 직접 확인
- vfx-study-v1.png: 내장 imagegen 1회, 1536×1024 보드. 원본 exec-8c3a4c0e-17a1-418b-912e-54c3cef56c08.png 보존/프로젝트 무변환 복사. 정확 프롬프트는 prompt-v1.md.
- 기본/완화 두열, CONTACT/ELEMENTS/SLASH/OVERLAP 네행과 T0/T1/T2 샘플 확인. 시간 샘플은 정량 프레임이나 실제 재생 결과가 아니다. 불꽃편·결정·방울연무·각진전기의 형태 구분 및 완화 입자 감소가 보인다.
- 한계: 완화 베기의 중심 프레임은 여전히 기본과 비슷하게 크고 밝다. 실제 적용은 칼날 실루엣을 유지하되 내측잔상/주변장식 제거를 더 엄격하게 한다. 하단은 경계와 아군효과가 대체로 떨어져 있는 개념도라 강한 중첩 가독성의 증거가 아니다. 실제공유도형과 현재경계색을 유지하며 보드의 새원/화살표형적탄을 그대로 대체하지 않는다.
- 생성바닥은 기존재질을 참고한 재해석이며 실제기존바닥픽셀 보존합성이 아니다. 캐릭터 없는 형태검토 보드로 몸/무기 가림·모바일축소/움직임·프레임은 판정할 수 없다. 추가 재생성 없이 이 제약을 명시해 디자인 방향 검토에 사용한다.
