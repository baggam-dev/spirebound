## 포즈와 분리 효과

납골술사는 보라 로브·상아 가면·물리적 등불, 수도사는 청록/상아 로브·종 지팡이, 수호체는 상아/회청 돌·보라 수정 흉갑이다. 오른쪽 3/4 포즈를 좌우 반전하며 걷기·시전·주먹은 실제 다른 프레임을 쓴다. 16방향 회전 시트는 아니다.

캐스터 0~8: 대기, 걷기 2종, 준비, 집중 시전, 발동, 회복, 무릎 붕괴, 쓰러짐. 돌 수호체 0~7: 대기, 걷기 2종, 주먹 준비, 공격, 회복, 붕괴, 돌무더기.

행 경계는 캐스터 y=0/341/682/1024, 수호체 y=0/512/1024다. 프레임 경계·고정 비율·발 기준선은 `src/rendering/support-sprites.js`를 따른다. 프레임마다 높이를 다시 맞추지 않아 시전 때 손·지팡이가 커졌다 작아지는 현상을 피했다. 피격 움찔을 별도로 얹지 않고 시전 중단은 회복 프레임·작은 취소 표시로 나타낸다.

소환 예고 원/연결선, 회복 연결선/수치, 약한 탄환 예고, 주먹 부채꼴과 먼지는 PNG에 굽지 않고 Canvas로 그린다. 물리적 등불/종/수정은 캐릭터에 포함하지만 마법 오라·치유 빔·입자·지면 그림자는 원본에 추가 합성하지 않았다. 런타임 그림자는 별도 렌더다.
