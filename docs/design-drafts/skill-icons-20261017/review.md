## 원래 후속 계획과 우선순위
기존TODO의큰순서는 걷기/피격사망 → 스킬효과 → 보스등장·페이즈·사망 → 대사·컷씬 → 배경·오브젝트였다. 스킬효과는2026-10-16배포, 캐릭터반응누적은이번배포범위. 대사컷씬은구체제작범위미확정. 사용자새제안에따라다음단위로아이콘품질업을먼저배치하는것을추천. 대사컷씬과배경의순서는재검토가능하며확정자동착수로쓰지않는다.

## 실제 현황
- pixel-icons.js는16x16좌표의3색SVG픽셀실루엣을코드로그린다. SVG형식자체보다낮은도상해상도와공유아이콘이구별을어렵게한다.
- draftMarkup은iconSVG(k.icon||k.id). 스킬23종 중전용보조8종이메인fire/frost/poison/chain그림을그대로공유한다. 성장3종도기존power/aura/haste도상을재사용한다.
- evolutionPanel은두분기모두iconSVG(key)를사용해선택양쪽그림이같다. 분기는10계열x2=20개.
- 현재draft아이콘표시크기PC56px/가로모바일30px. 큰원화만정교하게만들면모바일에서세부가뭉개질수있다.30/40/56px에서형태가먼저구별돼야한다.
