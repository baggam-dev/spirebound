## 실제 코드 근거와 다음 범위

`src/rendering/interaction-visuals.js`는 성공 이벤트만 emitInteraction으로 받으며 run별 WeakMap, 방 제한, 최대4개, elapsed 기준 .9초 수명을 이미 갖고 있다. 상자/샘물 등은 공통8조각을 사용하고 샘물만 가로줄2개를 더한다. roomClear는 실제 doorCenter와 doors 배열을 이용해 봉인 조각을 문설주로 물린다. 정수·성장·계단은 이미 별도 경로가 있으므로 이번에는 반복하지 않는다.

`src/game/game.js`의 상자 성공 후/샘물 사용 후/roomClear에서 이미 emit한다. 다음 구현은 이 이벤트와 수명·상한·보상 적용 시점을 재사용하고 효과 세부 표현만 구분한다. 현재 drawInteractionEffects에는 reduced 인수가 없으므로 승인 후 효과 줄이기 설정을 전달해 필수 피드백만 유지하도록 연결한다.

1. 상자: 기존 열림 자산/시설 위치 그대로, 뚜껑 근처에 짧은 금빛 부채꼴 입자와 작은 빛. 보상은 즉시 적용하며 애니메이션 대기나 별도 클릭을 추가하지 않는다. 기존 trap 이벤트는 금빛 성공으로 오인시키지 않도록 붉은 경고색·모양을 유지한다.
2. 샘물: 기존 샘물 위치(objectPoint/fountainPoint)에서 낮은 청록 물결과 짧은 회복 실줄기3개. 체력 회복/사용 후 소모·used 저장은 그대로다. 사용하지 않은 상시 물결과 사용 성공 효과는 구분하고, 지속 오라로 바꾸지 않는다.
3. 문 개방: 기존 roomClear/doors/doorCenter를 재사용해 얇은 연녹 봉인 조각이 문설주 양쪽으로 사라진다. 실제 길은 즉시 열리며 중앙 통로에 충돌물처럼 보이는 선을 남기지 않는다. 네 방향·오프셋 문·귀환 잠금/개방 조건을 그대로 유지한다.
