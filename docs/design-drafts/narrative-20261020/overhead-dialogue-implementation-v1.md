# 머리 위 보스 대사 구현 — 2026-10-20

## 승인과 범위
사용자 ‘진행’으로 overhead-dialogue-v1.png의 차콜판·회백문자·짧은꼬리/한명발화/큰보스옆이동 방향 승인. 앞의 말투/단서를 실제 보스에 연결했다. 새 PNG를 생성하거나 캐릭터/전장/HUD/보스크기를 바꾸지 않았다. 전체 서사6장면의 도입·대악마격파·탈출 새벽 컷씬을 구현한 것은 아니며, 이번 범위는 보스 머리 위 대사다. BGM은 보류한다.

## 연결
- `src/ui/boss-dialogue-data.js`: 파수꾼침묵·프리즘시스템·군체모방·칼드명령/베라힌트·모르도지배/왕좌너머·벨카르봉인/경고·본체위협. 문자열을 도트폰트로 직접 그려 생성시안의 문자를 이미지로 재사용하지 않는다.
- `src/rendering/boss-dialogue.js`: 기존 실체를 읽어 방/보스/사건별 한번만 큐에 넣는다. 대사 큐/읽기시계/앵커는 화면 상태이며 actor/AI/공격/보상/RNG를 수정하지 않는다. 기존 `stepRun` 직전 snapshot과 직후 death effect/현재 phase를 대조한다. 틱 사이 스킬로 HP가 이미0이 된 적도 snapshot에 남겨 처치 대사를 놓치지 않게 했다.
- 등장과 적 전멸 뒤 처치 대사는 `mode=dialogue`/paused로 전투·탄·장판·쿨타임·기록시간을 함께 멈추고, 머리 위 대사와 아래 작은 ‘다음’/‘대사 건너뛰기·ESC’ 버튼을 표시한다. 모든 문자는 바로 표시한다(타이핑효과는 이번에 넣지 않음). 다음버튼에 포커스·기존 모달Tab순환/Enter/Space·ESC 소비, 전투 dispatch 차단/스틱 해제로 입력이 전투로 흘러가지 않게 연결. 도움말 등으로 나갔다 돌아오면 남은 큐가 있으면 먼저 읽기로 복귀한다.
- 전환/한 문지기만 처치한 순간은 전투를 추가 정지하지 않는다. 투사체/장판/폭발/공격 예고 등이 있으면 표시하지 않고 최대6초 안에서 안전한 시점에만 노출, 누적3.2초 읽히면 종료한다. 안전한 틈이 없으면 그 선택 대사는 생략된다. 첫등장의 핵심 단서는 정지 읽기로 남는다.
- 군체는 최초 등장/최종 보스 분열체 전멸만 발화.2→4분열은 새 소개/처치로 보지 않는다. 소환몹/보스훈련/열쇠획득 후 귀환에는 새 이야기 대사를 넣지 않는다.
- 칼드 다음 베라 순서로 하나씩 소개. 첫 문지기 처치 때 상대가 살아 있는 경우에만 이름을 부르는 후속 사용. 베라가 마지막이면 ‘왕을… 깨우지 마…’, 칼드가 마지막이면 이미 죽은 베라를 부르지 않고 추가 후속을 생략. 둘이 동시에 죽어도 죽은 상대를 부르는 발화는 나오지 않는다.
- 대악마는 손발/눈코입을 사람 대사 화자로 만들지 않고3단계 상단벽 본체만 짧은 위협을 비차단으로 제시한다. 기존 최상층 열쇠/하강/36초봉인/최종탈출·결과/랭킹 판정은 그대로 둔다.

## 배치·저장
캔버스에서 최대2줄, 기본14px/터치16px·판폭330px 상한. 캐릭터별 머리/기존 체력표시·크기를 읽고 머리위→왼쪽→오른쪽 후보를 사용한다. y96 위 보스HUD와 우상단 미니맵 영역, 플레이어 부근을 피해 후보를 고르며 벽 보스는 화면 안으로 이동한다. 가까운 앵커에만 짧은 꼬리를 그려HUD를 가로질러 긴 선을 긋지 않는다. 모든 후보가 막히면 화면 안의 제한된 대체 위치로 옮기므로 극단적 배치의 가독성은 실제 QA가 필요하다. 비차단 대사는 위험 자체가 있으면 숨겨 전투 예고를 가리는 상황을 줄인다.

`styles/boss-dialogue.css`는 배경을 가리지 않는 오버레이와44px 이상 제어 버튼, 대사의 접근성 텍스트를 제공한다. 대사 중 모바일 좌/우레일·헤더가 기존 ‘메뉴 열림’ 규칙으로 숨지 않도록 별도 선택자를 두었다. 모바일조작 버튼은 보일 수 있지만 전투입력을 수행하지 않는다.

선택 저장필드 `bossDialogueSeen`에는 `층:방:보스:사건` 문자열 최대128개만 저장하고 중복/형식/초과를 `validateRun`에서 거부한다. 필드가 없는 구저장도 허용한다. ‘seen’은 **표시 큐 등록** 기준이며 큐/남은 읽기시간·좌표·actor 참조는 저장하지 않는다. 로드 때 이미 방문한 방의 살아 있는 보스 소개/지난 페이즈는 등록해 생략하고, 아직 도전하지 않은 pending 왕/군단장 또는 새 방 보스는 이후 소개한다. 스킵/탭 종료·로드 뒤 남은 문장이 생략될 수 있으나 보상/전투 상태를 대신 실행하거나 되돌리지 않는다. 새로 시작한 원정은 새 사건 기록을 사용한다. 기존 저장스키마/랭킹 버전/클라이언트0.42는 배포 준비까지 유지한다.
