# 승인 모바일 외곽 HUD·원형 조이스틱·액티브 아이콘

2026-10-13 사용자 ‘좋아 이렇게 하자 조이스틱도 이미지 바꾸고 액티브 스킬들도 아이콘화 하려고 했어’로 mobile-hud-v1.png 배치 승인. 로컬 구현만 수행, 테스트/브라우저 QA/푸시/배포하지 않았다.

## 변경

- mobile-hud.js가 모바일 coarse 모드에서 기존 체력/유물/정수/획득 기술 DOM을 왼쪽 레일에, 미니맵/수치를 오른쪽 레일에 연결한다. 기존 위치에 표식을 남겨 데스크톱 전환 시 원래 부모/순서로 복귀한다.
- 기존 drawMinimap의 지도/문/귀환경로 로직을 유지하면서 별도166×160 Canvas에 좌표 이동해 그린다. 모바일 게임 Canvas에는 미니맵을 겹쳐 그리지 않는다. 데스크톱은 기존 위치 유지.
- mobile-hud.css는 safe area와 헤더를 제외한 좌우 레일을 예약하고 가운데 게임 화면을 남은 폭/높이에 맞춘다. 기본 레일88~112 CSS px, 많은 유물/기술/하트는 레일 내부 스크롤·줄바꿈으로 제한한다. XP는 중앙 게임 화면 바로 아래에 두며, 기존 하단 기술 오버레이는 모바일에서 제거한다. 낮은 화면 높이에서는 수치도 스크롤할 수 있다.
- 조이스틱은 승인 시안의 원형 링·중앙 노브·방향 표식을 CSS로 구현한다. PNG 재생성 없이 기존 조작부를 확장했다. 화면 왼쪽 하단 레일에 고정하고 input.js가 중심을 기준으로 축을 계산한다. 기존 다중터치·pointer capture/reset 경로를 유지한다.
- 액티브 버튼은 기존 pixel-icons SVG 시스템의 실제 선택 기술(집중/응급 처치/수호 환영, 화살비/석궁, 점멸)에 맞는 아이콘을 사용한다. 물약은 같은16px 아이콘 시스템에 병 형태를 추가했다. 짧은 이름/물약 수/쿨다운/aria-label/title을 함께 제공하며 미습득 기술은 기존 hidden 규칙을 유지한다. 모바일 텍스트 덮어쓰기를 막고 상태가 바뀔 때만 마크업 갱신.
- public-https QA에 새 모듈·CSS·입력/아이콘 파일 일치 대상을 추가했다. 실행한 검증이 아니다.

## 남은 검증 — 배포 지시 후

보행·가로전용·더블탭 변경과 누적 검증한다. 실제기기/에뮬레이션 구분, 844×390/740×360/짧은가로/전체화면/safe area에서 게임-레일-버튼-스틱-상호작용-헤더-툴팁 겹침, 최대20하트·다량 유물/정수/기술의 스크롤과 손가락 두개 조작, 스틱중심/경계/입력해제, 액티브 숨김/비활성/선택별아이콘/쿨다운/물약개수, 세로전환/수동재개, desktop 모드복귀/구저장/귀환지도 확인.

새 원정/전투 밸런스/지도 생성/저장 버전/랭킹 변경 없음. 6~8 지도/복도/문 항목은 미구현. 새 PNG 디자인을 런타임에 넣은 것이 아니라 승인 배치를 기존 UI/아이콘/Canvas 코드로 연결했다. 실제 화면 결과는 아직 확인하지 않았다.
