첫 simulation 틱 전에 물약을 사용하더라도 성공조건 확인 후 실제 소모·회복 전 observeBossEncounter를 호출해 관찰 시점이 뒤집히지 않도록 했다. 실패 물약은 기록을 만들지 않는다. metrics가 새로 생성되는 경로에서도 전체 potionsUsed가 누락되면0부터 증가하도록 보완했다. 원정 기록의 보스 전체/단계 결과 사이에 교전 첫 관찰 값을 표시한다. 기본 공격력은 스킬별 최종 DPS가 아니며 유물은 개수만 남긴다. 외부 수집/새 스킬계산·수치조정은 하지 않는다.
선택 저장 객체에 유한비음수 값·정수 레벨/유물/물약·양수 최대하트·현재하트<=최대·boolean partial 검증을 추가하고 없는 구저장은 허용한다. boss-entry.test.js4건(재진입/로드 불변, 첫틱전 물약, 구기록, 잘못된 저장)을 작성만 했다. 누적 신규12건은 모두 미실행이며 정적 읽기/git diff --check만 완료했다. 기존 운영700 통과를 이번 변경 검증으로 인용하지 않는다. 사용자 일괄 배포 지시 후 누적 전체와 실제 원정기록PC/가로모바일·8/10층·저장재개·첫틱전 물약을 확인한다. 이 후속3건으로 관찰 자료 보완 구현은 마감하고 추가 난도 수치변경은 실전자료에 근거한다.
