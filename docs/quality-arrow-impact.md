# 사격·명중 리듬 — 기본/정밀 화살 접촉 (2026-10-06)

기본 사격에는 활 반동과 발사 효과음이 있지만 기본·정밀 화살의 명중 지점에는 속성 화살 같은 접촉 표현이 없었다. 일반 적중 표식도 적이 살아남을 때만 생성돼 처치 순간이 약했다.

실제로 화살이 적과 충돌한 좌표·방향에만 0.2초 작은 접촉 섬광을 더했다. 기본 화살은 밝은 석색, 정밀 화살은 옅은 금색이다. 명중 효과음도 직접 접촉과 같은 프레임에 울리므로 한 방 처치에도 발사→접촉의 박자가 이어진다. 속성 화살은 기존 전용 이펙트를 유지하고 섬광을 중복하지 않는다. 벽 뒤 적에는 표시하지 않으며 많은 투사체가 겹칠 때 새 섬광 최대 24개만 렌더한다. 공격력·충돌 판정·저장·시즌은 불변이다.

효과의 시간별 픽셀 비교: [PC](quality-arrow-impact/arrow-impact-pc.png)·[모바일 가로](quality-arrow-impact/arrow-impact-mobile.png). 동일 Canvas 효과를 두 화면에서 확인했다. 단위 테스트는 기본/정밀 한 방 처치·벽 차단·속성 비중복·밀도 제한을, 브라우저 QA는 위치/영역 밖 픽셀·페이지 오류와 1층/첫 보스 레이아웃을 확인한다. 실제 사람 체감과 실기기 평가 전이다.
