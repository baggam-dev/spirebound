# 2차 비주얼 개선 — 대표 성소와 하강

## 6-2 기존 근접병·궁수 동작 연결 (2026-11-21, 로컬 미검증)

기존 승인된 회색 복장/단검·활/체격과 4프레임 보행, 근접병 베기 원화를 유지한다. 이번은 새 캐릭터 디자인이나 신규 부위 애니메이션 제작이 아니라 기존 준비·공격·기본 프레임 사이의 동작 연결이다.

- 근접병: 현재 `chaserWindup/chaserStrike`를 따라 준비 때 약간 뒤로 무게를 싣고 베기 때 앞으로 디딤. 관측한 베기 종료 후0.14초 안에 기본 자세로 복귀한다. 베기 PNG는 기존 strike 구간에만 사용한다.
- 궁수: warning 진행에 맞춰 당김 자세, 실제 `shot` 증가마다0.12초 이내 짧은 반동, 마지막 발사 후 recover 진입 때0.24초 이내 활을 내린다. 새 연사의 첫 발에서 shot 카운터가 초기화돼도 관측한다. 단순히 firing 상태가 계속된다고 매 프레임 반동을 시작하지 않는다.
- 행동 중 보행 프레임/잔여 이동 bob을 배제하고 기존 조준 방향을 짧은 복귀까지 유지한다. 발 위치21px 기준 작은 이동/회전만 적용하며 확대/축소하지 않는다. 캐릭터 체격·히트박스·생명력바·경고·분리 베기·탄환 위치는 바꾸지 않는다.
- `grunt-actions.js`의 WeakMap에 화면용 짧은 이력만 기록한다. 로드/방 이동의 기존 presentation 초기화와 함께 비우며, 시간 역행/0.4초 이상 관측 공백/80px 초과 위치 변화/빙결·빈틈·상위 공격은 이력을 취소한다. 과거 공격을 뒤늦게 재생하지 않는다.
- 완화 모드는 같은 프레임·행동 구분과 방향을 쓰되 추가 이동/기울기를0으로 한다. 초상은 기존 정적 기본형, 자산 fallback은 기존 경로를 유지한다.

수정 `grunt-sprite/pixel-world/ordinary-presentation-state`와 신규 `grunt-actions`. AI·경직·공격 시작/피해 시점·명중 범위/치명/보상/저장·게임 RNG 불변. 기존 몸체가 이미 전용 아트와 보행을 갖추었으므로 불필요한 재생성이나 복장 교체는 하지 않았다.

정적 호출부·방 초기화·프레임/상태 전환·`git diff --check`만 확인했다. 테스트·구문 실행·서버·브라우저/실기기 QA·푸시/배포는 보류한다. 이미지 제작·신규 단위 테스트 없음. 최종 누적 QA에 근접병 준비/베기/복귀·궁수 연사 첫/중간/마지막과 다음 연사, 취소/빙결·회복·양방향·모바일/완화·저장 로드/방 이동·자산 실패/정적 초상·렌더 상태 불변을 포함한다. 새 팔/활시위 원화 프레임이 생긴 것은 아니며, 실제 크기에서의 연결 품질은 확인 전이다.

다음6-3 화살비·석궁·요정/요정왕의 효과 위계와 소환체 움직임 정리 후, 전체/API·정상 성장/모바일·밸런스를 누적 검증하고 한 번 배포한다.

## 6-1 추가: 승인된 바닥 무늬 (2026-11-21, 로컬 미검증)

사용자 승인한 `design-drafts/floor-decals-20261121/floor-decals-v1.png` 방향을 Canvas 코드 기반 6종(습기 얼룩/물웅덩이/오래된 혈흔/오망성/긁힘/이끼)으로 구현했다. 보드 이미지나 새 PNG를 런타임 자산으로 추가하지 않는다.

- 모든 층의 지면 패스에 연결. 방마다 작은 흔적3~6개를 시도하되 안전한 공간이 부족하면 줄인다. 일반 전투방만 오망성 추가 시도1개: 상승10%/하강28%. 발광·펄스·공격 판정 없는 끊긴 다섯 꼭짓점 선이다.
- 성소 상승은 물/얼룩/긁힘/이끼 위주. 다른 층 일반방에 혈흔을 섞고 하강은 혈흔 비중을 높인다. 온실/군체는 이끼, 최상층은 마른 흔적 위주. 시설·보스·관문·튜토리얼 방은 혈흔/오망성 제외.
- seed/층/방 좌표/상승·하강 단계로 독립 정수 해시. 같은 단계의 재입장/저장은 배치를 재추첨하지 않는다. 하강 전환은 그 단계의 고정 배치를 사용한다. 맵·전투·성장 RNG 불소비/저장 필드 추가 없음.
- 문 도착점은 그림 반경+78px, 시설·추가상자·공유샘·봉인핵은 반경+65px 회피. 장애물 바깥7px 여유/중앙 x325~635·y175~365 및 장식 간 간격을 보존. 입구가 없는 면도 같은 도착점 여유를 둔다.
- 배치/무늬 계획은 불변 WeakMap, 960×540 투명 레이어는 최대3방 캐시/2px 환경 표면으로 렌더. 일반/완화 모두 정적이며 물도 이번에는 움직이지 않는다. 게임 상태나 캐릭터/탄환/HUD에 필터를 적용하지 않는다.
- 기존 성소 전용 물웅덩이/14개 조각 그리기를 새 패스로 대체해 중복 밀도 방지. 옛 `environmentPlan`은 과거 QA import 호환용 진단으로만 남고, 실제 무늬 계획은 `floorDecalPlan`이다.

정적 호출/계획·캐시/제외 영역 및 `git diff --check` 확인. 테스트·구문 실행·서버/브라우저 QA·실기기·푸시배포는 보류한다. 이번 시각 변경에 신규 단위 테스트를 추가하지 않았다. 최종 배포 QA에서 실제 무늬6종/저밀도·희귀문양/재입장·로드·하강/문·핵·시설·장애물 회피·투명2px/일반완화/독·기관 예고·XP 대비/렌더 상태·난수 불변을 확인해야 한다. 이전 환경 QA 도구의 `environmentPlan` 진단만으로 신규 패스를 검증했다고 보지 않는다.

아래는 최초6-1 재질 작업 기록이다.

2026-11-21. 단계6-1 로컬 구현, 테스트/브라우저 QA/배포 전. 승인한 `design-drafts/major-upgrade-20261120/world-encounters-v1.png`의 01 SANCTUM / 02 DESCENT를 기준으로 한다. 새 PNG 생성 없이 기존 성소 atlas의 렌더 재질 캐시와 Canvas 상감/균열을 수정한다. 실제 화면이 승인 보드와 같은 품질인지, 모바일에서 대비가 충분한지는 아직 확인하지 않았다.

## 반영 범위

| 요소 | 변경 |
|---|---|
| 1층 성소 바닥 | 녹색 계열을 청회색 판석으로 분리. 원래 마모/깨짐/픽셀 텍스처 유지, 중앙 비네트의 검은 농도를 낮춤 |
| 성소 석벽 | 바닥과 같은 어두운 색 대신 상아빛 회색. 위/왼쪽 모서리 밝은 면, 아래/오른쪽 접지 그림자. 외곽/내부 벽에 같은 재질 적용 |
| 상감 | 중앙의 큰 원/빛나는 문양 대신 낮은 대비의 황동 모서리 네 곳. 중앙 전투 공간은 비움 |
| 문턱 | 실제 이웃 방이 있는 문에만 낮은 석재 받침과 황동 줄. 저장된 가변 문 좌표 사용 |
| 하강 전 층 | 바닥 위 붉은 전면색/붉은 모서리 표시를 차가운 저농도 음영과 가장자리 끊긴 봉인 균열로 교체. 각 층 고유 바닥은 유지 |
| 자산 지연/실패 | 성소 청회색 기본 바닥/석벽과 동일한 상감. 하강 장식도 기존 fallback에 적용 |

`environmentMaterial(...,{sanctum:true})` 옵션은 성소 atlas의 바닥2개/벽1개에만 적용한다. 다른 층의 팔레트와 가구/횃불/문 소품은 기존 경로다. RGB만 바꾸며 마스크 알파/충돌/atlas 원본은 유지한다. 표면은 기존 2px 픽셀 캐시로 축소한다.

`sanctum-finish.js`는 결정적 정수 해시로 장식을 만든다. 게임 난수·저장 객체에 쓰지 않고, 방별 WeakMap에 문/시설/좌표 기반 불변 계획만 보관한다. 문턱은 실제 문, 균열은 문 도착점100px·시설80px를 피해 y104~134 또는409~445 가장자리에만 둔다. 원/부채꼴/발광구역·깜빡임·움직이는 입자는 추가하지 않는다. 완화 모드에도 동일한 정적 장식이다.

성소 상감은 기존 바닥 캐시에 포함하고, 실제 문/시설 계획이 바뀌면 해당 캐시를 다시 만든다. 하강 균열은 정적 계획을 재사용해 지면 단계에서만 그린다. 적/주인공/탄환/공격 예고/HUD보다 먼저 렌더링한다. 지형 배치·장애물 윤곽·문 열림/봉인·적 체력/보상은 수정하지 않는다.

## 검증 상태와 다음 순서

정적 호출부/옵션 한정/캐시 키/원본 자산 불변·`git diff --check` 확인. 현재 작업 지침에 따라 테스트·구문 실행·개발 서버·브라우저 QA·푸시·배포는 하지 않았다. 이전853개 통과는 이번 변경 검증이 아니다. 시각만 바꾸는 이번 단위에 별도 단위 테스트를 추가하지 않았다.

최종 누적 검증에서 기존 환경/벽/문 회귀, 성소 일반/시설·가변 문/지형·자산 fallback, 상승/하강 각 테마, 일반/완화·PC/가로/세로 모바일 뷰포트, 초록 독/주황 기관/치명타/경험치 대비, 렌더 전후 상태·난수 불변과 저장/로드를 확인한다. 신성한 보스 등장 연출/보스 방 고유 자산을 바꾸는 단계는 아니다.

다음6-2는 기존 근접병/궁수의 승인된 재질·역할 구분·모션 패키지 정리다. 이어6-3 화살비/석궁/요정·요정왕 효과 위계 → 전체/API·정상 성장 플레이/모바일·부하/밸런스 검증 → 누적 일괄 배포. 대표 성소를 개선했다는 이유로 다른 층 전면 재작업이나 단계6 전체 완료로 처리하지 않는다.
