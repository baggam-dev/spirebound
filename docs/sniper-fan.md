# 플레이 피드백 3 — 상층 궁수 갈래 수

- 일반 astralSniper: 등반 시 좌우 2갈래(-0.18, +0.18 rad), 하강 시 기존 3갈래(-0.18, 0, +0.18 rad).
- 같은 몬스터의 저층 희귀 출현도 같은 등반/하강 규칙을 사용한다.
- 예고와 발사에서 공통 fanOffsets를 사용한다. 탄속·피해·조준 고정·공격 간격은 유지한다.
- 7층 화살 문지기의 5갈래 및 모르도 패턴은 이번 변경 대상에서 제외한다.
- 7·8층 등반/하강의 실제 발사 수와 각도, 예고 시간, 피해·회복 시간 및 보스 패턴 보존을 회귀 검사한다.
