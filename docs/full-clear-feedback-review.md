# 화염 궁수 완주 후기: 9·10층과 귀환 구간 개선 검토 (2026-09-30)

사용자 피드백은 화염 궁수로 10층까지 완주한 실제 플레이 후기다. 아래는 **구현 제안**이며 전투 수치·에셋·랭킹 규칙을 아직 변경하지 않았다. 자동 QA가 통과했더라도 체감 난이도/반복성이 해결됐다는 뜻은 아니다.

## 확인된 원인

- 9층 군단장(`commander.js`)은 HP 8500, 1/2페이즈 모두 같은 갈래 연속 사격만 반복하고, 첫 화살비는 9초 후·이후 20초 간격, 점멸은 10초 간격이다. 이동 속도 48이며 플레이어와 거리가 220~345px면 멈춘다. 화염 고화력 빌드가 빨리 잡으면 화살비/점멸을 충분히 보지 못하고 정지 사수처럼 느껴질 수 있다. 이는 코드에 근거한 **원인 추정**이며 실제 사용자의 교전 시간 측정값은 없다.
- 10층 대악마(`demon.js`)는 페이즈마다 주공격을 전역에서 한 번에 하나만 골라 예고한다. 1·2페이즈 공격 후 기본 대기 2.1초, 3페이즈 1.8초와 회복 시간이 추가된다. 대부분의 부위는 공격 담당일 때 이동하지 않는다. 발 구멍은 54×54 직사각형 최대 2개이며 세 번째 생성 때 가장 오래된 것을 대체하고, 페이즈 전환 때 모두 지운다. 화면상 구멍도 사각형이다.
- 9층 일반방은 `upperEncounter`가 7층 이후 누적 진형 전부를 같은 가중치로 뽑아 고유 몬스터가 없다. 10층은 **샘물/계단 입구방 + 보스방 두 개뿐**이므로 일반 몬스터 세트는 9층에 배치하고 10층은 보스 연출·제한적 소환으로 테마를 이어야 한다.
- 귀환도 같은 상층 진형을 넓은 풀에서 뽑고, 하층은 기존 `encounter` 그룹을 재사용한다. `drawRoomBackdrop`은 층 인덱스를 7로 제한하고 `drawFloorMood`의 톤 배열도 8개뿐이어서 9·10층은 독립된 던전 팔레트/구조를 갖지 못한다. 귀환 `brute`는 `escapeDepth`가 있으면 모든 세부 색을 빨강으로 덮어 형태를 읽기 어렵다.
- 현재 탈출은 열쇠를 얻어 1층 출구로 돌아온 뒤 상호작용하면 즉시 완료된다(`canEscape`). 마지막 전투/이벤트는 없다. 영웅은 코드 도형으로 얼굴 22×24px, 몸통 23×27px와 짧은 다리 비율이며 사용자가 상체가 길다고 느낀 부분을 시안으로 비교할 필요가 있다.

## 항목별 권장안

1. **9·10층 지옥 테마:** 검붉은 암석·금간 바닥·심부 발광·사슬/뼈·성문 파편을 같은 재질/광원 규칙으로 제작한다. 9층은 악마 군단의 진지, 10층은 벽 너머 대악마의 신체가 침범한 옥좌로 구별한다. 채도 높은 붉은색을 배경 전체에 쓰면 탄환·독 장판·피격 예고가 묻히므로 바닥은 어둡게, 위험 신호는 밝은 주황/자주/청색으로 분리한다. 정적 타일/장식은 기존 벽 캐시와 같은 방식으로 재사용해 성능을 확인한다. [Apple 게임 디자인 가이드](https://developer.apple.com/design/human-interface-guidelines/designing-for-games)는 작은 화면에서 글자·조작 가독성을 중시한다.
2. **새 적 4종은 9층에서 조합:** `폭렬 박쥐`는 낮은 HP·매우 빠른 돌진, 접근/자폭 전 짧고 명확한 예고 및 체인 폭발 상한. `심연 가시핵`은 바닥 고정·직선/부채 가시 예고로 안전 구역을 바꾼다. `악마 병사`는 근접 방패형/원거리 사수형을 같은 계열의 다른 실루엣으로 둔다. `악마 부대장`은 갑옷 해골 기사형 정예로 병사를 지휘하거나 돌진 방향을 강제한다. 1방에 박쥐+가시핵+사수가 모두 겹쳐 피할 수 없는 조합은 금지한다. 10층 일반방은 만들지 않고, 보스 페이즈 간 짧은 박쥐/병사 소환을 시험할 수 있으나 대악마 부위 읽기를 방해하면 제외한다.
3. **군단장: 움직이는 탄막 결투:** 먼저 전투 시간/패턴 노출을 계측한다. 첫 화살비를 대략 4~5초로 앞당기되 사용자가 확인한 **후속 시전 20초 간격은 유지**한다. 평상시 횡이동/거리 재조정·점멸 후 반격을 늘리고, 현 갈래 연속 사격 외에 `이동 경로 차단 부채탄`과 `짧은 예고 후 직선 고속 저격`처럼 회피 방향이 다른 1~2패턴을 넣는다. 2페이즈는 탄 수만 증가시키지 말고 점멸→위치 교환→측면 사격의 연쇄를 추가한다. HP는 패턴이 최소 한 차례 보일 정도로 조정하되 맨 먼저 배수로 올리지 않는다. 고화력 화염/낮은 화력 빌드 둘 다 지루한 장기전이 되지 않아야 한다. 공격 예고·회복 박자를 유지한다. [GDC 보스 설계 발표](https://media.gdcvault.com/gdc2018/presentations/Keren_Itay_BossUp.pdf)도 공격 예고를 핵심 요소로 다룬다.
4. **대악마: 페이즈별 압박 조정:** 1페이즈는 손/발 공격 간격을 조금 줄이고 손의 손가락별 탄 패턴을 더 자주 노출한다. 발 점프/돌진 비율과 이동을 높이되 착지·돌진이 동시에 확정 피해가 되지 않도록 한다. 2페이즈는 눈의 탄속/레이저 각, 코의 이동/독길, 입의 흡입/밀침을 단계적으로 강화한다. 3페이즈는 재사용 패턴 순서·발사체 속도/형태를 더 다양화하지만 같은 패턴 연속 사용 금지, 큰 공격 1개+보조 1개 상한과 안전 경로를 유지한다. 단순 전체 쿨다운 일괄 축소보다 페이즈별 위협·회피·반격 창을 측정한다.
5. **발자국 구멍:** 착지 때 발바닥/발가락이 보이는 깨진 지면 이미지와 충돌 윤곽을 최대한 맞춘다. 생성된 구멍은 전투 전체/페이즈 전환 후에도 유지하는 안을 우선 시험한다. 영구 누적은 방을 막으므로 최대 2~3개를 고정 상한으로 두고, 상한에 닿은 다음 스탬핑은 충격파만 발생시키되 새 구멍을 만들지 않는 방식이 일관적이다. 문·플레이어·자동조준 가능한 표적까지의 경로 연결성 검사는 유지한다. 현재 사각형 충돌을 모양만 발자국으로 바꾸면 빈 공간에서 막히는 문제가 생겨 충돌/시각을 함께 조정해야 한다.
6. **귀환 몬스터와 뚱땡이 외형:** 6층 군체·7층 천문관·8층 왕실·9층 악마 군단의 대표 적/진형을 해당 층에서 더 자주 뽑고, 귀환에서는 같은 적의 광폭 변형/신규 매복을 섞는다. 비중은 수치 확정 전에 같은 시드의 방별 출현표로 확인한다. `brute` 광폭화는 전체 빨간 도색을 없애고 원래 갑옷·피부 명암을 유지한 채 눈빛/균열/망토 일부만 붉게 발광시킨다. 모든 귀환 적이 한 색으로 뭉치지 않도록 역할 실루엣도 보존한다.
7. **1층 탈출구의 짧은 결말 전투:** 단순 추가 보스보다 `마지막 봉인 파괴`를 권한다. 열쇠를 넣으면 출구가 열리는 동안 악마 잔영/빠른 박쥐가 2~3차례 습격하고 플레이어는 봉인석을 부수거나 짧은 시간 버틴다. 이동 공간·안전 지대가 있고 30~45초 이내 끝나는 규모로 시작해, 긴 귀환 뒤 갑자기 또 긴 보스전에 들어가는 피로를 피한다. 선행 안내·저장 재개·방 이탈·사망/랭킹 조건을 설계한다. 보상은 별도 장비보다 탈출 장면의 서사/연출로 준다.
8. **영웅 얼굴/비율:** 기존 금발·활·용병 무드를 유지하고 얼굴 눈/눈썹·코·턱의 1~2px 대비를 시안 2~3개로 비교한다. 상체를 3~4px 줄이고 다리/허리 위치를 보정하는 시안부터 시험한다. 정지·걷기·활쏘기·피격 4자세를 PC 원본/모바일 축소에서 확인해 활/표정/발 접지가 잘 읽히는지 판단한다.

## 권장 작업 순서와 검증

1. **전투 기준선:** 실제 화염 완주 또는 동일 수준 빌드 재현으로 9/10층 보스 교전 시간, 노출 패턴 수, 피격/물약, 페이즈별 체류 시간과 귀환 방별 적 출현을 기록한다. 제공되지 않은 사용자 원시 플레이 로그를 있는 것처럼 취급하지 않는다.
2. **군단장/대악마 전투와 구멍 판정:** 공격 선택·이동·예고/회복·충돌을 소단위로 구현하고 PC/모바일 회피 가능성, 저장 재개, 동일 시드 재현, 길찾기/벽 충돌을 검증한다. 기존 보스 체력만 일괄 증가시키지 않는다.
3. **9층 적/전용 진형 + 6~9층 층별 가중치:** 일반방과 귀환 출현표를 먼저 검증하고, 이후 전투 화면에 연결한다. 10층 2방 구조를 보존한다.
4. **9·10층 아트 + 귀환/영웅 외형:** 비주얼 세로 조각에 신규 적, 보스 탄환, 발자국 구멍, 귀환 `brute`, 영웅 4자세를 묶어 실기기 가독성과 프레임 비용을 비교한다.
5. **출구 이벤트:** 귀환의 마지막 압박과 결과/랭킹 반영을 검증한다. 전투 난이도·지도/출구 조건·점수에 의미 있게 영향을 주면 기존 ASCENT-1 기록과의 비교 가능성을 검토해 새 시즌/rulesVersion으로 분리하는 쪽이 안전하다. 기존 저장과 BETA-1은 보존한다.

각 단계의 실제 난이도 수치와 에셋 방향은 플레이 테스트 후 확정한다. 이번 검토에는 코드 수정, 신규 시즌, 배포가 포함되지 않는다.
