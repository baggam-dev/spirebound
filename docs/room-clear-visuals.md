# 전투방 클리어·문 개방 연출

- 기존 `roomClear` 이벤트에서 0.9초 동안 전투 종료 안내를 표시한다.
- 등반 중 잠금이 해제된 방의 실제 연결 문에만 봉인이 양옆으로 흩어지는 효과를 표시한다. 입력·이동을 지연하지 않는다.
- 하강 중 이미 열린 문, 신전 선택으로 잠긴 방에는 출구 개방 표시를 하지 않는다. 즉시 궁극기로 마지막 적을 처치한 경우도 기존 처치 이벤트로 처리한다.
- 상호작용 연출의 WeakMap과 게임 경과 시간을 재사용한다. 일시정지 시 정지, 방을 나가면 숨김, 저장에서 재생하지 않음. 전투 규칙·보상·충돌 변경 없음.
- 전체 테스트 303개 통과. Edge의 4방향 문·4개 시간 단계 렌더링에서 정지 프레임 및 상태 보존 검증. PC·모바일 4개 화면 크기의 게임 실행에서 오류 없음. 실제 아이폰 검증 미실시.
