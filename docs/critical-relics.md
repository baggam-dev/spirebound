## 비용과 조건부 발동

- 금 간 왕관은 최대 체력 2 이상일 때만 획득한다. 획득 즉시 최대 체력을 1 줄이고 현재 체력은 새 상한까지만 유지한다. 피격·반격·불사조 발동을 유발하지 않는다. 중복 획득은 거부한다. 제거 시 최대 체력만 1 복구하고 현재 체력을 회복하지 않는다. 최대 체력 상한 1,000은 유지한다.
- 비용을 낼 수 없는 왕관은 새 보스/상자/시련 유물 풀에서 제외한다. 이미 저장된 보스 후보는 비활성화하고, 상자/시련 보상은 기존 대체 보상 경로를 사용한다. 건너뛰기는 계속 가능하다.
- 사냥꾼의 인장과 불굴의 문장은 깊이 0의 새 유효 명중만 처리한다. 빗나감·차단·같은 명중의 추가 속성 성분·지속 틱·파생은 발동하지 않는다. 원래 명중이 대상을 이미 처치했다면 인장은 발동하지 않는다.
- 인장 피해 한도에 쓰는 기본 공격력은 플레이어의 `damage`(궁술 연마·유물·주술 보정 전)다. 한도와 방어·표식 적용을 구분한다. 추가 피해는 비치명 파생으로 별도 결과를 남기며 치명 난수를 더 소비하지 않는다. 선고·표식·불굴·다른 인장을 재발동하지 않는다. 외부 호출자의 실제 HP 차이에 이미 포함되므로 전체 DPS에 별도 중복 가산하지 않는다.
- 불굴은 최대 5중첩이다. 현재 유효 확률 HUD와 보유 상세에 반영하며 치명타 확률 상한 50%를 유지한다. 비치명타가 이어질 때 보완하는 효과이며 치명타를 확정하지 않는다. 제거하면 중첩/증가 제한 상태를 지운다.

## 스킬·소환체·저장

정적 확률/배율은 스킬과 더한 뒤 기존 상한 50%/250%를 적용한다. 소환/설치 무기는 당시 유효 정적 스탯과 `criticalResolved:true`를 저장해, 복사된 유물 목록이 다시 치명 스탯에 더해지지 않도록 한다. 회피 집중은 기존 시전 스냅샷 규칙을 유지한다.

불굴의 조건부 확률은 프로필에 영구 저장하지 않고 실제 판정 시 현재 소유자의 상태에서 한 번 더한다. 따라서 중첩 5에서 설치한 석궁이 영구 +10%p를 갖지 않으며, 이후 치명타로 중첩이 초기화되면 다음 실제 공격도 이를 따른다. 인장/불굴과 스킬의 새 명중 발동은 소유자의 현재 패시브다. 이미 설치한 무기의 정적 스탯은 이후 성장/유물 제거로 바꾸지 않는다.

상태는 기존 저장 안에 보존한다: 플레이어 `resolveStacks/resolveNextAt`, 치명 상태 `hunterNextAt`, 무기/프로필 `criticalResolved`. 새 필드의 범위와 boolean을 검사한다. 기존 저장은 새 유물을 갖고 있지 않으므로 스탯 재작성·추첨·난수 초기화가 필요 없다.

파생 표기 점검에서 기존 번개 전이·서리 사망 파편·가시 반격 3경로의 `procDepth` 누락을 보완했다. 이 피해도 실제 피해/치명 판정은 유지하지만 추가 발동 스킬·유물을 재충전하지 않는다.
