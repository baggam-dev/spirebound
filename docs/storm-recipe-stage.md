# 첫 전투 시너지: 폭풍 화살 — 2026-10-06

기존 `갈래 화살+관통 화살` 조합은 모든 화살 직격 피해 +3뿐이었다. 새 도전에서는 이 수치를 유지하면서, 각 화살이 첫 적을 관통한 뒤 **전방 240px 이내의 벽에 가리지 않은 다른 적**에게 한 번 방향을 바꾼다. 거의 일직선의 적은 기존처럼 그대로 관통한다. 후방·차폐 대상, 발사체가 이미 맞힌 적, 관통 횟수가 끝난 탄, 서리 파편·별도 유도탄은 제외한다. 가장 가까운 후보를 선택하고, 새 발사체를 추가하지 않는다.

이로써 적이 벌어져 있는 방에서는 갈래 탄의 후속 경로가 바뀌고, 보스 한 체만 남은 상황은 기존 피해 +3과 직선 탄을 유지한다. 자동 조준을 반복하는 유도 화살과 달리 첫 관통 직후 한 번만 꺾인다. 실제 재미/체감 빈도는 사람 플레이로 판단해야 한다.

전투 규칙이 순위 비교에 영향을 주므로 신규 도전은 generationVersion29, 기본 BETA-5/ranking-v11, 확장 ASCENT-7/ranking-v12로 분리했다. 이전 generationVersion28 도전의 직선 행동과 BETA-4/ASCENT-6 기록은 보존하고, 이전 시즌은 조회 전용이다. 0.33.0-prebeta와 API 설정을 함께 바꿨다. 점수 계산식과 서버 운영 DB는 바꾸지 않는다.

검증: `tests/unit/storm-recipe.test.js`가 방향·차폐·후방·한 번 제한, 구도전 차이, 저장·재개를 확인한다. 전체 `node --test`, 로컬 Edge PC/모바일 `tools/qa/storm-recipe-qa.mjs`, 같은 시드 첫 방/보스 화면, 임시 SQLite 온라인 랭킹 시나리오를 실행한다. 최종 결과와 운영 릴리스는 `WORK_STATUS.md`에 기록한다.
