# 모바일 HUD 플레이 피드백 검토 — 2026-10-20

상태: 검토 완료, 통합 PNG 시안 준비 대기. 사용자 ‘지금 작업 이후 검토 진행’에 따라 기존 최적화 배포 종료 후 검토했다. runtime/자산 수정, 테스트·푸시·배포는 하지 않는다. 운영175020-8afe12/runtimeee2d31a/0.43 유지. 시작 git clean/e1038cf.

## 코드 확인
- styles/mobile-hud.css 마지막 enlarged map 규칙이 현재 기준. 기본 width=min(24vw,200px,(100dvh-100px)*.56), 좁은화면은 height-140px 기준이다. 기존 너비 전체를2/3배 하고 종횡비166/160 유지한다. 844×390에서는162.4→108.3px,740×360에서는123.2→82.1px 계산값(실기기 실측 아님).
- src/world/terrain.js drawMinimap: 배경#08120f80만 반투명, 방 fill은 불투명이다. 방/연결문/기호를 분리해서 투명도를 조정해야 한다.
- src/ui/mobile-hud.js는 map을 runHUD에 따로 두고 statReadout만 우측 rail로 옮긴다. 지도와 세부정보를 같은 우측 기준 컨테이너에 배치하는 편이 안정적이다.
- header는 좁은 rail 폭에 pause/menu50%를 배치하고780px이하에서 세로로 쌓는다. 현재pause는 CSS문자Ⅱ, 버튼은 PNG가 아니다.
- 액션4개는72px 원형, 배경#152322d9로 약85% 불투명. 물약 disabled 예외가 있으므로 전체opacity 한 번 적용하면 개수/쿨다운/비활성 구별이 약해진다.

## 제안안 (시안에서 함께 검토)
1. 지도: 현재 한변의2/3, 위치는 우측상단 유지. 방 채움 불투명도35~45%, 현재방65~75%, 길/기호는80~90% 정도로 구분. 지도배경20~30%. 지도 전체opacity 대신 층별요소에 적용한다. 축소시 작아지는 지도 제목/범례는 아래 정보블록에 넣어 글자가 깨지지 않게 한다.
2. 세부정보: 미니맵 아래6~8px, 우측 끝을 지도와 일치. 글자 우측정렬, 어두운 반투명 패널(불투명도25~35%). 긴 수치는 지도보다 넓은120~150px까지 왼쪽으로 펼쳐도 되며 플레이화면 침범 허용. LV/공격력/공속/이속/DPS 기존 항목 유지.
3. 일시정지/메뉴: 어두운 도트풍 금속테두리의 PNG 아이콘2개(명확한pause/menu 기호). 가로2개로 고정, 각각44px이상 터치영역, 전체폭 약96~104px. 상단 벽체 위로 걸쳐 배치, safe-area 유지. 기존 메뉴 열면 전체화면 덮는 동작은 유지. PNG 생성은 imagegen 내장도구로 하고 실제 PNG 통합시안을 먼저 제시한다. 코드/SVG로 이미지시안 대체 금지.
4. 액션4개(물약/유틸/궁극기/구르기): 현재72px 터치범위와 배치 유지, 배경 불투명도25~35%/테두리50~65%/아이콘80~90% 제안. 물약개수·쿨다운은 높은 가독성 유지, 사용불가상태는명도/채도/테두리로도 구분. transparent 영역도 기존 터치영역에 포함한다.

## 순서와 권한
