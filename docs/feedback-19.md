# 0.19 플레이 후기 반영

## 전투

- 등반 3층부터 근접 전열과 원거리 후열을 섞은 편성을 추가했다. 일반몹 전체 능력치는 일괄 인상하지 않았다.
- 화염 폭발 피해 10% 감소. 화염 3레벨 장판 기본 반경 85 → 75, 표시 불투명도를 높였다.
- 2층 파수꾼 이동속도 25 → 40. 패턴 회복과 연속 공격 간격을 약 20% 줄이고 회복 중 추격한다.
- 4층 프리즘은 10초마다 정예를 소환한다. 생존 소환수 최대 3마리, 전용 게이지와 남은 시간을 표시한다. 소환수는 경험치·물약·정수를 지급하지 않는다.
- 6층 슬라임 이동속도 20% 증가, 공격 간격 15% 감소. 독침과 독구슬 사격을 추가했다. 근접 독가스는 6초 주기로 예고 후 발생하며 분열 단계별 반경은 90/70/50이다. 예고 0.6초, 지속 3.4초로 빠져나갈 시간을 둔다.
- 분열 위치에 독장판을 남기고 두 자식이 서로 떨어진 임의 위치로 점프한다. 착지 예고와 공중 피격 제외를 적용했다. 보스 체력바는 분열 이후 체력까지 합산한다.
- 하강 팩 일부를 횡이동 사수·고리 탄막술사·매복 돌진자 3종으로 교체한다. 전체 수는 늘리지 않았다. 등반 시련에는 하강 전용 종류가 섞이지 않는다.

## 신전과 보상

신전 방은 정예 3마리와 싸운 뒤 반드시 두 주술 중 하나를 고른다. 이웃 방에서 입장 경고를 표시한다. 전투 및 선택 완료 전 출구가 잠기며 ESC나 재접속으로 선택을 건너뛸 수 없다. 15종에서 중복 없이 두 개를 뽑으므로 부정 효과끼리도 나올 수 있다.

| 구분 | 효과 |
| --- | --- |
| 긍정 | 공격력 +5 |
| 긍정 | 공격속도 +8% |
| 긍정 | 이동속도 +5% |
| 긍정 | 최대·현재 체력 +1 |
| 긍정 | 3하트 회복 |
| 긍정 | 궁극기 재사용 시간 10% 감소 |
| 긍정 | 점멸 재사용 시간 15% 감소 |
| 긍정 | 점멸 거리 +15% |
| 긍정 | 장비 보호막 획득, 이미 있으면 재충전 5초 단축 |
| 긍정 | 미소유 유물 1개 |
| 부정 | 공격력 8% 감소 |
| 부정 | 공격속도 8% 감소 |
| 부정 | 이동속도 5% 감소 |
| 부정 | 현재 체력 2 상실, 최소 1 유지 |
| 부정 | 궁극기 재사용 시간 10% 증가 |

정예 처치 물약은 방당 최대 1개로 제한했다. 기존 누적 유물 25종과 정수 규칙은 유지한다.

## HUD

- 왼쪽 위에 유물별 16×16 도트 아이콘 25종. 마우스 오버 또는 키보드 포커스로 효과 확인.
- 미니맵 아래 레벨, 공격력, 공격속도, 이동속도, 최근 5초 DPS 표시. DPS는 범위 피해를 포함한 실제 피해 합계 ÷ 5이며 재접속 직후에는 새로 집계한다. 공격력 숫자는 조건부 유물 효과를 제외한다.
- 왼쪽 아래 밝은 도트 하트와 정확한 체력 숫자. 최하단 하늘색 경험치 바.
- 중앙 아래 획득 기술 아이콘과 레벨. 기술 선택 카드에도 같은 도트 아이콘 사용.
- 근접 오라 3레벨 보호막이 준비되면 캐릭터를 흰 레이어로 감싼다. 보호막 상태와 재충전 시간을 HUD에도 표시한다.
- 기존 마름모는 사용하지 않는 최대 체력 슬롯 표시였다. 삭제하고 장비·오라 보호막을 별도 표시한다. 도움말에 설명을 추가했다.

## 저장 호환

기존 도전과 지도를 유지한다. 미사용 구버전 신전은 진입 시 정예 전투를 생성한다. 이미 수령한 신전 보상은 다시 지급하지 않는다. 주술 후보·선택 결과·누적 효과·보스 소환 시계·점프 상태를 저장한다. 새로운 일반 편성과 하강 종류를 모두 체험하려면 새 도전을 권장한다.

## 검증

- 자동 검사 176개 통과: 신전 강제 선택과 단일 지급, 저장 호환, 보스 소환 상한과 보상 제외, 슬라임 분열과 사격, 하강 편성, 물약 상한, 아이콘 구분, DPS 계산 포함.
- 파수꾼·프리즘·슬라임·하강 각각 120초 시뮬레이션과 저장 재개 검사 통과. 기술 트리 4종의 60초 검사 통과. 결과: qa-pressure.json, qa-tree.json.
- 별도 5193 QA 브라우저에서 도트 HUD, 유물 설명, 기술 선택 아이콘, 프리즘 소환 게이지 확인. 신전의 부정-부정 선택, ESC 잠금, 선택 후 재접속 유지 확인. 마지막 확인 시 브라우저 오류 로그 없음.
- PC 1280×800 기준 화면 확인. 실제 플레이의 체감 난이도와 모바일 조정은 별도 플레이 후 평가한다.
