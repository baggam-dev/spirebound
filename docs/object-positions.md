# 플레이 피드백 10 — 오브젝트 위치 무작위화

- 새 도전의 보물상자·추가 상자·샘물·신전·수상한 제단을 방 내부의 안전 후보에 무작위 배치한다. 계단과 보스 전용 오브젝트는 유지한다.
- 벽·장애물 55px 여유, 입구 145px 거리, 방 중심에서 이동 가능한 경로를 확인한다. 추가 상자는 주 오브젝트와 150px 이상 떨어진 후보를 사용한다.
- 표시·이름표·바닥 장식·사용 이펙트·상호작용 거리에서 같은 저장 좌표를 참조한다. 신전의 입장 즉시 선택 규칙은 유지한다.
- 위치는 저장·하강·재방문에 유지된다. 좌표 없는 기존 저장은 기존 위치를 사용하며 새 도전을 요구하지 않고 계속 플레이할 수 있다.
- 기존 전체 테스트 319개 및 신규 2개 통과. 40개 시드의 접근성·간격·저장/하강 안정성 검사.
- Edge PC·모바일 4개 화면에서 상자 개봉·샘물 회복 총 8회 실제 상호작용 및 저장 완료 확인, 브라우저 오류 없음. 실제 아이폰 검증 미실시.
