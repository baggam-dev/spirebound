# 0.14 · 메인 1개 + 보조 조합

첫 기술 획득에서 화염·서리·독·번개 중 메인 하나를 선택하며 기술 선택 1회를 쓴다. 이후 선택한 메인 강화와 보조만 제시한다. 한 도전에서 속성을 변경하거나 다른 메인을 중복 습득할 수 없다. 메인은 각 3레벨과 기존 2가지 최종 분기를 유지한다.

기존 여러 속성 빌드는 이어하기에서 유지할 메인을 직접 고른다. 버리는 속성의 투자 횟수는 모두 기술 선택으로 환급하고 해당 최종 분기는 제거한다. 새 속성을 선택하면 환급 포인트 1개를 사용해 1레벨을 배운다. 지도·체력·장비·남은 기술 선택과 전체 투자 합계를 보존하며 이관을 반복하지 않는다. 궁극기 해금에는 모든 메인/보조 투자 횟수를 합산한다.

## 보조

| 추적 화살 | 1 | 보이는 살아 있는 적으로 초당 최대 2.8라디안 선회. 속도 유지 | 0.04, 전설 |

선택한 메인의 추첨 가중치는 1이다. 후보는 중복 없이 최대 3개를 뽑고 만렙은 제외한다. 가중치는 고정 등장 확률이 아니며 남은 후보에 따라 실제 확률이 변한다. 연속 화살은 갈래 전체를 재발사하지 않고 기본 방향의 화살 한 발만 추가한다. 발사 전에 사망/방 이동 시 대기 탄환을 버린다. 유도탄은 벽을 통과하지 않으며 벽 너머 목표를 추적하지 않는다.

0.13의 중앙탄 전용 속성 규칙은 폐지한다. 메인 단일 선택으로 제한한 대신 갈래의 각 화살도 피해 감쇠와 함께 속성을 발동한다. 화염/독 중첩, 장판 피해, 번개 전이 피해에도 발사체 배율을 적용한다. 서리 중첩은 적중당 1회이다. 겹친 장판/독가스 피해 제한은 유지한다.

## 화염 조정

폭발과 장판 반경을 모두 절반으로 줄였다. 기본 반경은 27.5 / 35 / 42.5. 폭발·화상·장판 피해는 기존의 85%. 화살 기본 직격은 동일하다. 확산/응축 분기의 배율은 축소된 수치를 기준으로 적용한다.

## 서리 빙결

화살 첫 적중마다 서리 1중첩, 마지막 적중 후 3초가 지나면 초기화. 3중첩 시 일반몹 1.2초, 보스 0.45초 빙결. 이동, 근접/원거리 공격 동작, 정예 추가 사격 및 미발사 독 장판 예고를 정지하고 남은 공격 상태를 유지한다. 이미 발사된 탄환과 독 장판은 유지한다.

해빙 후 2초 동안 재빙결 중첩을 받지 않는다. 둔화는 계속 적용할 수 있다. 빙결 대상과 중첩은 청색 표시로 구분하며 저장 후에도 복원한다.

## 호환 정리 및 검증

동시에 배울 수 없어진 화염+서리 조합은 제거했다. 불씨 등불의 무의미해진 서리 페널티를 화살 직격 피해 -10%로 교체하고 지속 피해 +25%는 유지했다. 가방에 선택한 메인, 기술 카드에 메인/보조 및 희귀도를 표시한다. 세로 화면 메인 선택은 네 속성을 2×2로 표시한다.

자동 검사 116개 통과. 메인 잠금/환급/포인트 보존, 가중 추첨, 빙결과 면역, 미발사 예고 정지, 연속탄 지연, 유도 선회와 벽 차단, 오라 범위/공중 제외, 피해 배율, 저장 검증을 포함한다. 별도 브라우저에서 메인 선택→가방, 서리·연속탄·유도·오라 조합의 표시와 오류 로그를 확인했다. 실제 플레이 체감 밸런스는 다음 피드백으로 조정한다.
