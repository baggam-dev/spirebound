## 1. 액티브 룰렛 화면 비율과 선택 연출
- 사용자 평가: 액티브 룰렛은 전반적으로 좋다.
- 불편: 화면이 너무 꽉 찬다. UI 비율을 조절해 달라는 의견.
- 제안: 선택/당첨 시 연출을 더 극적으로 바꾸면 어떨지 검토. 예시는 빛이 나고 불꽃이 튀는 효과.
- 참고: 제공 사진 1은 ACTIVE · LEVEL 5 / 운명의 액티브 화면이며 후보 3개와 추첨 시작 버튼이 보인다.
- 상태: 기록 완료, 구체 비율·효과 미확정, 미구현. 수동 선택 기능을 요청한 것으로 확대 해석하지 않는다.

## 2. 안내 토스트 겹침과 최상단 시간 위치
- 불편: 상단 안내 토스트 문구가 너무 위에 있어 다른 표시와 겹쳐 잘 보이지 않는다.
- 제안: 토스트를 화면 정중앙보다 약간 위에 배치.
- 불편: 최상단 시간 표시가 문을 가린다.
- 제안: 시간 표시를 체력바 위로 이동.
- 참고: 이번 제공 사진 1의 상단 중앙에서 층/방/시간과 방 클리어 안내가 겹치는 상황. 사용자 실기기 종류는 확인하지 않았다.
- 상태: 기록 완료, 구체 좌표·배치 미확정, 미구현.

## 3. 유물 선택창 비율 유지와 긴 설명 내부 스크롤
- 불편: 설명이 길어 유물 선택창 전체에 스크롤이 생긴다.
- 요청: 기존 선택창·카드 비율을 유지하고, 설명이 긴 스킬/유물만 해당 카드의 설명 영역 내부에서 스크롤되도록 한다.
- 참고: 제공 사진은 수호자의 유물함이며 금 간 왕관 카드에 효과별 전후 수치와 긴 설명이 표시된다. 전체 스크롤 발생은 사용자 보고이며 별도 재현하지 않았다.
- 상태: 3번으로 기록 완료, 미구현. 현재 기록만 하라는 지시 유지.
