## 1. 액티브 룰렛 화면 비율과 선택 연출
- 사용자 평가: 액티브 룰렛은 전반적으로 좋다.
- 불편: 화면이 너무 꽉 찬다. UI 비율을 조절해 달라는 의견.
- 제안: 선택/당첨 시 연출을 더 극적으로 바꾸면 어떨지 검토. 예시는 빛이 나고 불꽃이 튀는 효과.
- 참고: 제공 사진 1은 ACTIVE · LEVEL 5 / 운명의 액티브 화면이며 후보 3개와 추첨 시작 버튼이 보인다.
- 상태: 기록 완료, 구체 비율·효과 미확정, 미구현. 수동 선택 기능을 요청한 것으로 확대 해석하지 않는다.

## 2. 안내 토스트 겹침과 최상단 시간 위치
- 불편: 상단 안내 토스트 문구가 너무 위에 있어 다른 표시와 겹쳐 잘 보이지 않는다.
- 제안: 토스트를 화면 정중앙보다 약간 위에 배치.
- 불편: 최상단 시간 표시가 문을 가린다.
- 제안: 시간 표시를 체력바 위로 이동.
- 참고: 이번 제공 사진 1의 상단 중앙에서 층/방/시간과 방 클리어 안내가 겹치는 상황. 사용자 실기기 종류는 확인하지 않았다.
- 상태: 기록 완료, 구체 좌표·배치 미확정, 미구현.

## 3. 유물 선택창 비율 유지와 긴 설명 내부 스크롤
- 불편: 설명이 길어 유물 선택창 전체에 스크롤이 생긴다.
- 요청: 기존 선택창·카드 비율을 유지하고, 설명이 긴 스킬/유물만 해당 카드의 설명 영역 내부에서 스크롤되도록 한다.
- 참고: 제공 사진은 수호자의 유물함이며 금 간 왕관 카드에 효과별 전후 수치와 긴 설명이 표시된다. 전체 스크롤 발생은 사용자 보고이며 별도 재현하지 않았다.
- 상태: 3번으로 기록 완료, 미구현. 현재 기록만 하라는 지시 유지.

## 4. 문 시인성 개선과 통로 스타일 다양화
- 불편: 일부 문은 횃불과 겹쳐 문인지 구별하기 어렵다.
- 불편: 횃불과 겹치지 않아도 문이 검은색 위주라 잘 보이지 않는다.
- 요청: 문의 시인성을 높이는 변경 계획을 마련하고 통로 스타일도 여러 종류로 만들어 볼 것.
- 후속 검토 범위: 문과 횃불 배치의 겹침 방지, 주변 벽과 구별되는 문 표현, 여러 통로 스타일 비교. 구체 색·형태·스타일 수는 사용자 미지정으로 미확정.
- 참고: 제공 사진은 9층 군단장의 전장 화면. 겹침 발생 조건·원인은 코드 조사/재현하지 않았다.
- 상태: 4번으로 기록 완료. 현재 피드백 수집/기록만 진행하며 시안·구현은 미착수. 디자인 반영은 기존 시안 승인 규칙을 따른다.

## 5. 성가 수도사 생존력·회복 속도·기동성과 지원 역할 강화
- 최신 사용자 지정(2026-11-22): 회복 횟수 제한 제거, 대상 최대 체력 기준 퍼센트 회복으로 변경. 고정 회복량 상한 없이 비율 회복. 후속 사용자 지정으로 1회 대상 최대 체력의20%를 초기 기준으로 정함(잃은 체력까지만 회복). 기존 체력/힐 속도/이속 강화 요청 유지. 기록만 완료·미구현.
- 체감: 성가 수도사가 일반 잡몹 하나처럼 느껴지며 변별력이 없다.
- 목표: 방치하면 성가시므로 우선 제거 대상으로 여겨지는 지원 적이어야 한다.
- 요청: 체력 버프(상향), 더 빠른 힐, 더 빠른 이동속도 등 변경 필요.
- 미확정: 상향 수치와 힐 가속 방식(시전 시간/회복 주기 등)은 정하지 않았다. 체력 버프의 구체 적용 대상/방식도 후속 설계에서 확인할 것.
- 참고: 제공 사진의 성가 수도사 도감 설명에는 특정 대상을 제외한 아군 한 체를 최대 3회 회복하고 시전 피해/빙결로 끊을 수 있다고 표시된다. 현재 코드 동작·전투 체감은 별도 조사/재현하지 않았다.
- 상태: 5번으로 기록 완료, 미구현. 현재 기록만 하라는 지시 유지.

## 6. 후반 성장 대비 봉인 추적자 전반 강화
- 체감: 덩치 큰 적인데 후반에 등장하여 이미 충분히 강해진 주인공에게 예상보다 너무 빨리 녹아내린다.
- 요청: 후반 성장 수준에서도 덩치에 맞는 위협이 느껴지도록 전반적인 버프 필요.
- 미확정: 강화할 항목·수치·방식은 미지정. 등장 시점 변경 요청으로 확대 해석하지 않는다.
- 참고: 제공 사진의 봉인 추적자 도감에는 하강 일반 방의 거대한 중장병, 느린 추적 후 고정 방향 돌진과 별도 예고의 2히트 중량 베기로 설명되어 있다. 현재 수치·처치 시간·빌드별 체감은 별도 조사/재현하지 않았다.
- 상태: 6번으로 기록 완료, 미구현. 현재 기록만 하라는 지시 유지.

- 요청: 칼드·베라만의 특수한 공격 패턴 구성으로 일반 적과 차별화.
- 요청: 클리어 시 보스 클리어 연출을 적용하고 경험치도 보스만큼 지급. 현재 경험치가 너무 적다는 의견.
- 미확정: 속도 수치·특수 패턴 내용·클리어 연출 세부·기준 보스와 경험치 수치는 미지정. 합동 패턴이나 다른 보상 변경으로 확대 해석하지 않는다.
- 참고: 제공 사진은 두 수문장의 도감 설명. 현재 코드 수치·패턴·경험치량·연출 유무는 별도 조사/재현하지 않았다.

## 8. 폭렬 박쥐 소형 고속 자폭 콘셉트와 마지막 봉인 과다 출현

- 원하는 동작: 매우 빠르게 움직이며 타깃 지정 후 직선으로 돌진하고 폭발.
- 현상 보고: 탈출 1층 마지막 봉인 해제 기믹에서 이상하게 박쥐가 많이 나온다. 박쥐 변경과 연관해 함께 원인 확인·수정 요청.
- 미확정: 크기·속도·타깃 지정/돌진 예고·폭발 수치·리디자인 세부는 미지정. 과다 출현의 원인과 박쥐 행동과의 인과관계는 미확인.
- 참고: 제공 도감 사진에는 폭렬 박쥐 처치 41회가 표시된다. 이 누적 수치만으로 마지막 봉인에서의 출현량이나 오류 여부를 확정하지 않는다. 코드 조사/재현 없음.

- 요청: 보스인 만큼 각종 공격 이펙트를 훨씬 화려하게 강화.
- 제안: 컷씬도 있으면 좋겠다는 의견.

- 참고: 사진에는 서리군단장 벨카르와 타락한 왕 모르도 도감이 표시된다. 난이도 비교는 사용자 플레이 체감이며 현재 코드/동일 빌드 비교는 별도 조사·재현하지 않았다.

## 11. 봉인의 잔해 기믹 전면 개편 검토안
- 평가: 현재 보스는 총체적인 문제가 있어 기믹 자체를 바꿔 보자는 제안.
- 외형 방향: 일단 현재 디자인 사용. 보스는 다리까지 있는 완전체로 설정.
- 탐색 단계: 이 보스가 있는 층 여러 방에 손·발·눈·코·입을 각 1체씩 랜덤 분포. 돌아다니다 큰 봉인문을 발견.
- 해제 조건: 각 부위 격파 시 봉인조각 1/5 획득, 5체 모두 격파하면 봉인문 입장 가능.
- 보스 1페이즈: 문 안에 봉인의 잔해 완전체 현현. 완전체 공격 패턴 전면 수정 필요.
- 보스 2페이즈: 완전체 격파 후 분리된 손·발·눈·코·입 5체가 일제 출격.
- 예비 평가(에이전트 의견, 미확정): 탐색에서 부위별 공격을 익히고 최종전에서 합쳐 대응하는 구조로 목표와 흐름이 명확해질 수 있다. 실제 재미/난이도는 미검증.
- 후속 검토 쟁점: 부위별 전투를 두 번 하므로 탐색 길이/반복감 조절, 동시 출격은 유지하되 5체 공격 예고/발동 간격 조율로 회피 공간 확보. 이는 제안이며 새 확정 규칙 아님.
- 후속 기술 검토: 조각 보유 전에도 5체 모두 접근 가능하도록 배치, 중복 획득 방지·저장/재접속 진행 보존, 기존 원정 호환 범위. 현 디자인으로 다리 포함 완전체 표현이 가능한지 자산 확인 필요. 아직 코드/자산 조사하지 않음.
- 미확정: 완전체 새 패턴, 방 배치 제약, 부위/페이즈별 체력·보상·전환 연출. 이번 제안을 구현 승인 또는 배포 지시로 취급하지 않는다.
- 상태: 11번 제안 기록 및 개념 검토 완료. 기존 기록만 지시 유지·시안/구현/테스트/푸시/배포 없음.

- 요청: 스킬 중 요정 계열의 등장 빈도를 아주 약간만 낮출 것.
- 미확정: 구체 감소 폭과 대상 스킬 목록·등장 경로는 미지정. 성능 하향이나 제거 요청으로 확대 해석하지 않는다.
- 상태: 기록 완료, 미구현. 현재 기록만 하라는 지시 유지·코드 조사/테스트/푸시/배포 없음.

## 14. 모르도 격파 후 붕괴 전환과 하강 환경 연출
- 요청: 모르도 클리어 후 화면이 크게 지진처럼 진동하고 파편이 떨어지는 연출.
- 서사 방향: 모르도가 마지막으로 절대 나가지 못하게 하라는 취지의 대사/연출. 정확한 대사는 미확정.
- 이후 하강: 바닥과 벽체 전반에 균열 및 불타는 텍스처를 추가하고, 가끔 파편이 떨어지는 연출.
- 연계: 9번 모르도 보스 연출/컷씬 제안과 연결해 후속 설계할 항목. 이번은 특히 격파 이후와 하강 환경의 변화에 관한 의견.
- 미확정: 진동 강도·길이·낙하 빈도·층별 적용 범위·효과 줄이기 동작·구체 텍스처. 파편 피해나 지형 파괴 같은 신규 전투 규칙 요청으로 확대 해석하지 않는다.
- 상태: 14번으로 기록 완료. 현재 기록만 하라는 지시 유지·시안/구현/테스트/푸시/배포 없음. 디자인 반영은 기존 시안 승인 규칙을 따른다.

## 15. 최종 탈출 5턴 그림자 보스 생존전 개편 검토안
- 체감: 최종 탈출까지 성장한 플레이어에게 기존 몬스터 소환이 위협되지 않는다.
- 시작 연출: 최종 탈출문 도착 시 바닥에 커다란 검은 육망성 소환진 표시.
- 진행: 총 5턴. 한 턴 시간이 되면 검정색 그림자/흑화 표현의 그림자 보스 1체씩 소환, 일반 하강 몬스터도 랜덤 2체씩 소환.
- 능력치: 그림자 보스 체력은 기존 보스의 70%. 다른 능력치 변경은 미지정.
- 개별 조건: 슬라임 분열은 1번만, 단장은 1페이즈, 모르도는 최종 페이즈 형태로 소환.
- 탈출 조건: 소환된 그림자 보스를 전부 처치할 필요 없음. 문이 열리면 버티다가 도망갈 수 있는 형태.
- 예비 평가(에이전트 의견, 미확정): 전멸전보다 생존/탈출 목표가 명확하며, 보스를 빨리 처치해 다음 턴 압박을 줄일지 회피하며 버틸지 선택이 생길 수 있다. 실제 위협과 재미는 미검증.
- 후속 검토 쟁점: 미처치 보스가 누적될 때 공격 예고 중첩/회피 공간, 검은 소환진·그림자와 어두운 바닥 사이 시인성, 개문/소환 남은 시간 안내. 기존 4번 시인성 의견도 함께 고려.
- 미확정: 턴 길이·첫 소환 시점·문 개방 시점, 보스 풀/순서/중복 여부·선정 방식, 일반 적 선정 범위, 그림자 보스 페이즈 고정의 동작 범위, 중단/저장 재개 규칙. 5턴의 보스가 특정 5종이라고 확정하지 않는다.
- 상태: 15번 제안 기록 및 개념 검토 완료. 현재 기록만 지시 유지·코드 조사/시안/구현/테스트/푸시/배포 없음. 구현 승인이나 배포 지시로 취급하지 않는다.
